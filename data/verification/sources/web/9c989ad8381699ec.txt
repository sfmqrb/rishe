 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From دانش ( dāniš  / dâneš ) +‎ ـکده ( -kada  / -kade ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /daː.ˈniʃ.ka.ˈda/ 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.nɪ́ʃ.kʰä.d̪á] 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.nɪ́ʃ.kʰä.d̪á] 
 ( Kabuli ) IPA ( key ) : [d̪ɑː.nɪ́ʃkʰä.d̪á] 

 ( Hazaragi ) IPA ( key ) : [d̪ɔː.níʃkʰä.d̪á] 

 ( Iran, formal ) IPA ( key ) : [d̪ɒː.néʃ.kʰʲæ.d̪é] 

 ( Tajik, formal ) IPA ( key ) : [d̪ɔ.níʃ.kʰä.d̪á]

 Noun
 [ edit ] 

 دانشکده • ( dāniškada / dâneškade ) ( plural دانشکده‌ها ( dāniškada-hā / dâneškade-hâ ) , Tajik spelling донишкада ) 

 college 

 faculty 
 Synonym: ( Dari ) فاکولْتَه ( fākōlta )

 [ edit ]
