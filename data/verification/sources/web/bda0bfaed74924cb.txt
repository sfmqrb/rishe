 Etymology
 [ edit ] 

 From the root  लुप् ( lup ) +‎ -त्र ( -tra ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /lɐu̯p.tɾɐ/ , [lɐu̯p̚.tɾɐ] 

 ( Classical Sanskrit ) IPA ( key ) : /l̪oːp.t̪ɾɐ/ , [l̪oːp̚.t̪ɾɐ] 

 Noun
 [ edit ] 

 लोप्त्र • ( loptra ) stem ,  n 

 stolen property ; loot ; booty
