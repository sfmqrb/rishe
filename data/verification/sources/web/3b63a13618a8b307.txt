 Ancient Greek
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kɛː.rós/ → /ciˈros/ → /ciˈros/ 

 ( 5 th BCE Attic ) IPA ( key ) : /kɛː.rós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ke̝ˈros/ 

 ( 4 th CE Koine ) IPA ( key ) : /ciˈros/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ciˈros/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ciˈros/ 

 Etymology 1
 [ edit ] 

 A foreign loan from a substrate language, cognate with Latin cēra and Albanian qiri , [ 1 ] and possibly also with Lithuanian korys , Latvian kāre . [ 2 ] 

 Noun
 [ edit ] 

 κηρός • ( kērós )  m ( genitive κηροῦ ) ; second declension 

 beeswax ; honeycomb 

 ( in the plural ) wax tapers 

 Declension
 [ edit ] 

 Second declension of ὁ κηρός ; τοῦ κηροῦ ( Attic )
