 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European *bʰol-yom , from Proto-Indo-European *bʰleh₃- ( “ leaf, blossom, flower ” ) . Cognates include Latin folium , Old Armenian բողբոջ ( bołboǰ ) , and English blossom . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pʰýl.lon/ → /ˈɸyl.lon/ → /ˈfi.lon/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pʰýl.lon/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈpʰyl.lon/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈɸyl.lon/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈfyl.lon/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈfi.lon/ 

 Noun
 [ edit ] 

 φῠ́λλον • ( phŭ́llon )  n ( genitive φῠ́λλου ) ; second declension 

 leaf 

 plant 

 ( in the plural ) foliage
