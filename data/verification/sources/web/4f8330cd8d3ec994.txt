 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian دَاسْتَان ( dāstān , “ tale, story ” ) .

 Noun
 [ edit ] 

 داستان • ( dastan, destan ) 

 tale , legend , myth , fable , any fictitious narrative told to excite wonder 
 Synonyms: اسطوره ( ustura ) , افسانه ( efsane ) , قصه ( kıssa ) , مثل ( masal ) 

 tale , chronicle , story , account , any narrative description of past events

 Alternative forms

 دستان ( dastān  / dastân ) 

 Etymology
 [ edit ] 

 Probably a clipping of Middle Persian [script needed] ( dātistān /⁠d'tst'n'⁠/ , “ law, process, court case ” ) , from Proto-Iranian *dāt-ya- ( “ of the law ” ) , from Proto-Iranian *daH- ( “ to place, put ” ) , from Proto-Indo-European *dʰeh₁- ( “ to do, place ” ) . [ 1 ] [ 2 ]

 [ edit ]

 ( Dari, formal ) IPA ( key ) : [d̪ɑːs.t̪ʰɑ́ːn]

 Noun
 [ edit ] 

 داستان • ( dāstān / dâstân ) ( plural داستان‌ها ( dāstān-hā / dâstân-hâ ) , Tajik spelling достон ) 

 tale , story 
 Synonym: قِصَّه ( qissa  / ġesse ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 694—695 : آمدیم اندر تمامی داستان / وز وفاداری جمع راستان‌ / کز پس این پیشوا برخاستند / بر مقامش نایبی می‌خواستند āmadēm andar tamāmī-yi dāstān / w-az wafādārī-yi jam'-i rāstān / k-az pas-i in pēšwā bar-xāstand / bar maqām-aš nā'īb-ē mē-xwāstand We come [now] to complete the tale and [speak] of the loyalty of the multitude of the righteous, who rose up after [the death of] this leader, demanding a vicar in his place.

 [ edit ]

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /d̪ɑːs.t̪ɑːn/ 

 ( poetic ) IPA ( key ) : /d̪ɑːs.t̪ɑ̃ː/ 

 Rhymes: -ɑːn , -ɑ̃ː 

 Noun
 [ edit ] 

 داسْتان • ( dāstān )  f ( Hindi spelling दास्तान ) 

 story , tale , narrative 
 Synonyms: قِصَّہ ( qissa ) , کَہانی ( kahānī )
