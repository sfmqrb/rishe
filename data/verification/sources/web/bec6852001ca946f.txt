 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( ʾwstwbʾl /⁠awestwār⁠/ ) , 𐫀𐫇𐫏𐫘𐫤𐫇𐫀𐫡 ( ʾwystwʾr ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔus.tu.ˈwaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʔʊs.t̪ʰʊ.wɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [ʔʊs.t̪ʰʊ.wɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔʊs.t̪ʰʊ.wɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔus.t̪ʰu.wɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [ʔos.t̪ʰo.vɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [ʔus.t̪ʰu.vɔ́ɾ] 

 Rhymes: -aːr 

 Readings

 Classical reading ? 

 ustuwār

 Dari reading ? 

 ustuwār

 Iranian reading ? 

 ostovâr

 Tajik reading ? 

 ustuvor

 Adjective
 [ edit ] 

 استوار • ( ustuwār / ostovâr ) ( Tajik spelling устувор ) 

 firm , stable , solid 

 reliable , consistent , steady 

 sound , healthy 

 steadfast , tenacious 

 secure , immovable 

 Descendants
 [ edit ] 

 → Urdu: استوار ( ustuvār ) 

 References
 [ edit ] 

 MacKenzie, D. N. ( 1971 ), “awestwār”, in A concise Pahlavi dictionary , London, New York, Toronto: Oxford University Press, page 14 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian استوار ( ustuwār , “ strong, firm ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ʊs.t̪ʊ.ʋɑːɾ/ , /ʊs.t̪ə.wɑːɾ/ 

 Rhymes: -ɑːɾ 

 Adjective
 [ edit ] 

 استوار • ( ustuvār or ustuwār ) ( comparative اُستُوار , Hindi spelling उस्तुवार ) 

 strong , powerful , mighty 

 durable , firm , solid , bold 

 inviolate , indissoluble 

 even , leveled 

 straight , consistent
