 Armenian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Armenian քով ( kʻov ) .

 Pronunciation
 [ edit ] 

 ( Eastern Armenian ) IPA ( key ) : /kʰov/ [kʰov] 

 ( Western Armenian ) IPA ( key ) : /kov/ [kʰov] 

 Postposition
 [ edit ] 

 քով • ( kʻov ) ( Western Armenian ) 

 close to , near , by 
 Synonym: մոտ ( mot ) 
 Գնաց, մօրը քով կանգնեցաւ։ Gnacʻ, mōrə kʻov kangnecʻaw. He/she went and stood by his/her mother. 

 Ես քու քովդ քնանալ պիտի չեմ ըլլար։ Es kʻu kʻovd kʻnanal piti čʻem əllar. I will not sleep next to you. 

 Middle Armenian
 [ edit ] 

 Etymology
 [ edit ] 

 Perhaps lexicalized from Old Armenian քով ( kʻov ) , the instrumental singular of քո ( kʻo , “ your, thy ” ) , with a sense development "by your" → "*near you" → "near".

 [ edit ]

 Noun
 [ edit ] 

 քով • ( kʻov ) 

 side , flank 
 1466 – 1469 , Amirdovlatʻ Amasiacʻi , Ogut bžškutʻean [The Benefits of Medicine] 80: [ 3 ] Եւ թէ ի ժիր ի վերայ կռնակին պառկի և ի վերայ քովուն չկարենայ պառկիլ՝ պեղծ նշան ե։ Ew tʻē i žir i veray kṙnakin paṙki ew i veray kʻovun čʻkarenay paṙkil, peġc nšan e.
