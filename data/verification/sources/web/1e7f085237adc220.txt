 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 τῦμος ( tûmos ) — Corcyraean 

 Etymology
 [ edit ] 

 From Proto-Indo-European *tum- ( “ to swell ” ) , which Beekes implicitly takes as a Mediterranean substrate root. [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /tým.bos/ → /ˈtym.bos/ → /ˈtim.bos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /tým.bos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈtym.bos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈtym.bos/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈtym.bos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈtim.bos/ 

 Noun
 [ edit ] 

 τῠ́μβος • ( tŭ́mbos )  m ( genitive τῠ́μβου ) ; second declension 

 funeral mound ; tomb ; grave 
 441 BCE , Sophocles, Antigone ‎ [1] , section 891: ὦ τύμβος , ὦ νυμφεῖον, ὦ κατασκαφὴς οἴκησις ἀείφρουρος ô túmbos , ô numpheîon, ô kataskaphḕs oíkēsis aeíphrouros ο tomb , o ⁠bridal chamber, o deep-dug home forever guarded 

 Declension
 [ edit ] 

 Second declension of ὁ τῠ́μβος ; τοῦ τῠ́μβου ( Attic )
