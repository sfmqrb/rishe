 Adjective
 [ edit ] 

 ستوه • ( sutōh / sotuh ) 

 ( archaic ) defeated , beaten 
 Synonym: شکست‌خورده ( šikast-xwarda  / šekast-xorde ) 

 ( archaic ) fatigued , exhausted 
 Synonyms: خسته ( xasta  / xaste ) , افگار ( afgār  / afgâr ) 

 overwhelmed , helpless 
 Synonyms: درمانده ( darmānda  / darmânde ) , عاجز ( ājiz  / âjez ) , ملول ( malūl  / malul ) , بیچاره ( bēčāra  / bičâre )
