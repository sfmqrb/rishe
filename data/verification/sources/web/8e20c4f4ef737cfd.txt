 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *h₂melǵ- [ 1 ] 

 to milk 

 milk 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *h₂melǵ- (23 c, 0 e) 

 *h₂mélǵ-ti ~ *h₂ml̥ǵ-énti ( athematic root present ) 

 *h₂molǵ-éye-ti ( iterative ) 
 Proto-Italic: *molgeō 
 Latin: mulgeō ( “ I milk ” ) 

 *h₂mélǵ-os ~ h₂mélǵ-es-os ( s-stem noun ) 
 Proto-Celtic: *melgos 
 Old Irish: melg 

 Unsorted formations 

 Proto-Balto-Slavic: 
 Latvian: malks ( “ sip, nip, swig ” ) 

 Lithuanian: malkas 

 Proto-Celtic: *mlixtus (< * h₂ml̥ǵtus )
 Old Irish: mlicht 
 Middle Irish: blicht 
 Irish: bleacht ( “ milk yield ” ) 

 Proto-Brythonic: bliθ 
 Welsh: blith ( “ milch ” ) 

 Proto-Germanic: *melkaz ( “ milky, milk-giving ” ) ( see there for further descendants )

 Proto-Germanic: *meluks ( “ milk ” ) ( with unexplained -u- ) ( see there for further descendants )

 Proto-Tocharian: 
 Tocharian A: malke ( “ milk ” ) , ( denominative ) mālk- ( “ to milk ” ) 

 Tocharian B: malkwer ( “ milk ” )
