 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 λᾰκᾰ́νη ( lăkắnē ) — Koine 

 Etymology
 [ edit ] 

 From λέκος ( lékos , “ dish; pot; pan ” ) +‎ -ᾰ́νη ( -ắnē , suffix for utensil names ) , alleged to be from Pre-Greek ; however, see λᾰ́γῡνος ( lắgūnos , “ flask ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /le.ká.nɛː/ → /leˈka.ni/ → /leˈka.ni/ 

 ( 5 th BCE Attic ) IPA ( key ) : /le.ká.nɛː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /leˈka.ne̝/ 

 ( 4 th CE Koine ) IPA ( key ) : /leˈka.ni/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /leˈka.ni/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /leˈka.ni/ 

 Noun
 [ edit ] 

 λεκᾰ́νη • ( lekắnē )  f ( genitive λεκᾰ́νης ) ; first declension 

 dish ; pot ; pan ; basin

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek λεκάνη ( lekánē ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /leˈka.ni/ 

 Noun
 [ edit ] 

 λεκάνη • ( lekáni )  f ( plural λεκάνες ) 

 any large bowl 

 washbasin , handbasin , sink 

 toilet bowl , toilet pan 

 ( anatomy ) pelvis 

 ( geography ) basin , catchment ( An area of water that drains into a river )
