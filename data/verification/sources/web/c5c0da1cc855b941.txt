 Noun
 [ edit ] 

 τετράων • ( tetráōn )  m ( genitive τετράωνος ) ; third declension 

 ( hapax legomenon ) grouse 

 Declension
 [ edit ] 

 Third declension of ὁ τετράων ; τοῦ τετράωνος ( Attic )
