 Etymology tree

 Persian پوپک

 Noun
 [ edit ] 

 پوپک • ( pupak ) ( plural پوپک‌ها ) 

 hoopoe 
 Synonyms: هدهد ( hodhod ) , شانه‌بسر ( šâne-besar ) , پوپو ( pupu )
