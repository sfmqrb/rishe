 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کاز ( kâz ) , کاژه ( kâža ) , کاشه ( kâša ) 

 Etymology
 [ edit ] 

 Borrowed from Sogdian [script needed] ( kʾzʾk , “ little house ” ) . Cognate with Khotanese [script needed] ( khāśā̮na- , “ abode, place ” ) , etc.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kaː.ˈza/ 

 ( Dari, formal ) IPA ( key ) : [kʰɑː.zä] 

 ( Dari, formal ) IPA ( key ) : [kʰɑː.zä] 
 ( Kabuli ) IPA ( key ) : [kʰɑː.zä] 

 ( Hazaragi ) IPA ( key ) : [kʰɔː.zä] 

 ( Iran, formal ) IPA ( key ) : [kʰɒː.ze] 

 ( Tajik, formal ) IPA ( key ) : [kʰɔ.zä] 

 Rhymes: -a 

 Readings

 Classical reading ? 

 kāza

 Dari reading ? 

 kāza

 Iranian reading ? 

 kâze

 Tajik reading ? 

 koza

 Noun
 [ edit ] 

 کازه • ( kāza / kâze ) ( Tajik spelling коза ) 

 ( archaic ) hut ; cottage
