 Arabic
 [ edit ] 

 Root 

 ع ر ف ( ʕ r f )

 Etymology
 [ edit ] 

 Verbal noun of عَرَّفَ ( ʕarrafa ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /taʕ.riːf/ 

 Rhymes: -iːf 

 Noun
 [ edit ] 

 تَعْرِيف • ( taʕrīf )  m ( plural تَعْرِيفَات ( taʕrīfāt ) or تَعَارِيف ( taʕārīf ) ) 

 verbal noun of عَرَّفَ ( ʕarrafa )   ( form II ) 

 definition 
 a. 1367 , Ibn Aqīl , “ الكلام وما يتألف منه ”, in شرح ابن عقيل على ألفية ابن مالك : وإنما قال المصنف «كلامنا» ليعلم أن التعريف إنما هو للكلام في اصطلاح النحويين، لا في اصطلاح اللغوين، وهو في اللغة: اسم لكل ما يُتَكَلَّمُ به، مفيدًا كان أو غير مفيد.
