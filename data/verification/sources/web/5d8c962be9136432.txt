 Alternative forms
 [ edit ] 

 آبروی ( âberuy ) 

 آب روی ( âb-e ruy ) 

 Etymology
 [ edit ] 

 Shortened form of آبروی ( âb-e-ruy ) , compound of آب ( âb ) +‎ روی ( ruy ) . Cognate with Northern Kurdish avrû and Central Kurdish ئاوڕوو ( awrrû )

 [ edit ]
