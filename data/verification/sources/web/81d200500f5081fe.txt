 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From هم ( ham , “ also, too, same ” ) +‎ شیر ( šīr  / šir , “ milk ” ) +‎ ـه ( -a  / -e , noun forming suffix ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ham.ʃiː.ˈra/ 

 ( Dari, formal ) IPA ( key ) : [häm.ʃiː.ɾá] 

 ( Dari, formal ) IPA ( key ) : [häm.ʃiː.ɾá] 
 ( Kabuli ) IPA ( key ) : [ʔäm.ʃiː.ɾá] 

 ( Hazaragi ) IPA ( key ) : [ʔäm.ʃi.ɾá] 

 ( Iran, formal ) IPA ( key ) : [hæm.ʃiː.ɹé] 

 ( Tajik, formal ) IPA ( key ) : [häm.ʃi.ɾá] 

 Rhymes: -a
