 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 ده ( “ village ” ) +‎ Arabic ات . Compare formation of باغات ( “ gardens ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /di.ˈhaːt/ 

 ( Dari, formal ) IPA ( key ) : [d̪e̞.ɦɑ́ːt̪] 

 ( Dari, formal ) IPA ( key ) : [d̪e̞.ɦɑ́ːt̪] 
 ( Kabuli ) IPA ( key ) : [d̪i.jɑ́ːt̪] 

 ( Hazaragi ) IPA ( key ) : [d̪i.jɔ́ːt̪] 

 ( Iran, formal ) IPA ( key ) : [d̪e.ɦɒ́ːt̪ʰ] 

 ( Tajik, formal ) IPA ( key ) : [d̪i.ɦɔ́t̪] 

 Rhymes: -aːt
