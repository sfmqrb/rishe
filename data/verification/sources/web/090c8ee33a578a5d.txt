 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic دَائِرَة ( dāʔira ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /daː.ji.ˈra/ 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.jɪ.ɾá] 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.jɪ.ɾá] 
 ( Kabuli ) IPA ( key ) : [d̪ɑː.jɪ.ɾá] 

 ( Hazaragi ) IPA ( key ) : [d̪ɔː.ji.ɾá] 

 ( Iran, formal ) IPA ( key ) : [d̪ɒː.je.ɹé] 

 ( Tajik, formal ) IPA ( key ) : [d̪ɔ.ji.ɾá] 

 Rhymes: -a

 Noun
 [ edit ] 

 دایره • ( dāyira / dâyere ) ( plural دوائر , Tajik spelling доира ) 

 circle 
 Synonym: پرهون ( parhun ) 
 دایره کشیدن ― dâyere kešidan ― to draw a circle 

 extent ; limit 

 dayereh , tambourine
