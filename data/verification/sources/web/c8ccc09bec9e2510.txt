 Pronunciation
 [ edit ] 

 IPA ( key ) : /lǎː.da.non/ → /ˈla.ða.non/ → /ˈla.ða.non/ 

 ( 5 th BCE Attic ) IPA ( key ) : /lǎː.da.non/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈla.da.non/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈla.ða.non/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈla.ða.non/

 Noun
 [ edit ] 

 λᾱ́δᾰνον • ( lā́dănon )  n ( genitive λᾱδάνου ) ; second declension 

 alternative form of λήδανον ( lḗdanon ) 

 Inflection
 [ edit ]
