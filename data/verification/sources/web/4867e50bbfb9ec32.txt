 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ζώνᾱ ( zṓnā ) — Doric 

 Etymology
 [ edit ] 

 Related to ζώννῡμι ( zṓnnūmi , “ to gird ” ) ; ultimately from Proto-Indo-European *yoh₃snéh₂ , from the root *yeh₃s- ( “ gird ” ) . Compare Old Church Slavonic (по)ꙗсъ ( (po)jasŭ ) , Sanskrit रास्ना ( rā́snā ) (< *yā́snā ). [ 1 ] [ 2 ]

 [ edit ]

 ( 5 th BCE Attic ) IPA ( key ) : /zdɔ̌ː.nɛː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈzo.ne̝/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈzo.ni/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈzo.ni/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈzo.ni/ 

 Noun
 [ edit ] 

 ζώνη • ( zṓnē )  f ( genitive ζώνης ) ; first declension ( Attic , Epic , Ionic , Koine ) 

 belt , sash

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek ζώνη ( zṓnē , “ belt; loins, waist ” ) .

 Noun
 [ edit ] 

 ζώνη • ( zóni )  f ( plural ζώνες ) 

 belt , sash , seat belt 
 Δέσε τη ζώνη σου, σε παρακαλώ ― Dése ti zóni sou, se parakaló ― Fasten your seat belt , please 
 μαύρη ζώνη στο καράτε. ― mávri zóni sto karáte. ― black belt in karate. 

 zone 

 band 
 ζώνη συχνοτήτων ― zóni sychnotíton ― frequency band
