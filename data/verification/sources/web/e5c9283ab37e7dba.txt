 Egyptian Arabic
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈfaʃʃ/ 

 Verb
 [ edit ] 

 فشّ • ( fašš ) I ( non-past يفشّ ( yifišš ) , verbal noun فششان ( fašašān ) , active participle فاشش ( fāšiš ) , passive participle مفشوش ( mafšūš ) ) 

 ( transitive ) to deflate ; to vent (one's anger )
 1994 , w:Yusuf al-Qa'id , chapter 1, in لبن العصفور ‎ [1] : أنا عاوزة، أفش غلي. I want to vent my anger.

 South Levantine Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From فيه ( fī , “ there is/are ” ) + ـش ( -š , “ not ” ) .

 Particle
 [ edit ] 

 فش • ( fišš ) 

 alternative form of في ش ( fīš ) 
 Synonyms: مافي ( mā-fi ) , ما في ش ( ma fīš ) , ما فش ( ma fišš ) 
 Antonym: فيه ( fī )
