 Etymology 1
 [ edit ] 

 From Middle Persian [script needed] ( hw'l /⁠xᵛār⁠/ ) , from Proto-Iranian *ātra- / *āθra- ( “ spirit, breath ” ) , of unknown further origin. [ 1 ] 

 Adjective
 [ edit ] 

 خوار • ( xvâr ) 

 ( archaic ) easy 

 mean , abject 

 Descendants
 [ edit ] 

 → Kazakh: қор ( qor ) 

 → Ottoman Turkish: خور ( hor ) , خوار ( har, hor ) Turkish: hor 
 → Armenian: խոռ ( xoṙ ) 

 → Turkmen: har , hor
