 Chagatai
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian پَیْکَر ( paykar ) .

 Noun
 [ edit ] 

 پیکر • ( päykär ) ( plural پیکرها ( päykär-hā ) ) 

 face , visage ( the front part of the head of a human or other animal, featuring the eyes, nose, and mouth, and the surrounding area ) 
 Synonyms: چهره ( čährä ) , یوز ( yüz ) , جبین ( jäbīn ) , روی ( rūy ) 
 1484 , Ali-Shir Nava'i , فرهاد و شیرین [ Farhad and Shirin ], page 266a , line 9: بولوب اول ایلا کیم شاه کواکب 
 فلک‌وش اژدها پیکرغا راکب bolup ol äylä kim şāh käwākib
fäläk-wäš äždähā päykärğa rākib (please add an English translation of this quotation) 

 face , appearance 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐭯𐭲𐭪𐭫 ( ptkl /⁠patkar, pahikar⁠/ , “ picture, image ” ) , from Old Persian 𐎱𐎫𐎡𐎣𐎼 ( p-t-i-k-r /⁠patikarā⁠/ ) , from Proto-Iranian *patikárah . Compare Armenian պատկեր ( patker , “ picture, likeness ” ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paj.ˈkar/ 

 ( Dari, formal ) IPA ( key ) : [pʰäj.kʰáɾ] 

 ( Dari, formal ) IPA ( key ) : [pʰäj.kʰáɾ] 
 ( Kabuli ) IPA ( key ) : [pʰäj.kʰáɾ] 

 ( Hazaragi ) IPA ( key ) : [pʰäj.kʰáɾ] 

 ( Iran, formal ) IPA ( key ) : [pʰej.kʰʲǽɹ] 

 ( Tajik, formal ) IPA ( key ) : [pʰäj.kʰáɾ] 

 Rhymes: -ar

 Noun
 [ edit ] 

 پیکر • ( paykar / peykar ) ( plural پیکرها ( paykar-hā / peykar-hâ ) , Tajik spelling пайкар ) 

 face , countenance 

 form , figure , mould , model 

 portrait , likeness 

 idol - temple 

 body
