 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 شبان ( šubān  / šobân, šabān  / šabân ) , شوبان ( šōbān  / šubân ) , چوبان ( čōbān  / čubân ) , چپان ( čapān  / čapân ) 

 چوپون ( čupun ) ( colloquial, Tehran ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐫢𐫇𐫁𐫀𐫗 ( šwbʾn /⁠šubān⁠/ ) , from Old Persian *fšupāna- , composed of [script needed] ( fšu- , “ sheep ” ) (compare Old Armenian շպետ ( špet ) , Sanskrit पशुपन् ( paśupan ) ) and [script needed] ( pāna- , “ protector ” ) . Cognate with Pashto شپون ( špun ) , Baluchi شپانک ( šipánk ) , Northern Kurdish şivan , Zazaki şıwane , Northern Luri شڤا ( şeva ) , Bactrian χοβανο ( khobano ) , Wakhi шәбын , шәпын .

 Urdu
 [ edit ] 

 A Pakistani چوپان ( caupān , "shepherd") herding his flock 
 Etymology
 [ edit ] 

 Borrowed from Classical Persian چوپَان ( čōpān ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /t͡ʃɔː.pɑːn/ , /t͡ʃoː.pɑːn/ , /t͡ʃuː.pɑːn/ 

 Noun
 [ edit ] 

 چوپان • ( caupān )  m ( Hindi spelling चूपान ) 

 shepherd ; cowherd ; herder 

 caretaker 

 Derived terms
 [ edit ] 

 چَوپانِی ( caupānī , “ herding; shepherding ” ) 

 چَوپان پیشَہ ( caupān-pēša , “ shepherd's profession ” ) 

 چَوپان گَری ( caupān-garī , “ herd-guarding ” )
