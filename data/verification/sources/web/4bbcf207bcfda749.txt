 Alternative forms
 [ edit ] 

 إِبْرَٰهِيم ( ʔibrāhīm ) , إبرهم ( ʔibrāhīm ) , إِبْرَٰهِـۧم ( ʔibrāhīm ) — classical spellings, used in the Qur'an 

 Etymology
 [ edit ] 

 Etymology tree

 Biblical Hebrew אַבְרָהָם ( ʔaḇrɔhɔm ) bor. 
 Aramaic אַבְרָהָם ( ʾaḇrāhām ) bor. 
 Arabic إبراهيم 

 Borrowed from Aramaic אַבְרָהָם ( ʾaḇrāhām ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔib.raː.hiːm/ 

 Rhymes: -iːm 

 Proper noun
 [ edit ] 

 إِبْرَاهِيم • ( ʔibrāhīm )  m 

 ( biblical , Islam ) Abraham 

 ( Islam ) The 14th sura (chapter) of the Qur'an .

 a male given name , Ibrahim
