 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Aramaic צפר with unattested -ān ending, compare زَعْتَر ( zaʕtar , “ wild thyme ” ) and juxtapose عُصْفُر ( ʕuṣfur ) for a native form from أَصْفَر ( ʔaṣfar , “ yellow ” )  of the root ص ف ر ( ṣ f r ) .

 A Middle Iranian borrowing is also maintained, which invites comparison with Persian جعفری ( ja'fari , “ parsley ” ) .

 [ edit ] 

 IPA ( key ) : /zaʕ.fa.raːn/

 Alternative forms
 [ edit ] 

 زغفران ( zağferan, zagferan ) , صفران ( safran ) 

 Etymology
 [ edit ] 

 From Arabic زَعْفَرَان ( zaʕfarān ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /zɑʔfɛˈɾɑn/ 

 Noun
 [ edit ] 

 زعفران • ( zaʼferan ) 

 saffron 
 1914 , Harun Reşit Kocacan, Muhtasar ilm-i kımya: Darülmuallimin ve Darülfünun ile mekâtib-i iʼdadiye sınıflarına mahsustur , İstanbul: Kitaphane-yi İslâm ve Askerı̂, page 254 : طبیعی بویالرك اك مهملری كوك بویا ، بقام اغاجی ، چیوید ، زغفران جهرى وقرمزدر . tabiʼi boyalarıñ eñ mühimleri kök boya, bakkam ağacı, ‍çivid, zağferan [,] cehri ve kırmızdır. The most important natural dyes are madder, bloodwood, indigo, saffron , yellowberry, and kermes.
