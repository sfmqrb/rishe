 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( kārd , “ knife ” ) , akin to Northern Kurdish kêr , Central Kurdish کێرد ( kêrd ) , from Proto-Indo-European *(s)ker- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈkaːrd/ 

 ( Dari, formal ) IPA ( key ) : [kʰɑːɹd̪]
