 Ottoman Turkish
 [ edit ] 

 پرچینلر 
 Alternative forms
 [ edit ] 

 برچین ( berçin ) 

 Etymology
 [ edit ] 

 Borrowed from Persian پرچین ( parčin , “ hook, nail; to put together ” ) .

 Noun
 [ edit ] 

 پرچین • ( perçin ) ( definite accusative پرچینی ( perçini ) , plural پرچینلر ( perçinler ) ) 

 rivet , a kind of permanent, mechanical fastener with a cylindrical shaft 
 Synonym: چیوی ( çivi ) 

 clenching , riveting , the act by which something is clenched or riveted

 Derived terms
 [ edit ] 

 پرچین ایتمك ( perçin etmek , “ to rivet, clench ” ) 
 پرچینلتمك ( perçinletmek , “ to make or let be clenched ” ) 
 پرچینلمك ( perçinlemek , “ to rivet, clench ” ) 
 پرچینلنمك ( perçinlenmek , “ to be clenched ” ) 
 پرچینلو ( perçinli , “ furnished with rivets ” ) 
 پول پرچین ( pul perçin , “ clenching-ring ” ) 

 Descendants
