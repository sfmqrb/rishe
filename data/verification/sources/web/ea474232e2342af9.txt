 Arabic
 [ edit ] 

 Verb
 [ edit ] 

 نهان ( form IV ) 

 نُهَانُ ( nuhānu ) /nu.haː.nu/ : first-person plural non-past passive indicative of أَهَانَ ( ʔahāna ) 

 نُهَانَ ( nuhāna ) /nu.haː.na/ : first-person plural non-past passive subjunctive of أَهَانَ ( ʔahāna ) 

 Chagatai
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian نِهَان ( nihān ) .

 Adjective
 [ edit ] 

 نهان • ( nhʾn / nihān /) ( comparative نهان‌راق ( /⁠nihānraq⁠/ ) ) 

 secret , hidden , concealed 
 Synonyms: پنهان ( pnhʾn /⁠pinhān⁠/ ) , مخفی ( mxfy /⁠mäxfī⁠/ ) , نهفت ( nhft /⁠nühüft⁠/ ) , یاشورون ( yʾšwrwn /⁠yašurun⁠/ ) , کیزلی ( kyzly /⁠kizli⁠/ ) , کیزلانچو ( kyzlʾnčw /⁠kizlänčü⁠/ ) , مستور ( mstwr /⁠mästūr⁠/ ) 
 نهان قالماق ― nhʾn qʾlmʾq / nihān qalmaq / ― to remain secret 
 نهان توتماق ― nhʾn twtmʾq / nihān tutmaq / ― to keep secret 
 نهان بولماق ― nhʾn bwlmʾq / nihān bolmaq / ― to become secret 
 نهان اولماق ― nhʾn ʾwlmʾq / nihān olmaq / ― to become secret

 نهان قیلماق ( nhʾn qylmʾq /⁠nihān qılmaq⁠/ , “ to hide, conceal ” ) 
 نهانخانه ( secret place /⁠nihānxānä⁠/ )

 نهان‌لیق ( nhʾn-lyq /⁠nihānlıq⁠/ , “ secrecy ” ) 
 نهان‌کار ( secret servant /⁠nihānkār⁠/ )

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian نِهَان ( nihān ) .

 Adjective
 [ edit ] 

 نهان • ( nihân ) 

 secret , hidden , concealed 
 Synonyms: كزلو ( gizlü ) , پنهان ( pinhân ) , مخفی ( mahfî ) , نهفت ( nühüft ) , مستور ( mestûr ) 
 نهان اولمق ― nihân olmak ― to be hidden 
 c. 1531 , Muhyî, translated by Okuyucu, Cihan and Yazar, Sadık, ترجمهٔ ابتدانامه [ tercüme-i ibtidānāme , Translation of İbtidâ-Nâme ], Ankara: Turkish Language Association, published 2018 , →ISBN , page 2a: اُولْكِه دَایِمْ جَلْوَه اَیْلَرْ آشِكَارَا وُ نِهَانْ 
 خَاصُ و عَامَهْ قُدْرَتْيلَه زِی كَرِیم مُسْتَعَانْ olki dâyim cilve eyler âşikârâ vü nihân 
hâs û ʿâma kudretile zî kerîm [û] müsteʿân (please add an English translation of this quotation) 

 Noun
 [ edit ] 

 نهان • ( nihân ) ( definite accusative نهانی ( nihanı ) , plural نهانلر ( nihânlar ) ) 

 secret 
 Synonym: سر ( sırr ) 

 Derived terms
 [ edit ] 

 نهان ایتمك ( nihân etmek , “ to hide ” ) 
 نهان ایلمك ( nihân eylemek , “ to hide ” ) 
 نهانجه ( nihânce , “ little secret ” ) 
 نهانخانه ( nihânhâne , “ hiding place; private, secret room ” ) 
 نهاندار ( nihândâr , “ secret-keeper ” ) 
 نهاندان ( nihândân , “ place where things can be hidden ” ) 
 نهانی ( nihânî , “ private, privacy ” )

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( nyhʾn' /⁠nihān⁠/ , “ concealment, secrecy ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ni.ˈhaːn/ , /na.ˈhaːn/ 

 ( Dari, formal ) IPA ( key ) : [ne̞.ɦɑːn] , [nä.ɦɑːn] 

 ( Dari, formal ) IPA ( key ) : [ne̞.ɦɑːn] , [nä.ɦɑːn] 
 ( Kabuli ) IPA ( key ) : [ni.jɑːn] , [nɑːɑːn] 

 ( Hazaragi ) IPA ( key ) : [ni.jɔːn] , [nɔːɔːn] 

 ( Iran, formal ) IPA ( key ) : [ne.ɦɒːn] , [næ.ɦɒːn] 

 ( Tajik, formal ) IPA ( key ) : [ni.ɦɔn] , [nä.ɦɔn] 

 Rhymes: -aːn

 Adjective
 [ edit ] 

 نهان • ( nahân or nehân ) 

 hidden , secret , arcane 
 Synonyms: پنهان ( penhân ) , مخفی ( maxfi ) , پوشیده ( pušide ) , نپیدا ( napeydâ ) 
 Antonyms: پیدا ( peydâ ) , آشکار ( âškâr )
