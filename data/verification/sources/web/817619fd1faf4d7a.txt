 Alternative forms
 [ edit ] 

 بزغ ( bazaġ ) , پزغ ( pazaġ ) , وزق ( vazaq ) , وزک ( vazak ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( wzγ /⁠wazaγ⁠/ , “ frog ” ) . Akin to Avestan 𐬬𐬀𐬰𐬀𐬖𐬁 ( vazaγā , “ lizard, frog ” ) , compare وزغه ( vazaġe , “ small lizard ” ) , and to Old Armenian Վազգէն ( Vazgēn ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /wa.ˈzaɣ/ 

 ( Dari, formal ) IPA ( key ) : [wä.záɣ] 

 ( Dari, formal ) IPA ( key ) : [wä.záɣ] 
 ( Kabuli ) IPA ( key ) : [wä.záɣ] 

 ( Hazaragi ) IPA ( key ) : [wä.záɣ] 

 ( Iran, formal ) IPA ( key ) : [væ.zǽɢ̥] 

 ( Tajik, formal ) IPA ( key ) : [vä.záʁ] 

 Rhymes: -aɣ
