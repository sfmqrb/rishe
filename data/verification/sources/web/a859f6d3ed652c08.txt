 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *h₂wer- [ 1 ] [ 2 ] [ 3 ] 

 to lift , to raise 

 to cover , to enclose , to bind 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *h₂wer- (37 c, 0 e) 

 *h₂wér-ti ( athematic root present ) 
 Proto-Albanian: *werti ( “ to hang, suspend ” ) 
 Albanian: vjerr ( “ to hang, suspend ” ) 

 *h₂wér-ye-ti ( ye-present ) 
 Proto-Hellenic: *awéřřō ( “ to lift, raise ” ) 
 Ancient Greek: ἀείρω ( aeírō , “ to lift, raise ” ) ( see there for further descendants )

 Proto-Italic: *-weriō ( “ to open ” ) 
 Latin: aperiō ( “ to open ” ) , operiō ( “ to cover ” ) ( see there for further descendants )

 *h₂wr̥-né-ti ~ *h₂wr̥-n-énti ( né-present ) 
 Proto-Indo-Iranian: *wr̥náwti ( “ to cover, ward off ” ) 
 Proto-Indo-Aryan: *wr̥náwti ( “ to cover, ward off ” ) 
 Sanskrit: वृणोति ( vṛṇóti , “ to cover, ward off ” ) 

 *h₂wor ( noun ) 
 Proto-Hellenic: *awor ( “ sword, belt ” ) 
 Ancient Greek: ἄορ ( áor , “ sword, belt ” )
