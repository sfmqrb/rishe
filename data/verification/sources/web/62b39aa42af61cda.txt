 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 دوختن ( dōxtan  / duxtan ) ( literary , archaic ) 

 دوشتن ( dōštan  / duštan ) ( colloquial , Kerman, Rochan ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( dwšytn' /⁠dōšīdan⁠/ , “ to milk ” ) , [ 1 ] from Old Persian *dauxšatī , from Proto-Iranian *dáwxšati ( “ to milk ” ) (compare Baluchi دوشگ ( dōšag "milk" ) , Northern Kurdish dotin / doşîn ), ultimately from a suffixed form of Proto-Indo-European *dewk- (compare Latin duco ).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /doː.ʃiː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [d̪oː.ʃiː.d̪än] 

 ( Dari, formal ) IPA ( key ) : [d̪oː.ʃiː.d̪än] 
 ( Kabuli ) IPA ( key ) : [d̪oː.ʃiː.d̪än] 

 ( Hazaragi ) IPA ( key ) : [d̪u.ʃi.d̪än] 

 ( Iran, formal ) IPA ( key ) : [d̪uː.ʃiː.d̪æn] 

 ( Tajik, formal ) IPA ( key ) : [d̪ɵ.ʃi.d̪än] 

 Rhymes: -an

 Verb

 دوشیدن • ( dōšīdan  / dušidan ) ( present stem دوش ( dōš  / duš ) , Tajik spelling дӯшидан ) 

 to milk
