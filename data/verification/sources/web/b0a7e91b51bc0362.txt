 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From در ( dar ) + بار ( bâr ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /dar.ˈbaːr/ 

 ( Dari, formal ) IPA ( key ) : [d̪äɾ.bɑːɾ] 

 ( Dari, formal ) IPA ( key ) : [d̪äɾ.bɑːɾ] 
 ( Kabuli ) IPA ( key ) : [d̪äɾ.bɑːɾ] 

 ( Hazaragi ) IPA ( key ) : [d̪äɾ.bɔːɾ] 

 ( Iran, formal ) IPA ( key ) : [d̪æɹ.bɒːɹ] 

 ( Tajik, formal ) IPA ( key ) : [d̪äɾ.bɔɾ] 

 Rhymes: -aːr 

 Readings

 Tajik reading ?

 Noun
 [ edit ] 

 دربار • ( darbār / darbâr ) ( Tajik spelling дарбор ) 

 royal court , palace 

 royal audience , court gathering , durbar 

 ( obsolete ) home
