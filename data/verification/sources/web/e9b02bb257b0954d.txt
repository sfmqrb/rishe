 Arabic
 [ edit ] 

 Etymology 1
 [ edit ] 

 From ص ف ر ( ṣ f r , “ void ” ) , supposedly because pagan Arabs looted during this month and left the houses empty.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sˤa.far/ 

 Proper noun
 [ edit ] 

 صَفَر • ( ṣafar )  m ( plural أَصْفَار ( ʔaṣfār ) ) 

 ( Islam ) Safar ( the second month of the Islamic calendar )

 Verb

 to be empty , to be devoid , to be vacant
