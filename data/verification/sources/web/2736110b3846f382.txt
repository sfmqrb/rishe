 Latin
 [ edit ] 

 Alternative forms
 [ edit ] 

 lepor 

 Etymology
 [ edit ] 

 From *lep- +‎ -ōs ( suffix forming abstract nouns ) , related to the suffixed adjective lepidus ( “ pleasant, charming ” ) . The origin of the root is unknown. 

 Based purely on form, it has been compared with Ancient Greek λεπτός ( leptós ) and λέπω ( lépō , “ to peel ” ) , but because of the different meanings, this connection is uncertain and rejected by Ernout and Meillet 1985. [ 1 ] De Vaan 2008 is skeptical, but suggests a change from "what has been peeled" to "refinement" is thinkable. [ 2 ] 

 Machek considers a connection with Proto-Slavic *lěpъ ( “ beautiful ” ) . [ 3 ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈɫɛ.poːs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈlɛː.pos] 

 Noun
 [ edit ] 

 lepōs   m ( genitive lepōris ) ; third declension 

 pleasantness , charm , attractiveness , agreeableness 

 politeness , grace 

 pleasantry , wit , humor 

 ( term of endearment ) delight
