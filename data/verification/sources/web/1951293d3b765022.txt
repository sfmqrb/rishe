 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 κιννάβαρις ( kinnábaris ) 

 τιγγάβαρι ( tingábari ) , τυγγάβαρι ( tungábari ) , τιγγάβαρυ ( tingábaru ) , τιαγγάβαρι ( tiangábari ) — Attic 

 Etymology
 [ edit ] 

 Probably an eastern loanword according to Beekes. [ 1 ] Compare Arabic زِنْجَفْر ( zinjafr ) , related to Persian شنگرف ( šangarf ) from Old Persian 𐎿𐎡𐎣𐎲𐎽𐎢𐏁 ( s-i-k-b-ru-u-š /⁠si n kabruš⁠/ , “ carnelian ” ) , of unknown origin.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kin.ná.ba.ri/ → /cinˈna.βa.ri/ → /ciˈna.va.ri/ 

 ( 5 th BCE Attic ) IPA ( key ) : /kin.ná.ba.ri/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /kinˈna.ba.ri/ 

 ( 4 th CE Koine ) IPA ( key ) : /cinˈna.βa.ri/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /cinˈna.va.ri/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ciˈna.va.ri/ 

 Noun
 [ edit ] 

 κιννάβᾰρῐ • ( kinnábărĭ )  n ( genitive κιννᾰβάρεως ) ; third declension 

 cinnabar , bisulphuret of mercury 
 Synonym: ψάδδα ( psádda ) 

 vermilion 

 Inflection
 [ edit ] 

 Third declension of τὸ κιννᾰ́βᾰρῐ ; τοῦ κιννᾰβᾰ́ρεως ( Attic )
