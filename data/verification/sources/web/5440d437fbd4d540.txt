 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( plcʾnk' /⁠frazānag⁠/ , “ wise, intelligent ” ) , which is cognate with Parthian 𐫜𐫡𐫉𐫀𐫗𐫃 ( frzʾng /⁠frazānag⁠/ , “ wise, clever ” ) . Equivalent to فرزان ( farzân ) +‎ ـه ( e ) .
Perhaps related to Sanskrit प्रज्ञान।Prajnaana (knowledgeful)

 Adjective
 [ edit ] 

 فرزانه • ( farzâne ) ( comparative فرزانه‌تَر , superlative فرزانه‌تَرین ) 

 wise , learned , sapient 

 Noun
 [ edit ] 

 فرزانه • ( farzâne ) ( plural فرزانه‌ها , or فرزانگان ( farzânegân ) ) 

 wise person

 Proper noun
 [ edit ] 

 فرزانه • ( farzâne ) 

 a female given name , Farzaneh 

 a surname
