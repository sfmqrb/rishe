 Punjabi
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Apabhramsa वेला ( velā ) , from Prakrit 𑀯𑁂𑀮𑀸 ( velā ) , from Sanskrit वेला॑ ( vélā ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /ʋeː.läː/ , [ʋeː.ɭäː] 

 Rhymes: -äː 

 Homophone : ویہلا ( vehlā ) 

 Noun
 [ edit ] 

 ویلا • ( velā )  m ( Gurmukhi spelling ਵੇਲ਼ਾ or ਵੇਲਾ ) [ 2 ] [ 3 ] 

 time 
 Synonyms: وَقَت ( vaqat ) , سَماں ( samāṉ ) 
 ایس ویلے ہی آ! es veḷe hī ā! Come right this instance ! 

 time ; hour 

 season 

 difficulty 

 life 

 opportunity ; occasion 

 duration
