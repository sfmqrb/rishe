 Wikipedia ar 

 Etymology
 [ edit ] 

 From Middle Iranian ; see بنفشه ( banafše ) and compare Middle Persian wnpšk' ( wanafšag , “ violet ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ba.naf.sad͡ʒ/ 

 Noun
 [ edit ] 

 بَنَفْسَج • ( banafsaj )  m ( collective , singulative بَنَفْسَجَة   f ( banafsaja ) ) 

 violet
