 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 زمی ( zami ) ( archaic, dialectal ) 

 Etymology
 [ edit ] 

 From earlier زمی ( zamī ) , from Middle Persian zmyk' ( zamīg , “ earth ” ) , from Proto-Iranian *jā́h , from Proto-Indo-Iranian *ȷ́ʰžʰā́s , ultimately from Proto-Indo-European *dʰéǵʰōm .

 Indo-Iranian cognates include: Northern Kurdish zevî , Northern Luri زمی ( zemi ) , Avestan 𐬰𐬃 ( zā̊ ) , Sanskrit क्ष ( kṣa )

 Etymology
 [ edit ] 

 Borrowed from Classical Persian زَمِین ( zamīn ) . First attested in c. 1564 as Middle Hindi زمین ( zmyn /⁠zamīn⁠/ ) . [ 1 ] Compare Punjabi زمین ( zamīn ) , Sindhi زَمِينُ ( zamīnu ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /zə.miːn/ 

 Rhymes: -iːn 

 Hyphenation: زَ‧مِین 

 Noun
 [ edit ] 

 زَمِین • ( zamīn )  f ( Hindi spelling ज़मीन ) 

 land , plot , estate ( area ) 

 soil 
 Synonyms: مِٹّی ( miṭṭī ) , خاک ( xāk ) 

 the earth , world ( as opposed to the sky , heaven ) 
 Synonyms: دُنْیَا ( dunyā ) , دَھرْتِی ( dhartī ) 

 surface , ground 
 Synonym: فَرْش ( farś ) 

 region , area 
 Synonyms: خِطَّا ( xittā ) , اَرْض ( arz ) , عِلَاقَہ ( 'ilāqa ) 

 country , land , homeland 
 Synonyms: وَطَن ( vatan ) , دیس ( des ) , سَرْزَمِین ( sarzamīn )
