 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( plcyn' /⁠frazēn⁠/ , “ guard, (chess) queen ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /far.ˈziːn/ 

 ( Dari, formal ) IPA ( key ) : [fäɾ.zíːn] 

 ( Dari, formal ) IPA ( key ) : [fäɾ.zíːn] 
 ( Kabuli ) IPA ( key ) : [fäɾ.zíːn] 

 ( Hazaragi ) IPA ( key ) : [fäɾ.zín] 

 ( Iran, formal ) IPA ( key ) : [fæɹ.zíːn] 

 ( Tajik, formal ) IPA ( key ) : [fäɾ.zín] 

 Rhymes: -iːn

 Noun
 [ edit ] 

 فرزین • ( farzīn / farzin ) ( Tajik spelling фарзин ) 

 ( archaic , chess ) queen , fers 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume III, verse 535: از سفر بیدق شود فرزین راد
وز سفر یابید یوسف صد مراد az safar baydaq šawad farzīn -i rād
waz safar yābīd yūsuf sad murād Through travel the pawn becomes a noble queen ,
and through travel Joseph gained a hundred objects of desire.

 Urdu
 [ edit ] 

 Alternative forms
 [ edit ] 

 فَرْزِیں ( farzī̃ ) , فَرْزِی ( farzī ) 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian فَرْزِین ( farzīn ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /fəɾ.ziːn/ 

 Rhymes: -iːn 

 Adjective
 [ edit ] 

 فَرْزِین • ( farzīn ) ( Hindi spelling फ़र्ज़ीन ) 

 wise , intelligent , sagacious 
 Synonyms: دَانَا ( dānā ) , عَاقِل ( 'āqil ) 

 Noun
 [ edit ] 

 فَرْزِین • ( farzīn )  m ( Hindi spelling फ़र्ज़ीन ) 

 ( chess ) fers or queen 
 Synonym: وَزِیر ( vazīr )
