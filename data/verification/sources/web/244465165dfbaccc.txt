 See also: سيما , سیما , and شيماء 

 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 سِيمَى ( sīmā ) , سِيمًى ( sīman ) , سِيمَة ( sīma ) , سِيمِيَاء ( sīmiyāʔ ) , سِيمَا ( sīmā ) 

 Etymology
 [ edit ] 

 Borrowed from Aramaic סִימָא ( sīmā ) / סִימָנָא ( sīmānā ) , from Ancient Greek σῆμα ( sêma ) , σημεῖον ( sēmeîon ) . Compare Arabic شِيم ( šīm ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /siː.maːʔ/ 

 Noun
 [ edit ] 

 سِيمَاء • ( sīmāʔ )  f ( plural سِيَم ( siyam ) ) 

 sign , mark , trait 

 look , appearance , expression 
 609–632 CE , Qur'an , 48:29 : سِيمَاهُمْ فِي وُجُوهِهِمْ مِنْ أَثَرِ السُّجُودِ sīmāhum fī wujūhihim min ʔaṯari s-sujūdi The mark of them is on their foreheads from the traces of prostration.
