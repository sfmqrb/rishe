 Kashmiri
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Sanskrit 𑆄𑆰𑆳𑆞 ( āṣāḍha ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [haːr] 

 Proper noun
 [ edit ] 

 हार • ( hār )  m ( Perso-Arabic ہار ) 

 Fourth month of Kashmiri calendar corresponding to June - July of the Gregorian calendar .

 See also
 [ edit ] 

 Previous month : ज़ेठ ( zēṭh ) 

 Next month : श्रावुन ( śrٛāvun )
