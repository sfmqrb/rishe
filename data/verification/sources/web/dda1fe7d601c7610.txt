 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( dwtkmʾn /⁠dūtakmān, dūdagmān⁠/ ) . By surface analysis , دود ( dud , “ smoke ” ) +‎ ـمان ( -mân ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /duːd.ˈmaːn/ 

 ( Dari, formal ) IPA ( key ) : [d̪uːd̪.mɑ́ːn] 

 ( Dari, formal ) IPA ( key ) : [d̪uːd̪.mɑ́ːn] 
 ( Kabuli ) IPA ( key ) : [d̪uːd̪.mɑ́ːn] 

 ( Hazaragi ) IPA ( key ) : [d̪ud̪.mɔ́ːn] 

 ( Iran, formal ) IPA ( key ) : [d̪uːd̪.mɒ́ːn] 

 ( Tajik, formal ) IPA ( key ) : [d̪ud̪.mɔ́n] 

 Rhymes: -aːn

 Noun
 [ edit ] 

 دودمان • ( dūdmān / dudmân ) ( plural دودمان‌ها ( dūdmān-hā / dudmân-hâ ) , Tajik spelling дудмон ) 

 dynasty , lineage , house 
 Synonym: سلسله ( selsele ) 
 دودمان پهلوی ― dudmân -e pahlavi ― Pahlavi dynasty 
 دودمان سونگ ― dudmân -e sung ― Song dynasty 
 1628—1629 , Iskandar Beg Munshi , عالم‌آرای عباسی [ Tarikh-e Alam-ara-ye Abbasi ]: به توره و آئین مقرر صوفیان دودمان صفویه بر تخت سلطنت و قالیچه ارشاد که میراث آباء و اجداد عظام جنت مقام است متمکن گردانیده شرف پای بوس دریافتند. be ture va â'yen-e moqarrar-e sufiyân-e dudmân -e safaviyye bar taxt-e saltanat va qâliče-ye eršâd ke mirâs-e âbâ' va ajdâd-e 'ezâm-e jannat-maqâm ast motammaken gardânide šaraf-e pây-bus dar-yâftand. In accordance with the established custom and practice of the Sufis of the Safavid house , they placed him on the throne of the sultanate, and they laid out the prayer rug of spiritual guidance, an heirloom from his great, heavenly-ranked ancestors, and were honored with kissing his feet. (from the Roger M. Savory translation)

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 From Classical Persian دُودْمَان ( dūdmān , “ dynasty; lineage ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /d̪uːd̪.mɑːn/ 

 Noun
 [ edit ] 

 دُودْمان • ( dūdmān )  m ( Hindi spelling दूदमान ) 

 dynasty ; family , house 

 tribe ; clan 

 lineage , bloodline ; ancestry , genealogy 

 race ; birth ; stock 

 ( figuratively ) fragrance , scent 

 Usage notes
 [ edit ] 

 The term refers especially to direct descent , hence its broad meaning of dynasty , family , and clan , all of which pertain to common descent and lineage .

 Derived terms
 [ edit ]

 والا دُودْمَان ( vālā dūdmān , “ (of) noble lineage ” ) 

 دُودْمانِ عِلْم ( dūdmān-i 'ilm , “ learned family ” )
