 Persian
 [ edit ] 

 Persian Wikipedia has an article on: ترور 

 Wikipedia fa 

 Etymology
 [ edit ] 

 Pseudo-Gallicism , derived from terreur , or pseudo-anglicism derived from terror .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰe.ɹóɹ] 

 Readings

 Iranian reading ? 

 teror

 Noun
 [ edit ] 

 ترور • ( teror ) 

 assassination 
 ترور هدفمند ― teror -e hadafmand ― targeted assassination 

 Usage notes
 [ edit ] 

 Not to be confused with تروریسم ( terorism , “ terrorism ” ) .

 Derived terms
 [ edit ] 

 ترور شدن ( teror šodan , “ to be assassinated ” ) 
 ترور کردن ( teror kardan , “ to assassinate ” )
