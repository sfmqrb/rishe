 Etymology
 [ edit ] 

 From Parthian 𐫍𐫇𐫝𐫏𐫍𐫡 ( hwcyhr /⁠hužihr⁠⁠/ ) . Doublet of خجیر ( xujīr  / xojir ) .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [hʊ.ʒiːɾ]

 Proper noun
 [ edit ] 

 هژیر • ( hužīr  / hožir ) ( Tajik spelling Ҳужир ) 

 ( Iranian mythology ) Hojir 

 a male given name , Hojir , Hozhir , Hajir , and Hazhir , from Parthian or the Iranian epic Shahnameh
