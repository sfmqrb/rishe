 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 چابوک ( čâbuk ) , چاپک ( čâpok ) , چاپوک ( čâpuk ) 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( cʾp̄wk' /⁠čābuk⁠/ , “ agile, nimble; excellent ” ) , Northern Luri چںڤوک ( çəvok ) , suffixed from an unattested root borrowed as Old Armenian ճեպ ( čep , “ haste ” ) . Akin to Old Armenian ճապուկ ( čapuk ) , Old Georgian ჭაპუკი ( č̣aṗuḳi ) , ჭაბუკი ( č̣abuḳi ) , Middle Iranian borrowings.
