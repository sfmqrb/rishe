 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Hellenic *gonwía , from *gónu ( “ knee ” , whence γόνυ ( gónu ) ) , ultimately from Proto-Indo-European *ǵónu ( “ id ” ) . The long ω ( ō ) is from the regular Doric development of an unattested *γονϝ-ία ( *gonw-ía ) , as the paradigm of *ǵónu shows no lengthened grade (thus precluding a derivation from such an ablaut), while most mathematicians in Greek antiquity (who were most likely responsible for the word's formation) were Pythagorean (and thus wrote in Doric). [ 1 ] Despite superficial and coincidental similarities, unrelated to Sanskrit कोण ( koṇa , “ corner, angle ” ) .

 Noun
 [ edit ] 

 γωνῐ́ᾱ • ( gōnĭ́ā )  f ( genitive γωνῐ́ᾱς ) ; first declension 

 ( geometry ) corner ; angle 

 joiner 's square 

 cornerstone
