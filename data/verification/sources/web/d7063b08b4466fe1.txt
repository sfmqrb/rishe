 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Related to چلیدن ( čalidan , “ to walk proudly, saunter ” ) , ultimately from Proto-Indo-European *kʷel- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /t͡ʃaː.ˈlaːk/ 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰɑː.lɑ́ːk] 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰɑː.lɑ́ːk] 
 ( Kabuli ) IPA ( key ) : [t͡ʃʰɑː.lɑ́ːk] 

 ( Hazaragi ) IPA ( key ) : [t͡ʃʰɔː.lɔ́ːk] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰɒː.lɒ́ːkʰʲ]

 Adjective
 [ edit ] 

 چالاک • ( čâlâk ) ( comparative چالاک‌تَر , superlative چالاک‌تَرین ) 

 nimble ; quick 
 Synonyms: چست ( čost ) , جلد ( jald ) , چابک ( čâbok ) 
 c. 1260 , Saʿdī , “Ghazal 70”, in دیوان سعدی [ The Divān of Saʿdī ]‎ [1] : ای که از سرو روان قد تو چالاکترست
دل به روی تو ز روی تو طربناکترست ay ki az sarw-i rawān qadd-e tu čālāktar ast
dil ba rōy-i tu zi rōy-i tu tarabnāktar ast O you whose stature is nimbler than the swaying cypress,
Thanks to your face, my heart has more delight than [even] your face. (Classical Persian transliteration) 

 clever ; smart 
 Synonym: زرنگ ( zerang )

 Noun
 [ edit ] 

 چالاک • ( čâlâk ) 

 ( Dari ) cunning person ; quick wit ; trickster 

 ( obsolete or Dari ) thief ; scammer 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian چالاک ( cālāk ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /t͡ʃɑː.lɑːk/ 

 Adjective
 [ edit ] 

 چالاک • ( cālāk ) ( Hindi spelling चालाक ) 

 quick ; speedy 

 watchful ; vigilant 

 cunning ; sly 

 Noun
 [ edit ] 

 چالاک • ( cālāk )  m or f ( Hindi spelling चालाक ) 

 a sly or cunning individual
