 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-New Indo-Aryan *बाब्ब ( bābba ) + Middle Indo-Aryan -𑀉𑀓- ( -uka- ) , imitative of baby talk.

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /bɑː.buː/ , [bäː.buː] 

 Rhymes: -uː 

 Noun
 [ edit ] 

 बाबू • ( bābū )  m ( Urdu spelling بابو ) 

 papa , father 

 clerk 
 सरकारी बाबू ― sarkārī bābū ― governmental clerk 

 ( polite , to elders ) sir , mister 

 Term of address for a little boy or one's son.
