 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Old Persian *frasanhvah .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pa.ra.sáŋ.ɡɛːs/ → /pa.raˈsaɲ.ɟis/ → /pa.raˈsaɲ.ɟis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pa.ra.sáŋ.ɡɛːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /pa.raˈsaŋ.ɡe̝s/ 

 ( 4 th CE Koine ) IPA ( key ) : /pa.raˈsaɲ.ɟis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /pa.raˈsaɲ.ɟis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /pa.raˈsaɲ.ɟis/ 

 Noun
 [ edit ] 

 πᾰρᾰσάγγης • ( părăsángēs )  m ( genitive πᾰρᾰσάγγου ) ; first declension 

 parasang : a Persian unit of length equal to 4 Roman miles

 Declension
 [ edit ]
