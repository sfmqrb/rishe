 Persian
 [ edit ] 

 Persian Wikipedia has an article on: نوید 

 Wikipedia fa 

 Etymology
 [ edit ] 

 Inherited from Middle Persian nwyk' ( *niwē ) , from Proto-Iranian *wayd- . Compare Manichaean Parthian nwydg ( niwēdag , “ good news ” ) . Related to Parthian nwyst ( niwist , “ invited ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /na.ˈwiːd/ , /nu.ˈweːd/ 

 ( Dari, formal ) IPA ( key ) : [nä.wiːd̪] 

 ( Dari, formal ) IPA ( key ) : [nä.wiːd̪] 
 ( Kabuli ) IPA ( key ) : [nä.wiːd̪] 

 ( Hazaragi ) IPA ( key ) : [nä.wid̪̥] 

 ( Iran, formal ) IPA ( key ) : [næ.viːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [nä.vid̪] 

 Rhymes: -iːd , -eːd

 Noun
 [ edit ] 

 نوید • ( nawīd, nuwēd / navid ) ( Tajik spelling навид ) 

 ( archaic ) invitation 

 annunciation 

 good news 

 Synonyms
 [ edit ] 

 مژده ( mužda  / možde ) 

 Proper noun
 [ edit ] 

 نوید • ( nawīd  / navid or nuwēd  / - ) ( Tajik spelling Навид ) 

 a male given name , Navid , Nawid , Naveed , and Naweed 

 References
 [ edit ] 

 MacKenzie, D. N. ( 1971 ), “niwē”, in A concise Pahlavi dictionary , London, New York, Toronto: Oxford University Press 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian نوید ( nawēd, nuwēd ) , from Middle Persian nwyk' ( *niwē ) , from Proto-Iranian *wayd- . Compare Manichaean Parthian nwydg ( niwēdag , “ good news ” ) . Related to Parthian nwyst ( niwist , “ invited ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /nə.ʋiːd̪/ , /nə.ʋeːd̪/ 

 Noun
 [ edit ] 

 نَوِید or نَوید • ( navīd or naved )  m or f ( Hindi spelling नवीद ) 

 good news 

 wedding invitation 

 Proper noun
 [ edit ] 

 نَوِید or نَوید • ( navīd or naved )  m ( Hindi spelling नवीद ) 

 a male given name , Navid , Naveed , and Naved , from Persian
