 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Italic *kal(V)wos . Cognate with Sanskrit कुल्व ( kulvá , “ bald ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈkaɫ.wʊs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈkal.vus] 

 Adjective
 [ edit ] 

 calvus ( feminine calva , neuter calvum ) ; first / second-declension adjective 

 hairless , bald
