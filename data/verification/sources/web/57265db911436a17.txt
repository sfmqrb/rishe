 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 Possibly related to Proto-Indo-European *reu- . [ 1 ] Compare the classical form رت ( rot ) with the same meaning.

 Adjective
 [ edit ] 

 Dari

 لخت 

 Iranian Persian

 Tajik

 лухт 

 لخت • ( loxt ) 

 naked , nude 
 Synonyms: برهنه ( berahne ) , عریان ( oryân ) 

 Etymology 2
 [ edit ] 

 From لخشیدن ( laxšidan , “ to slide ” ) .

 Adjective
 [ edit ] 

 لخت • ( laxt ) 

 ( Iran , of hair ) sleek 

 Etymology 3
 [ edit ] 

 An imitative element borrowed from dialects. [ 2 ]

 [ edit ]

 لخت

 Etymology 4
