 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پاداشن ( pādāšn  / pâdâšn ) , پاداشت ( pādāšt  / pâdâšt ) , پادش ( pādaš  / pâdaš ) , باداش ( bādāš  / bâdâš ) , باداشن ( bādāšn  / bâdâšn ) , پای‌داش ( pāy-dāš  / pây-dâš ) 

 Etymology
 [ edit ] 

 From Middle Persian pʾtdʾšn' ( pādāšn , “ reward, retribution ” ) . Equivalent to پادـ ( pād-  / pâd- , “ counter-, re- ” ) +‎ دهش ( dahiš  / daheš , “ giving ” ) .

 Noun
 [ edit ] 

 پاداش • ( pādāš / pâdâš ) ( plural پاداش‌ها ( pādāš-hā / pâdâš-hâ ) , Tajik spelling подош ) 

 reward 
 خدایش پاداشن نیک دهاد! xodâyaš pâdâšn -e nik dehâd! May God grant him a good reward ! 

 remuneration 

 compensation 

 retribution
