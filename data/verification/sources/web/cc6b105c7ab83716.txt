 Persian Wikipedia has an article on: زیبا 

 Wikipedia fa 

 Etymology
 [ edit ] 

 From زیب ( zib ) +‎ ـا ( -â ) . The adjective form of the verb زیفتن ( ziftan , “ to deserve, to shine, to have beauty and form. ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /zeː.ˈbaː/ 

 ( Dari, formal ) IPA ( key ) : [zeː.bɑː] 

 ( Dari, formal ) IPA ( key ) : [zeː.bɑː] 
 ( Kabuli ) IPA ( key ) : [zeː.bɑː] 

 ( Hazaragi ) IPA ( key ) : [zeː.bɔː] 

 ( Iran, formal ) IPA ( key ) : [ziː.bɒː] 

 ( Tajik, formal ) IPA ( key ) : [ze.bɔ]

 زیبا • ( zibâ ) ( comparative زیباتَر , superlative زیباتَرین ) 

 beautiful 
 این دُخْتَرِ زیبا رو می‌شِناسی؟ ( Iranian Persian ) ― in doxtar-e zibâ ro mi-šenâsi? ― Do you know this beautiful girl? 

 elegant 

 pretty 

 cute 

 stylish , chic 

 picturesque
