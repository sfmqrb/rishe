 Hebrew
 [ edit ] 

 שלושת מיני הפילים החיים כיום 
 Etymology
 [ edit ] 

 Uncertain, but usually regarded as a non-Semitic Afroasiatic loanword, see Akkadian 𒄠𒋛 ( pīru ) .

 Other Semitic cognates include Aramaic פִּילָא ( pīlā ) and Arabic فِيل ( fīl ) . Compare also Old Armenian փիղ ( pʻił ) , Persian پیل ( pil ) , Sanskrit पीलु ( pīlu ) .

 Noun
 [ edit ] 

 פִּיל • ( píl )  m ( plural indefinite פִּילִים , singular construct פִּילֵי־ ) 

 elephant
