 Adjective
 [ edit ] 

 هویدا • ( hoveydâ ) 

 visible ; apparent ; manifest 
 Synonyms: پیدا ( peydâ ) , پدید ( padid ) , ظاهر ( zâher ) 
 Antonyms: پنهان ( penhân ) , نهان ( nahân ) , باطن ( bâten ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 343: تا نماند در جهان نصرانیی 
 نی هویدا دین و نی پنهانیی tā na-mānad dar jahān nasrānīyē
nē huwaydā dīn u nē panhānīyē So that there may not remain a single Christian in the world, neither one whose religion is manifest nor one who is concealed. ( Classical Persian transliteration )
