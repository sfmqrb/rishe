 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 λᾱ́δᾰνον ( lā́dănon ) 

 Etymology
 [ edit ] 

 A loan, originally from Semitic . Compare Akkadian 𒆷𒁷𒉡 ( ladinnu ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /lɛ̌ː.da.non/ → /ˈli.ða.non/ → /ˈli.ða.non/ 

 ( 5 th BCE Attic ) IPA ( key ) : /lɛ̌ː.da.non/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈle̝.da.non/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈli.ða.non/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈli.ða.non/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈli.ða.non/ 

 Noun
 [ edit ] 

 λήδᾰνον • ( lḗdănon )  n ( genitive ληδᾰ́νου ) ; second declension 

 labdanum , a resin obtained from rockroses 

 Inflection
 [ edit ] 

 Second declension of τὸ λήδᾰνον ; τοῦ ληδᾰ́νου ( Attic )
