 فَرْمان ( frman , “ royal mandate ” ) 
 Etymology
 [ edit ] 

 Borrowed from Classical Persian فَرْمَان ( farmān ) . Compare Old Punjabi ਫੁਰਮਾਣੁ ( phuramāṇu ) and Old Gujarati फुरमाण ( phuramāṇa ) .

 Noun
 [ edit ] 

 فَرْمان ( frman )  m ( Middle Hindi ) 

 decree , order 
 1564 , حَسَن شَوقِی ( hasan śauqī ) , مِعْراج اُلْعَاشِقِین ( mi'rāj ul'āśiqīn ) , page 82 : نِظامِیَاں کوں فَرْمان یُوں لیکھ توں
جِیتے قاعِدے ہِندوی سِیکھ توں nz̤amyaṉ kvṉ frman yvṉ lykh tvṉ

 فَرْمان ( “ royal mandate ” ) 
 Alternative forms
 [ edit ] 

 فرمون ( farmūn ) ( colloquial ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( plmʾn' ) , 𐫜𐫡𐫖𐫀𐫗 ( frmʾn /⁠framān⁠/ , “ order, command ” ) , from Old Persian 𐎳𐎼𐎶𐎠𐎴𐎠 ( framānā , “ command ” ) , from Proto-Iranian *framaHanaH , ultimately from Proto-Indo-European *meh₁- ( “ to measure ” ) . 

 Cognate with Bactrian φρομανο ( fromano ) , Gurani ھەرمانە ( harmāna , “ work ” ) and Iranian loanwords Old Armenian հրաման ( hraman , “ order, command, injunction ” ) , Aramaic הַרְמָן ( hrmnʾ , “ order ” ) . A similar formation is Sanskrit प्रमाण ( pramāṇa , “ authority, proof ” ) .

 فَرْمان ( farmān , “ royal mandate ” ) 
 Etymology
 [ edit ] 

 Borrowed from Classical Persian فَرْمَان ( farmān ) . First attested in c. 1564 as Middle Hindi فَرْمَان ( frman ) . Doublet of پْرَمَان ( pramān ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /fəɾ.mɑːn/ 

 Rhymes: -ɑːn 

 Hyphenation: فَر‧مان 

 Noun
 [ edit ] 

 فَرْمَان • ( farmān )  m ( formal plural فَرَامِین ( farāmīn ) , Hindi spelling फ़रमान ) 

 a royal decree , order 

 a command ( by any individual ) 

 ( historical ) a firman , decree ; mandate ( especially a royal or an official one )

 Adjective
 [ edit ] 

 فَرْمَان • ( farmān ) ( indeclinable , Hindi spelling फ़रमान ) ( poetic ) 

 obedient , servant 
 مَیں قائِد کا فَرْمَان ۔ میرے سِینے میں قُرْآن ma͠i qāid kā farmān . mere sīne mẽ qur-ān I am servant of my leader , with the Word of God lying against my heart; chest.
