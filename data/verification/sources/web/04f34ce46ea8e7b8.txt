 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 آروق ( “ âruq ” ) , آرق ( âroq ) ( Iran , eye dialect ) 

 آرغ ( āruġ  / âroġ ) , وروغ ( wurōġ  / voruġ ) , روغ ( rōġ  / ruġ ) , رغ ( ruġ  / roġ ) , ارغ ( arōġ  / aruġ ) 

 Etymology
 [ edit ] 

 Ultimately from Proto-Indo-European *h₁rewg- ( “ belch, roar ” ) . Cognate with Latin erugo ( “ belch ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ˈroːɣ/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ɾóːɣ]

 ( Hazaragi ) IPA ( key ) : [ʔɔː.ɾʊ́ːɣ] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.ɹúːɢ̥] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.ɹúːɢ̥]

 Noun
 [ edit ] 

 آروغ • ( ārōġ / âruġ ) ( plural آروغ‌ها ( ārōġ-hā / âruġ-hâ ) , Tajik spelling орӯғ ) 

 burp 

 belch
