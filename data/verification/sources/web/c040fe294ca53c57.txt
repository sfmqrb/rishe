 Alternative forms
 [ edit ] 

 پراگندن ( parâgandan ) 

 Etymology
 [ edit ] 

 From Parthian prʾgn- ( parāgan- , “ to scatter, sow ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [pæɾɒːkænˈdæn] 

 Verb
 [ edit ] 

 پراکندن • ( parâkandan ) ( present stem پراکن ( parâkan ) ) 

 to scatter , disperse
