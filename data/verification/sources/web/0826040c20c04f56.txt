 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( nhwptn' /⁠nihuftan⁠/ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ni.huf.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [ne̞.ɦʊf.t̪ʰän] 

 ( Dari, formal ) IPA ( key ) : [ne̞.ɦʊf.t̪ʰän] 
 ( Kabuli ) IPA ( key ) : [ni.jʊf.t̪ʰän] 

 ( Hazaragi ) IPA ( key ) : [nuuf.t̪ʰän] 

 ( Iran, formal ) IPA ( key ) : [no.ɦof.t̪ʰæn] , [ne.ɦof.t̪ʰæn] 

 ( Tajik, formal ) IPA ( key ) : [ni.ɦuf.t̪ʰän] 

 Rhymes: -an 

 Readings

 Classical reading ? 

 nihuftan

 Dari reading ? 

 nehuftan

 Iranian reading ? 

 nohoftan, nehoftan

 Tajik reading ? 

 nihuftan

 Verb
 [ edit ] 

 نهفتن • ( nohoftan ) ( present stem نهنب ( nohomb ) ) 

 to hide ; to conceal 
 Synonym: پنهان کردن ( penhân kardan )
