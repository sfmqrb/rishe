 Persian
 [ edit ] 

 Persian Wikipedia has an article on: تنباکو

 Alternative forms
 [ edit ] 

 تنباک ( tanbâk ) , تنبک ( tanbak ) 

 تماکو ( tamâku, tammâku ) ( dialectal or Tajik ) 

 Etymology
 [ edit ] 

 Borrowed from Portuguese tabaco .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /tan.baː.ˈkuː/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰäm.bɑː.kʰúː] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰäm.bɑː.kʰúː] 
 ( Kabuli ) IPA ( key ) : [t̪ʰäm.bɑː.kʰúː] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰäm.bɔː.kʰú] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰæm.bɒː.kʰúː] 

 ( Tajik, formal ) IPA ( key ) : [t̪ʰä.mɔ.kʰú] 

 Rhymes: -uː

 Noun
 [ edit ] 

 تنباکو • ( tanbākū / tanbâku ) ( Tajik spelling тамоку ) 

 tobacco 
 Synonym: توتون ( tūtūn  / tutun )
