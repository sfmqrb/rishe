 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic أُبَّهَة ( ʔubbaha ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔub.ba.ˈhat/ , /ʔub.bu.ˈhat/ 

 ( Dari, formal ) IPA ( key ) : [ʔʊ.bo̞ɦ.hát̪] 

 ( Dari, formal ) IPA ( key ) : [ʔʊ.bo̞ɦ.hát̪] 
 ( Kabuli ) IPA ( key ) : [ʔʊ.bʊát̪] 

 ( Hazaragi ) IPA ( key ) : [ʔu.buát̪] 

 ( Iran, formal ) IPA ( key ) : [ʔo.boɦ.hǽt̪ʰ] 

 ( Tajik, formal ) IPA ( key ) : [ʔub.bä.ɦát̪] , [ʔub.bu.ɦát̪] 

 Rhymes: -at 

 Readings

 Classical reading ? 

 ubbahát, ubbuhát

 Dari reading ? 

 ubohhat

 Iranian reading ? 

 obohhat

 Tajik reading ? 

 ubbahat, ubbuhat

 Noun
 [ edit ] 

 ابهت • ( ubbahat, ubbuhat, ubuhhat / obohhat ) ( Tajik spelling уббаҳат ) 

 magnificence , grandeur , imposing presence 
 پِسَری کِه ریش نَداشْتِه باشِه اَصَن اون اُبُهَّت‌ها رو نَدارِه. pesari ke riš nadâšte bâše asan un obohhat-hâ ro nadâre. A guy who doesn't have a beard doesn't have those imposing looks at all.
