 Egyptian Arabic عمو 

 From عمّ ( ʕamm ) + -ـو ( -u ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕammu/ 

 Noun
 [ edit ] 

 عمو • ( ʕammu )  m ( feminine عمتو ( ʕammitu ) ) 

 endearing form of عم ( ʕamm , “ uncle ” ) : uncley 

 possisive form of عم ( ʕamm , “ uncle ” ) : his uncle
 alternative spelling of عمه 

 ( informal ) Term of address to older male strangers 

 Usage notes
 [ edit ] 

 As a term of address, it is used very often by children, and less often by teenagers.

 عمو • ( amō / amu ) ( plural عموها ( amō-hā / amu-hâ ) , Tajik spelling амӯ ) 

 ( chiefly Indo-Persian , Iran ) paternal uncle 
 Synonyms: کاکا ( kâkâ ) , کاکو ( kâko ) , ( archaic ) افدر ( afdar ) 
 Coordinate terms: ( in Iran ) دایی ( dâyi ) , ( in Dari ) ماما ( mâmâ ) 

 uncle (title)
