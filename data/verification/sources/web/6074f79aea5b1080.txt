 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( splhm /⁠sprahm⁠/ , “ flower, fragrant herb ” ) , from Proto-Iranian *spr̥Hgmáh ( “ flower ” ) .

 Alternative forms
 [ edit ] 

 اسفرم ( esfaram ) , اسفرغم ( esfaraġm ) , اسپرغم ( esparaġm ) , سفرم ( sefaram ) , سپرم ( separam ) , اسفرهم ( esfarahm ) , اسبرهم ( esparahm ) , سپرهم ( separahm ) , سپرغم ( separaġm ) 

 Noun
 [ edit ] 

 اسپرم • ( esparam ) 

 fragrant herb ; medicinal herb 

 Derived terms
 [ edit ] 

 شاه اسپرم ( šâh esparam ) , شاهسپرم ( šâhesparam ) , and with other variants and also without شاه ( šâh ) means costmary ( Tanacetum balsamita ) and basil ( Ocimum basilicum )

 مورد اسفرم ( murd esfaram ) and with other variants means box holly ( Ruscus genus and species)

 Etymology 2
 [ edit ] 

 Borrowed from French sperme .

 Persian Wikipedia has an article on: اسپرم
