 Pashto
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian اَنجام ( anjām ) .

 Noun
 [ edit ] 

 انجام • ( anjām )  m 

 end , conclusion , outcome 

 tip , extremity 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Term?] ( /⁠hanǰām⁠/ , “ end, completion, outcome ” ) , from Old Persian [script needed] ( *hanǰāma- , “ end, conclusion ” ) , from Proto-Iranian *ham- + *gam ( “ to come ” ) , ultimately from Proto-Indo-European *gʷem- ( “ to go, stand ” ) . Compare Sanskrit संगम ( saṃgama ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔan.ˈd͡ʒaːm/ 

 ( Dari, formal ) IPA ( key ) : [ʔän.d͡ʒɑːm] 

 ( Dari, formal ) IPA ( key ) : [ʔän.d͡ʒɑːm] 
 ( Kabuli ) IPA ( key ) : [ʔän.d͡ʒɑːm] 

 ( Hazaragi ) IPA ( key ) : [ʔän.d͡ʒɔːm] 

 ( Iran, formal ) IPA ( key ) : [ʔæn.d͡ʒɒːm] 

 ( Tajik, formal ) IPA ( key ) : [ʔän.d͡ʒɔm] 

 Rhymes: -aːm

 Noun
 [ edit ] 

 Dari

 انجام 

 Iranian Persian

 Tajik

 анҷом 

 انجام • ( anjâm ) 

 end , conclusion 
 Antonyms: آغاز ( âġâz ) , شُروع ( šoru' ) 
 c. 1030 , Farrukhī Sīstānī , “Qaṣīda 115”, in دیوان فرخی سیستانی [ Dīvān of Farrukhī ]‎ [1] : در همه شغلها که دست برد
نیکش آغاز و نیکتر انجام dar hama šugl-hā ki dast burd
nēk-aš āġāz u nēktar anjām For every work you have done,
Its beginning was good, its end was better. (Classical Persian transliteration) 

 accomplishment , action

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian انجام ( anjām ) , from Middle Persian [script needed] ( hanǰām , “ end, completion, outcome ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ən.d͡ʒɑːm/ 

 Audio ( Pakistan ) : ( file ) 

 Rhymes: -ɑːm 

 Noun
 [ edit ] 

 اَن٘جام • ( añjām )  m ( Hindi spelling अंजाम ) 

 end , finishing 

 result , conclusion 
 اس کا انجام ٹھیک نہیں ہو گا۔ is kā añjām ṭhīk nahī̃ ho gā The result of it won't be right.
