 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Hellenic *gumnós (with Cowgill's Law : o → u between labial and resonant), from Proto-Indo-European *nogʷnós by metathesis (possible taboo deformation; if the metathesis didn't happen we would have *νυγνός ( *nugnós ) ), from *nogʷós ( “ naked ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡym.nós/ → /ʝymˈnos/ → /ʝimˈnos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ɡym.nós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ɡymˈnos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ʝymˈnos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ʝymˈnos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ʝimˈnos/ 

 Adjective
 [ edit ] 

 γυμνός • ( gumnós )  m ( feminine γυμνή , neuter γυμνόν ) ; first / second declension 

 naked ; nude ; unclad 

 unarmed ; without armor ; defenseless 

 bare ; uncovered 

 stripped ; destitute 

 lightly clad 

 mere

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek γυμνός ( gumnós ) , from Proto-Hellenic *gʷomnós , ultimately from Proto-Indo-European *nogʷós .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ʝimˈnɔs] 

 Adjective
 [ edit ] 

 γυμνός • ( gymnós )  m ( feminine γυμνή , neuter γυμνό ) 

 naked , unsheathed , bare .
