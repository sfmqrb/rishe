 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From earlier باشد ( bāšad , imperative of بودن , literally “ let it be ” ) .

 Interjection
 [ edit ] 

 باشه • ( bāša  / bâše ) 

 Used to indicate acknowledgement or acceptance. OK 
 Synonyms: اوکی ( ōkay ) , خب ( xub ) , چشم ( čašm ) 

 Etymology 2
 [ edit ] 

 From Middle Persian , also borrowed from Arabic بَاشَق ( bāšaq ) . Akin to Mazanderani واشه ( wāša , “ sparrowhawk ” ) and Northern Kurdish waşe ( “ sparrow-hawk ” ) . Connected to Sanskrit भास ( bhāsa , “ a bird of prey ” ) and to Persian باز ( bāz , “ falcon, hawk ” ) .

 Alternative forms
 [ edit ] 

 باسه ( bāsa ) ( Khurasan ) 

 بَاشَق ( bāšaq ) ( occasional Arabism in Classical Persian )

 Noun
 [ edit ] 

 باشه • ( bāša / bâše ) ( plural بَوَاشِق ( bawāšiq / bavâšeġ ) , Tajik spelling боша ) 

 ( Indo-Persian ) sparrowhawk
