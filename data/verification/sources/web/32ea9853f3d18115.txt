 Persian

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /si.ˈriːʃ/ 

 ( Dari, formal ) IPA ( key ) : [sɪ.ɾíːʃ] 

 ( Dari, formal ) IPA ( key ) : [sɪ.ɾíːʃ] 
 ( Kabuli ) IPA ( key ) : [sɪ.ɾíːʃ] 

 ( Hazaragi ) IPA ( key ) : [si.ɾíʃ] 

 ( Iran, formal ) IPA ( key ) : [se.ɹíːʃ] 

 ( Tajik, formal ) IPA ( key ) : [si.ɾíʃ]

 Verb
 [ edit ] 

 سریش • ( seriš ) 

 present stem form of سرشتن ( sereštan ) 

 Noun
 [ edit ] 

 سریش • ( seriš ) 

 lime , glue 

 gluten , the sticky part from bran 

 isinglass 

 kingspear ( Asphodelus gen. et spp.)

 desert candle ( Eremurus gen. et spp.)

 ( figurative ) wailing , lamentation
