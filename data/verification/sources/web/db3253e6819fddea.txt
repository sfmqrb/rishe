 Wikipedia la 

 ebur bȳzantīnum ― a Byzantine ivory 
 Alternative forms
 [ edit ] 

 ebor ( Medieval Latin ) 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Afroasiatic *leb- 
 Egyptian ꜣbw 
 Demotic Egyptian yb bor. ? 
 Latin ebur 

 Loan word, probably from Demotic Egyptian yb ( “ ivory, Elephantine ” ) , from Egyptian 

 ( ꜣbw , “ ivory, elephant, Elephantine ” ) . Compare Coptic ⲓⲏⲃ ( iēb , “ Elephantine ” ) ; also note Sanskrit इभ ( ibha ) and Tigre ኣቦት ( ʾabot ) .

 In any case, probably cognate with the second half of Ancient Greek ἐλέφας ( eléphas , “ elephant ” )

 [ edit ]

 Noun
 [ edit ] 

 ebur   n ( genitive eboris ) ; third declension 

 ivory (material)

 a thing made of ivory.

 ( figuratively ) an elephant 
 Synonyms: elephantus , elephās
