 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 بنبشه ( banabše ) ( dialectal , Kashan ) [ 1 ] 

 Etymology
 [ edit ] 

 From Middle Persian wnpšk' ( wanafšag , “ violet ” ) , of uncertain origin; see there for further information.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bu.naf.ˈʃa/ , /bi.naf.ˈʃa/ , /ba.naf.ˈʃa/ 

 ( Dari, formal ) IPA ( key ) : [bɪ.näf.ʃä] 

 ( Dari, formal ) IPA ( key ) : [bɪ.näf.ʃä] 
 ( Kabuli ) IPA ( key ) : [bɪ.näf.ʃä] 

 ( Hazaragi ) IPA ( key ) : [bi.näf.ʃä] 

 ( Iran, formal ) IPA ( key ) : [bæ.næf.ʃé] 

 ( Tajik, formal ) IPA ( key ) : [bu.näf.ʃä] 

 Rhymes: -a 

 Readings

 Classical reading ? 

 bunafša, binafša, banafša

 Dari reading ? 

 binafša

 Iranian reading ? 

 banafše

 Tajik reading ? 

 bunafša

 Audio ( Iran ) : ( file )

 بنفشه • ( banafše ) ( plural بنفشه‌ها )

 بنفشه فرنگی ― banafše -ye farangi ― pansy
