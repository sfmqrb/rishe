 Arabic
 [ edit ] 

 Root 

 ق ل ب ( q l b ) 

 15 terms 

 Etymology
 [ edit ] 

 From Classical Syriac ܩܠܒܝܕ ( /⁠*qālobīḏ⁠/ , “ last ” ) , from Ancient Greek καλοπόδιον ( kalopódion , “ last ” ) , diminutive of καλόπους ( kalópous , “ last ” ) , compound of κᾶλον ( kâlon , “ wood ” ) and πούς ( poús , “ foot ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /qaː.lab/ , /qaː.lib/ 

 Noun
 [ edit ] 

 قَالَب or قالِب • ( qālab or qālib )  m ( plural قَوَالِب ( qawālib ) ) 

 form , mould , last ( for casting shapes by it ) 

 ( computing ) template ; boilerplate

 [ edit ] 

 قالب • ( gālib or gālab )  m ( plural قَوَالِب ( gawālib ) ) 

 bakery pan , cake mold 

 form , mould , last

 قالب • ( gālib ) ( feminine قالبة ( gālba ) , common plural قالبين ( gālbīn ) )

 Noun
 [ edit ] 

 قالب • ( qālib / ġâleb ) ( plural قالب‌ها ( qālib-hā / ġâleb-hâ ) , Tajik spelling қолиб ) 

 mould 

 template 
 قالب وردپرس ― qâleb -e vordpres ― WordPress template ; WordPress theme 

 form , shape 
 شیطانی در قالب فرشته šeytâni dar qâleb -e ferešte a demon in the shape of an angel 

 body (as opposed to soul)

 cake , block ; counter for blocks of soap, cheese, etc. 
 قالب صابون ― qâleb -e sâbun ― cake of soap 
 قالب پنیر ― qâleb -e panir ― block of cheese
