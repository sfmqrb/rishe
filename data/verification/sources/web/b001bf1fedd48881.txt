 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 πᾰρᾰ́δισος ( părắdisos ) 

 Παράδεισος ( Parádeisos ) 

 Etymology
 [ edit ] 

 An Iranian borrowing, ultimately from Proto-Iranian *paridayjah . [ 1 ] [ 2 ] [ 3 ] 

 Compare native περίβολος ( períbolos ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pa.rá.deː.sos/ → /paˈra.ði.sos/ → /paˈra.ði.sos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pa.rá.deː.sos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /paˈra.di.sos/ 

 ( 4 th CE Koine ) IPA ( key ) : /paˈra.ði.sos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /paˈra.ði.sos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /paˈra.ði.sos/ 

 Noun
 [ edit ] 

 πᾰρᾰ́δεισος • ( părắdeisos )  m ( genitive πᾰρᾰδείσου ) ; second declension 

 the garden owned by the Persian nobility 

 enclosed park , pleasure-ground 

 ( biblical ) Garden of Eden 

 the afterlife location of the blessed : paradise 

 Declension
 [ edit ] 

 Second declension of ὁ πᾰρᾰ́δεισος ; τοῦ πᾰρᾰδείσου ( Attic )
