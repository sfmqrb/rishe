 Etymology
 [ edit ]

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /d͡ʒoː.ʃiː.ˈðan/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒoː.ʃiː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒoː.ʃiː.d̪án]

 ( Hazaragi ) IPA ( key ) : [d͡ʒu.ʃi.d̪án]
