 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Avestan 𐬨𐬀𐬥𐬎𐬱𐬗𐬌𐬚𐬭𐬀 ( manušciθra ) . Akin to Old Armenian Մանաճիհր ( Manačihr ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ma.nuː.ˈt͡ʃihr/ 

 ( Dari, formal ) IPA ( key ) : [mä.nuː.t͡ʃʰe̞ɦɾ] 

 ( Dari, formal ) IPA ( key ) : [mä.nuː.t͡ʃʰe̞ɦɾ] 
 ( Kabuli ) IPA ( key ) : [mä.nuː.t͡ʃʰɪɾ] 

 ( Hazaragi ) IPA ( key ) : [mä.nu.t͡ʃʰiɾ] 

 ( Iran, formal ) IPA ( key ) : [mæ.nuː.t͡ʃʰeɦɹ] 

 ( Tajik, formal ) IPA ( key ) : [mä.nu.t͡ʃʰeɦɾ] 

 Rhymes: -ihr
