 Old Anatolian Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian بها ( bahâ ) . [ 1 ] 

 Noun
 [ edit ] 

 بَهَا • ( bähā ) 

 price , value , valor , worth 
 Synonym: دَكَرْ ( dägär ) 

 Descendants
 [ edit ] 

 Azerbaijani: baha 

 Gagauz: paa 

 Ottoman Turkish: بها ( baha ) 
 Turkish: paha 

 References
 [ edit ] 

 ^ Nişanyan, Sevan ( 2002– ), “ paha ”, in Nişanyan Sözlük 

 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Inherited from Old Anatolian Turkish بَهَا ( bahā ) , from Classical Persian بها ( bahâ ) , from Middle Persian [script needed] ( whʾk /⁠wahāg⁠/ ) .

 Noun
 [ edit ] 

 بها • ( baha ) 

 price 

 Descendants
 [ edit ] 

 Turkish: paha 

 Etymology 2
 [ edit ] 

 Borrowed from Arabic بَهَاء ( bahāʔ ) .

 Alternative forms
 [ edit ] 

 بهاء ( bahâ' ) 

 Noun
 [ edit ] 

 بها • ( bahâ ) 

 beauty , comeliness 

 Related terms
 [ edit ] 

 بهاء الدین ( Bahâ'uddîn ) 

 Etymology 3
 [ edit ] 

 Borrowed from Arabic بِهَا ( bi-hā ) .

 Prepositional phrase
 [ edit ] 

 بها • ( bi-hâ ) 

 by her

 Further reading
 [ edit ] 

 Redhouse, James W. ( 1890 ), “ بها ”, in A Turkish and English Lexicon ‎ [1] , Constantinople: A. H. Boyajian, page 414 

 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [script needed] ( whʾk /⁠wahāg⁠/ ) ; ultimately from Proto-Indo-European *wes- ( “ to sell, trade ” ) . Akin to Armenian գին ( gin , “ price ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ba.ˈhaː/ 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑ́ː] 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑ́ː] 
 ( Kabuli ) IPA ( key ) : [bɑːɑ́ː] 

 ( Hazaragi ) IPA ( key ) : [bɔː] 

 ( Iran, formal ) IPA ( key ) : [bæ.ɦɒ́ː] 

 ( Tajik, formal ) IPA ( key ) : [bä.ɦɔ́] 

 Rhymes: -aː
