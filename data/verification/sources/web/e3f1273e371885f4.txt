 Middle Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 [Book Pahlavi needed] ( pylwc' ) — Book Pahlavi 

 𐫛𐫏𐫡𐫇𐫉 ( pyrwz ) — Manichaean 

 Etymology
 [ edit ] 

 From Parthian 𐭐𐭓𐭂𐭅𐭆 ( prgwz /⁠Paryōž⁠/ ) , itself from Avestan 𐬞𐬀𐬌𐬭𐬌⸱𐬀𐬊𐬘𐬀𐬵 ( pa i ri.aojah ) , composed of 𐬞𐬀𐬌𐬭𐬌 ( pa i ri , “ around ” ) +‎ 𐬀𐬊𐬘𐬀𐬵 ( aojah , “ strength, power ” ) , from Proto-Indo-Iranian *pari , from Proto-Indo-European *péri + Proto-Indo-Iranian *Háwgas . [ 1 ] [ 2 ] [ 3 ] 

 Compare the Old Armenian given name Վարազ-Պերոժ ( Varaz-Perož ) , the place names Պերոժ-Կաւատ ( Perož-Kawat ) , Հրաքոտպերոժ ( Hrakʻotperož ) , Սպանդարանպերոժ ( Spandaranperož ) , Որմզդպերոժ ( Ormzdperož ) , as well as the given name Պելուժավր ( Pelužavr ) , all Iranian borrowings. [ 4 ] [ 5 ]

 victorious

 Proper noun
 [ edit ] 

 𐭯𐭩𐭫𐭥𐭰 • ( pylwc / Pērōz /) 

 a male given name , Peroz , Perozes , and Peirozes
