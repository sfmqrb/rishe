 Etymology 1
 [ edit ] 

 Root 

 ع و ر ( ʕ w r ) 

 14 terms 

 From the root ع و ر ( ʕ w r ) , related to ideas of missing one eye or having a lacuna .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕa.waːr/ 

 Noun
 [ edit ] 

 عَوَار • ( ʕawār )  m 

 fault , flaw , defect , crevasse

 Etymology 2
 [ edit ] 

 Root 

 ع و ذ ( ʕ w ḏ ) 

 12 terms 

 Apparently a corruption of عُوَّاذ ( ʕuwwāḏ ) from the root ع و ذ ( ʕ w ḏ ) , related to taking refuge.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕuw.waːr/ 

 Noun
 [ edit ] 

 عُوَّار • ( ʕuwwār )  m ( plural عَوَاوِير ( ʕawāwīr ) ) 

 martin ( certain birds in the family Hirundinidae )

 Gulf Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Arabic عَوَار ( ʕawār ) .

 Pronunciation
 [ edit ] 

 ( Kuwait ) IPA ( key ) : /ʕəˈwɑːr/ 

 Noun
 [ edit ] 

 عَوار • ( ʕawār )  m 

 ( also figuratively ) pain
