 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Syriac ܨܠܝܒܐ ( ṣəlīḇā ) or some other Aramaic form, perhaps via Sogdian ܨܠܝܒܐ ( clybʾ , “ Cross, crucifix ” ) . Aramaic /ṣ/ is often borrowed as /č/ in Middle Iranian . Doublet of صلیب ( salib ) .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.liː.pʰɑ́ː] 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.liː.pʰɑ́ː]

 Noun
 [ edit ] 

 Dari

 چلیپا 

 Iranian Persian

 Tajik

 чалипо 

 چلیپا • ( čalīpā / čalipâ ) ( Tajik spelling чалипо ) 

 cross , crucifix 
 Synonym: صلیب ( salib ) 

 something cruciform or crooked :
 curl of hair 
 Synonyms: زلف ( zolf ) , طره ( torre ) 

 ( calligraphy ) Chalipa (calligraphic panel)

 swastika 
 Synonyms: صلیب شکسته ( salib-e šekaste ) , سواستیکا ( sevâstikâ ) 

 ( genetics ) synonym of کیاسما ( kiyâsmâ , “ chiasma ” ) 

 Adjective
 [ edit ] 

 چلیپا • ( čalipâ ) 

 cruciform , cross-like in shape

 crooked , curly 
 c. 1520 , Selim I of the Ottoman Empire , edited by Benedek Péri, The Persian Dīvān of Yavuz Sulṭān Selīm , Budapest, Hungary: Research Centre for the Humanities, Eötvös Loránd Research Network, →ISBN , page 131 : هر که با زلف چلیپا عشق ورزیدن گرفت
ترک تقوی کرد و راه بت پرستیدن گرفت har ki bā zulf-i čalīpā išq warzīdan girift
tark-i taqwā kard u rāh-i but parastīdan girift Whoever has chosen to love curly locks of hair
Has abandoned piety and chosen the road of idolatry. (Classical Persian transliteration)
