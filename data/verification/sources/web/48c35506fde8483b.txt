 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 A Semitic loanword, [ 1 ] found as Aramaic סָסָא / ܣܳܣܳܐ ( sāsā , “ moth ” ) , Hebrew סָס ( sās , “ moth ” ) , Akkadian 𒌨𒈨 ( sāsum , “ moth ” ) , Arabic سُوس ( sūs , “ moth-worm ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sɛ̌ːs/ → /ˈsis/ → /ˈsis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /sɛ̌ːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈse̝s/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈsis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈsis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈsis/ 

 Noun
 [ edit ] 

 σής • ( sḗs )  m ( genitive σεός or σητός ) ; third declension 

 moth 
 Synonyms: ἠπίολος ( ēpíolos ) , φάλαινα ( phálaina )
