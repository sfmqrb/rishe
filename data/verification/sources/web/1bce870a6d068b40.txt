 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic نَبِيّ ( nabiyy ) .

 Noun
 [ edit ] 

 نبی • ( nebî ) ( definite accusative نبییی ( nebiyi ) , plural انبیا ( enbiyâ ) ) 

 ( religion , chiefly Islam ) prophet 
 Synonyms: رسول ( resûl ) , ( more common ) پیغامبر ( peygamber )

 Etymology 1
 [ edit ] 

 Borrowed from Arabic نَبِيّ ( nabiyy ) , from Aramaic נְבִיָּא ( nəḇiyyā ) (absolutive form: נְבִי ( nəḇī ) ). Compare Hebrew נָבִיא ( nāḇīʔ ) .
