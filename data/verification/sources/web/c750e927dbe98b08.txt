 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *custáh , from Proto-Indo-Iranian *čutˢtás , from Proto-Indo-European *(s)kud-tó-s ( “ propelled ” ) , from *(s)kewd- ( “ to shoot, throw ” ) . Cognate with Sanskrit चोदति ( códati , “ to impel ” ) .

 Adjective
 [ edit ] 

 چست • ( čost ) ( comparative چست‌تَر , superlative چست‌تَرین ) 

 quick 

 brisk 

 active 

 fleet 

 agile 

 dexterous 

 Descendants
 [ edit ] 

 → Bengali: চোস্ত ( cōsto ) 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian چُسْت ( čust ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /t͡ʃʊst̪/ 

 Adjective
 [ edit ] 

 چُسْت • ( cust ) ( Hindi spelling चुस्त ) 

 clever , ingenious , elegant 

 brisk , quick , active , agile , alert
