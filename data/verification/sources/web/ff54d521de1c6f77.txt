 Noun
 [ edit ] 

 سَطِل or سَطْل • ( saṭil or saṭl )  m ( plural أَسْطَال ( ʔasṭāl ) or أَسْطُل ( ʔasṭul ) or سُطُول ( suṭūl ) ) 

 bucket , pail 
 Alternative forms: سَيْطَل ( sayṭal ) , سَطْلَة ( saṭla ) 
 Synonyms: دَلْو ( dalw ) , مِدْلَجَة ( midlaja ) , جَرْدَل ( jardal )

 Etymology 2
 [ edit ] 

 Denominal verb of سَطْل ( saṭl ) , in the sense of a jar or wine jug, "being like a thing filled up with liquid".

 [ edit ] 

 سَطَلَ • ( saṭala ) I ( non-past يَسْطُلُ ( yasṭulu ) , verbal noun سَطْل ( saṭl ) ) 

 to intoxicate , to besot , to make high
