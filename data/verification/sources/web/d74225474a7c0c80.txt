 Alternative forms

 کربه ( kurba  / korbe ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐫐𐫇𐫡𐫁𐫃 ( kwrbg /⁠kurbag⁠/ , “ humble dwelling, hut ” ) . The basic meaning is "formed, shaped;" compare Middle Persian klp ( kirb , “ body, form ” ) , from Proto-Iranian *kŕ̥pš , from Proto-Indo-Iranian *kŕ̥ps , ultimately from Proto-Indo-European *krep- ( “ body ” ) .

 Cognate with Avestan 𐬵𐬎𐬐𐬆𐬭𐬆𐬞𐬙𐬀 ( hukər ə pta , “ well-formed ” ) . Akin to the Iranian borrowings: Old Armenian կրպակ ( krpak ) , կուղպակ ( kułpak ) , Old Georgian ქულბაგი ( kulbagi ) , Georgian ქულბაქი ( kulbaki ) , Arabic كُرْبَق ( kurbaq ) , قُرْبَق ( qurbaq ) , كُرْبَج ( kurbaj ) . Unrelated to Ancient Greek καλύβη ( kalúbē ) .

 Noun
 [ edit ] 

 کلبه • ( kulba / kolbe ) ( Tajik spelling кулба ) 

 hut , cottage 

 ( archaic ) store , shop
