 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian lwtbʾl ( rōd-bār , “ river bank ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /roːd.ˈbaːr/ 

 ( Dari, formal ) IPA ( key ) : [roːd̪.bɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [roːd̪.bɑ́ːɾ]
