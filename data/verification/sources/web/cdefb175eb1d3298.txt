 Etymology
 [ edit ] 

 From Aramaic קוּבְּתָא / ܩܘܼܒ݁ܬ݂ܵܐ ( qubbəṯā ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /qub.ba/ 
 ( Moroccan ) IPA ( key ) : /qub.ba/ 

 Noun
 [ edit ] 

 قُبَّة • ( qubba )  f ( plural قِبَاب ( qibāb ) or قُبَب ( qubab ) ) 

 canopy , pavilion ; dome , cupola 

 ( Judaism ) kippah , yarmulke ( Jewish head covering )

 Etymology
 [ edit ]

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡub.ba/ , [ɡʊb.ba] , [qʊb.ba] 

 Noun
 [ edit ] 

 قبة • ( gubba )  f ( plural قُبَب ( gubab ) ) 

 dome , cupola
