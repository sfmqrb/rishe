 Etymology
 [ edit ] 

 Borrowed from Arabic هالة ( hāla , “ halo ” ) , from Ancient Greek ἅλως ( hálōs , “ halo ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /haː.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [hɑː.lá] 

 ( Dari, formal ) IPA ( key ) : [hɑː.lá] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.lá] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.lá] 

 ( Iran, formal ) IPA ( key ) : [hɒː.lé] 

 ( Tajik, formal ) IPA ( key ) : [hɔ.lá] 

 Rhymes: -a

 Noun
 [ edit ] 

 هاله • ( hâle ) ( plural هاله‌ها ) 

 halo 
 Synonym: شایورد ( šāyward  / šâyvard ) 
 هاله‌ ماه ― hâle -ye mâh ― halo of the moon 

 Descendants
 [ edit ] 

 → Gujarati: હાલા ( hālā ) 

 Proper noun
 [ edit ] 

 هاله • ( hâle ) 

 a female given name , Haleh , from Ancient Greek
