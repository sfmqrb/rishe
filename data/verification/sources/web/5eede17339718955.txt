 Finnish
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Finnic *vacca (compare Estonian vats , Karelian vačča , Veps vac ). [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈʋɑtsɑ/ , [ˈʋɑ̝ts̠ɑ̝] 

 Rhymes: -ɑtsɑ 

 Syllabification ( key ) : vat‧sa 

 Hyphenation ( key ) : vat‧sa 

 Noun
 [ edit ] 

 vatsa 

 belly , abdomen ( part of the body between the thorax and the pelvis, not including the back ) 
 Synonyms: maha , ( childish ) masu 

 stomach ( in common language only, not as an anatomical term ) 
 Synonyms: maha , mahalaukku 

 Usage notes
 [ edit ] 

 In anatomy, vatsa refers to the belly or the abdomen, not the stomach.
