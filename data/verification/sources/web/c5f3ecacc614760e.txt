 Etymology
 [ edit ]

 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /daː.ˈʃan/ 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.ʃán] 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.ʃán]
