 Verb

 زَوَّدَ • ( zawwada ) II ( non-past يُزَوِّدُ ( yuzawwidu ) , verbal noun تَزْوِيد ( tazwīd ) ) 

 ( transitive ) to provide , to equip , to supply [ with accusative ‘someone’ and بِ ( bi ) ‘with something’ ]

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From a Proto-Indo-Iranian [Term?] root shared with Sanskrit जू ( jū , “ hurry on, hurry, be quick ” ) , Avestan 𐬰𐬆𐬬𐬍𐬱𐬙𐬫𐬀 ( zəvīštya , “ the quickest ” ) , and Northern Kurdish zû , Northern Luri زی ( zi ) , possibly from Proto-Indo-European *ǵewH- ( “ force, drive ” ) and thus further cognate with Proto-Slavic *žuriti ( “ to rage ” ) and Old Norse keyra ( “ drive ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈzuːd/ 

 ( Dari, formal ) IPA ( key ) : [zuːd̪] 

 ( Dari, formal ) IPA ( key ) : [zuːd̪] 
 ( Kabuli ) IPA ( key ) : [zuːd̪] 

 ( Hazaragi ) IPA ( key ) : [zud̪̥] 

 ( Iran, formal ) IPA ( key ) : [zuːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [zud̪] 

 Rhymes: -uːd

 Adjective
 [ edit ] 

 زود • ( zūd / zud ) ( comparative زودتَر , superlative زودتَرین , Tajik spelling зуд ) 

 early 

 Adverb
 [ edit ] 

 زود • ( zūd  / zud ) ( Tajik spelling зуд ) 

 early 
 زود از خواب بیدار می‌شدم. ― zud az xâb bidâr mi-šodam. ― I used to wake up early . 

 quickly 
 چقدر زود گذشت، انگار همین دیروز بود čeqadr zud gozašt, engâr hamin diruz bud It went by so quickly , it feels like it was just yesterday 

 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume IV, verse 2709: زانک دوزخ گوید: ای مؤمن تو زود برگذر که نورت آتش را ربود z-an-kē dōzax gōyad: ey mu'min tu zūd bar-guzar kē nūr-at ātaš-rā rebud. For Hell says, "O true believer, pass by quickly , since thy light has taken away [extinguished] the Fire." 

 soon 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 176: گفت پیغمبر که هر که سر نهفت زود گردد با مراد خویش جفت goft payġambar kē har ki sirr nahuft zūd gardad bā murād-i xwēš juft The Prophet said that any one who hides his inmost thought will soon attain to the object of his desire.
