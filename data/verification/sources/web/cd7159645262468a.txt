 Baluchi
 [ edit ] 

 Alternative forms
 [ edit ] 

 سروپ ( sròp, srup ) 

 Etymology
 [ edit ] 

 Inherited from Proto-Iranian *cáywaH . Cognate with Persian سیب ( sib ) , Central Kurdish سێو ( sêw ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /soːp/ [soːp] 
 ( Iran ) IPA ( key ) : [sɯːp] 

 Noun
 [ edit ] 

 سوپ • ( sòp ) 

 apple 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from French soupe .

 Pronunciation
 [ edit ] 

 ( Iran ) IPA ( key ) : [suːpʰ] 

 Noun
 [ edit ] 

 سوپ • ( sup ) ( plural سوپ‌ها ) 

 soup 
 Synonym: آشامه ( âšâme )
