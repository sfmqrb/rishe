 Tunisian Arabic
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Arabic بَرَكَةٌ ( barakatun ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ˈbɐɾ.kə] 

 Noun
 [ edit ] 

 بركة ( barkə ) 

 a divine blessing 

 Adverb
 [ edit ] 

 بركة ( barkə ) 

 (de-complicating a matter; introducing or rushing a simple solution) already 
 قُصّهَا التِّسكرَة بَركَة ― qoṣṣhə t-teskra barkə ― buy the ticket already 
 Synonym: بَرك ( bark ) 

 Determiner
 [ edit ] 

 بركة ( barkə ) 

 only , just , enough 

 Derived terms
 [ edit ] 

 بَرك 

 Etymology 2
 [ edit ] 

 Noun from برِك ( brek ) from Arabic بَرَكَ ( baraka ) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ˈbæɾ.kə] 

 Noun
 [ edit ] 

 بركة ( bærkə ) 

 idling , staying still doing nothing 

 degrading 

 (by extension) a curse 

 ( dated ) a place of rest for cattle 

 Etymology 3
 [ edit ] 

 From Arabic بِرْكَةٌ ( birkatun ) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ˈbɘɾ.kə] 

 Noun
 [ edit ] 

 بركة ( berkə ) 

 ( rare to dated ) a pond 
 Coordinate terms: بُحَيرَة ( boḥayra ) , لَاك ( lāk )
