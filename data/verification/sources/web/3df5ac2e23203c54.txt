 Etymology
 [ edit ] 

 Inherited from Middle Persian ʾhlmn' ( /⁠ahreman⁠/ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔah.riː.ˈman/ , /ʔah.reː.ˈman/ 

 ( Dari, formal ) IPA ( key ) : [ʔäɦ.ɾiː.mán] 

 ( Dari, formal ) IPA ( key ) : [ʔäɦ.ɾiː.mán] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.ɾiː.mán] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.ɾi.mán] 

 ( Iran, formal ) IPA ( key ) : [ʔæɦ.ɹiː.mǽn]

 Noun
 [ edit ] 

 اهریمن • ( ahrīman / ahriman ) ( plural اهریمنان ( ahrīmanān / ahrimanân ) , or اهریمن‌ها ( ahrīman-hā / ahriman-hâ ) , Tajik spelling аҳриман ) 

 devil 

 Proper noun
 [ edit ] 

 اهریمن • ( ahrīman  / ahriman ) ( Tajik spelling Аҳриман ) 

 ( Zoroastrianism ) Ahriman ( the hypostasis of chaos , destruction , and evil )
