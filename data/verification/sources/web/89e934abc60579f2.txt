 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek γωνία ( gōnía , “ corner, angle; joiner's square; cornerstone ” ) , probably via Classical Syriac ܓܘܢܝܐ ( gōnyā ) . Doublet of زانو .

 Noun
 [ edit ] 

 گونیا • ( guniyâ ) ( plural گونیاها )
