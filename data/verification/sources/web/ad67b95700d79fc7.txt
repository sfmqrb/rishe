 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐭩𐭠𐭥𐭩𐭲𐭠 ( yʾwyt' /⁠jāwēd⁠/ , “ eternal ” ) , from Old Persian *yāvaitat . Compare Old Armenian յաւէտ ( yawēt ) , an Iranian borrowing. compare Avestan 𐬫𐬀𐬎𐬎𐬀𐬈-𐬘𐬍- ( yauuae-jī- , “ living forever ” ) . [ 1 ] [ 2 ] [ 3 ] Ultimately from Proto-Indo-European *h₂óyu and *gʷeyh₃- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /d͡ʒaː.ˈweːd/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒɑː.wíːd̪] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒɑː.wíːd̪] 
 ( Kabuli ) IPA ( key ) : [d͡ʒɑː.wíːd̪] 

 ( Hazaragi ) IPA ( key ) : [d͡ʒɔː.wíd̪̥] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒɒː.víːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [d͡ʒɔ.víd̪] 

 Rhymes: -eːd

 Adjective
 [ edit ] 

 جاوید • ( jāwēd / jâvid ) ( Tajik spelling ҷовид ) 

 eternal 
 Synonym: جاودان ( jâvedân ) 
 جاوید شاه ― jâvid šâh ― Long Live the Shah (King) 

 Proper noun
 [ edit ] 

 جاوید • ( jāwēd  / jâvid ) ( Tajik spelling Ҷовид ) 

 a male given name , Javeed , Jawed , Javid , and Javed , from Middle Persian

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 From Classical Persian جاوید ( jāwēd , “ eternal ” ) , from Middle Persian [script needed] ( yʾwyt' /⁠jāwēd⁠/ , “ eternal ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /d͡ʒɑː.ʋeːd̪/ , /d͡ʒɑː.ʋiːd̪/ 

 Adjective
 [ edit ] 

 جاوید • ( jāvēd or jāvīd ) ( Hindi spelling जावेद or जावीद ) 

 eternal , undying , everlasting , perpetual 

 Proper noun
 [ edit ] 

 جاوید • ( jāved or jāvīd )  m ( Hindi spelling जावेद or जावीद ) 

 a male given name , Javed , Jawed , and Jaweed , from Persian
