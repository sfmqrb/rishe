 Verb
 [ edit ] 

 جَمُلَ • ( jamula ) I ( non-past يَجْمُلُ ( yajmulu ) , verbal noun جَمَال ( jamāl ) ) 

 to be beautiful , to be pretty , to be graceful 

 to be handsome , to be comely 

 to be appropriate , to be proper , to be suitable

 Noun
 [ edit ] 

 جَمَل • ( jamal )  m ( plural جِمَال ( jimāl ) or جِمَالَة ( jimāla ) or أَجْمَال ( ʔajmāl ) or أَجْمُل ( ʔajmul ) or جِمَالَات ( jimālāt ) , feminine نَاقَة ( nāqa ) ) 

 male camel
