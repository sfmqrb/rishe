 Etymology
 [ edit ] 

 From *չորիրոդ ( *čʻorirod ) , from չորի- ( čʻori- ) +‎ -րորդ ( -rord ) .

 Numeral
 [ edit ] 

 չորրորդ • ( čʻorrord ) 

 fourth 
 չորրորդ տասն ― čʻorrord tasn ― forty 
 չորրորդք ― čʻorrordkʻ ― the marrying four times; the fourth marriage, or the fourth time married
