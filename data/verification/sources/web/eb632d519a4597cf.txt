 Etymology
 [ edit ] 

 The LIV claims that the term was inherited from Proto-Indo-European *skénd-e-ti , itself from the root *skend- . The LIV adduces Latin scandō ( “ to jump ” ) and Middle Welsh kychwyn as direct cognates, [ 1 ] though the Latin form has been derived from the zero-grade *skn̥d- . [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /skɐ́n.dɐ.ti/ 

 ( Classical Sanskrit ) IPA ( key ) : /s̪kɐn̪.d̪ɐ.t̪i/ 

 Verb
 [ edit ] 

 स्कन्द॑ति • ( skándati ) third-singular indicative ( class 1, type P , root स्कन्द् ) 

 to leap , jump , hop , spring 

 to drop , fall down 

 to perish 

 ( primarily said of semen ) to be split or effused 

 to emit seminal fluid
