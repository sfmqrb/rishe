 Alternative forms

 Σπιθραδάτης ( Spithradátēs ) 

 Etymology
 [ edit ] 

 Borrowed from Old Persian *Spiθradātah . [ 1 ] [ 2 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /spi.tʰri.dǎː.tɛːs/ → /spi.θriˈða.tis/ → /spi.θriˈða.tis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /spi.tʰri.dǎː.tɛːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /spi.tʰriˈda.te̝s/ 

 ( 4 th CE Koine ) IPA ( key ) : /spi.θriˈða.tis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /spi.θriˈða.tis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /spi.θriˈða.tis/ 

 Proper noun
 [ edit ] 

 Σπῐθρῐδᾱ́της • ( Spĭthrĭdā́tēs )  m ( genitive Σπῐθρῐδᾱ́του ) ; first declension 

 a male given name , Spithridates , from Old Persian 
 an Achaemenid general who revolted against Pharnabazus II 

 brother of Rhosaces and satrap of Lydia and Ionia who smashed Alexander the Great 's helmet at the Battle of the Granicus
