 Etymology 1
 [ edit ] 

 Cognate with Biblical Hebrew גָּבַר ( gɔḇar ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /d͡ʒa.ba.ra/ 

 Verb
 [ edit ] 

 جَبَرَ • ( jabara ) I ( non-past يَجْبُرُ ( yajburu ) , verbal noun جَبْر ( jabr ) or جُبُور ( jubūr ) ) 

 to set (a broken bone)

 to restore 

 to force , to compel

 Noun
 [ edit ] 

 جَبْر • ( jabr )  m 

 verbal noun of جَبَرَ ( jabara )   ( form I ) 

 setting of broken bones

 force , compulsion , coercion , duress 

 ( philosophy ) determinism , fatalism , predestination , predetermination 
 Antonym: قَدَر ( qadar )
