 Verb

 مَتَرَ • ( matara ) I ( non-past يَمْتُرُ ( yamturu ) , verbal noun مَتْر ( matr ) ) 

 to extend , to lengthen 
 Synonym: مَدّ ( madd ) 

 to cut 
 Synonyms: قَطَعَ ( qaṭaʕa ) , بَتَرَ ( batara )
