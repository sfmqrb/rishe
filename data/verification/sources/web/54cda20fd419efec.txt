 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 Compare کژ ( kaž , “ crooked ” ) .

 Alternative forms
 [ edit ] 

 گوژ ( guž ) 

 Adjective
 [ edit ] 

 کوژ • ( kuž ) 

 convex 
 Synonym: محدب ( mohaddab ) 
 Antonym: کاو ( kâv ) 

 Etymology 2
 [ edit ] 

 Compare غوره ( ġure , “ unripe grapes ” ) .

 Noun
 [ edit ] 

 کوژ • ( kewž, kuviž ) 

 ( obsolete ) fruit of the medlar 

 Descendants
 [ edit ] 

 → Arabic: كِوَز ( kiwaz ) , كُوِز ( kuwiz )
