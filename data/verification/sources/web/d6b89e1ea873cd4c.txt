 Persian الکل 

 Borrowed from French alcool , from Arabic الْكُحُل ( al-kuḥul ) (a direct boring from Arabic would drop the definite article ال ( al- ) ), see there for more. Doublet of کحل ( kuhl  / kohl ) and الکحل ( alkuhul  / alkohol ) .
