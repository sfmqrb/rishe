 Brooke's Point Palawano
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Malay selamat , from Arabic سَلَامَة ( salāma , “ good health ” ) .

 Interjection
 [ edit ] 

 selamat 

 thank you 

 Indonesian
 [ edit ] 

 Alternative forms
 [ edit ] 

 met ( apheretic form ) 

 Etymology
 [ edit ] 

 Inherited from Malay selamat , from Arabic سَلَامَات ( salāmāt ) , plural of سَلَام ( salām ) . Compare to Javanese ꦱ꧀ꦭꦩꦼꦠ꧀ ( slamet ) .

 Pronunciation
 [ edit ] 

 ( Standard Indonesian ) IPA ( key ) : /səˈlamat/ [səˈla.mat̪̚] 

 Rhymes: -amat 

 Syllabification: se‧la‧mat 

 Interjection
 [ edit ] 

 sêlamat 

 congratulations !
 Synonyms: proficiat , tahniah ( common in Standard Malay ) 

 Noun
 [ edit ] 

 sêlamat 

 safety 
 Synonym: keselamatan 

 wholeness 
 Synonym: keutuhan 

 Adjective
 [ edit ] 

 sêlamat 

 safe 
 Synonym: aman 

 healthy 
 Synonyms: afiat , sehat 

 successful 
 Synonyms: berhasil , berjaya 

 happy , merry 
 Selamat Ulang Tahun! ― Happy Birthday! 
 Selamat Natal! ― Merry Christmas! 

 good 
 Selamat pagi ― Good morning 
 Selamat malam ― Good night 

 enjoy 
 Selamat makan ― Enjoy (your) meal

 Malay
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic سَلَامَة ( salāma ) .

 Pronunciation
 [ edit ] 

 ( schwa-variety , Literary Standard ) IPA ( key ) : /səˈlamat/ [səˈla.mat̪̚] 

 Audio ( Malaysia ) : ( file ) 

 Rhymes: -amat , -mat , -at 

 Hyphenation: se‧la‧mat 

 Noun
 [ edit ] 

 sĕlamat ( Jawi spelling سلامت , plural selamat - selamat or selamat 2 ) 

 safety , security , peace 

 Adjective
 [ edit ] 

 sĕlamat ( Jawi spelling سلامت , comparative lebih selamat , superlative paling selamat ) 

 safe , secure 

 Adverb
 [ edit ] 

 sĕlamat ( Jawi spelling سلامت ) 

 may there be...
 Selamat jalan! May you go safely!/Goodbye! 

 Adjective
 [ edit ] 

 sĕlamat ( Jawi spelling سلامت , comparative lebih selamat , superlative paling selamat ) 

 happy ; merry 
 Selamat Hari Raya! Happy Eid ul-Fitr! 

 Selamat Hari Krismas! Happy Christmas! 

 Selamat Tahun Bahru! Happy New Year!
