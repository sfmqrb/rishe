 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 لستن ( lestan ) 

 لشتن ( leštan ) 

 لیشتن ( lištan ) 

 Etymology
 [ edit ] 

 Ultimately from Proto-Indo-European *leyǵʰ- ( “ to lick ” ) (compare Old Irish ligid , Latin lingō ( “ lick ” ) , English lick ).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /leː.siː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [leː.siː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [leː.siː.d̪án] 
 ( Kabuli ) IPA ( key ) : [leː.siː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [li.si.d̪án] 

 ( Iran, formal ) IPA ( key ) : [liː.siː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [le.si.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 لیسیدن • ( lēsīdan  / lisidan ) ( present stem لیس ( lis ) , Tajik spelling лесидан ) 

 to lick
