 Etymology
 [ edit ] 

 Inherited from Proto-Indo-Iranian *rać- ( “ to bind, tie ” ) , whence also Sanskrit रश्मन् ( raśmán ) , रश्मि ( raśmí ) . Cognate with Middle Persian lsn' ( rasan ) , Classical Persian رَسَن ( rasan ) (whence Hindustani रसन ( rasan ) / رَسَن ( rasan ) ). Compare also Old Armenian առասան ( aṙasan ) , an Iranian borrowing. See also रज्जु ( rájju ) .

 Synonyms: रज्जु ( rájju ) , सूत्र ( sū́tra )
