 Arabic
 [ edit ] 

 Etymology 1
 [ edit ] 

 Etymology tree

 Proto-Afroasiatic *yamin- 
 Proto-Semitic *yamīn- 
 Arabic يمين 

 Inherited from Proto-Semitic *yamīn- ( “ right ” ) , from Proto-Afroasiatic *yamin- ( “ right ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ja.miːn/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 يَمِين • ( yamīn )  m or f ( plural أَيْمُن ( ʔaymun ) or يَمَائِن ( yamāʔin ) or أَيْمَان ( ʔaymān ) ) 

 right , right side ( opposed to left ) 
 Antonyms: يَسَار ( yasār ) , شِمَال ( šimāl ) 
 ثُمَّ ٱنْعَطِفْ يَمِينًا . ― ṯumma nʕaṭif yamīnan . ― Then, turn right . 

 right hand 
 Antonym: شِمَال ( šimāl ) 
 609–632 CE , Qur'an , 20:17 : وَمَا تِلْكَ بِ يَمِينِ كَ يَا مُوسَى wa-mā tilka bi- yamīni ka yā mūsā And what is that in your right hand , O Moses? 

 oath

 Verb
 [ edit ] 

 يمين ( form I ) 

 يَمِينُ ( yamīnu ) /ja.miː.nu/ : third-person masculine singular non-past active indicative of مَانَ ( māna ) 

 يَمِينَ ( yamīna ) /ja.miː.na/ : third-person masculine singular non-past active subjunctive of مَانَ ( māna )

 South Levantine Arabic يمين 

 Inherited from Arabic يَمِين ( yamīn ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ja.miːn/ , [jaˈmiːn] 

 Audio ( Jerusalem ) : ( file ) 

 Noun
 [ edit ] 

 يمين • ( yamīn )  m 

 right ( side or direction ) 
 Antonym: شمال ( šmāl ) 
 لف ع إيد ك اليمين ! liff ʕa-ʔīdak il-yamīn ! Turn right ! (literally, “ Turn on your right hand! ”)
