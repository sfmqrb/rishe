 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( syc /⁠sēj⁠/ , “ danger, trouble ” ) , compare Avestan 𐬌𐬚𐬌𐬌𐬈𐬘𐬀𐬵 ( i θiiejah ) .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [seːd͡ʒ] 

 ( Dari, formal ) IPA ( key ) : [seːd͡ʒ] 
 ( Kabuli ) IPA ( key ) : [seːd͡ʒ] 

 ( Hazaragi ) IPA ( key ) : [seːd͡ʒ̥] 

 ( Iran, formal ) IPA ( key ) : [siːd͡ʒ̥]

 Noun
 [ edit ] 

 سیج • ( sēj / sij ) ( plural سیج‌ها ( sēj-hā / sij-hâ ) , Tajik spelling сеҷ ) 

 ( obsolete ) danger 
 Synonym: خطر ( xatar ) 

 ( obsolete ) suffering , hardship 
 Synonyms: سختی ( saxtī  / saxti ) , محنت ( mihnat  / mehnat ) , مشقت ( mašaqqat  / mašaġġat ) , رنج ( ranj )

 Etymology
 [ edit ]

 Punjabi سیج 

 Inherited from Prakrit 𑀲𑁂𑀚𑁆𑀚𑀸 ( sĕjjā ) , from Sanskrit शय्या ( śayyā ) , from शी ( śī ) + -या ( -yā ) .

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /seːd͡ʒ/ , [seːd͡ʒ(ə̆)] 

 Noun
 [ edit ] 

 سیج • ( sej )  f ( Gurmukhi spelling ਸੇਜ ) 

 a soft or decorated bed ( for a couple on a wedding day ) 

 ( figuratively ) a modest ; meek wedding
