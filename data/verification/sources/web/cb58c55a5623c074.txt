 Etymology
 [ edit ] 

 From Old Iranian (compare Avestan 𐬟𐬭𐬀𐬛𐬀𐬑𐬴𐬀𐬥𐬁 ( fradaxṣ̌anā , “ sling ” ) ), probably via Bactrian .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /fælɒːˈxæn/ 

 Noun
 [ edit ] 

 فلاخن • ( falâxan ) ( plural فلاخن‌ها ) 

 sling ( weapon ) 
 Synonyms: قلاب‌سنگ ( qollâb-sang ) , کلاسنگ ( kalâsang ) 

 Descendants
 [ edit ] 

 → Chagatai: فلخمان ( flxmʾn /⁠fäläxmān⁠/ ) 
 Uzbek: palaxmon , palaqmon
