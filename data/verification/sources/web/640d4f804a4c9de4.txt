 Ancient Greek
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /bys.sós/ → /βysˈsos/ → /viˈsos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /bys.sós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /bysˈsos/ 

 ( 4 th CE Koine ) IPA ( key ) : /βysˈsos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /vysˈsos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /viˈsos/ 

 Noun
 [ edit ] 

 βῠσσός • ( bŭssós )  m ( genitive βῠσσοῦ ) ; second declension 

 alternative form of βῠθός ( bŭthós ) 

 Inflection
 [ edit ] 

 Second declension of ὁ βῠσσός ; τοῦ βῠσσοῦ ( Attic )
