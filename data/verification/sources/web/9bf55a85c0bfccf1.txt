 Arabic
 [ edit ] 

 قَفَص 
 Etymology
 [ edit ] 

 From Aramaic קוּפְסָא ( qūp̄sā ) / קַפְצָא ( qap̄əṣā ) / ܩܰܦܣܳܐ ( qap̄əsā ) / ܩܰܦܨܳܐ ( qap̄əṣā , “ cage ” ) , from Ancient Greek κάψα ( kápsa ) or Latin capsus .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /qa.fasˤ/ , ( obsolete ) /qufsˤ/ 
 ( Moroccan ) IPA ( key ) : /qfasˤ/ 

 Noun
 [ edit ] 

 قَفَص or قُفْص • ( qafaṣ or qufṣ )  m ( plural أَقْفَاص ( ʔaqfāṣ ) ) 

 cage , birdcage , pen , coop 

 basket , particularly if it is similar in mould to a cage
 Synonym: سَلَّة ( salla ) 

 thorax
