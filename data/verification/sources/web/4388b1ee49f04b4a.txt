 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 خورسند ( xorsand ) ( misspelling ) 

 خنسند ( xunsand ) ( obsolete ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( hwnsnd /⁠hunsand⁠/ , “ happy, contented ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /xur.ˈsand/ 

 ( Dari, formal ) IPA ( key ) : [xʊɾ.sán̪d̪] 

 ( Dari, formal ) IPA ( key ) : [xʊɾ.sán̪d̪] 
 ( Kabuli ) IPA ( key ) : [xʊɾ.sán̪d̪] 

 ( Hazaragi ) IPA ( key ) : [xuɾ.sán̪d̪̥] 

 ( Iran, formal ) IPA ( key ) : [xoɹ.sǽn̪d̪̥] 

 ( Tajik, formal ) IPA ( key ) : [χuɾ.sán̪d̪]

 Adjective
 [ edit ] 

 خرسند • ( xursand / xorsand ) ( comparative خرسندتَر , superlative خرسندتَرین , Tajik spelling хурсанд ) 

 happy , pleased 
 Synonym: خوشحال ( xošhâl ) 

 content , satisfied 
 late 1400s , ʿAbd al-Raḥmān Jāmī, فاتحة الشباب ‎ [1] : مگوییدم که شو خرسند چون دیدار او دیدی
مسلمانان نیاید راست با هم عشق و خرسندی ma-gōyēdam ki šaw xursand čūn dīdār-i ō dīdī
musalmānān nay-āyad rāst bā ham išq u xursandī Do not tell me to be content when I have seen his [the beloved's] face;
Muslims! Love and contentment do not go together. (Classical Persian transliteration)
