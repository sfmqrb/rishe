 Noun
 [ edit ] 

 چهره • ( čhrh / čihrä, čehrä /) ( plural چهره‌ها ( /⁠čihrä-hā, čehrä-hā⁠/ ) ) 

 face , visage 
 Synonyms: یوز ( ywz /⁠yüz⁠/ ) , پیکر ( pykr /⁠päykär⁠/ ) , جبین ( jbyn /⁠jäbīn⁠/ ) , روی ( rwy /⁠rūy⁠/ ) , چیرای ( čyrʾy /⁠čıray⁠/ )

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭰𐭧𐭫𐭪𐭩 ( čihrag ) , from Old Persian *čiθrakah , from Proto-Iranian *čiθrákah , from Proto-Indo-Iranian *čitrám , from Proto-Indo-European *kʷi-tróm , from *kʷey- ( “ bright, burning ” ) . [ 1 ] Cognate with Sanskrit चित्र ( citra ) and Baluchi چِهرَگ ( čihrag , “ countenance, face ” )

 Noun
 [ edit ] 

 چهره • ( čihra / čehre ) ( plural چهره‌ها ( čihra-hā / čehre-hâ ) , Tajik spelling чеҳра ) 

 visage , face 
 Synonym: صورت ( surat ) 

 figure , individual 
 چهره‌ها ی سرشناس اپوزیسیون čehre-hâ- ye saršenâs-e opozisyon prominent opposition figures
