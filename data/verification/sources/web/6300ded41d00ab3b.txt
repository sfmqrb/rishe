 Arabic
 [ edit ] 

 Verb
 [ edit ] 

 شُوهِرَ • ( šūhira ) ( form III ) /ʃuː.hi.ra/ 

 third-person masculine singular past passive of شَاهَرَ ( šāhara ) 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *fšautar , from Proto-Iranian *fšau- ( “ to raise cattle ” ) , from Proto-Indo-European *peh₂- ( “ to protect; to shepherd ” ) . Compare Khotanese [script needed] ( kṣondai , “ husband ” ) , Yidgha [script needed] ( šfuy , “ husband ” ) , Avestan 𐬟𐬱𐬎𐬌𐬌𐬀𐬥𐬝 ( fšuiiant̰ , “ husbandman, commoner ” ) , [ 1 ] Northern Luri شی ( şi , “ husband ” ) , Baluchi شو ( šú , “ husband ” ) .

 Noun
 [ edit ] 

 شوهر • ( šawhar / šowhar ) ( plural شوهران ( šawharān / šowharân ) , or شوهرها ( šawhar-hā / šowhar-hâ ) , Tajik spelling шавҳар ) 

 husband 
 مَن و شُوْهَرَ م دو تا پِسَر و سِه‌ تا دُخْتَر داریم. man o šowhar -am do tâ pesar o se tâ doxtar dârim. My husband and I have two sons and three daughters.
