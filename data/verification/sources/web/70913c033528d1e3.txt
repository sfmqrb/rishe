 Etymology
 [ edit ] 

 Etymology tree

 Ancient Greek μαστίχη ( mastíkhē ) bor.

 Arabic مصطكى 

 Borrowed from Aramaic מצטכי ( mūṣṭəḵē ) , borrowed from Ancient Greek μαστίχη ( mastíkhē ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /musˤ.tˤa.kaː/ 

 Noun
 [ edit ] 

 مُصْطَكَى • ( muṣṭakā )  f 

 mastic , the gum-resin of Pistacia lentiscus 
 Synonyms: رَمَاص ( ramāṣ ) , عِلْك ( ʕilk ) 
 Holonyms: ضَرْو ( ḍarw ) , رَامَك ( rāmak )
