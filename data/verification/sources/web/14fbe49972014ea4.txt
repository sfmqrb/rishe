 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( swsn' /⁠sōsan⁠/ ) , from Ancient Greek σοῦσον ( soûson ) , ultimately from Egyptian zšn . Compare Old Armenian շուշան ( šušan ) , Old Georgian შროშანი ( šrošani ) , Biblical Hebrew שׁוֹשָׁן ( šōšān ) , שׁוֹשַׁנָּה ( šōšannā ) , Aramaic שַׁוֹשַׁנְתָּא ( šōšantā ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /soː.ˈsan/ , /saw.ˈsan/ 

 ( Dari, formal ) IPA ( key ) : [soː.sán] , [säw.sán] 

 ( Dari, formal ) IPA ( key ) : [soː.sán] , [säw.sán]

 Noun
 [ edit ] 

 سوسن • ( sōsan, sawsan / susan, sowsan ) ( plural سوسن‌ها ( sōsan-hā, sawsan-hā / susan-hâ, sowsan-hâ ) , Tajik spelling сӯсан , or савсан ) 

 lily

 Proper noun
 [ edit ] 

 سوسن • ( sōsan  / susan or sawsan  / sowsan ) ( Tajik spelling Сӯсан or Савсан ) 

 a female given name , Sosan , Sousan , Susan , Soosan , and Sawsan , from Persian
