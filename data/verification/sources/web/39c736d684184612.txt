 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Avestan , etymologically related to زیرک ( zīrak , “ clever ” ) and چیره ( čēra , “ dominant , victorious ” ) .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ʒíːɾ]

 Adjective
 [ edit ] 

 آژیر • ( āžīr / âžir ) ( Tajik spelling ожир ) 

 ( archaic ) alert , alarm 
 10 th Century CE , Ferdowsi , Shahnameh 
 سپه را بیارای و آژیر باش
شب و روز با ترکش و تیر باش sipah rā biyārāy-u -āžīr bāš
šab-u rōz bā tarkiš-u tīr bāš Muster the army and stay alert ,
stick to your quiver and arrows night and day 

 Noun
 [ edit ] 

 آژیر • ( āžīr / âžir ) ( plural آژیرها ( āžīr-hā / âžir-hâ ) , Tajik spelling ожир ) 

 ( technology ) siren 
 آژیرها به صدا در آمدند. ― âžir-ha be sedâ dar âmadand. ― Sirens blared.
