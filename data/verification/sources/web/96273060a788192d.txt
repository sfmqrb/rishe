 Persian
 [ edit ] 

 Persian Wikipedia has an article on: گیتی 

 Wikipedia fa 

 Alternative forms
 [ edit ] 

 گیتا ( gitâ ) 

 Etymology
 [ edit ] 

 From Middle Persian gytyḵ ( gētīg , “ the material world; worldly ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡeː.ˈtiː/ 

 ( Dari, formal ) IPA ( key ) : [ɡiː.t̪ʰíː] , [ɡäj.t̪ʰíː] 

 ( Dari, formal ) IPA ( key ) : [ɡiː.t̪ʰíː] , [ɡäj.t̪ʰíː] 
 ( Kabuli ) IPA ( key ) : [ɡiː.t̪ʰíː] , [ɡäj.t̪ʰíː] 

 ( Hazaragi ) IPA ( key ) : [ɡi.t̪ʰí] , [ɡäj.t̪ʰí] 

 ( Iran, formal ) IPA ( key ) : [ɡʲiː.t̪ʰíː] 

 ( Tajik, formal ) IPA ( key ) : [ɡe.t̪ʰí] 

 Rhymes: -iː

 Noun
 [ edit ] 

 گیتی • ( gētī / giti ) ( Tajik spelling гетӣ ) 

 The Universe 
 Synonym: جهان ( jahân ) 
 1932 , محمد اقبال [ Muhammad Iqbāl ], “The noble spirits of Hallaj, Ghalib, and Qurrat al-Ain Tahira”, in Arthur J. Arberry , transl., جاویدنامه [ Jāvīdnāma , Book of Eternity ]‎ [1] : پیش خود دیدم سہ روح پاکباز
آتش اندر سینہ شان گیتی گداز pēš-i xwad dīdam sih rūh-i pākbāz
ātaš andar sīna-šan gētī gudāz I saw before me three pure spirits
the fire in whose breasts might melt the world . (Indo-Persian script) 

 Proper noun
 [ edit ] 

 گیتی • ( gētī  / giti ) ( Tajik spelling Гетӣ ) 

 a female given name , Giti , Geti , and Geeti , from Middle Persian
