 Khowar

 Etymology
 [ edit ] 

 From Sanskrit शत ( śata ) , from Proto-Indo-Iranian *ćatám , from Proto-Indo-European *ḱm̥tóm . Compare Hindi सौ ( sau ) , Urdu سو ( sau ) , Gujarati સો ( so ) , Assamese শ ( xo ) .

 Numeral
 [ edit ] 

 شور ( šor ) 

 hundred

 Etymology 1
 [ edit ] 

 Etymology tree

 Proto-Indo-European *súHros 
 Proto-Iranian *sauraH ? 
 Parthian 𐫢𐫇𐫡 ( šwr /⁠šōr⁠/ ) bor. 
 Persian شور 

 Borrowed from Parthian 𐫢𐫇𐫡 ( šwr /⁠šōr⁠/ ) , possibly from Proto-Iranian *sauraH ( “ salty ” ) , from Proto-Indo-European *súHros ( “ sour, acidic, salty ” ) . Compare with Middle Persian [script needed] ( swr /⁠sōr⁠/ ) . cognate with Northern Kurdish şor , sûr , Central Kurdish سوێر ( swêr ) , Baluchi شور ( šōr, šowr ) , Baluchi سور ( sowr ) , Harzani سور ( sür ) and Pashto ښرنه ( x̌arǝ́na , “ saline ” ) .

 Adjective
 [ edit ] 

 شور • ( šōr / šur ) ( Tajik spelling шӯр ) 

 salty ( of taste ) 
 Coordinate terms: شیرین ( šīrīn  / širin ) , تلخ ( talx ) , ترش ( turš  / torš ) , تند ( tund  / tond ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume II, verse 1118: او ز بحر عذب آب شور خورد / تا که آب شور او را کور کرد ō z-i bahr-i azb āb-i šōr xward / tā ki āb-i šōr ō-rā kōr kard He has drunk salt water from the sweet Sea, so that the salt water has made him blind. ( Classical Romanization )

 Etymology 2
 [ edit ] 

 Derived from the verb شوریدن ( šōrīdan  / šuridan ) , شولیدن ( šōlīdan  / šulidan ) .

 Noun
 [ edit ] 

 شور • ( šōr / šur ) ( Tajik spelling шӯр ) 

 excitement 

 uproar , clamor , commotion 

 Dastgāh-e Šur , one of the seven dastgahs of Persian Music.

 Derived terms
 [ edit ]

 پرشور ( pur-šōr  / por-šur , “ passionate, ardent ” )
