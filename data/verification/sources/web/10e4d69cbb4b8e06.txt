 Verb
 [ edit ] 

 شیفْتَن • ( šēftan / šiftan ) ( present stem شیب ( šēb / šib ) , Tajik spelling шефтан ) 

 to fall in love , enamour 

 to be captivated , be allured 

 to fascinate 
 Synonyms: عاشق شدن ( āšiq šudan  / âšeġ šodan ) , شیفته کردن ( šēfta kardan  / šifte kardan )
