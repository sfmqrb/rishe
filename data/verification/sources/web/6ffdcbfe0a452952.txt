 Arabic
 [ edit ] 

 Root 

 م و ت ( m w t ) 

 14 terms 

 Etymology
 [ edit ] 

 Inherited from Proto-Semitic *mawt- ( “ death ” ) . Compare Akkadian 𒁁 ( mūtum , “ death ” ) , Ugaritic 𐎎𐎚 ( mt , “ death ” ) , Aramaic ܡܘܬܐ ( mawtā ) , Hebrew מָוֶת ( mávet , “ death ” ) , Amharic ሞት ( mot , “ death ” ) and Egyptian mt 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /mawt/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 مَوْت • ( mawt )  m 

 verbal noun of مَاتَ ( māta , “ to die ” )   ( form I ) 

 death 
 Antonym: حَيَاة ( ḥayāh ) 
 609–632 CE , Qur'an , 4:78 : أَيۡنَمَا تَكُونُوا۟ يُدۡرِككُّمُ ٱلۡمَوۡتُ وَلَوۡ كُنتُمۡ فِي بُرُوجࣲ مُّشَيَّدَةࣲ ʾaynamā takūnū yudrikkumu l-mawtu wa-law kuntum fī burūjin mušayyadatin Wherever you may be, death will overtake you, even if you should be within towers of lofty construction. 

 demise

 ( transitive ) to make die , let perish , to kill , to cause the death of

 to death , a lot , so much 
 Synonyms: أوي ( awi ) , جامد ( gāmid ) ; ( vulgar ) نيك ( nēk ) , فشخ ( fašḵ )
