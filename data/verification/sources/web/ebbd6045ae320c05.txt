 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian ltg' ( /⁠radag⁠/ , “ line , rank , row ” ) . [ 1 ] , ultimately from Proto-Indo-European *h₂rey- ( “ to arrange, count ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ra.ˈda/ 

 ( Dari, formal ) IPA ( key ) : [rä.d̪á] 

 ( Dari, formal ) IPA ( key ) : [rä.d̪á] 
 ( Kabuli ) IPA ( key ) : [rä.d̪á] 

 ( Hazaragi ) IPA ( key ) : [rä.d̪á] 

 ( Iran, formal ) IPA ( key ) : [ɹæ.d̪é] 

 ( Tajik, formal ) IPA ( key ) : [ɾä.d̪á] 

 Rhymes: -a
