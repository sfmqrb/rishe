 Ancient Greek

 Wikipedia 

 Alternative forms
 [ edit ] 

 τέχνᾱ ( tékhnā ) — Doric 

 Etymology
 [ edit ] 

 From Proto-Indo-European *téḱ-sneh₂ , from *tetḱ- ( “ to create, produce ” ) . Cognate with τίκτω ( tíktō ) , τέκτων ( téktōn ) , Sanskrit तक्षति ( takṣati ) , Avestan 𐬙𐬀𐬱𐬀𐬌𐬙𐬌 ( taša i ti ) , Latin texō , tēla , tignum , Proto-Germanic *þahsuz . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /té.kʰnɛː/ → /ˈte.xni/ → /ˈte.xni/ 

 ( 5 th BCE Attic ) IPA ( key ) : /té.kʰnɛː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈte.kʰne̝/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈte.xni/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈte.xni/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈte.xni/ 

 Noun
 [ edit ] 

 τέχνη • ( tékhnē )  f ( genitive τέχνης ) ; first declension 

 craft , skill , trade 

 art 

 cunning , wile 

 means
