 Noun

 تَابِستَان ( tobiston ) ( Latin spelling tobiston , Cyrillic spelling тобистон ) 

 summer

 Alternative forms
 [ edit ] 

 تابستون ( tâbestun ) ( dialectal , Tehrani ) 

 توسون ( tovessun ) ( dialectal , Shiraz ) [ 1 ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭲𐭠𐭯𐭮𐭲𐭠𐭭 ( tʾpstʾn /⁠tābestān⁠/ ) . By surface analysis , تاب ( tâb , “ heat ” ) +‎ ـستان ( estân ) .
