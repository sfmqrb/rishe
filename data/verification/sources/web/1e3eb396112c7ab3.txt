 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( ’ndwh /⁠andōh⁠/ , “ sorrow ” ) . Noun form of the verb اندوهیدن . 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔan.ˈdoːh/ 

 ( Dari, formal ) IPA ( key ) : [ʔän̪.d̪oːʱ] 

 ( Dari, formal ) IPA ( key ) : [ʔän̪.d̪oːʱ] 
 ( Kabuli ) IPA ( key ) : [ʔän̪.d̪oː]

 Noun
 [ edit ] 

 اندوه • ( andōh / anduh ) ( Tajik spelling андӯҳ ) 

 sorrow , sadness , melancholy 
 Synonyms: غم ( ġam ) , غصه ( ġussa  / ġosse ) , حزن ( huzn  / hozn ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 2611: چون بر او بنشست زین اندوه گرد / بر همه شاهان عالم رحم کرد čun bar ō binišast z-īn andōh gard / bar hama shāhān-i alām rahm kard Since dust settled on him from this sorrow , he [Solomon] had compassion for all the kings of the world.
