 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek Ὠκεανός ( Ōkeanós ) . Doublet of قَامُوس ( qāmūs ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔuːq.jaː.nuːs/ 

 Noun
 [ edit ] 

 أُوقْيَانُوس • ( ʔūqyānūs )  ? 

 ( archaic ) ocean
