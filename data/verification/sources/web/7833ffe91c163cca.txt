 Arabic
 [ edit ] 

 Root 

 ر و ض ( r w ḍ ) 

 7 terms 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /raw.dˤa/ 

 Noun
 [ edit ] 

 رَوْضَة • ( rawḍa )  f ( plural رَوْضَات ( rawḍāt ) or رِيَاض ( riyāḍ ) ) 

 garden , meadow 
 609–632 CE , Qur'an , 30:15 : فَأَمَّا الَّذِينَ آمَنُوا وَعَمِلُوا الصَّالِحَاتِ فَهُمْ فِي رَوْضَةٍ يُحْبَرُونَ faʔammā llaḏīna ʔāmanū waʕamilū ṣ-ṣāliḥāti fahum fī rawḍatin yuḥbarūna And as for those who had believed and done righteous deeds, they will be in a garden [of Paradise], delighted. 

 kindergarten

 Gulf Arabic
 [ edit ] 

 Root 

 ر و ض 

 1 term 

 Etymology
 [ edit ] 

 Inherited from Arabic رَوْضَة ( rawḍa ) .

 Pronunciation
 [ edit ] 

 ( Kuwait ) IPA ( key ) : /ˈroː.ðˤə/ 

 Noun
 [ edit ] 

 روضة • ( rōḏ̣a )  f ( plural روضات ( rōḏ̣āt ) ) 

 kindergarten 
 فاطمة بالروضة صارت ولا للحينها بالحضانة؟ Is Fatma in kindergarten now or is she still in the nursery?
