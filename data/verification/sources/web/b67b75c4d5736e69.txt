 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek νᾶνος ( nânos , “ dwarf ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈnaː.nʊs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈnaː.nus] 

 Noun
 [ edit ] 

 nānus   m ( genitive nānī ) ; second declension 

 dwarf 

 ( transferred ) small horse
