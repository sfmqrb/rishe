 Verb
 [ edit ] 

 هَاوَنَ • ( hāwana ) III ( non-past يُهَاوِنُ ( yuhāwinu ) , verbal noun مُهَاوَنَة ( muhāwana ) ) 

 to be engaged in what is easy , to do what one finds brings ease or is easiest to do, to be one without stress or only doing what comes easy 

 to be self-indulgent , to adopt an epicurean mindset, to engage in contemptible or trifling activities

 to be gentle on (someone)

 Etymology 2
 [ edit ] 

 Borrowed from Middle Persian [script needed] ( hʾwn' /⁠hāwan⁠/ , “ mortar ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /haː.wun/ 

 Noun
 [ edit ] 

 هَاوُن • ( hāwun )  m ( plural أَهْوَان ( ʔahwān ) or هَوَاوِين ( hawāwīn ) ) 

 mortar ( tool used with a pestle ) 
 Synonyms: مِهْرَاس ( mihrās ) , جُرْن ( jurn ) , نِجْر ( nijr ) 

 mortar ( weapon )

 Etymology 1
 [ edit ] 

 یک هاون یونانی برنزی و دسته‌اش 
Mortar and Pestle from bronze alloy, Greece. 
 Inherited from Middle Persian [script needed] ( hʾwn' /⁠hāwan⁠/ , “ mortar ” ) .

 Alternative forms
 [ edit ] 

 هونگ ( havang ) , ( Dari ) هاوان ( hāwān ) 

 Noun
 [ edit ] 

 هاون • ( hāwan / hâvan ) ( Tajik spelling ҳован ) 

 mortar ( tool used with pestle ) 

 ( by extension ) pestle and mortar 

 Derived terms
 [ edit ] 

 دسته‌هاون ( dasta-hāwan  / daste-hâvan , “ pestle ” , literally “ mortar handle ” ) 

 آب در هاون کوبیدن ( āb dar hāwan kōbīdan  / âb dar hâvan kubidan , “ to beat a dead horse ” , literally “ to grind water in a mortar ” )

 Noun
 [ edit ] 

 هاون • ( hāwan / hâvan ) ( Tajik spelling ҳован ) 

 ( Zoroastrianism ) The first ritual division of the 24-hour day, spanning from sunrise to noon and accompanied by the prayer هوانگاه ( hawāngāh  / havângâh ) .
