 Noun
 [ edit ] 

 زیور • ( zēwar / zivar ) ( Tajik spelling зевар ) 

 ornament , decoration 
 Synonyms: آرایش ( ārāyiš  / ârâyeš ) , آذین ( āzīn  / âzin ) , زیب ( zēb  / zib ) , پیرایش ( pīrāyiš  / pirâyeš ) , تزیین ( tazyīn  / tazyin ) , زینت ( zīnat  / zinat )

 Etymology
 [ edit ] 

 Borrowed from Classical Persian زیور ( zēwar ) , related to زیبیدن ( zēbīdan ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /zeː.ʋəɾ/ 

 Rhymes: -əɾ 

 Hyphenation: زے‧وَر 

 Noun
 [ edit ] 

 زیوَر • ( zevar )  m ( formal plural زیوَرَات ( zevarāt ) , Hindi spelling ज़ेवर ) 

 jewellery , ornament 

 ( figuratively ) grounds for adornment
