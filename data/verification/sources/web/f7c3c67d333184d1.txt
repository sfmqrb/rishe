 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 أَنْبِيق ( ʔanbīq ) 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek ἄμβιξ ( ámbix ) , allegedly via Classical Syriac .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔin.biːq/ 

 Noun
 [ edit ] 

 إِنْبِيق • ( ʔinbīq )  m ( plural أَنَابِيق ( ʔanābīq ) ) 

 retort , still , alembic
