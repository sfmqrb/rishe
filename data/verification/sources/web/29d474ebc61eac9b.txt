 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From گل ( gul ) +‎ شن ( šan ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡul.ˈʃan/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊl.ʃän] 

 ( Dari, formal ) IPA ( key ) : [ɡʊl.ʃän] 
 ( Kabuli ) IPA ( key ) : [ɡʊl.ʃän] 

 ( Hazaragi ) IPA ( key ) : [ɡul.ʃän] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥ol.ʃæn] 

 ( Tajik, formal ) IPA ( key ) : [ɡul.ʃän]

 Noun
 [ edit ] 

 گلشن • ( gulšan / golšan ) ( Tajik spelling гулшан ) 

 ( archaic ) flowerbed ; rose-garden 
 Synonyms: چَمَن ( čaman ) , گُلِسْتَان ( gulistān ) , گُلْزَار ( gulzār ) , خِیَابَان ( xiyābān )

 Urdu
 [ edit ] 

 گُلشَن 
 Etymology
 [ edit ] 

 Borrowed from Classical Persian گُلْشَن ( gulšan ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɡʊl.ʃən/ 

 Noun
 [ edit ] 

 گُلْشَن • ( gulśan )  m ( Hindi spelling गुलशन ) 

 flower garden ; rose-garden ; garden 
 Synonyms: چَمَن ( caman ) , گُلِسْتَان ( gulistān ) , گُلْزَار ( gulzār ) , خِیَابَان ( xiyābān ) 
 جنگجو کا گُلْشَن ہے فردوس۔ jangjū kā gulśan hai firdaus. the highest heaven is the warrior's garden . 

 flowerbed 

 a place of joy and happiness
