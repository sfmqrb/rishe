 English
 [ edit ] 

 Taj Mahal in 2004. 
 Etymology
 [ edit ] 

 From Hindustani ताज महल / تاج محل ( tāj mahal , “ crown of palaces ” ) , from Classical Persian , ultimately from Arabic, corresponding to English taj + mahal .

 Pronunciation
 [ edit ] 

 ( South Asia ) IPA ( key ) : /t̪ɑd͡ʒ mɛhɛl/ 

 ( UK , US ) 
 ( hyperforeign ) IPA ( key ) : /ˌtɑːʒ məˈhɑːl/ [ 1 ] 

 IPA ( key ) : /ˌtɑːdʒ məˈhɑːl/ 

 Audio ( Southern England ) : ( file ) 

 The first pronunciation is hyperforeign , but most common.

 Proper noun
 [ edit ] 

 the Taj Mahal 

 A monument in Agra , India , constructed between 1631 and 1654, considered one of the finest examples of Mughal architecture in the world.
