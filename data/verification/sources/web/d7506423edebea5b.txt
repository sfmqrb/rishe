 Chagatai

 Etymology
 [ edit ] 

 Borrowed from Classical Persian خَاک ( xāk , “ soil ” ) .

 Noun
 [ edit ] 

 خاک • ( ḫāk ) 

 soil , earth , dirt 
 Synonyms: تراب ( türāb ) , توفراق ( tofraq ) , گرد ( gärd ) 
 خاک پای ― ḫāk-i pāy ― the dirt of the foot 

 ash , ashes 
 Synonym: کول ( kül ) 

 dust

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( hʾk' /⁠xāk⁠/ ) , ultimately from Proto-Indo-European *h₂eHs- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈxaːk/ 

 ( Dari, formal ) IPA ( key ) : [xɑːk] 

 ( Dari, formal ) IPA ( key ) : [xɑːk] 
 ( Kabuli ) IPA ( key ) : [xɑːk] 

 ( Hazaragi ) IPA ( key ) : [xɔːɡ̥] 

 ( Iran, formal ) IPA ( key ) : [xɒːkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [χɔk] 

 Rhymes: -aːk
