 Azerbaijani
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کوشک ( “ palace, portico ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [cœʃc] 

 Noun
 [ edit ] 

 köşk ( definite accusative köşkü , plural köşklər ) 

 arbor , gazebo , pavilion ( a shady place for sitting ) 

 kiosk 

 ( archaic ) palace 

 ( archaic ) summer mansion 

 References
 [ edit ] 

 Orucov, Əliheydər , editor ( 2006 ), “köşk”, in Azərbaycan dilinin izahlı lüğəti [ Explanatory Dictionary of the Azerbaijani Language ]‎ [1] (in Azerbaijani), 2nd edition, volume 2, Baku: Şərq-Qərb

 [ edit ]

 Pronunciation

 köşk ( definite accusative köşkü , plural köşkler )
