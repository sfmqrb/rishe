 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From تنک ( tonok , “ thin, flimsy ” ) +‎ ـه ( -e ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /tu.nu.ˈka/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊ.nʊ.kʰá] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊ.nʊ.kʰá] 
 ( Kabuli ) IPA ( key ) : [t̪ʰʊ.nʊ.kʰá] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰu.nu.kʰá] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰo.no.kʰʲé] 

 ( Tajik, formal ) IPA ( key ) : [t̪ʰu.nu.kʰá] 

 Rhymes: -a

 Noun
 [ edit ] 

 تنکه • ( tonoke ) 

 wrestler 's shorts 

 ( dated ) underwear , underclothing 

 ( dated ) thin sheet of metal
