 Adjective
 [ edit ] 

 شوخ • ( šōx / šux ) ( Tajik spelling шӯх ) 

 shameless , saucy , brazen 

 jocose , jovial , gay 

 Derived terms
 [ edit ] 

 شوخی ( šôxi , “ shamelessness; joke ” ) 

 شوخ‌چشم ( šôx-češm , “ shameless ” ) 

 شوخ‌روی ( šôx-rôy , “ shameless ” ) 

 Noun
 [ edit ] 

 شوخ • ( šōx / šux ) ( Tajik spelling шӯх ) 

 filth , muck 

 pus 

 Alternative forms
 [ edit ] 

 شوغ ( šôġ ) , شخ ( šox )
