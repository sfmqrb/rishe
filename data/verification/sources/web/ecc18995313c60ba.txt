 Alternative forms

 اردبهشت ( ardbehešt ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐭠𐭥𐭲𐭥𐭧𐭱𐭲𐭩 ( Ardwahišt ) , “right”; name of the second Amahraspand (divine deity) in Zoroastrianism. Compare ارد ( ard , “ truth ” ) and بهشت ( bihišt  / behešt , “ heaven ” ) .

 Proper noun
 [ edit ] 

 اردیبهشت • ( urdībihišt  / ordibehešt ) ( Tajik spelling урдибиҳишт ) 

 Ordibehesht ( the second solar month of the Persian calendar ) 

 Name of the third day of any month of the solar Persian calendar.
