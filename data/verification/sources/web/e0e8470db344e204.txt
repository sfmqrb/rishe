 Persian کام 

 From Middle Persian 𐭠‎𐭬‎𐭪 ( kʾm ) , 𐫐𐫀𐫖 ( kʾm /⁠kām⁠/ , “ will, desire, purpose ” ) , from Old Persian 𐎣𐎠𐎶 ( k-a-m /⁠kāmaʰ⁠⁠/ ) , from Proto-Iranian *káHmah , from Proto-Indo-Iranian *káHmas , from Proto-Indo-European *kóh₂mos , from Proto-Indo-European *keh₂- ( “ to desire, wish ” ) .

 Urdu
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /kɑːm/ 

 Audio : ( file ) 

 Rhymes: -ɑːm 

 Etymology 1
 [ edit ] 

 Inherited from Sauraseni Prakrit 𑀓𑀫𑁆𑀫 ( kamma ) , from Sanskrit कर्मन् ( karman ) . Cognate with Punjabi کَمّ ( kamm ) , Doublet of کار ( kār ) 

 Noun
 [ edit ] 

 کام • ( kām )  m ( Hindi spelling काम ) 

 task , action , work 
 آپ کا کام یہ ہے ― āp kā kām yih hai ― This is your task ... 

 employment , job 
 Synonym: نوکری ( naukarī ) 
 آج کل میں کام ڈھونڈ رہا ہوں۔ āj kal ma͠i kām ḍhūnḍ rahā hū̃ These days I'm looking for a job . 

 favour , chore 
 میرے لئے ایک کام کرنا ― mere liye aik kām karnā ― do me a favour ... 

 function , purpose 
 Synonym: مقصد ( maqsad ) 
 یہ مشین گھاس کاٹنے کا کام دے گی۔ yih maśīn ghās kāṭne kā kām de gī. This machine will serve as the grass cutter. 

 ( poetry , figuratively ) deed , work , attribute 
 محمد ہی نام اور محمد ہی کام muḥammad hī nām aur muḥammad hī kām Muhammad - admired is his name; admired are his deeds
