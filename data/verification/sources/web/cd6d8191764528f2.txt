 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Uncertain. Perhaps a reduplicated form of Proto-Indo-European *leh₂- , with cognates including Latin lallō , Lithuanian laluoti , German lallen , English loll , and Welsh llolian . Could also simply be onomatopoeic. Beekes notes that the suffix -έω ( -éō ) is also present in other verbs pertaining to sound, such as κελαδέω ( keladéō ) and βομβέω ( bombéō ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /la.lé.ɔː/ → /laˈle.o/ → /laˈle.o/ 

 ( 5 th BCE Attic ) IPA ( key ) : /la.lé.ɔː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /laˈle.o/ 

 ( 4 th CE Koine ) IPA ( key ) : /laˈle.o/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /laˈle.o/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /laˈle.o/ 

 Verb
 [ edit ] 

 λᾰλέω • ( lăléō ) 

 to talk , chat , prattle 
 to talk, speak 

 to chatter , chirp 

 to make sound
