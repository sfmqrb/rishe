 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit जीर्ण ( jīrṇa ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /d͡ʒiːɾɳ/ 

 Adjective
 [ edit ] 

 जीर्ण • ( jīrṇ ) 

 old , ancient , aged 
 Synonyms: पुराना ( purānā ) , प्राचीन ( prācīn ) , वृद्ध ( vŕddh ) 

 decayed , decrepit , worn out , dilapidated 
 Synonyms: जर्जर ( jarjar ) , शिथिल ( śithil ) 
 Antonyms: नूतन ( nūtan ) , नया ( nayā ) , नवीन ( navīn ) 

 shattered , broken , tattered 

 Noun
 [ edit ] 

 जीर्ण • ( jīrṇ )  m 

 digestion 

 old age 

 benzoin

 Etymology
 [ edit ] 

 From Proto-Indo-European *ǵr̥h₂-nó-s , from *ǵerh₂- ( “ to grow old, mature ” ) . Doublet of जूर्ण ( jūrṇá ) . The Sanskrit root is जॄ ( jṝ ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /d͡ʑiːɾ.ɳɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /d͡ʑiːɾ.ɳɐ/ 

 Adjective
 [ edit ] 

 जी॒र्ण • ( jīrṇá ) stem 

 old , aged 
 Synonyms: सन॑ ( sána ) , लाट ( lāṭa ) , जर ( jara ) , स्थविर ( sthavira ) 
 c. 1200 BCE – 1000 BCE , Atharvaveda 10.8.27 : त्वं स्त्री त्वं पुमान् असि त्वं कुमार उत वा कुमारी॥
त्वं जीर्णो दण्डेन वञ्चसि त्वं जातो भवसि विश्वतोमुखः ॥ tvaṃ strī tvaṃ pumān asi tvaṃ kumāra uta vā kumārī.
tvaṃ jīrṇo daṇḍena vañcasi tvaṃ jāto bhavasi viśvatomukhaḥ. (O Supreme Being) You are a woman, and a man; you are a maiden and a boy.
 Grown old , you totter with a staff, new-born you look every way. 

 c. 800 CE , Śankarācāryaḥ, Commentary to the Bhagavad-Gītā 2.22: वासांसि जीर्णानि यथा विहाय नवानि गृह्णाति नरो ऽपराणि 
 तथा शरीराणि विहाय जीर्णान्य् अन्यानि संयाति नवानि देही vāsāṃsi jīrṇāni yathā vihāya navāni gṛhṇāti naro ʼparāṇi 
 tathā śarīrāṇi vihāya jīrṇāny anyāni saṃyāti navāni dehī As old clothes are cast away and new ones are in its turn grabbed by man 
 So old bodies are cast (by a soul) going to a new body 

 worn out , decayed 
 Synonyms: जिव्रि ( jivri ) , निरमण ( niramaṇa ) , प्रहीण ( prahīṇa ) , क्षित ( kṣita ) 

 digested
