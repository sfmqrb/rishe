 Central Kurdish
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *náymah , from Proto-Indo-Iranian *náymas ( “ half ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /niːu̯/ 

 Noun
 [ edit ] 

 Northern Kurdish

 nîv 

 نیو ( nîw ) 

 half 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐭭𐭩𐭥 ( nyw /⁠nēw⁠/ , “ good, brave, valiant ” ) , from Old Persian 𐎴𐎡𐎲 ( n-i-b /⁠naibaʰ⁠/ , “ blessed ” ) , from Proto-Iranian *naybah ( “ fortunate, blessed ” ) . [ 1 ] [ 2 ] [ 3 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈneːw/ 

 ( Dari, formal ) IPA ( key ) : [neːw] 

 ( Dari, formal ) IPA ( key ) : [neːw] 
 ( Kabuli ) IPA ( key ) : [neːw] 

 ( Hazaragi ) IPA ( key ) : [neːw] 

 ( Iran, formal ) IPA ( key ) : [niːv] 

 ( Tajik, formal ) IPA ( key ) : [new] 

 Rhymes: -eːw 

 Readings

 Adjective
 [ edit ] 

 نیو • ( niv ) ( comparative نیوتَر , superlative نیوتَرین ) 

 ( archaic ) brave , valiant
