 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 أُنْبُوبَة ( ʔunbūba ) 

 Etymology
 [ edit ] 

 From Aramaic אַבּוּבָא / ܐܰܒܽܘܒܐ ( ʾabbūḇā , “ flute ; pipe ” ) , from Akkadian 𒄀𒁍 ( enbūbu , “ flute ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔun.buːb/ 

 Noun
 [ edit ] 

 أُنْبُوب • ( ʔunbūb )  m ( plural أَنَابِيب ( ʔanābīb ) ) 

 tube , pipe 

 nozzle
