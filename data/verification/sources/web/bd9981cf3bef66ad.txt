 Central Kurdish
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *pawHākáh , from Proto-Indo-Iranian *pawHākás , from Proto-Indo-European *pewH- .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /paːk/ 

 Adjective
 [ edit ] 

 پاک ( pak ) 

 clean , pure 
 Synonym: خاوێن ( xawên ) 

 chaste 

 innocent , clean-handed , sinless

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( pʾk' /⁠pāk⁠/ , “ clean, pure, holy ” ) , from Proto-Iranian *pawHākáh , from Proto-Indo-Iranian *pawHākás , from Proto-Indo-European *pewH- ( “ to cleanse, purify ” ) . Cognate with Sanskrit पावक ( pāvaká , “ pure, clean, clear ” ) , Latin purus .

 Urdu
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /pɑːk/ 

 Rhymes: -ɑːk 

 Etymology 1
 [ edit ] 

 Etymology tree

 Proto-Indo-European *pewH- 
 Classical Persian پَاک ( pāk ) bor. 
 Urdu پاک 

 Borrowed from Classical Persian پَاک ( pāk ) . First attested in c. 1265 as Old Hindi پاک ( pak /⁠pāk⁠/ ) . [ 1 ] 

 Adjective
 [ edit ] 

 پَاک • ( pāk ) ( indeclinable , Hindi spelling पाक ) 

 clean , pure 

 Etymology 2
 [ edit ] 

 Shortening of پَاکِسْتَان ( pākistān ) , itself from پاک ( pāk ) +‎ ـِسْتَان ( -istān ) .

 Noun
 [ edit ] 

 پَاک • ( pāk )  m ( Hindi spelling पाक ) 

 clipping of پاکستان ( “ Pakistan ” ) 
 پاک فَوج ― pāk fauj ― Pakistan army
