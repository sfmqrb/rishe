 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( bʾlyn' /⁠balēn⁠/ , “ cushion; pillow ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /baː.ˈliːn/ 

 ( Dari, formal ) IPA ( key ) : [bɑː.líːn] 

 ( Dari, formal ) IPA ( key ) : [bɑː.líːn] 
 ( Kabuli ) IPA ( key ) : [bɑː.líːn] 

 ( Hazaragi ) IPA ( key ) : [bɔː.lín] 

 ( Iran, formal ) IPA ( key ) : [bɒː.líːn] 

 ( Tajik, formal ) IPA ( key ) : [bɔ.lín] 

 Rhymes: -iːn 

 Readings

 Noun
 [ edit ] 

 بالین • ( bālīn / bâlin ) ( Tajik spelling болин ) 

 ( archaic ) pillow 
 Synonyms: see بالش
