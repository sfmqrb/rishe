 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit प्राण ( prāṇa ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /pɾɑːɳ/ , [pɾä̃ːɳ] 

 Noun
 [ edit ] 

 प्राण • ( prāṇ )  m ( Urdu spelling پراݨ ) 

 vitality , life , spirit , animation 
 Synonyms: जान ( jān ) , दम ( dam ) 
 उसके शरीर में कोई प्राण नहीं रहा। uske śarīr mẽ koī prāṇ nahī̃ rahā. There was no life left in his body. 

 ( chiefly in compounds ) breath

 Marathi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit प्राण ( prāṇa ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pɾaɳ/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 प्राण • ( prāṇ )  m 

 life , spirit , life force 
 Synonym: जीव ( jīv ) 
 त्याचे प्राण संकटात घालू नकोस! tyāce prāṇ saṅkṭāt ghālū nakos! Do not put his life in danger! 

 ( figuratively ) air , wind 

 ( poetic ) dearly loved

 Etymology
 [ edit ] 

 प्र- ( pra- ) +‎ अन ( aná ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /pɾɑː.ɳɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /pɾɑː.ɳɐ/ 

 Noun
 [ edit ] 

 प्रा॒ण • ( prāṇá ) stem ,  m 

 breath , respiration , the breath of life, vitality , life , vital air (usually plural in this sense) 
 c. 1500 BCE – 1000 BCE , Ṛgveda 

 the first of the five life-winds or vital airs, which has its seat in the lungs (the other four being अपान ( apāna ) , समान ( samāna ) , व्यान ( vyāna ) and उदान ( udāna ) )

 wind , inhaled air

 energy , vigor , strength , power (as in प्राणसार ( prāṇasāra ) )

 the spirit or soul (as opposed to शरीर ( śarīra ) )

 the Supreme Spirit (see आत्मन् ( ātman ) )
