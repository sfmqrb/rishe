 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ʾh(y)n' /⁠āhan⁠/ , “ iron ” ) , from Proto-Iranian *Hácwā .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ˈhan/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ɦän] 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ɦän] 
 ( Kabuli ) IPA ( key ) : [ʔɑːjn] , [ʔɑːän] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.ji]
