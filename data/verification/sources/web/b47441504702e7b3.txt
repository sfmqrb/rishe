 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Etymology 1
 [ edit ] 

 Root
 [ edit ] 

 *bʰeyh₂- [ 1 ] 

 to shake , tremble 
 Synonyms: *tres- , *trem- 

 to fear , be afraid 
 Synonyms: *bʰeyh₂- , *dwey- 

 Alternative reconstructions
 [ edit ] 

 *bʰey- [ 2 ] 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *bʰeyh₂- (fear) (30 c, 0 e) 

 *bʰéyh₂-e-tor ~ *bʰéyh₂-o-ntor ( mediopassive root present ) [ 1 ] 
 Proto-Indo-Iranian: *bʰáyHatay ( see there for further descendants )

 *bʰéyh₂-dʰe-ti ( dʰe-present ) 
 Proto-Balto-Slavic: 
 Latvian: baĩdît 

 Lithuanian: baidýti 

 Old Prussian: pobaiint 

 ⇒ Proto-Balto-Slavic: *baiˀsás ( “ demon, evil spirit ” ) 

 Proto-Italic: *foiðō 
 ⇒ Proto-Italic: *foiðos 
 Latin: foedus ( see there for further descendants )

 *bʰéyh₂-t ~ *bʰih₂-ént ( athematic root aorist ) [ 1 ] 
 Proto-Indo-Iranian: *bʰáyHt 
 Proto-Indo-Aryan: *bʰáyHt 
 Sanskrit: भेम ( bhema , 1pl.inj.act. ) 

 *bʰe-bʰóyh₂-e ~ *bʰe-bʰih₂-ḗr ( reduplicated stative ) [ 1 ] 

 *bʰih₂-mó-s

 *bʰih₂-tó-s 
 Proto-Indo-Iranian: *bʰiHtás ( see there for further descendants )

 Etymology 2
 [ edit ] 

 Possibly connected with *bʰeyh₂- ( “ to shake; to fear ” ) above, as a semantic relationship between “shake” and “strike” is widely paralleled.

 Root
 [ edit ] 

 *bʰeyh₂- [ 1 ] 

 to strike , hit 
 Synonyms: *gʷʰen- , *bʰerH- 

 to hew , cut 

 Alternative reconstructions
 [ edit ] 

 *bʰeyH- [ 2 ] [ 3 ] 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *bʰeyh₂- (strike) (37 c, 0 e) 

 *bʰi-né-h₂-ti ( nasal-infix present ) [ 2 ] [ 4 ] 
 Proto-Celtic: *binati ( “ to strike, hit ” ) [ 5 ] ( see there for further descendants )

 Proto-Italic: *finō [ 6 ] 
 Latin: *perfinō ( “ I break ” ) , perfinēs ( 2p.sing.pres.act.subj. ) 

 *bʰih₂-yé-ti [ 2 ] 
 Proto-Balto-Slavic: *bī́ˀtei ( “ to beat ” ) [ 7 ] ( or present stem derived from aorist ) 
 Proto-Slavic: *bìti , *bьjǫ ( 1sg.pres. ) ( see there for further descendants )

 *bʰih₂-éh₁ye-ti ( eh₁-stative ) [ 4 ] 
 Proto-Germanic: *bijēną , *biēną ( “ to hit ” ) [ 4 ]

 *bʰḗyh₂-s-t ~ *bʰéyh₂-s-n̥t [ 2 ] 
 Proto-Balto-Slavic: 
 Proto-Slavic: *bi(tъ) ( 3sg.aor. ) , *bišę ( 3pl.aor. ) 

 *bʰih₂-tró-s [ 4 ] [ 8 ]

 Ancient Greek: φιτρός ( phitrós , “ trunk, log ” ) 

 *bʰih₂-tweh₂ [ 7 ] [ 4 ]

 Proto-Slavic: *bìtva ( “ a battle, fight ” ) [ 7 ] ( see there for further descendants )
