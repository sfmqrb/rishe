 English
 [ edit ] 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *nana- der. ? 
 Latin nonnus 
 Late Latin nonna 
 Italian nonna bor. 
 English nonna 

 Borrowed from Italian nonna . Doublet of nun .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈnɒnə/ , /ˈnɔːnə/ , /ˈnoʊnə/ 

 Audio ( Southern England ) : ( file ) 

 Rhymes: -ɒnə , -ɔːnə , -əʊnə 

 Noun
 [ edit ] 

 nonna ( plural nonnas ) 

 ( informal ) A grandmother , especially one with Italian ancestry.
 2009 July 29, Alex Witchel, “Borscht: What Would Nana Say?”, in New York Times ‎ [1] : An article last month in The Daily News talked about Enoteca Maria, a restaurant in Staten Island that has no professional chef, just a rotating roster of eight nonnas , or grandmothers, from different regions of Italy.

 [ edit ]

 Dutch
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Malay nyonya .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈnɔ.naː/ 

 Audio : ( file ) 

 Hyphenation: non‧na 

 Noun
 [ edit ] 

 nonna   f ( plural nonna's , diminutive nonnaatje   n or nonnie   n ) 

 ( Indonesia , Netherlands , historical ) a (young) woman of mixed Indonesian / Malay and European descent
 Hypernym: Indo 
 Coordinate term: sinjo 

 ( historical ) a young lady , a miss
