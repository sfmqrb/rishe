 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ottoman Turkish اسكله ( iskele ) , from Italian scala .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔis.ka.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [ʔɪs.kʰä.lá] 

 ( Dari, formal ) IPA ( key ) : [ʔɪs.kʰä.lá] 
 ( Kabuli ) IPA ( key ) : [ʔɪs.kʰä.lá] 

 ( Hazaragi ) IPA ( key ) : [ʔis.kʰä.lá] 

 ( Iran, formal ) IPA ( key ) : [ʔes.kʰʲe.lé] 

 ( Tajik, formal ) IPA ( key ) : [ʔis.kʰä.lá] 

 Rhymes: -a

 Noun
 [ edit ] 

 اسکله • ( iskala / eskele ) ( Tajik spelling искала ) 

 pier , wharf , quay
