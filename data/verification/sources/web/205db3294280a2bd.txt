 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 فسردن ( fesordan ) ( poetic ) 

 Etymology
 [ edit ] 

 From Middle Persian ʾpsltn' ( absardan , “ to cool down ” ) . Compare Middle Persian slt' ( “ cold ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaf.sur.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [ʔäf.sʊɾ.d̪án] 

 ( Dari, formal ) IPA ( key ) : [ʔäf.sʊɾ.d̪án] 
 ( Kabuli ) IPA ( key ) : [ʔäf.sʊɾ.d̪án] 

 ( Hazaragi ) IPA ( key ) : [ʔäf.suɾ.d̪án] 

 ( Iran, formal ) IPA ( key ) : [ʔæf.soɹ.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [ʔäf.suɾ.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 افسردن • ( afsordan ) ( present stem افسر ( afsor ) ) 

 ( archaic ) to cool down ; freeze
