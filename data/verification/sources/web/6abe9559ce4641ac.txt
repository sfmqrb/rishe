 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 چیلانگر ( čilângar ) , چلینگر ( čelingar ) , جلانگر ( jelângar ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( cyl’ngl /⁠čēlāngar⁠/ ) . Equivalent to چیلان ( čilân , “ iron chain, lock, ring ” ) +‎ ـگر ( gar , “ -er ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /t͡ʃi.lin.ˈɡar/ 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰɪ.lɪŋ.ɡáɾ] 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰɪ.lɪŋ.ɡáɾ] 
 ( Kabuli ) IPA ( key ) : [t͡ʃʰɪ.lɪŋ.ɡáɾ] 

 ( Hazaragi ) IPA ( key ) : [t͡ʃʰi.liŋ.ɡáɾ] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰe.leɲ.ɡʲǽɹ] 

 ( Tajik, formal ) IPA ( key ) : [t͡ʃʰi.liŋ.ɡáɾ]

 چلنگر 

 Iranian Persian

 Tajik

 چِلِنْگَر • ( čelengar ) 

 a locksmith 
 Synonyms: قُفْلْ‌ساز ( qofl-sâz ) , کِلیدْساز ( kelid-sâz ) 

 ( archaic , obsolete ) a bladesmith
