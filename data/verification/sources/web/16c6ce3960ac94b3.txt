 ژاله 
 Etymology
 [ edit ] 

 From Proto-Indo-European *gʰelh₂d- ( “ ice ” ) . Cognate with Ancient Greek χάλαζα ( khálaza ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʒaː.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [ʒɑː.lá] 

 ( Dari, formal ) IPA ( key ) : [ʒɑː.lá] 
 ( Kabuli ) IPA ( key ) : [ʒɑː.lá] 

 ( Hazaragi ) IPA ( key ) : [ʒɔː.lá] 

 ( Iran, formal ) IPA ( key ) : [ʒɒː.lé] 

 ( Tajik, formal ) IPA ( key ) : [ʒɔ.lá] 

 Rhymes: -a
