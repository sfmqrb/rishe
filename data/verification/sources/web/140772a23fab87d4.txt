 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian قهرمان ( qahramân , “ hero ” ) .

 Noun
 [ edit ] 

 قهرمان • ( kahraman ) 

 hero , someone who possess great bravery 
 Synonyms: شاهباز ( şahbaz ) , قوچ ( koç ) , قوچاق ( koçak ) , یگیت ( yiğit )

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کهرمان ( kahramān ) 

 Etymology
 [ edit ] 

 From Classical Persian قهرمان ( qahramān ) , ultimately from a Middle Iranian administrative term. Compare Middle Persian [script needed] ( kār-framān , “ manager, overseer ” ) , from [script needed] ( kār , “ work, affair ” ) + [script needed] ( framān , “ command, order ” ) . Possible from کهرمان ( kahramān ) , a dialectal form of Middle Persian [Book Pahlavi needed] ( kʾlplmʾn /⁠kārframān⁠/ , “ overseer, manager ” ) , from Old Median *karhramāna- . 

 The attested Arabic قَهْرَمَان ( qahramān , “ superintendent, majordomo ” ) is usually derived through Aramaic from this Iranian word, which accounts for the initial قـ ( q- ) . The association with Arabic قَهْر ( qahr , “ subjugation, force, wrath ” ) is secondary.
