 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 لَاذَن ( lāḏan ) , لَدَان ( ladān ) , لَذَان ( laḏān ) 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek λᾱ́δᾰνον ( lā́dănon ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /laː.dan/ 

 Noun
 [ edit ] 

 لَادَن • ( lādan )  m 

 gum cistus 
 Synonym: قِسْتُوس ( qistūs )
