 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Traditionally derived from ῥέπω ( rhépō , “ to decline, descend ” ) , but perhaps not related to the verb.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /r̥ó.pa.lon/ → /ˈro.pa.lon/ → /ˈro.pa.lon/ 

 ( 5 th BCE Attic ) IPA ( key ) : /r̥ó.pa.lon/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈro.pa.lon/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈro.pa.lon/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈro.pa.lon/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈro.pa.lon/ 

 Noun
 [ edit ] 

 ῥόπᾰλον • ( rhópălon )  n ( genitive ῥοπᾰ́λου ) ; second declension 

 club , cudgel , mace shod with metal 
 Synonym: κορύνη ( korúnē ) 

 hunter 's staff 

 penis
