 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پیژاما ( pižâmâ ) , پیجامه ( pijâme ) 

 Etymology
 [ edit ] 

 Borrowed from British English pyjama , from Hindi पैजामा ( paijāmā ) / Urdu پائِجامَہ ( pāijāma ) , from Persian پایجامه ( pāyjāma ) , archaic form of پاجامه ( pājāma ) . Doublet of پاجامه .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /piː.ʒaː.ˈma/ 

 ( Dari, formal ) IPA ( key ) : [pʰiː.ʒɑː.má] 

 ( Dari, formal ) IPA ( key ) : [pʰiː.ʒɑː.má] 
 ( Kabuli ) IPA ( key ) : [pʰiː.ʒɑː.má] 

 ( Hazaragi ) IPA ( key ) : [pʰi.ʒɔː.má] 

 ( Iran, formal ) IPA ( key ) : [pʰiː.ʒɒː.mé] 

 ( Tajik, formal ) IPA ( key ) : [pʰi.ʒɔ.má] 

 Rhymes: -a

 Noun
 [ edit ] 

 پیژامه • ( pižâme ) ( plural پیژامه‌ها ) 

 pyjamas (clothes for wearing to bed and sleeping in)
