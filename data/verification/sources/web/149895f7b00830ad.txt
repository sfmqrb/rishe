 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 بیک ( beyk ) , بگ ( bag ) , بک ( bak ) 

 Etymology
 [ edit ] 

 Borrowed from Proto-Turkic *bēg via a Turkic language, perhaps ultimately from Middle Iranian , in which case it is a doublet of فغ ( faġ , “ idol; companion, friend ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈbeːɡ/ 

 ( Iran, formal ) IPA ( key ) : [bejɡʲ̥] , [bæɡʲ̥] , [bækʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [bek] 

 Rhymes: -eːɡ 

 Readings

 Classical reading ? 

 bēg

 Iranian reading ? 

 beyg, bag, bak

 Tajik reading ? 

 bek

 Noun
 [ edit ] 

 بیگ • ( bēg / beyg ) ( Tajik spelling бег ) 

 ( historical ) bey ; a former aristocratic title in Iran , Central Asia , South Asia and Turkey .

 [ edit ]
