 Alternative forms

 إِكْسِيرِين ( ʔiksīrīn ) 

 Etymology
 [ edit ] 

 Borrowed from Classical Syriac ܟܣܝܪܝܢ ( ksīrīn ) , from Ancient Greek ξηρίον ( xēríon , “ medicinal powder ” ) .

 Noun
 [ edit ] 

 إِكْسِير • ( ʔiksīr )  m ( plural أَكَاسِير ( ʔakāsīr ) ) 

 elixir
