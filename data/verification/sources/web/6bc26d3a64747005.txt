 Mazanderani

 Etymology

 Related to Zazaki bıne .

 Noun
 [ edit ] 

 بنه ( bëne ) 

 ground , soil , land 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From بن ( bon ) + ـه ( -e ) . Compare Old Armenian բնակ ( bnak ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bu.ˈna/ 

 ( Dari, formal ) IPA ( key ) : [bʊ.nä] 

 ( Dari, formal ) IPA ( key ) : [bʊ.nä] 
 ( Kabuli ) IPA ( key ) : [bʊ.nä] 

 ( Hazaragi ) IPA ( key ) : [bu.nä] 

 ( Iran, formal ) IPA ( key ) : [bo.ne] 

 ( Tajik, formal ) IPA ( key ) : [bu.nä] 

 Rhymes: -a 

 Readings

 Classical reading ? 

 buna

 Dari reading ? 

 buna

 Iranian reading ? 

 bone

 Tajik reading ? 

 buna

 Noun
 [ edit ] 

 بنه • ( bone ) 

 home appliances , household   apparatus ; baggage , impedimenta 
 Synonym: رخت ( raxt ) 

 home , shed , dwelling , abode 

 fundament , root
