 Persian

 Etymology 1
 [ edit ] 

 From French rouge à lèvres translated as رژ لب ( rož-e lab ) or رژلب ( rož-lab, rože-lab ) .

 Noun
 [ edit ] 

 رژ • ( rož ) 

 ( colloquial-un ) Short for رژ لب ( rož-e lab ) 
 Synonyms: رژ لب ( rož-e lab ) , ماتیک ( mâtik )
