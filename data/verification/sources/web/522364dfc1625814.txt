 Arabic

 Etymology 1
 [ edit ] 

 An Iranian borrowing: compare Persian کندک ( kandak ) , کنده ( kanda ) , Old Armenian քանդակ ( kʻandak ) (also from Iranian).

 Pronunciation
 [ edit ] 

 IPA ( key ) : /xan.da.qa/ 

 Verb
 [ edit ] 

 خَنْدَقَ • ( ḵandaqa ) Iq ( non-past يُخَنْدِقُ ( yuḵandiqu ) , verbal noun خَنْدَقَة ( ḵandaqa ) ) 

 to dig a trench , to make a trench 

 to dig a moat , to make a moat

 Ottoman Turkish
 [ edit ] 

 خندق 
 Etymology
 [ edit ] 

 Borrowed from Persian خندق ( xandaq ) , itself from Arabic خَنْدَق ( ḵandaq , “ trench, moat ” ) , ultimately from Middle Persian *handag .

 Noun
 [ edit ] 

 خندق • ( hendek ) ( definite accusative خندقی ( hendeki ) , plural خنادق ( henadik ) ) 

 ( military ) trench , a narrow excavation as used in warfare 
 Synonym: سپر ( siper ) 

 moat , fosse , a deep and defensive ditch normally filled with water 
 Synonym: صو خندقی ( su hendeki ) 

 ditch , trench , gutter , dyke , any long, shallow indentation dug to conduct water 
 Synonym: آرق ( ark ) ( irrigation ditch ) 

 Derived terms
 [ edit ] 

 برج خندقی ( burc hendeki , “ fosse, moat ” ) 
 دوه‌یه خندق آتلاتمق ( deveye hendek atlatmak , “ to force an obstinate man to do a thing ” , literally “ to make a camel leap a ditch ” ) 
 صو خندقی ( su hendeki , “ moat ” ) 
 صولی خندق ( sulu hendek , “ flooded trench ” ) 
 قورو خندق ( kuru hendek , “ dried ditch ” ) 
 یول خندقی ( yol hendeki , “ ditch at the side of a road ” )
