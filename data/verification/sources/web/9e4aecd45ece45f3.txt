 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ῐ̓́στωρ ( ĭ́stōr ) 

 ϝῐ́στωρ ( wĭ́stōr ) — Boeotian 

 Etymology
 [ edit ] 

 From Proto-Hellenic *wístōr , from Proto-Indo-European *wéydtōr ( “ knower, wise person ” ) , from *weyd- ( “ to see ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /hís.tɔːr/ → /ˈis.tor/ → /ˈis.tor/ 

 ( 5 th BCE Attic ) IPA ( key ) : /hís.tɔːr/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈ(h)is.tor/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈis.tor/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈis.tor/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈis.tor/ 

 Noun
 [ edit ] 

 ῐ̔́στωρ • ( hĭ́stōr )  m ( genitive ῐ̔́στορος ) ; third declension 

 judge ( one who knows the law and what is right ) 

 witness 

 wise man 

 Declension
 [ edit ] 

 Third declension of ὁ ῐ̔́στωρ ; τοῦ ῐ̔́στορος ( Attic )
