 Adjective
 [ edit ] 

 غَازٍ • ( ḡāzin ) ( informal غَازِي ( ḡāzī ) , feminine غَازِيَة ( ḡāziya ) , masculine plural غَازُون ( ḡāzūn ) , feminine plural غَازِيَات ( ḡāziyāt ) ) 

 active participle of غَزَا ( ḡazā ) 

 ( botany , zoology ) invasive 
 أَنْوَاع غَازِيَة ― ʔanwāʕ ḡāziya ― invasive species

 Etymology
 [ edit ] 

 A Turkic borrowing: compare Chagatai غاز ( ğaz ) , Ottoman Turkish قاز ( qaz ) , Azerbaijani qaz . [ 1 ] Ultimately from Proto-Turkic *kāŕ .
