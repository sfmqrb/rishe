 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 Inherited from Middle Persian [script needed] ( ʾstl /⁠astar⁠⁠/ ) , from Old Persian *asatarah , from Proto-Iranian *Hacwataráh , from Proto-Indo-Iranian *Haćwatarás .

 Noun
 [ edit ] 

 استر • ( astar ) ( Tajik spelling астар ) 

 mule ; hinny 
 Synonym: قاطر ( qātir  / ġâter ) 

 Alternative forms
 [ edit ] 

 ستر ( satar ) 

 Derived terms
