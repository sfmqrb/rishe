 Arabic

 Etymology 1
 [ edit ] 

 From the root د ي ن ( d y n ) . Compare Hebrew דן .

 Verb
 [ edit ] 

 دَانَ • ( dāna ) I ( non-past يَدِينُ ( yadīnu ) , verbal noun دَيْن ( dayn ) ) 

 to owe ( money ) 

 to borrow 

 to lend 

 to compel 

 to render contemptible 

 to submit , to yield , to obey

 Verb
 [ edit ] 

 دَانَ • ( dāna ) I ( non-past يَدِينُ ( yadīnu ) , verbal noun دَيْن ( dayn ) or دَيْنُونَة ( daynūna ) or دِين ( dīn ) ) , passive participle مَدِين ( madīn ) or مَدْيُون ( madyūn ) 

 to judge 
 609–632 CE , Qur'an , 37:53 : أَإِذَا مِتْنَا وَكُنَّا تُرَابًا وَعِظَامًا أَإِنَّا لَمَدِينُونَ ʔaʔiḏā mitnā wakunnā turāban waʕiẓāman ʔaʔinnā lamadīnūna ...after we die and become dust and bone, [that] we shall be brought for judgement?”’

 Derived terms
 [ edit ] 

 كَمَا تَدِينُ تُدَانُ ( kamā tadīnu tudānu , proverb , literally “ As you judge, you will be judged ” ) 

 Verb
 [ edit ] 

 دَانَ • ( dāna ) I ( non-past يَدِينُ ( yadīnu ) , verbal noun دِين ( dīn ) or دِيَانَة ( diyāna ) ) 

 ( intransitive ) to hold religion .

 Suffix
 [ edit ] 

 دان ( -dān ) 

 Forms nouns denoting a container or place (usually for the noun it is suffixed to).
 From زبڵ ( zibil , “ rubbish ” ) + -dān to form زبڵدان ( zibildan , “ dustbin, trash can ” ) . 
 خوێ ( xwe , “ salt ” ) + -dān to form خوێدان ( xwedān , “ salt shaker, salt container ” ) .
