 Etymology
 [ edit ] 

 Etymology tree

 Middle Persian lwʾk' ( /⁠ravāg⁠/ ) bor. 
 Arabic رَوَاج ( rawāj ) bor. 
 Persian رواج 

 Reborrowed from Arabic رَوَاج ( rawāj ) , from Middle Persian [script needed] ( lwʾk' /⁠ravāg⁠/ , “ going ” ) . Doublet of روا ( rawâ ) .

 Noun
 [ edit ] 

 رواج • ( rawāj / ravâj ) ( Tajik spelling равоҷ ) 

 prevalence , popularity 
 Hafiz :
 دهان شهد تو داده رواج آب خضر/لب چو قند تو برد از نبات مصر رواج (please add an English translation of this quotation)
