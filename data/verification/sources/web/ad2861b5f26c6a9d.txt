 Alternative forms

 یوز پلنگ ( yuzpalang ) 

 Etymology
 [ edit ] 

 From یوز ( yuz , “ cheetah, hunting dog ” ) + پلنگ ( palang , “ panther, leopard ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /joːz.pa.ˈlanɡ/ 

 ( Dari, formal ) IPA ( key ) : [joːz.pʰä.läŋɡ] 

 ( Dari, formal ) IPA ( key ) : [joːz.pʰä.läŋɡ] 
 ( Kabuli ) IPA ( key ) : [joːz.pʰä.läŋɡ] 

 ( Hazaragi ) IPA ( key ) : [jʊːz.pʰä.läŋɡ̥] 

 ( Iran, formal ) IPA ( key ) : [juːz.pʰæ.læɲɡʲ̥] 

 ( Tajik, formal ) IPA ( key ) : [jɵz.pʰä.läŋɡ]
