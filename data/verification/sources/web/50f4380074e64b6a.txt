 Ottoman Turkish
 [ edit ] 

 قیر 
 Etymology
 [ edit ] 

 Inherited from Proto-Turkic *kïr ( “ isolated mountain; steppe, wilderness ” ) .

 cognates

 Cognate with Azerbaijani qır , Bashkir ҡыр ( qır ) , Chuvash хир ( hir ) , Kazakh қыр ( qır ) , Kyrgyz кыр ( kır ) , Turkmen gyr , Uyghur قىر ( qir ) and Uzbek qir .

 Noun
 [ edit ] 

 قیر • ( kır ) ( definite accusative قیری ( kırı ) , plural قیرلر ( kırlar ) ) 

 steppe 
 Synonym: سته‌پ ( step ) 

 wilderness , waste 
 Synonym: یابان ( yaban ) 

 countryside 
 Synonym: كوی ( köy ) 

 Adjective
 [ edit ] 

 قیر • ( kır ) 

 grey 
 Synonym: بوز ( boz ) 

 uncultivated 

 Derived terms
 [ edit ] 

 قیر سرداری ( kır serdarı , “ chief of rural police ” ) 
 قیر شهری ( kır şehri , “ Kırşehir, a city and province in Turkey ” ) 
 قیرچیل ( kırçıl , “ somewhat mixed with grey ” ) 

 Related terms
 [ edit ] 

 قیراچ ( kıraç , “ uncultivated, left in fallow ” ) 

 Descendants
 [ edit ] 

 Turkish: kır 

 → Armenian: խըռ ( xəṙ ) , ղըռ ( ġəṙ ) 

 → Serbo-Croatian: kŕdža , кр́џа
