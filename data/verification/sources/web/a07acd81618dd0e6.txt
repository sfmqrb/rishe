 Etymology 1
 [ edit ] 

 Root 

 ق ل ب ( q l b ) 

 15 terms 

 Derived from قَلَبَ ( qalaba , “ to turn ” ) .
Alternatively, from Proto-Semitic *libb- ( “ heart ” ) , with the initial ق possibly being a phonological insertion to break a biconsonantal cluster and avoid * ∅alb or * ∅ulb , thus * lb → * ∅alb → qalb . See also Arabic لُبّ ( lubb ) , "core, heart, intellect", without q- as well.

 Pronunciation
 [ edit ] 

 ( heart ) : IPA ( key ) : /qalb/ Audio : ( file ) 

 ( to turn ) : IPA ( key ) : /qa.la.ba/ 

 ( to flip ) : IPA ( key ) : /qal.la.ba/ 

 ( skillful in turning ) : IPA ( key ) : /qul.lab/ 

 Noun
 [ edit ] 

 قَلْب • ( qalb )  m ( plural قُلُوب ( qulūb ) ) 

 verbal noun of قَلَبَ ( qalaba )   ( form I ) 

 heart (organ)

 heart ( the symbolic seat of human emotion ) 
 إِنَّمَا يُمْكِنُ لِلْإِنْسَانِ أَنْ يَرَى بِصُورَةٍ صَحِيحَةٍ مِنْ خِلَالِ قَلْبِهِ ؛ فَالْأُمُورَ الْجَوْهَرِيَّةِ غَيْرُ مُرَئِيَّةٍ لِلْعَيْنِ. ʔinnamā yumkinu lilʔinsāni ʔan yarā biṣūratin ṣaḥīḥatin min ḵilāli qalbihi ; fālʔumūra l-jawhariyyati ḡayru muraʔiyyatin lilʕayni. It is only with the heart that one can see rightly; what is essential is invisible to the eye.

 [ edit ] 

 قَلَّبَ • ( qallaba ) II ( non-past يُقَلِّبُ ( yuqallibu ) , verbal noun تَقْلِيب ( taqlīb ) ) 

 to turn , to flip , to roll over repeatedly
 قَلَّبَ صَفَحَاتِ الْكِتَابِ ― qallaba ṣafaḥāti l-kitābi ― He flipped through the book.

 Etymology 2
 [ edit ] 

 While it could be thought as from the root ق ل ب ( q l b ) due to being “ turned over ” or “ warped ” around the arm, Classical Syriac ܩܘܠܒܐ ( qulbā , “ bracelet ” ) is attested early and suggested as a source for this Arabic word, and as Aramaic lacks this root, Akkadian 𒄑𒆪𒌌𒁍 ( GIŠ qu 3 -ul-pu /⁠qulpu⁠/ , “ encasement, bark of wood ” ) is suggested as its source. The later sense may also be reflected in a different homophonic Akkadian 𒆰𒁍 ( qul-pu /⁠qulpu⁠/ , “ a type of barley ” ) .

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 From Arabic قَلْب ( qalb ) . 

 Noun
 [ edit ] 

 قلب • ( kalb ) ( definite accusative قلبی ( kalbi ) ) 

 heart (organ)
 1918 August 1, “ ماره‌شال آیخهرورن ایله یاورینه سوء قصد [ mareşal ayhhorn ile yaverine suikasd , Marshal Eichhorn and aide assassinated ]”, in İkdam ‎ [5] , Istanbul: فلدماره‌شال آیخهورن ۳۰ تموزده اقشام اوزری ساعت اونده ‌وفات ایتمشدر. مشارالیهك آلمش اولدیغی یاره‌لره علاوةٔ اقشام اوزری قلبی صیقیشمشدر. قلبك فعالیتنی ادامه ایچون اجرا اولنان مداوات یالكز موقت غاز یاپمشدر. فلد ماره‌شال آیخهورنك یاوری اولوب سوه‌قصداثناسنده یاره‌لنمش اولان یوزباشی (دره‌سله‌ر) کلب فلد ماره‌شالك وفاتندن بر آز اول فضله قان ضیاعندن طولایی ترك حیات ایلمشدر. feldmareşal ayhhorn 30 temmuzda akşam üzeri saat onda vefat etmiştir. müşarünileyhin almış olduğu yaralara ilave-i akşam üzeri kalbi sıkışmıştır. kalbin faaliyeti idame için icra olunan müdavat yalnız muvakkat gaz yapmıştır. feldmareşal ayhhornun yaveri olup yüzbaşı Dresler feldmareşalin vefatinden bir az o fazla kan zaya'indan dolayı terk heyat eylemiştir. (please add an English translation of this quotation) 

 ( figurative ) heart (center, essence, core)

 ( figurative ) heart (seat of emotion)
