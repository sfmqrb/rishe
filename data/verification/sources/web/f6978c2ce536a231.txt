 Persian

 Dari

 بیمار 

 Iranian Persian

 Tajik

 Etymology
 [ edit ] 

 From Middle Persian 𐭥𐭩𐭬𐭠𐭫 ( wēmār , “ sick, ill ” ) , from Proto-Indo-European *wemh₁- ( “ to spew, vomit ” ) + ār ( agent suffix ) . Cognate with Latin vomō ( “ be sick, vomit ” ) , Northern Kurdish bîvêr .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [beː.mɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [beː.mɑ́ːɾ]

 Noun
 [ edit ] 

 بیمار • ( bēmār, bīmār / bimâr, bimâr ) ( plural بیماران ( bēmārān, bīmārān / bimârân, bimârân ) , or بیمارها ( bēmār-hā, bīmār-hā / bimâr-hâ, bimâr-hâ ) , Tajik spelling бемор , or бемор ) 

 sick or ill person
 Synonyms: مریض ( mariz ) , ناخوش ( nâxoš ) , دردمند ( dardmand ) , ناتندرست ( nâtandorost ) 

 Derived terms
 [ edit ]

 [ edit ] 

 بیمار • ( bimâr ) ( comparative بیمارتَر , superlative بیمارتَرین )

 Etymology
 [ edit ]

 Adjective
 [ edit ]

 Synonyms: مَرِیض ( marīẓ ) , روگی ( rogī )
