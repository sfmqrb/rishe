 Persian

 Alternative forms
 [ edit ] 

 صحراء ( sahrā'  / sahrâ' ) 

 Etymology
 [ edit ] 

 Borrowed from Arabic صَحْرَاء ( ṣaḥrāʔ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /sah.ˈraː/ 

 ( Dari, formal ) IPA ( key ) : [säɦ.ɾɑ́ː] 

 ( Dari, formal ) IPA ( key ) : [säɦ.ɾɑ́ː] 
 ( Kabuli ) IPA ( key ) : [sɑː.ɾɑ́ː] 

 ( Hazaragi ) IPA ( key ) : [sɔː.ɾɔ́ː] 

 ( Iran, formal ) IPA ( key ) : [sæɦ.ɹɒ́ː] 

 ( Tajik, formal ) IPA ( key ) : [säɦ.ɾɔ́] 

 Rhymes: -aː

 Noun
 [ edit ] 

 صحرا • ( sahrā / sahrâ ) ( Tajik spelling саҳро ) 

 desert 
 Synonyms: بیابان ( biyâbân ) , هامون ( hâmun ) 

 plain 
 Synonym: دشت ( dašt )
