 Alternative forms
 [ edit ] 

 کوش ( kowš ) ( colloquial, Shiraz ) [ 1 ] 

 Etymology
 [ edit ] 

 From Middle Persian kpš ( kafš , “ shoe ” ) , with further origin uncertain. Akin to Old Armenian կօշիկ ( kōšik ) , Northern Luri کڢش ( kwṣ ) and Arabic قَفْش ( qafš ) , Iranian loanwords, as well as perhaps Old Armenian կապ ( kap , “ bond ” ) , which would seem to suggest potential derivation from some extension or compound of Proto-Indo-European *kap- ( “ to seize, hold ” ) , albeit with formal details unclear.

 کفش • ( kafš ) ( plural کفش‌ها ( kafš-hā / kafš-hâ ) , Tajik spelling кафш ) 

 a shoe 
 Synonym: بشماق ( bašmâq ) 

 a pair of shoes
 Synonym: جفت کفش ( joft-e kafš ) 

 Usage notes
 [ edit ] 

 One often uses the singular for a pair of shoes: این کفش ( in kafš , “ these shoes, this pair of shoes ” ) . This is different from the use of the singular for an indefinite number, which is possible with all nouns: کفش می‌فروشند ( kafš mi-forušand , “ they sell shoes ” ) .
