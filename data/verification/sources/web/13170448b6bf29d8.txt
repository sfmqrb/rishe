 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from French paquet . Compare Ottoman Turkish پاكت .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paː.ˈkat/ 

 ( Dari, formal ) IPA ( key ) : [pʰɑː.kʰät̪] 

 ( Dari, formal ) IPA ( key ) : [pʰɑː.kʰät̪] 
 ( Kabuli ) IPA ( key ) : [pʰɑː.kʰät̪] 

 ( Hazaragi ) IPA ( key ) : [pʰɔː.kʰät̪] 

 ( Iran, formal ) IPA ( key ) : [pʰɒː.kʰʲæt̪ʰ] 

 ( Tajik, formal ) IPA ( key ) : [pʰɔ.kʰät̪] 

 Rhymes: -at

 Noun
 [ edit ]
