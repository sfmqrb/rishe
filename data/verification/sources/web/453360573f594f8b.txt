 Etymology
 [ edit ] 

 Borrowed from Classical Persian مَرْیَم ( maryam ) , from Arabic مَرْيَم ( maryam ) , from Aramaic מרים ( maryam ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /məɾ.jəm/ , [mə.ɾɪ.jəm] 

 Rhymes: -əm 

 Proper noun
 [ edit ] 

 مَرْیَم • ( maryam )  f ( Hindi spelling मरियम ) 

 ( religion ) Mary ( the mother of Jesus ) 
 اِبْنِ مَرْیَم ― ibn-i maryam ― Jesus Christ (literally, “ son of Mary ”) 

 ( biblical ) Miriam ( the sister of Moses and Aaron and the daughter of Amram and Jochebed ) 

 a female given name , Maryam and Mariyam 

 Noun
 [ edit ] 

 مَرْیَم • ( maryam )  f ( Hindi spelling मरियम ) 

 ( figurative ) a virgin , maiden
