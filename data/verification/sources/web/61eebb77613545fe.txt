 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek ὄργανον ( órganon ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔar.ɣa.ˈnuːn/ 

 ( Dari, formal ) IPA ( key ) : [ʔäɾ.ɣä.núːn] 

 ( Dari, formal ) IPA ( key ) : [ʔäɾ.ɣä.núːn] 
 ( Kabuli ) IPA ( key ) : [ʔäɾ.ɣä.núːn] 

 ( Hazaragi ) IPA ( key ) : [ʔäɾ.ɣä.nún] 

 ( Iran, formal ) IPA ( key ) : [ʔæɹ.ɢæ.núːn] 

 ( Tajik, formal ) IPA ( key ) : [ʔäɾ.ʁä.nún]

 Noun
 [ edit ] 

 ارغنون • ( arġanūn / arġanun ) ( plural ارغنون‌ها ( arġanūn-hā / arġanun-hâ ) , Tajik spelling арғанун ) 

 ( music ) organ 
 1207-1273 , Rumi , Masnawī-i Ma'nawī 
 پس عدم گردم عدم چو ارغنون 
 گویدم کانا الیه راجعون pas adam gardam, adam ču arġanūn 
 gōyadam k'"innā ilayhi rāji'ūn" (please add an English translation of this quotation) 

 Synonym: ارگ ( org )
