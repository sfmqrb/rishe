 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From Aramaic כובא ( kūbā ) / ܟܘܒܐ ( kūbā ) , from Byzantine Greek κοῦπα ( koûpa ) , from Latin cuppa , from Latin cūpa .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kuːb/ 

 Noun
 [ edit ] 

 كُوب • ( kūb )  m ( plural أَكْوَاب ( ʔakwāb ) ) 

 glass , cup 
 609–632 CE , Qur'an , 56:17-18 : يَطُوفُ عَلَيْهِمْ وِلْدَانٌ مُّخَلَّدُونَ بِأَكْوَابٍ وَأَبَارِيقَ وَكَأْسٍ مِّن مَّعِينٍ yaṭūfu ʕalayhim wildānun muḵalladūna biʔakwābin waʔabārīqa wakaʔsin min maʕīnin There will circulate among them young boys made eternal, with beakers, pitchers and a glass of spring water.
