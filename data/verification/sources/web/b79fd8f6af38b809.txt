 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian wsydy ( /⁠wizend⁠/ , “ hurt , harm , injury ” ) [ 1 ] , a prefixed form of Proto-Iranian *ǰán- . See زَدَن ( zadan ) for more.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡa.ˈzand/ 

 ( Dari, formal ) IPA ( key ) : [ɡä.zán̪d̪] 

 ( Dari, formal ) IPA ( key ) : [ɡä.zán̪d̪] 
 ( Kabuli ) IPA ( key ) : [ɡä.zán̪d̪] 

 ( Hazaragi ) IPA ( key ) : [ɡä.zán̪d̪̥] 

 ( Iran, formal ) IPA ( key ) : [ɡʲæ.zǽn̪d̪̥] 

 ( Tajik, formal ) IPA ( key ) : [ɡä.zán̪d̪] 

 Rhymes: -and

 Noun
 [ edit ] 

 گزند • ( gazand ) 

 harm ; damage 
 Synonyms: آسیب ( âsib ) , آفت ( âfat ) 

 the evil eye 
 Synonym: چشم زخم ( češm-e zaxm ) 

 ( Tajik ) shoemaker's knife , cobbler's knife
