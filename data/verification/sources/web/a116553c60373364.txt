 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( šyt' /⁠šēd⁠/ , “ bright; sorrel (horse) ” ) , from Proto-Iranian *xšaytah ( “ bright, shining ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈʃeːd/ 

 ( Dari, formal ) IPA ( key ) : [ʃeːd̪] 

 ( Dari, formal ) IPA ( key ) : [ʃeːd̪] 
 ( Kabuli ) IPA ( key ) : [ʃeːd̪] 

 ( Hazaragi ) IPA ( key ) : [ʃeːd̪̥] 

 ( Iran, formal ) IPA ( key ) : [ʃiːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [ʃed̪] 

 Rhymes: -eːd

 Adjective
 [ edit ] 

 شید • ( šēd / šid ) ( Tajik spelling шед ) 

 splendid , brilliant , bright , luminous 

 Noun
 [ edit ] 

 شید • ( šēd / šid ) ( Tajik spelling шед ) 

 shine , radiance 

 Derived terms
 [ edit ] 

 شیده ( šēda  / šide , “ shine; bright, luminous ” ) 

 Related terms
 [ edit ] 

 جمشید ( jamšēd  / jamšid , “ Jamshid ” ) 

 خورشید ( xwaršēd  / xoršid , “ sun ” )
