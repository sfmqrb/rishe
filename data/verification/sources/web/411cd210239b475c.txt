 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit सक्थि ( sákthi ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /sək.t̪ʰiː/ , [sɐk.t̪ʰiː] 

 Noun
 [ edit ] 

 सक्थि • ( sakthi )  f or m ( rare , formal ) 

 the thigh , thigh-bone

 the pole or shafts of a cart

 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *sáktʰi , from Proto-Indo-European *sokʷHt-i-s ( “ thigh ” ) . Cognate with Avestan 𐬵𐬀𐬑𐬙𐬌 ( haxti , “ thigh ” ) , Old Armenian ազդր ( azdr ) , Middle Persian [script needed] ( h(ʾ)ht' /⁠haxt⁠/ , “ thigh ” ) , Ossetian агъд ( aǧd ) , Hittite [Term?] ( /⁠šakuttai⁠/ ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /sɐ́k.tʰi/ , [sɐ́k̚.tʰi] 

 ( Classical Sanskrit ) IPA ( key ) : /s̪ɐk.t̪ʰi/ , [s̪ɐk̚.t̪ʰi] 

 Noun
 [ edit ] 

 सक्थि॑ • ( sákthi ) stem ,  n 

 the thigh , thigh-bone
 c. 1500 BCE – 1000 BCE , Ṛgveda 

 the pole or shafts of a cart

 ( euphemistic , in the dual ) the female genitals
 c. 1500 BCE – 1000 BCE , Ṛgveda
