 Etymology 2
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /za.nix/ 
 ( Iraq ) IPA ( key ) : [ˈzɐ.nɪχ] 

 Adjective
 [ edit ] 

 زَنِخ • ( zaniḵ ) ( feminine زَنِخَة ( zaniḵa ) , masculine plural زَنِخُون ( zaniḵūn ) , elative أَزْنَخ ( ʔaznaḵ ) ) 

 rancid , unpleasant , off 
 آمُلُ أَلَّا يَكُونَ كَلَامِي زَنِخًا . ʔāmulu ʔallā yakūna kalāmī zaniḵan . I hope I don't come across as off .

 South Levantine Arabic
 [ edit ] 

 Root 

 ز ن خ 

 1 term 

 Etymology
 [ edit ] 

 Inherited from Arabic زَنِخ ( zaniḵ ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /zi.nix/ , [ˈzɪ.nɪx] 

 Audio ( Ramallah ) : ( file ) 

 Adjective
 [ edit ] 

 زنخ • ( ziniḵ ) ( feminine زنخة ( zinḵa ) , common plural زنخين ( zinḵīn ) , elative أزنخ ( ʔaznaḵ ) ) 

 rancid 

 ( by extension ) unpleasant , disagreeable , irritating , boring ( of a person ) 
 Synonym: تقيل الدمّ ( tʔīl id-damm )
