 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 فالیز ( fālēz  / fâliz ) 

 Etymology
 [ edit ] 

 Borrowed from Sogdian prδyz ( /⁠parδēz⁠/ , “ fruit garden; orchard ” ) , from Proto-Iranian *paridayjah . Doublet of پردیس ( pardis ) and فردوس ( ferdows ) . 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paː.ˈleːz/ 

 ( Dari, formal ) IPA ( key ) : [pʰɑː.léːz] 

 ( Dari, formal ) IPA ( key ) : [pʰɑː.léːz] 
 ( Kabuli ) IPA ( key ) : [pʰɑː.léːz] 

 ( Hazaragi ) IPA ( key ) : [pʰɔː.léːz] 

 ( Iran, formal ) IPA ( key ) : [pʰɒː.líːz] 

 ( Tajik, formal ) IPA ( key ) : [pʰɔ.líz] , [pʰɔ.léz] 

 Rhymes: -eːz

 Noun
 [ edit ] 

 پالیز • ( pālēz / pâliz ) ( Tajik spelling полиз , or полез ) 

 orchard ; a garden where fruits are grown 

 Descendants
 [ edit ]
