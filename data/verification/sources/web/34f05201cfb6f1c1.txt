 Arabic
 [ edit ] 

 Root 

 ك و ن ( k w n ) 

 11 terms 

 Etymology
 [ edit ] 

 Noun of place from the verb كَانَ ( kāna ) . Cognate with Hebrew מָכוֹן ( mɔḵōn ) and Ge'ez መካን ( mäkan ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ma.kaːn/ 

 Noun
 [ edit ] 

 مَكَان • ( makān )  m ( plural أَمْكِنَة ( ʔamkina ) or أَمَاكِن ( ʔamākin ) ) 

 place , location , position 
 Synonyms: مَكَانَة ( makāna ) , مَوْضِع ( mawḍiʕ ) , مَقَام ( maqām ) 

 status , dignity 
 Synonyms: مَكَانَة ( makāna ) , مَنْزِلَة ( manzila ) , شَأْن ( šaʔn ) 

 in place of 
 609–632 CE , Qur'an , 7:95 : ثُمَّ بَدَّلْنَا مَكَانَ ٱلسَّيِّئَةِ ٱلْحَسَنَةَ حَتَّى عَفَوْا ṯumma baddalnā makāna s-sayyiʔati l-ḥasanata ḥattā ʕafaw (please add an English translation of this quotation)

 Etymology

 Pronunciation

 IPA ( key ) : /mkaːn/ 

 Noun
 [ edit ] 

 مكان • ( mkān )  m ( plural مكاين ( mkāyin ) ) 

 place 
 Synonyms: بلاصة ( blāṣa ) , موضع ( mawṭaʕ or mawḍaʕ or mūṭaʕ or mūḍaʕ ) , محل ( maḥall ) 

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic مَكَان ( makān ) .

 Noun
 [ edit ] 

 مكان • ( mekân ) ( definite accusative مكانی ( mekânı ) , plural اماكن ( emâkin ) or امكنه ( emkine ) ) 

 place , location , position , spot , a particular point in physical space 
 Synonyms: اورون ( orun ) , محل ( mahal ) , یر ( yer ) 

 abode , residence , dwelling , a house or place in which a person lives
 Synonym: مسكن ( mesken ) 

 Derived terms
 [ edit ] 

 مكان رفیع ( mekân-ı refiʼ , “ exalted position ” ) 
 مكان طوتمق ( mekân tutmak , “ to settle, establish oneself ” ) 
 مكانلانمق ( mekânlanmak , “ to settle in a place ” ) 
 مكانی ( mekâni , “ pertaining to a place, local ” ) 

 Descendants
 [ edit ] 

 Turkish: mekân
