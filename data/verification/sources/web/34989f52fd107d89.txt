 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From earlier هَنْدَزَة ( handaza ) , from هَنْدَاز ( handāz ) , borrowed from Middle Persian handʾc- ( handāz- ) , hndʾhtn' ( handāxtan , “ to plan, to allot, to reckon, to judge ” ) , or hndʾck' ( handāzag , “ measure, manner ” ) (whence Persian اندازه ( andâza ) ).

 Pronunciation
 [ edit ] 

 IPA ( key ) : /han.da.sa/
