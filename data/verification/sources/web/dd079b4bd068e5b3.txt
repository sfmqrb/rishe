 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ὀβολός ( obolós ) 

 ὀδελός ( odelós ) — Doric 

 ὀβελλός ( obellós ) — Thessalian 

 Etymology
 [ edit ] 

 Possibly an alteration of βέλος ( bélos , “ missile ” ) , but the initial vocal cannot be accounted for. According to Beekes and Furnée, the word is clearly Pre-Greek . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /o.be.lós/ → /o.βeˈlos/ → /o.veˈlos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /o.be.lós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /o.beˈlos/ 

 ( 4 th CE Koine ) IPA ( key ) : /o.βeˈlos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /o.veˈlos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /o.veˈlos/ 

 Noun
 [ edit ] 

 ὀβελός • ( obelós )  m ( genitive ὀβελοῦ ) ; second declension 

 a spit , rod 
 Synonym: βουπόρος ( boupóros ) 
 460 BCE – 430 BCE , Herodotus , Histories 2.41 

 ( ὀβελὸς λίθινος ) a pointed square pillar, obelisk 

 a horizontal line
 Lucianus, Essays in Portraiture Defended 24

 Usage notes
 [ edit ] 

 The horizontal line was used as a critical mark to point out that a passage was spurious, but with one point below and one above (÷) ( ὀβελὸς περιστιγμένος ( obelòs peristigménos ) ) it denoted superfluous passages, especially in philosophical writings.

 Inflection
 [ edit ] 

 Second declension of ὁ ὀβελός ; τοῦ ὀβελοῦ ( Attic )
