 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Manichaean Middle Persian 𐫞𐫇𐫡𐫃 ( qwrg /⁠kūrag⁠/ , “ furnace, kiln ” ) . A Semitic borrowing. Compare Classical Syriac ܟܘܪܐ ( kūrā , “ melting pot; furnace ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /koː.ˈra/ 

 ( Dari, formal ) IPA ( key ) : [kʰoː.ɾä] 

 ( Dari, formal ) IPA ( key ) : [kʰoː.ɾä] 
 ( Kabuli ) IPA ( key ) : [kʰoː.ɾä] 

 ( Hazaragi ) IPA ( key ) : [kʰʊː.ɾä] 

 ( Iran, formal ) IPA ( key ) : [kʰuː.ɹe] 

 ( Tajik, formal ) IPA ( key ) : [kʰɵ.ɾä] 

 Rhymes: -a
