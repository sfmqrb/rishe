 Etymology 1
 [ edit ] 

 From Proto-Indo-European *ḱanḱest- , *kankest- ( “ horse ” ) . Cognate with Proto-Germanic *hangistaz , and thereby with German Hengst . ( Can this ( + ) etymology be sourced ?) 

 Noun
 [ edit ] 

 خنگ • ( xing / xeng ) ( Tajik spelling хинг ) 

 horse 
 Synonym: اسب ( asb ) 

 white horse 
 Synonyms: چرمه ( čarma  / čarme ) , الوس ( alūs  / alus ) 

 gray horse

 [ edit ] 

 Adjective
 [ edit ] 

 خنگ • ( xing / xeng ) ( Tajik spelling хинг ) 

 dumb , stupid 

 Descendants
 [ edit ]
