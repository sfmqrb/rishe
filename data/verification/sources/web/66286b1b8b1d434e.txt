 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 γάγραινα ( gágraina ) 

 Etymology
 [ edit ] 

 In antiquity it was compared with γράω ( gráō , “ to devour ” ) (a theory which Etymonline corroborates), but this is likely incorrect. It is most probably a Pre-Greek word.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡáŋ.ɡrai̯.na/ → /ˈɣaŋ.ɡrɛ.na/ → /ˈɣaŋ.ɡre.na/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ɡáŋ.ɡrai̯.na/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈɡaŋ.ɡrɛ.na/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈɣaŋ.ɡrɛ.na/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈɣaŋ.ɡre.na/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈɣaŋ.ɡre.na/ 

 Noun
 [ edit ] 

 γάγγραινᾰ • ( gángraină )  f ( genitive γαγγραίνης ) ; first declension 

 ( pathology ) gangrene

 [ edit ]
