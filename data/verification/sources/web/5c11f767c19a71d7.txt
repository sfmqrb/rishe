 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 شتابیدن ( šetâbidan ) , اشتافتن ( eštâftan ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian awištāftan > ōštāftan .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʃi.taːf.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [ʃɪ.t̪ʰɑːf.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [ʃɪ.t̪ʰɑːf.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [ʃɪ.t̪ʰɑːf.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [ʃi.t̪ʰɔːf.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [ʃe.t̪ʰɒːf.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [ʃi.t̪ʰɔf.t̪ʰán] 

 Rhymes: -an 

 Readings

 Verb
 [ edit ] 

 شتافتن • ( šetâftan ) ( present stem شتاب ( šetâb ) ) 

 to hasten 

 to speed up
