 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( brydan /⁠ burr- / brīdan ⁠/ , “ cut , cutting off ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bu.riː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [bʊ.ɾiː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [bʊ.ɾiː.d̪án] 
 ( Kabuli ) IPA ( key ) : [bʊ.ɾiː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [bu.ɾi.d̪án] 

 ( Iran, formal ) IPA ( key ) : [bo.ɹiː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [bu.ɾi.d̪án]

 Verb
 [ edit ] 

 بریدن • ( burīdan  / boridan ) ( present stem بر ( bur  / bor ) , Tajik spelling буридан ) 

 to cut 
 در کوه‌ها چوب‌ می‌برد dar kōh-hā čōb mē-burad  / dar kuh-hâ čub mi-borad He chops wood in the mountains 

 to become fed up 
 از این دنیا بریدم az īn dunyā burīdam  / az in donyâ boridam I'm fed up with this world
