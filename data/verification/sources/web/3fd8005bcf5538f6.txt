 Arabic
 [ edit ] 

 Root 

 ص ن ع ( ṣ n ʕ ) 

 16 terms 

 Etymology
 [ edit ] 

 Verbal noun of صَنَعَ ( ṣanaʕa , “ to make , manufacture ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sˤi.naː.ʕa/ 

 Noun
 [ edit ] 

 صِنَاعَة • ( ṣināʕa )  f ( plural صِنَاعَات ( ṣināʕāt ) or صَنَائِع ( ṣanāʔiʕ ) ) 

 verbal noun of صَنَعَ ( ṣanaʕa )   ( form I ) 

 art , skill 

 occupation , profession 

 handicraft 

 trade , craft 

 manufacture 

 industry
