 Etymology 1
 [ edit ] 

 Root 

 א־ל־ף ( ʾ-l-p ) 

 7 terms 

 From Proto-Semitic *ʔalp- ( “ thousand; cattle ” ) . Cognate with Arabic ألف ( ʔalf ) .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /ʔalpʰ/ 

 ( Tiberian ) IPA ( key ) : /ˈʔɛlɛf/ , [ˈʔɛːlɛf] 

 ( Yemenite ) IPA ( key ) : /ˈʔalaf/ , [ˈʔæːlæf] 

 ( Persian ) IPA ( key ) : /ˈ(ʔ)elef/ 

 ( Ashkenazi ) IPA ( key ) : /ˈɛlɛf/ 

 ( Modern Israeli ) IPA ( key ) : /ˈ(ʔ)elef/

 Noun
 [ edit ] 

 אֶלֶף • ( élef )  m ( plural indefinite אֲלָפִים , singular construct אֶלֶף־ , plural construct אַלְפֵי־ ) [pattern: קֶטֶל ] 

 millennium 

 thousandship , a part of thousand of a tribe 
 Synonym: מִשְׁפָּחָה ( mishpakhá )
