 Etymology
 [ edit ] 

 Inherited from Proto-Indo-Iranian *úštras . See there for more. Cognate with Avestan 𐬎𐬱𐬙𐬭𐬀 ( uštra ) , Old English ūr .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /úʂ.ʈɾɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /uʂ.ʈɾɐ/ 

 Noun
 [ edit ] 

 उष्ट्र॑ • ( úṣṭra ) stem ,  m 

 camel 

 buffalo 

 a wagon or a cart drawn by either
