 English
 [ edit ] 

 Etymology
 [ edit ] 

 Italian gruppo ( literally “ group ” ) .

 Noun
 [ edit ] 

 gruppo 

 ( cycling ) Synonym of groupset .

 ( music ) A cadential trill that alternates with the auxiliary note directly above it and ends with a musical turn as additional ornamentation .
 Synonym: groppo

 Etymology
 [ edit ]

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈɡrup.po/ 

 Audio : ( file )

 Noun
 [ edit ] 

 gruppo   m ( plural gruppi ) 

 group , cluster , party , team , covey 

 ( sports ) pack 

 ( cycling ) peloton 

 ( music ) band 
 Synonyms: gruppo musicale , band
