 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( zylk /⁠zīrak⁠/ ) (Manichaean Middle Persian 𐫉𐫏𐫡 ( zyr ) ).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ziː.ˈrak/ 

 ( Dari, formal ) IPA ( key ) : [ziː.ɾák]

 ( Hazaragi ) IPA ( key ) : [zi.ɾák] 

 ( Iran, formal ) IPA ( key ) : [ziː.ɹǽkʰʲ]

 Adjective
 [ edit ] 

 زیرک • ( zīrak / zirak ) ( comparative زیرک‌تَر , superlative زیرک‌تَرین , Tajik spelling зирак ) 

 clever , nimble , keen , astute 
 Synonyms: هوشیار ( hušyâr ) , زِرَنگ ( zerang ) , ناقُلا ( nâqolâ ) 
 1200s , Sadīd ud-Dīn Muḥammad ibn Muḥammad 'Awfī Bukhārī , Jawāmi ul-Hikāyāt wa Lawāmi' ul-Riwāyāt : و اهل آن زیرکترین مردمانند در صنعت و شناختن آلت و هیچ صنف از اصناف بنی آدم با ایشان در آن مبارات نتواند [ … ] va ahl-e ân zirak-tarin mardomân-and dar san'at o šenâxtan-e âlat va hič senf az asnâf-e bani âdam bâ išân dar ân mobârât na-tavânand [ … ] And its people [the Chinese] are the cleverest of men in industry and knowledge of instruments, and no group among the groups of the sons of Adam can compare with them in that [ … ]
