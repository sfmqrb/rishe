 Etymology
 [ edit ] 

 Etymology tree

 Persian بس ( bas ) 

 Proto-Indo-European *-onts der. 
 Middle Persian [script needed] ( -ntk' /⁠-andag⁠/ ) 
 Persian ـنده ( -ande/ande ) 

 Persian بسنده 

 From بس ( bas ) + ـنده ( -ande/ande ) .

 Adjective
 [ edit ] 

 بسنده • ( basanda / basande ) ( Tajik spelling басанда ) 

 sufficient ; ( adverb ) enough
