 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic اِبْتِكَار ( ibtikār ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔib.ti.ˈkaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʔɪb.t̪ʰɪ.kʰɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [ʔɪb.t̪ʰɪ.kʰɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔɪb.t̪ʰɪ.kʰɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔib.t̪ʰi.kʰɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [ʔeb.t̪ʰe.kʰɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [ʔib.t̪ʰi.kʰɔ́ɾ] 

 Rhymes: -aːr 

 Readings

 ibtikār

 Dari reading ?

 Tajik reading ?

 Noun
 [ edit ] 

 ابتکار • ( ibtikār / ebtekâr ) ( Tajik spelling ибтикор ) 

 initiative 
 ابتکار و خلاقیت ― ebtekâr o xallâqiyyat ― initiative and creativity 
 به ابتکار رئیس‌جمهور be ebtekâr -e ra'is-jomhur on the initiative of the president
