 Etymology
 [ edit ] 

 From Ottoman Turkish قایق ( kayık ) , from Proto-Turkic *kiayguk ( “ boat, oar ” ) . Cognate with Azerbaijani qayıq , Crimean Tatar qayıq , Uzbek qayiq .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ka.jɯk/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 kayık ( definite accusative kayığı , plural kayıklar )
