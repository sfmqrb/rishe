 French anglais 

 Inherited from Middle French anglois , from Old French anglois . By surface analysis , Angle ( “ Angle ” ) +‎ -ais ( “ -ese ” ) .

 Pronunciation
 [ edit ]

 ( Canada ) IPA ( key ) : /ã.ɡlɛ/ 

 Audio ( France ) : ( file )

 Rhymes: -ɛ 

 Adjective
 [ edit ] 

 anglais ( feminine anglaise , masculine plural anglais , feminine plural anglaises ) 

 English 
 Il est anglais . ― He is English. 
 Ceci n'est pas un avion anglais . ― This is not an English airplane. 

 ( Louisiana ) Anglo-American or Anglophone 
 Synonym: yankee 

 Usage notes
 [ edit ] 

 Loosely, anglais is often used to refer to all British people.
