 [ edit ] 

 आ- ( ā- ) +‎ भा ( bhā , “ to shine ” ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɑː.bʱɑː/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɑː.bʱɑː/ 

 Noun
 [ edit ] 

 आभा • ( ābhā ) stem ,  f 

 appearance 

 splendour , glamour
