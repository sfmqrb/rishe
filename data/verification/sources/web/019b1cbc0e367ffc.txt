 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐫅𐫏𐫗𐫀𐫓 ( dynʾl' /⁠dēnār⁠/ , “ (gold) dinar ” ) , from Ancient Greek δηνάριον ( dēnárion ) , from Latin dēnārius , perhaps through Aramaic דֵּינָרָא / ܕܝܢܪܐ ( dēnārā ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian , Dari ) IPA ( key ) : [deːnɑːɾ] , [diːnɑːɾ] 

 ( Iran ) IPA ( key ) : [diːnɑːɾ] 

 Noun
 [ edit ] 

 دینار • ( dinâr ) ( plural دینار‌ها ) 

 dinar
