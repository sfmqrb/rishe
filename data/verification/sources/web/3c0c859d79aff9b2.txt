 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From διαδέω ( diadéō , “ to bind round ” ) +‎ -μα ( -ma , result noun suffix ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /di.á.dɛː.ma/ → /ðiˈa.ði.ma/ → /ðiˈa.ði.ma/ 

 ( 5 th BCE Attic ) IPA ( key ) : /di.á.dɛː.ma/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /diˈa.de̝.ma/ 

 ( 4 th CE Koine ) IPA ( key ) : /ðiˈa.ði.ma/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ðiˈa.ði.ma/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ðiˈa.ði.ma/ 

 Noun
 [ edit ] 

 δῐᾰ́δημᾰ • ( dĭắdēmă )  n ( genitive δῐᾰδήμᾰτος ) ; third declension 

 headband 

 diadem (especially that of the Persian kings), crown 

 Inflection
 [ edit ] 

 Third declension of τὸ δῐᾰ́δημᾰ ; τοῦ δῐᾰδήμᾰτος ( Attic )
