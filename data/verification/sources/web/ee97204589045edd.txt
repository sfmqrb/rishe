 Hindi

 Etymology
 [ edit ] 

 Borrowed from Sanskrit अभ्र ( abhra ) . Doublet of आभ ( ābh ) and अब्र ( abra ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /əbʱ.ɾᵊ/ , [ɐbʱ.ɾᵊ] 

 Noun
 [ edit ] 

 अभ्र • ( abhra )  m 

 cloud 
 Synonyms: see Thesaurus: बादल 

 sky 
 Synonyms: see Thesaurus: आकाश

 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *abʰrás ( “ cloud ” ) , from Proto-Indo-European *n̥bʰrós . Cognate with Avestan 𐬀𐬡𐬭𐬀 ( aβra ) , Persian ابر ( abr ) , Latin imber and Ancient Greek ἀφρός ( aphrós ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɐbʱ.ɾɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɐbʱ.ɾɐ/ 

 Noun
 [ edit ] 

 अ॒भ्र • ( abhrá ) stem ,  n or m 

 cloud , thunder -cloud, rainy weather
 Synonym: मेघ ( meghá ) 
 c. 1500 BCE – 1000 BCE , Ṛgveda 6.44.12 : उद् अभ्राणी व स्तनयन्नियर्तीन्द्रो राधांस्यश्व्यानि गव्या। ud abhrāṇī va stanayanniyartīndro rādhāṃsyaśvyāni gavyā. As Indra, thundering, impels the rain-clouds , so doth he send us store of kine and horses. 

 sky , atmosphere 

 ( arithmetic ) a cypher 

 dust 
 c. 1200 BCE – 1000 BCE , Atharvaveda 

 ( medicine ) talc , mica
