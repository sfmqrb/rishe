 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پازهر ( pāzahr ) , پای‌زهر ( pāy-zahr ) , پاوزهر ( pāwzahr ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian pʾtzhl ( pādzahr , “ bezoar, antidote ” ) . By surface analysis , پاد ( pād- , “ anti- ” ) +‎ زهر ( zahr , “ poison, venom ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paːd.ˈzahr/ 

 ( Dari, formal ) IPA ( key ) : [pʰɑːd̪.záɦɾ] 

 ( Dari, formal ) IPA ( key ) : [pʰɑːd̪.záɦɾ] 
 ( Kabuli ) IPA ( key ) : [pʰɑːd̪.záɾ] 

 ( Hazaragi ) IPA ( key ) : [pʰɔːd̪.záɾ] 

 ( Iran, formal ) IPA ( key ) : [pʰɒːd̪.zǽɦɹ]

 Noun
 [ edit ] 

 پادزهر • ( pâdzahr ) ( plural پادزهرها ) 

 antidote 
 Synonyms: تریاک ( teryâk ) , نوش‌دارو ( nušdâru ) , ضدزهر ( zedd-e-zahr ) 
 اگر در بدن انسان هم سم با دوز خیلی کم وارد شود بدن پادزهر آن را می‌سازد agar dar badan-e ensân ham samm bâ doz-e xeyli kam vâred šavad badan pâdzahr -e ân râ mi-sâzad. If poison enters the body of a human in a very small dose the body will generate its antidote . 

 c. 1599 , Baha al-Din al-Amili , “Section 5, Part 2”, in کشکول ‎ [1] : زهر را با تکیه به پادزهر ی که داری، منوش. zahr râ bâ takye be pâdzahr i ke dâri, ma-nuš. Don't drink poison relying on the antidote that you have. 

 bezoar 
 Synonym: بنداک ( bandâk )
