 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 پشمان ( pişman ) — vulgar 

 փէշիման ( peşiman ) , փիշման ( pişman ) , փիւշման ( püşman ) — Armeno-Turkish 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian پَشِیمَان ( pašīmān ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /peʃiːˈmaːn/ , ( vulgar ) /piʃˈman/ 

 Noun
 [ edit ] 

 پشیمان • ( peşiman ) 

 regretful , remorseful , sorry 
 Synonym: نادم ( nadim ) 
 پشیمان اولمق ― peşiman olmak ― to regret

 [ edit ]

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پشمان ( pašimān, pušimān ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( pšymʾn' /⁠pašēmān⁠/ , “ penitent, repentant ” ) , Northern Luri پںشیمۆ ( pəşimø ) . Akin to Old Armenian փաշաման ( pʻašaman ) , a Middle Iranian borrowing.

 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /pa.ʃeː.ˈmaːn/ , /pu.ʃaj.ˈmaːn/ 

 ( Dari, formal ) IPA ( key ) : [pʰä.ʃeː.mɑ́ːn] , [pʰʊ.ʃäj.mɑ́ːn]

 Adjective
 [ edit ] 

 Dari

 پشیمان 

 Iranian Persian

 Tajik

 пушаймон 

 پشیمان • ( pašimân ) ( comparative پشیمان‌تَر , superlative پشیمان‌تَرین ) 

 regretful , sorry , penitent 
 1010 , Ferdowsi , شاهنامه [ Shahnameh ]: سپهبد پشیمان شد از کار اوی
بپیچید ازان راست گفتار اوی sipahbud pašēmān šud az kār-i ōy
bipēčīd az ān rāst guftār-i ōy The general became penitent from those deeds of his;
He writhed [from shame] at those righteous words of his. (romanization in Classical Persian)
