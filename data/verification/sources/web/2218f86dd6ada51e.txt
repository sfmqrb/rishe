 Arabic
 [ edit ] 

 Root 

 ل ت ت ( l t t ) 

 2 terms 

 Verb
 [ edit ] 

 لَتَّ • ( latta ) I ( non-past يَلُتُّ ( yaluttu ) , verbal noun لَتّ ( latt ) ) 

 to chatter , to prattle 
 لَتَّ وَعَجَنَ في مَسْأَلَةٍ ― to discuss a question back and forth 

 to knead dough 
 تُشَارِكُ الأُخْتُ الصُّغْرَى فِي لَتِّ العَجِينِ tušāriku l-ʔuḵtu ṣ-ṣuḡrā fī latti l-ʕajīni The youngest sister participated in kneading the dough 

 to pound , to bray , to crush 

 to mix with water

 Noun
 [ edit ] 

 لَتّ • ( latt )  m 

 verbal noun of لَتَّ ( latta ) 

 idle talk, prattle 

 Descendants
 [ edit ]

 → Egyptian Arabic: لَتّ

 Etymology
 [ edit ] 

 Inherited from Paisaci Prakrit 𑀮𑀢𑁆𑀢𑀸 ( lattā ) . Cognate with Urdu لات ( lāt ) / Hindi लात ( lāt , “ kick ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /lət̪.t̪ə̆/ , [lɐt̪.t̪ə̆] 

 Noun
 [ edit ] 

 لَتّ • ( latt )  f ( Gurmukhi spelling ਲੱਤ ) 

 ( anatomy ) leg 
 Synonym: ٹَن٘گ ( ṭaṉg ) 

 kick , blow given from the foot
