 Arabic إقليم 

 Borrowed from Ancient Greek κλίμα ( klíma ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔiq.liːm/ 

 Noun
 [ edit ] 

 إِقْلِيم • ( ʔiqlīm )  m ( plural أَقَالِيم ( ʔaqālīm ) ) 

 region , climate ( geographical area of the earth, particularly a zone of latitude ) 

 territory ( geographical area under the legal control of a country )
