 Chagatai
 [ edit ] 

 قوز 
 Etymology
 [ edit ] 

 Iranian borrowing, see Old Armenian ընկոյզ ( ənkoyz ) for more.

 Noun
 [ edit ] 

 قوز • ( qwz / qoz /) ( plural قوزلار ) 

 walnut ( a nut of the walnut tree ) 

 Derived terms
 [ edit ] 

 قوزلوق ( qwzlwq /⁠qozluq⁠/ , “ walnut ( a hardwood tree of the genus Juglans ) ” ) 

 Further reading
 [ edit ] 

 Vámbery, Ármin ( 1867 ), “ قوز ”, in Ćagataische sprachstudien ‎ [1] (in German), Leipzig, F. A. Brockhaus, page 318

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 From Romanian coz ( “ trump ” ) , clipped from Russian ко́зырь ( kózyrʹ , “ trump ” ) , from Polish kozyr , see the Russian for more.

 Noun
 [ edit ] 

 قوز • ( koz ) 

 ( card games ) trump 

 Descendants
 [ edit ] 

 Turkish: koz 

 → Armenian: ղոզ ( ġoz ) , խոզ ( xoz ) , կոզ ( koz ) 

 → Bulgarian: коз ( koz )
