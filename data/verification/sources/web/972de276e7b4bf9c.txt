 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Hebrew כרוב .

 Noun
 [ edit ] 

 كَرُوبِيّ • ( karūbiyy )  m ( plural كَرُوبِيُّون ( karūbiyyūn ) , feminine كَرُوبِيَّة ( karūbiyya ) ) 

 Archangel ( usually in الملائكَة الكروبيون )
