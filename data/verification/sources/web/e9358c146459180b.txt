 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit शालि ( śāli , “ rice ” ) .

 Noun
 [ edit ] 

 شالی • ( šâli ) 

 rice-hull , rice-husk 

 rice still in the husk 

 Derived terms
 [ edit ] 

 شلتوک ( šaltôk ) 

 شالیزار ( šâlizâr )
