 Etymology
 [ edit ] 

 See निस्- ( nís- ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /nís/ 

 ( Classical Sanskrit ) IPA ( key ) : /n̪is̪/ 

 Adverb
 [ edit ] 

 निस् • ( nís ) 

 out , forth , away &c.

 Usage notes
 [ edit ] 

 Rarely used independently ( AV. ), but normally as a prefix to verbs and their derivatives, or to nouns not immediately connected with verbs, in which case it has the sense, "out of", "away from" or that of a negative adverb.
