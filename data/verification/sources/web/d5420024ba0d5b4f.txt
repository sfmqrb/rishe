 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Alternative forms
 [ edit ] 

 *(s)kenǵ- [ 1 ] 

 Root
 [ edit ] 

 *(s)keng- [ 1 ] 

 to limp , hobble 

 to tilt , be askew 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *(s)keng- (25 c, 0 e)

 Proto-Germanic: *hinkaną 
 Proto-West Germanic: *hinkan ( see there for further descendants )

 *(s)kn̥g-yé-ti ( deponent yé -present ) [ 1 ] 
 Proto-Hellenic: *skəd͏̌d͏̌ō
