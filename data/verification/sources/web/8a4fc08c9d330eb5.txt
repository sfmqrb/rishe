 Etymology
 [ edit ] 

 Most likely from Ancient Greek εὐαγγέλιον ( euangélion ) , probably through Classical Syriac ܐܘܢܓܠܝܘܢ ( ʾewwangellīōn ) or a variant thereof, though also Ge'ez ወንጌል ( wängel ) or unattested Old South Arabian have been suggested as the immediate source.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔin.d͡ʒiːl/ 

 Noun
 [ edit ] 

 إِنْجِيل • ( ʔinjīl )  m ( plural أَنَاجِيل ( ʔanājīl ) ) 

 ( Christianity , Islam ) the Gospel , the evangel 

 ( Christianity ) the New Testament
