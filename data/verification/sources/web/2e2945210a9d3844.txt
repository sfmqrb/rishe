 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Of unknown origin. 
Possibly a Wanderwort , cf. Akkadian 𒅎𒌓 (IM.BABBAR /⁠gaṣṣu⁠/, “gypsum”) > Classical Syriac ܓܨܐ (gaṣṣā, “gypsum”) and Middle Persian gc (gač, “gypsum”).

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡýp.sos/ → /ˈʝyp.sos/ → /ˈʝip.sos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ɡýp.sos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈɡyp.sos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈʝyp.sos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈʝyp.sos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈʝip.sos/ 

 Noun
 [ edit ] 

 γῠ́ψος • ( gŭ́psos )  f ( genitive γῠ́ψου ) ; second declension 

 chalk 

 cement

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek γύψος ( gúpsos ) .

 Noun
 [ edit ] 

 γύψος • ( gýpsos )  m ( plural γύψοι ) 

 gypsum 

 plaster ( wall coating ) 

 plaster of Paris , plaster cast ( treatment for broken bones )
