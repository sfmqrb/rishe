 Persian
 [ edit ] 

 Persian Wikipedia has an article on: شیپور 

 Wikipedia fa 

 Alternative forms
 [ edit ] 

 شپور , شیبور ( šaybūr  / šeybur ) 

 Etymology
 [ edit ] 

 Borrowed from Aramaic שֽׁיפּוּרָא / שֽׁפּוּרָא ( šippūrā ) / ܫܝܺܦܘܿܪܳܐ ( šippōrā , “ trumpet, shofar ” ) , whence also Arabic شَبُّور ( šabbūr ) .

 Noun
 [ edit ] 

 شیپور • ( šaypūr / šeypur ) ( Tajik spelling шайпур ) 

   bugle , horn , trumpet
