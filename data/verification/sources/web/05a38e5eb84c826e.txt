 Middle Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 𐫗𐫖𐫏𐫍𐫐 ( nmyhk /⁠namak⁠/ ) ( Manichaean ) 

 Etymology
 [ edit ] 

 From Proto-Iranian *namadka- , [ 1 ] compare Bactrian ναμιλγο ( namilgo ) .

 Noun
 [ edit ] 

 nmk' • ( namak ) 

 ( Book Pahlavi ) salt 

 Descendants
 [ edit ]

 Persian: نمک ( namak ) 

 → Hindi: नमक ( namak ) 

 → Urdu: نمک ( namak )
