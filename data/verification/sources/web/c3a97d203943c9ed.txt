 Khowar
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Sanskrit दश ( daśa ) , from Proto-Indo-Iranian *dáća , from Proto-Indo-European *déḱm̥ .

 Numeral
 [ edit ] 

 جوش ( ǰoš ) 

 ten 

 References
 [ edit ] 

 Elena Bashir; Maula Nigah; Rahmat Karim Baig ( 2022 ), “ جوش ”, in A digital Khowar-English dictionary with audio ‎ [1] , second edition, Chicago, IL: South Asia Language and Area Center, University of Chicago , archived from the original on 19 January 2023 . 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Ultimately from Proto-Indo-European *yes- ( “ to foam, boil ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈd͡ʒoːʃ/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒoːʃ] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒoːʃ] 
 ( Kabuli ) IPA ( key ) : [d͡ʒoːʃ] 

 ( Hazaragi ) IPA ( key ) : [d͡ʒʊːʃ] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒuːʃ] 

 ( Tajik, formal ) IPA ( key ) : [d͡ʒɵʃ] 

 Rhymes: -oːʃ

 Verb
 [ edit ] 

 جوش • ( jōš  / juš ) ( Tajik spelling ҷӯш ) 

 present stem of جوشیدن ( jōšīdan/jušidan ) 

 Noun
 [ edit ] 

 جوش • ( jōš / juš ) ( Tajik spelling ҷӯш ) 

 boiling of a liquid

 pimple , boil , exanthema 

 welding , soldering 

 healing of a wound , cicatrization 

 ( figurative ) ebullition , boiling , agitation 

 ( figurative ) enthusiasm , ardor 

 References
 [ edit ] 

 ^ Cheung, Johnny ( 2007 ), “ *i̯ah ”, in Etymological Dictionary of the Iranian Verb (Leiden Indo-European Etymological Dictionary Series; 2), Leiden, Boston: Brill, →ISBN , pages 209-210 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian جوش ( jōš ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /d͡ʒoːʃ/ 

 Noun
 [ edit ] 

 جوش • ( joś )  m ( Hindi spelling जोश ) 

 enthusiasm , zeal , ardour 

 passion , excitement 

 animation 

 ( literal ) boiling
