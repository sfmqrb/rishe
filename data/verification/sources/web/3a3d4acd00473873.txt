 Alternative forms
 [ edit ] 

 طنبور ( tanbūr  / tanbur ) , طنبوره ( tanbūra  / tanbure ) , طنبار ( tanbār  / tanbâr ) , دنبره ( dunbara  / donbare, danbara  / danbare ) , دنبوره ( danbūra  / danbure ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( tmbwl /⁠tambūr⁠/ ) , [Book Pahlavi needed] ( tnbwl ) , Manichaean Middle Persian 𐫤𐫖𐫁𐫇𐫡 ( tmbwr /⁠tambūr⁠/ ) ). According to Watkins, possibly (with metathesis of consonants) from Ancient Greek πανδοῦρα ( pandoûra , “ three-stringed lute ” ) . [ 1 ] [ 2 ]
