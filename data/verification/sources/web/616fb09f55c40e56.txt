 See also: मोजा , मज़ा , and मेज़ 

 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian موزه ( mōza ) . Compare Assamese মোজা ( müza ) , Bengali মোজা ( mōja ) , Gujarati મોજું ( mojũ ) , Marathi मोजा ( mojā ) , Nepali मोजा ( mojā ) . Doublet of मोची ( mocī ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /moː.zɑː/ , [moː.zäː] , /moː.d͡ʒɑː/ , [moː.d͡ʒäː] 

 Noun
 [ edit ] 

 मोज़ा • ( mozā )  m ( Urdu spelling موزہ ) 

 a sock , stocking 
 Synonyms: जुर्राब ( jurrāb ) , जुराब ( jurāb ) , पादावरण ( pādāvraṇ )
