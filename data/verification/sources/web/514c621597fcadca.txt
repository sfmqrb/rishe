 Arabic

 Pronunciation
 [ edit ] 

 IPA ( key ) : /d͡ʒaww/ 
 ( Hijazi ) IPA ( key ) : /d͡ʒaww/ 

 ( Moroccan ) IPA ( key ) : /ʒaww/ 

 Noun
 [ edit ] 

 جَوّ • ( jaww )  m ( plural أَجْوَاء ( ʔajwāʔ ) or جِوَاء ( jiwāʔ ) ) 

 air (the apparently open space above the ground)
 Coordinate terms: بَحْر ( baḥr ) , بَرّ ( barr ) 

 weather 

 atmosphere 

 ( figurative ) atmosphere ( apparent mood ) 

 wide valley 

 open pasture - ground 

 interior of a house 
 Antonym: بَرّ ( barr ) 

 hall
