 Italian

 Etymology
 [ edit ] 

 From Late Latin cofia ( “ bonnet ” ) , probably of Germanic origin, from Proto-West Germanic *kuffju .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈkuf.fja/ 

 Rhymes: -uffja 

 Hyphenation: cùf‧fia 

 Audio : ( file ) 

 Noun
 [ edit ] 

 cuffia   f ( plural cuffie ) 

 bonnet , cap 
 cuffia da bagno ― bathing cap 

 ( in the plural ) headphones
