 Etymology 1
 [ edit ] 

 Likely borrowed from a Nuristani language, with proto-form along the lines of *kāt's'a ; said form is cognate with the Sanskrit root काश् ( kāś , “ to shine brightly, appear ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /kɑː.t͡ɕɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /kɑː.t͡ɕɐ/ 

 Noun
 [ edit ] 

 का॒च • ( kācá ) stem ,  m or n 

 glass 

 crystal , quartz 

 alkaline salt , block salt

 Etymology 2
 [ edit ] 

 Probably a post-Vedic formation of an unattested root *कङक् ( *kaṅak , “ to tie down ” ) , of unclear further origin. [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Classical Sanskrit ) IPA ( key ) : /kɑː.t͡ɕɐ/ 

 Noun
 [ edit ] 

 काच • ( kāca ) stem ,  m 

 a loop 

 a string fastened to each end of a pole with a net in which burdens etc. are held or suspended 

 a yoke to support burdens etc.

 the string of the scale of a balance
