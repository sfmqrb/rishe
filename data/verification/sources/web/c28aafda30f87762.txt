 Arabic
 [ edit ] 

 Root 

 د ش ن ( d š n ) 

 4 terms 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /daʃ.ʃa.na/ 

 Verb
 [ edit ] 

 دَشَّنَ • ( daššana ) II ( non-past يُدَشِّنُ ( yudaššinu ) , verbal noun تَدْشِين ( tadšīn ) ) 

 ( transitive ) to handover , present 

 ( transitive ) to augurate , open , consecrate
