 Ancient Greek
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /a.mor.bós/ → /a.morˈβos/ → /a.morˈvos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /a.mor.bós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /a.morˈbos/ 

 ( 4 th CE Koine ) IPA ( key ) : /a.morˈβos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /a.morˈvos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /a.morˈvos/ 

 Etymology 1
 [ edit ] 

 Unknown. [ 1 ] One theory relates the word to Sanskrit मार्ग ( mārga , “ path ” ) ; see there for more.

 Noun
 [ edit ] 

 ἀμορβός • ( amorbós )  m ( genitive ἀμορβοῦ ) ; second declension 

 follower , attendant 

 shepherd 

 Inflection
 [ edit ]

 Etymology 2
 [ edit ] 

 From Proto-Indo-European *h₂mergʷ- ( “ dark ” ) . Cognate with Proto-Germanic *merkuz ( “ dark ” ) , Lithuanian márgas ( “ colorful ” ) , Proto-Celtic *mrixtos ( “ painted, speckled ” ) . ( Can this ( + ) etymology be sourced ?)
