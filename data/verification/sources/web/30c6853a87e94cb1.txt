 Persian کَشَف 

 From Middle Persian [Book Pahlavi needed] ( kšwk' /⁠kašawag⁠/ , “ tortoise ” ) , from Proto-Iranian *kacyápah . Cognate with Sanskrit कच्छप ( kacchapa ) .

 Noun
 [ edit ] 

 کشف • ( kašaf ) ( Tajik spelling кашаф ) 

 ( archaic ) tortoise , turtle 
 Synonym: لاک‌پشت ( lāk-pušt  / lâk-pošt ) 

 ( astrology , obsolete ) Cancer

 Urdu کَشْف 

 Borrowed from Classical Persian کَشْف ( kašf ) , borrowed from Arabic كَشْف ( kašf ) . First attested in c. 1564 as Middle Hindi کشف ( kśf /⁠kaśf⁠/ ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /kəʃf/ 

 ( colloquial ) IPA ( key ) : [kə.ʃəf] 

 Rhymes: -əʃf 

 Noun
 [ edit ] 

 کَشْف • ( kaśf )  m ( Hindi spelling कश्फ़ ) 

 divine inspiration 

 revelation , manifestation 

 ( dated sense ) discovery 

 ( rare ) unveil , unveiling
