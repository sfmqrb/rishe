 Adjective
 [ edit ] 

 شَفَّاف • ( šaffāf ) ( feminine شَفَّافَة ( šaffāfa ) , masculine plural شَفَّافُون ( šaffāfūn ) , feminine plural شَفَّافَات ( šaffāfāt ) ) 

 see-through , transparent 

 ( textiles ) sheer , thin , fine , delicate , see-through , transparent 
 Synonym: رَقِيق ( raqīq )

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic شَفَّاف ( šaffāf , “ see-through, transparent ” ) . 

 Adjective
 [ edit ] 

 شفاف • ( şeffaf ) 

 transparent , see-through , diaphanous , clear , translucent , having the property that light passes through it almost undisturbed 

 Derived terms
 [ edit ] 

 شفافلق ( şeffaflık , “ transparency ” ) 
 شفافمسی ( şeffafımsı , “ somewhat transparent ” ) 
 شفافیت ( şeffafiyet , “ transparency ” ) 

 Descendants
 [ edit ]

 Adjective
 [ edit ] 

 شفاف • ( šaffâf ) 

 transparent , see-through 

 transparent , open , public 

 ( of a dream ) lucid 
 خواب شفاف ― xâb-e šaffâf ― lucid dream 
 رویای شفاف ― ro'yâ-ye šaffâf ― lucid dream
