 Alternative forms

 Etymology
 [ edit ] 

 Ultimately from Middle Persian *Kaf kōf ( “ Mount Qaf ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /qaf.ˈqaːz/ 

 ( Dari, formal ) IPA ( key ) : [qäf.qɑːz] 

 ( Dari, formal ) IPA ( key ) : [qäf.qɑːz]

 ( Iran, formal ) IPA ( key ) : [qæf.ɢɒːz]
