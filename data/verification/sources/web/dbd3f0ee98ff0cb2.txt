 Northern Kurdish
 [ edit ] 

 Noun
 [ edit ] 

 آذر ( azer )  f 

 alternative form of Adar ( “ March ” ) 

 References
 [ edit ] 

 Chyet, Michael L. ( 2020 ), “ Adar ”, in Ferhenga Birûskî: Kurmanji–English Dictionary (Language Series; 1), volume 1, London: Transnational Press, page 1 

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 آدر ( ādar ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐭭𐭥𐭥𐭠 ( NWRA /⁠ādur⁠/ ) , from Proto-Iranian *HáHtr̥š , perhaps from Proto-Indo-European *h₂eh₁-tr- . Cognate with Avestan 𐬁𐬙𐬀𐬭 ( ātar ) . Doublet of آتش .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ˈðar/ , /ʔaː.ˈzar/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.zäɾ] 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.zäɾ] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.zäɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.zäɾ] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.zæɹ] 

 ( Tajik, formal ) IPA ( key ) : [ʔɔ.zäɾ] 

 Rhymes: -ar

 Noun
 [ edit ] 

 آذر • ( āzar / âzar ) ( Tajik spelling озар ) 

 ( archaic ) fire 
 Synonym: آتش ( ātiš ) 

 Proper noun
 [ edit ] 

 آذر • ( āzar  / âzar ) ( Tajik spelling Озар ) 

 Azar ( the ninth solar month of the Persian calendar ) 

 Name of the ninth day of any month of the solar Persian calendar.

 a female given name , Azar

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian آذَر ( āḏar ) , from Middle Persian 𐭭𐭥𐭥𐭠 ( NWRA /⁠ādur⁠/ ) 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɑː.zəɾ/ 

 Noun
 [ edit ] 

 آذَر • ( āzar )  m ( Hindi spelling आज़र ) 

 autumn ; the season and months of autumn

 fire , flame 
 Synonyms: آتش ( ātiš ) , آگ ( āg ) 

 Proper noun
 [ edit ] 

 آذَر • ( āzar )  m ( Hindi spelling आज़र ) 

 Azar , the ninth month of the solar Persian calendar .
