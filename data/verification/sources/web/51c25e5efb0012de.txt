 Khalaj

 Adjective
 [ edit ] 

 قَشَنگ ( qəşəng ) 

 Arabic spelling of qəşəng ( “ beautiful , pretty , handsome ” ) 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Sogdian ʾγšnk- ( (ə)xšank , “ beautiful ” ) , Northern Luri خشںݩ ( xşəŋ ) , related to Proto-Iranian *gr̥šáti ( “ to rejoice, be happy ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /qa.ˈʃanɡ/ 

 ( Dari, formal ) IPA ( key ) : [qä.ʃáŋɡ] 

 ( Dari, formal ) IPA ( key ) : [qä.ʃáŋɡ] 
 ( Kabuli ) IPA ( key ) : [qä.ʃáŋɡ] 

 ( Hazaragi ) IPA ( key ) : [qä.ʃáŋɡ̥] 

 ( Iran, formal ) IPA ( key ) : [qæ.ʃǽɲɡʲ̥] 

 ( Tajik, formal ) IPA ( key ) : [qä.ʃáŋɡ] 

 Rhymes: -anɡ 

 Readings

 Classical reading ? 

 qašang

 Dari reading ? 

 qašang

 Iranian reading ? 

 ġašang

 Tajik reading ? 

 qašang

 ( Hamadan ) IPA ( key ) : [ɢeˈʃæŋɡ] 

 Adjective
 [ edit ] 

 قَشَنْگ • ( qašang / ġašang ) ( comparative قَشَنْگ‌تَر , superlative قَشَنْگ‌تَرین , Tajik spelling қашанг ) 

 beautiful 
 Synonyms: زیبا ( zibâ ) , خوشگل ( xošgel ) , خجیر ( xojir ) 

 lovely 

 pretty

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 From Classical Persian قَشَنْگ ( qašang , “ beautiful, lovely ” ) , ultimately from Sogdian ʾγšnk- ( (ə)xšank , “ beautiful ” ) . 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /qə.ʃəŋɡ/ 

 Adjective
 [ edit ] 

 قَشَن٘گ • ( qaśaṅg ) ( Hindi spelling क़शंग ) 

 attractive , good-looking ; beautiful 

 pleasant , agreeable 

 excellent , superb
