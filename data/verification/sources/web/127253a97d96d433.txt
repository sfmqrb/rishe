 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 بَاتِنْجَان ( bātinjān ) , بَتِنْجَان ( batinjān ) , بِدِنْجَان ( bidinjān ) 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Dravidian *waẓVtV der. 
 Sanskrit वातिङ्गण ( vātiṅgaṇa ) bor. 
 Classical Persian بَاذِنْگَان ( bāzingān ) bor. 
 Arabic باذنجان 

 Borrowed from Classical Persian بَاذِنْگَان ( bāzingān ) , بَاتِنْگَان ( bātingān ) , an Indo-Aryan borrowing, from Sanskrit वातिङ्गण ( vātiṅgaṇa ) , from Dravidian , ultimately from Proto-Dravidian *waẓVtV .

 [ edit ] 

 IPA ( key ) : /baː.ðin.d͡ʒaːn/ 

 Noun
 [ edit ] 

 بَاذِنْجَان • ( bāḏinjān )  m 

 ( collective ) eggplant , aubergine
