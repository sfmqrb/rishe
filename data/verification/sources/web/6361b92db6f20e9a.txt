 Alternative forms
 [ edit ] 

 کهربای ( kahrobây ) , کهرباء ( kahrobâ' ) , کاهربا ( kâhrobâ ) 

 Etymology
 [ edit ] 

 From earlier کهربای ( kahrobây ) , from Middle Persian khlpʾd ( kah-rubāy , “ amber ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kah.ru.ˈbaː/ 

 ( Dari, formal ) IPA ( key ) : [kʰäɦ.ɾʊ.bɑː] 

 ( Dari, formal ) IPA ( key ) : [kʰäɦ.ɾʊ.bɑː] 
 ( Kabuli ) IPA ( key ) : [kʰɑː.ɾʊ.bɑː] 

 ( Hazaragi ) IPA ( key ) : [kʰɔː.ɾu.bɔː] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæɦ.ɹo.bɒː] 

 ( Tajik, formal ) IPA ( key ) : [kʰäɦ.ɾä.bɔ] 

 Rhymes: -aː

 Noun
