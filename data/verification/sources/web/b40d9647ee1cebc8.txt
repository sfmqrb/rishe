 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic عُصَارَة ( ʕuṣāra ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔu.saː.ˈra/ 

 ( Dari, formal ) IPA ( key ) : [ʔʊ.sɑː.ɾä] 

 ( Dari, formal ) IPA ( key ) : [ʔʊ.sɑː.ɾä] 
 ( Kabuli ) IPA ( key ) : [ʔʊ.sɑː.ɾä] 

 ( Hazaragi ) IPA ( key ) : [ʔu.sɔː.ɾä] 

 ( Iran, formal ) IPA ( key ) : [ʔo.sɒː.ɹe] 

 ( Tajik, formal ) IPA ( key ) : [ʔu.sɔ.ɾä] 

 Rhymes: -a

 Noun
 [ edit ] 

 عصاره • ( usāra / osâre ) ( Tajik spelling усора ) 

 sap , extract ( somewhat viscose liquid that one obtains by wringing )
