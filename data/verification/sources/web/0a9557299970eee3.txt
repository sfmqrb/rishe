 Arabic
 [ edit ] 

 Etymology 1
 [ edit ] 

 Clipping of نَرْدَشِير ( nardašīr ) or from Persian نرد ( nard ) .

 Alternative forms
 [ edit ] 

 نَرْدَشِير ( nardašīr ) (obsolete)

 Noun
 [ edit ] 

 نَرْد • ( nard )  m 

 ( collective ) dice ; game with dice 
 Synonym: زَهْر ( zahr )

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian نرد ( nard , “ backgammon ” ) .

 Noun
 [ edit ] 

 نرد • ( nerd ) 

 backgammon , a board game for two players 

 Descendants
 [ edit ] 

 Turkish: nerd
