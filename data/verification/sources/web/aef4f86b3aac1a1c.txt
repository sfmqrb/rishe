 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Hellenic *tónos , from Proto-Indo-European *tón-os , from *ten- ( “ stretch ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /tó.nos/ → /ˈto.nos/ → /ˈto.nos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /tó.nos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈto.nos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈto.nos/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈto.nos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈto.nos/ 

 Noun
 [ edit ] 

 τόνος • ( tónos )  m ( genitive τόνου ) ; second declension 

 ( literal ) tension (as produced in something which is stretched )

 that which undergoes or induces tension
 a cord , rope or string 

 a tendon 

 the tone or note produced by plucking a string under tension

 Declension
 [ edit ] 

 Second declension of ὁ τόνος ; τοῦ τόνου ( Attic )

 τόνος • ( tónos )  m ( plural τόνοι ) 

 ( orthography , typography , grammar ) accent ( ΄ ) , tonos ( the stress accent used in modern Greek ) 

 ( music ) note , pitch , tone
