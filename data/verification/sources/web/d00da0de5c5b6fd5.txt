 English
 [ edit ] 

 Noun
 [ edit ] 

 albacora ( plural albacoras ) 

 Obsolete form of albacore ( “ longfin tuna ” ) .

 Galician
 [ edit ] 

 Etymology
 [ edit ] 

 From Andalusian Arabic , from classical Arabic اَلْبَكُورَة ( al-bakūra , “ the young camels ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /albaˈkɔɾa/ [ɑl.β̞ɑˈkɔ.ɾɐ] 

 Rhymes: -ɔɾa 

 Noun
 [ edit ] 

 albacora   f ( plural albacoras ) 

 albacore , longfin tuna ( Thunnus alalunga , a large marine fish )

 [ edit ]

 Spanish
 [ edit ] 

 Alternative forms
 [ edit ] 

 abacora 

 Etymology
 [ edit ] 

 From Andalusian Arabic اَلْبَاكُورَة ( al-bācórah ) , from classical Arabic باكورة ( bākūrah , “ early fruits ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /albaˈkoɾa/ [al.β̞aˈko.ɾa] 

 Rhymes: -oɾa 

 Syllabification: al‧ba‧co‧ra 

 Noun
 [ edit ] 

 albacora   f ( plural albacoras ) 

 breba , an early Ficus carica fig
 Synonym: breva 

 swordfish ( Xiphias gladius ) 
 Synonym: pez espada
