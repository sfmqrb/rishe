 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 تهل ( tahl ) ( dialectal , Kazerun ) 

 Etymology
 [ edit ] 

 From Middle Persian t’hl’ ( taxl ) , from Proto-Indo-Iranian *tákram , Northern Luri تݖل ( təəl ) , compare Sanskrit तक्र ( tákra , “ buttermilk mixed with water ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈtalx/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰälx] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰälx] 
 ( Kabuli ) IPA ( key ) : [t̪ʰälx] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰälx] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰælx] 

 ( Tajik, formal ) IPA ( key ) : [t̪ʰälχ] 

 Rhymes: -alx

 Adjective
 [ edit ] 

 تلخ • ( talx ) ( Tajik spelling талх ) 

 bitter

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian تلخ ( talx ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /t̪əl̪x/ , /t̪əl̪əx/ 

 Adjective
 [ edit ] 

 تَلْخ or تَلَخ • ( talx or talax ) ( indeclinable , Hindi spelling तल्ख़ ) 

 bitter , distasteful 
 Synonyms: کڑوا ( kaṛvā ) , بدمزہ ( badmaza )

 [ edit ]
