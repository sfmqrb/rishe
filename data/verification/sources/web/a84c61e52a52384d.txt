 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Ultimately from Proto-Iranian *wr̥jyáti ; see there for further information. Cognate with English work and Ancient Greek ἔργον ( érgon ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /war.ziː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [wäɾ.ziː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [wäɾ.ziː.d̪án] 
 ( Kabuli ) IPA ( key ) : [wäɾ.ziː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [wäɾ.zi.d̪án] 

 ( Iran, formal ) IPA ( key ) : [væɹ.ziː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [väɾ.zi.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 Dari

 ورزیدن 

 Iranian Persian

 Tajik

 варзидан 

 ورزیدن • ( varzidan ) ( present stem ورز ( varz ) ) 

 to exercise 

 to train 

 ( chiefly archaic ) to work
