 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 مورانه ( murâne ) , مورجانه ( murjâne ) , مورچانه ( murčane ) 

 Etymology
 [ edit ] 

 Derived from the word مور ( mur , “ ant ” ) , from Proto-Indo-Iranian *marwíš .

 Noun
 [ edit ] 

 موریانه • ( muryâne ) ( plural موریانه‌ها ) 

 termite 
 Synonyms: مورچه‌ی سفید ( murče-ye sefid ) , ریونجه ( rivanje ) , ترده ( tarde ) 

 References
 [ edit ]
