 Alternative forms
 [ edit ] 

 چوکان ( čowkân ) , چولگان ( čowlagân ) , چویگان ( čuygân ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian cwpkʾn' ( čōbagān, *čaw(la)gān ) , cwgʾn' ( čōgān ) .

 Noun
 [ edit ] 

 چوگان • ( čawgān / čowgân ) ( Tajik spelling чавгон ) 

 ( archaic ) crosier 

 polo-stick 
 977-1010 , Ferdowsi , Shahnameh 
 ز چوگان او گوی شد ناپدید
تو گفتی سپهرش همی‌برکشید zi čawgān -i ō gōy šud nāpadīd
tu guftī sipihraš hamē-bar-kašīd From [the kick of] his polo-stick, the ball disappeared
 It looked such that it was surpassing the heavens 

 polo 
 Synonym: گوی و چوگان ( gōy u čawgān  / guy o čowgân )
