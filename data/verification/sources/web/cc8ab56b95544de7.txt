 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 جاویدن ( jâvidan ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ywtn’ /⁠jūdan⁠/ ) , from Proto-Indo-European *ǵyewh₁- . Cognate with English chew , Pashto ژول ( žovạl , “ to gnaw ” ) , Baluchi جایگ ( jáyag ) , Northern Kurdish cûtin , Northern Luri ژایێ ( jayı ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /d͡ʒa.wiː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒä.wiː.d̪än] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒä.wiː.d̪än] 
 ( Kabuli ) IPA ( key ) : [d͡ʒä.wiː.d̪än] 

 ( Hazaragi ) IPA ( key ) : [d͡ʒä.wi.d̪än] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒæ.viː.d̪æn] 

 ( Tajik, formal ) IPA ( key ) : [d͡ʒä.vi.d̪än] 

 Rhymes: -an

 Verb
 [ edit ] 

 جویدن • ( javidan ) ( present stem جو ( jav ) ) 

 to chew ; to gnaw 
 Synonym: خاییدن ( xāyīdan/xâyidan ) 
 موش جویده ― muš javide ― gnawed by mice
