 Etymology
 [ edit ] 

 Borrowed from Turkic , from the same source as Turkish araba . See there for more.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔa.raː.ˈba/ 

 ( Dari, formal ) IPA ( key ) : [ʔä.ɾɑː.bá] 

 ( Dari, formal ) IPA ( key ) : [ʔä.ɾɑː.bá] 
 ( Kabuli ) IPA ( key ) : [ʔä.ɾɑː.bá] 

 ( Hazaragi ) IPA ( key ) : [ʔä.ɾɔː.bá] 

 ( Iran, formal ) IPA ( key ) : [ʔæ.ɹɒː.bé] 

 ( Tajik, formal ) IPA ( key ) : [ʔä.ɾɔ.bá] 

 Rhymes: -a

 Noun
 [ edit ] 

 ارابه • ( arāba / arâbe ) ( Tajik spelling ароба ) 

 carriage 

 chariot 
 ارابهٔ عصر برنز ― arâbe -ye asr-e boronz ― Bronze Age chariot 

 ( colloquial ) run-down car
