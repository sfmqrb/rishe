 Armenian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Old Armenian կօշիկ ( kōšik ) .

 Pronunciation
 [ edit ] 

 ( Eastern Armenian ) IPA ( key ) : /koˈʃik/ [koʃík] 

 ( Western Armenian ) IPA ( key ) : /ɡoˈʃiɡ/ [ɡoʃíɡ] 

 Audio ( Eastern Armenian ) : ( file ) 

 Noun
 [ edit ] 

 կոշիկ • ( košik ) ( traditional orthography spelling կօշիկ ) 

 shoe 
 երկարաճիտ կոշիկ ― erkaračit košik ― boot
