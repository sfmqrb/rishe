 Arabic
 [ edit ] 

 سِوَار 
 Etymology
 [ edit ] 

 Though Fraenkel assumed that the Arabic word is genuine and not a loan, likely a perhaps early loan from a byform of Aramaic שֵׁירָא / ܫܶܐܪܳܐ ( šērā ) , see the exposure at ش ج ر ( š j r ) . Juxtapose قُلْب ( qulb , “ bracelet ” ) for a Syriac loan. Compare also دُمْلُوج ( dumlūj ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /si.waːr/

 [ edit ] 

 سِوَار • ( siwār )  m ( plural أَسْوِرَة ( ʔaswira ) or أَسَاوِر ( ʔasāwir ) )

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 اسوار ( aswār  / asvâr ) , سواره ( sawāra  / savâre ) 

 Etymology
 [ edit ] 

 From Middle Persian ʾswbʾl , ʾsp̄wʾl ( /⁠aswār⁠/ , “ horseman, rider ” ) , from Old Persian 𐎠𐎿𐎲𐎠𐎼 ( a-s-b-a-r /⁠asabāra-⁠/ , “ horseman ” ) , from Proto-Iranian *Hacwabāráh , from Proto-Indo-Iranian *Haćwabʰāras .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /sa.ˈwaːr/ , /su.ˈwaːr/ 

 ( Dari, formal ) IPA ( key ) : [sä.wɑ́ːɾ] , [sʊ.wɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [sä.wɑ́ːɾ] , [sʊ.wɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [sä.wɑ́ːɾ] , [sʊ.wɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [sä.wɔ́ːɾ] , [su.wɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [sæ.vɒ́ːɹ] , [so.vɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [sä.vɔ́ɾ] , [su.vɔ́ɾ] 

 Rhymes: -aːr 

 Readings

 Classical reading ? 

 sawār, suwār

 sawār, suwār

 savor, suvor

 Noun
 [ edit ] 

 سوار • ( sawār, suwār / savâr, sovâr ) ( plural سواران ( sawārān, suwārān / savârân, sovârân ) , Tajik spelling савор , or сувор ) 

 horseman , rider 

 cavalryman 
 پادشاه‌ ارابه‌ها و سواران‌ را جمع کرد. pādišāh arāba-hā wa sawārān rā jam' kard.  / pâdešâh arâbe-hâ va savârân râ jam' kard. The king assembled chariots and cavalrymen. 

 11th century CE , Abulfazl Bayhaqi, edited by Ali-Akbar Fayyaz, Tarikh-i Bayhaqi , page 73 : حَسَن فَرْمُود تَا عَلَامَتِ بُزُرْگ رَا پیشْتَر بُرْدَنْد وَ بَا سَوَارَانِ پُخْتَهٔ گَزِیدَه حَمْلَه اَفْگَنْد بَفیروزِی hasan farmūd tā alāmat-i buzurg rā pēštar burdand wa bā sawārān-i puxta-yi gazīda hamla afgand ba-fērōzī Hasan ordered to move the great emblem forward and attacked victoriously with hand-picked veteran cavalrymen . (Classical Persian romanization) 

 passenger , someone who is riding 
 سوار آن قطار بودم. sawār-i ān qatār būdam.  / savâr-e ân ġatâr budam. I was on that train. (literally, “ I was a passenger of that train. ”)
