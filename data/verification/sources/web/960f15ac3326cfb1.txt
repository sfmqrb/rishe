 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 An Iranian borrowing, ultimately from Proto-Iranian *paridayjah . According to Eilers, an Iranian form *parādēs , which resembles the very common broken plural pattern فَعَالِيق ( faʕālīq ) , was perhaps borrowed as a plural فَرَادِيس ( farādīs ) and the singular فِرْدَوْس ( firdaws ) created as a back-formation from it. [ 1 ] However, the plural فَرَادِيس ( farādīs ) could have been borrowed from Ancient Greek παράδεισος ( parádeisos ) instead. In either way the word went through the Arabic phonological shift /p/ to /f/. [ 2 ] 

 Noun
 [ edit ] 

 فِرْدَوْس • ( firdaws )  m or f ( plural فَرَادِيس ( farādīs ) ) 

 a group of gardens , Elysium , Eden , heaven , Heaven , paradise 
 Synonyms: جَنَّة ( janna ) , نَعِيم ( naʕīm ) 
 Antonyms: سَعِير ( saʕīr ) , لَظَىٰ ( laẓā ) , النَّار ( an-nār ) , جَهَنَّم ( jahannam ) , جَحِيم ( jaḥīm ) , حُطَمَة ( ḥuṭama ) , سَقَر ( saqar ) , هَاوِيَة ( hāwiya ) 
 The Paradise / Firdaus ; the highest place in the celestial garden.
 Antonym: دَرْك ( dark )

 Old Anatolian Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic فِرْدَوْس ( firdaws , “ paradise, Heaven ” ) , ultimately from Proto-Iranian *paridayjah .

 Noun
 [ edit ] 

 فردوس • ( firdevs ) ( definite accusative فردوسی ( firdevsi ) , plural فرادیس ( ferādis ) ) 

 garden , park , any outdoor, luxuriant area where plants are grown for ornamental purposes
 Synonyms: باغ ( baġ ) , باغچه ( baġçe ) , جنت ( cennet ) 

 ( religion ) Heaven , paradise , the abode of God or the gods , when considered as a specific location 
 Synonyms: اوچمق ( uçmaq ) , جنت ( cennet ) , بهشت ( behişt )

 Ottoman Turkish

 Etymology
 [ edit ] 

 Inherited from Old Anatolian Turkish فردوس ( firdevs ) , from Arabic فِرْدَوْس ( firdaws , “ paradise, Heaven ” ) , ultimately from Proto-Iranian *paridayjah .

 Noun
 [ edit ] 

 فردوس • ( firdevs ) ( definite accusative فردوسی ( firdevsi ) , plural فرادیس ( feradis ) ) 

 ( originally ) garden , park , any outdoor, luxuriant area where plants are grown for ornamental purposes
 Synonyms: باغ ( bağ ) , باغچه ( bağçe ) , جنت ( cennet ) 

 ( religion ) Heaven , paradise , the abode of God or the gods , when considered as a specific location 
 Synonyms: اوچماق ( uçmak ) , جنت ( cennet )
