 Etymology
 [ edit ] 

 From Latin Bactria , from Ancient Greek Βακτρίᾱ ( Baktríā ) , from Old Persian 𐎲𐎠𐎧𐎫𐎼𐎡𐏁 ( b-a-x-t-r-i-š /⁠bâxtriš⁠/ ) . Compare Persian باختر ( bâxtar ) and Hindi बाख़्त्र ( bāxtra ) , बाख़्तर ( bāxtar ) .

 Pronunciation
 [ edit ] 

 ( UK ) IPA ( key ) : /ˈbæktɹɪə/ 

 Audio ( Southern England ) : ( file ) 

 Proper noun
 [ edit ] 

 Bactria 

 The ancient name of the country between the range of the Hindu Kush and the Amu Darya in West Asia, encompassing parts of northern Afghanistan , eastern Turkmenistan , southern Uzbekistan , Tajikistan and northern Pakistan .
