 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Ultimately from Proto-Iranian *wr̥jyáti ; see there for more. Cognate with English work and Ancient Greek ἔργον ( érgon ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈwarz/ 

 ( Dari, formal ) IPA ( key ) : [wäɹz] 

 ( Dari, formal ) IPA ( key ) : [wäɹz] 
 ( Kabuli ) IPA ( key ) : [wäɹz] 

 ( Hazaragi ) IPA ( key ) : [wäɹz] 

 ( Iran, formal ) IPA ( key ) : [væɹz] 

 ( Tajik, formal ) IPA ( key ) : [väɹz] 

 Rhymes: -arz

 Noun
 [ edit ] 

 ورز • ( varz ) 

 gain , profit , acquisition 

 custom , habit 

 trade , art , craft ; art of tanning 

 growing corn 

 a sown field

 agriculture

 [ edit ]

 Verb
 [ edit ]
