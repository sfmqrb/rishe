 Central Bikol
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Malayo-Polynesian *kabiʀ .

 Pronunciation
 [ edit ] 

 Hyphenation: ka‧big 

 IPA ( key ) : /ˈkabiɡ/ [ˈka.biɡ] 

 Noun
 [ edit ] 

 kabig 

 manner of raking with one's hand(s)

 Derived terms
 [ edit ] 

 kabigon

 Tagalog
 [ edit ] 

 Alternative forms
 [ edit ] 

 cabig — obsolete , Spanish-based spelling 

 Etymology
 [ edit ] 

 Inherited from Proto-Malayo-Polynesian *kabiʀ .

 Pronunciation
 [ edit ] 

 ( Standard Tagalog ) IPA ( key ) : /ˈkabiɡ/ [ˈk̠aː.bɪɡ̠̚] 

 Rhymes: -abiɡ 

 Syllabification: ka‧big 

 Noun
 [ edit ] 

 kabig ( Baybayin spelling ᜃᜊᜒᜄ᜔ ) 

 act of drawing or pulling something into oneself

 vassal ; subject ; follower
