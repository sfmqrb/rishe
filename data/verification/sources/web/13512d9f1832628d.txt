 Pronunciation
 [ edit ] 

 IPA ( key ) : /tˤi.lasm/ 

 Noun
 [ edit ] 

 طِلَسْم or طِلَّسْم • ( ṭilasm or ṭillasm )  m ( plural طِلَسْمَات ( ṭilasmāt ) or طِلَّسْمَات ( ṭillasmāt ) or طَلَاسِم ( ṭalāsim ) ) 

 enigma 

 talisman 

 seal inscribed with cryptic characters or words

 cryptogram 
 Synonym: شِفْرَة ( šifra , “ cipher; code ” )

 Noun
 [ edit ] 

 طلسم • ( tilism / telesm ) ( plural طلسم‌ها ( tilism-hā / telesm-hâ ) , Tajik spelling тилисм ) 

 spell , incantation , charm 

 talisman , amulet 

 ( figurative ) enigma , mystery
