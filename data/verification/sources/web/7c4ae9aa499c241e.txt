 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [script needed] ( HLLWN-tn' /⁠šustan⁠/ ) , from Proto-Iranian *xšawd- ( “ to wash ” ) , from Proto-Indo-Iranian *kšáwd- ( “ to crush, disperse ” ) , traditionally derived from Proto-Indo-European *k⁽ʷ⁾sewd- ( “ to crush, disintegrate ” ) , though Cheung has reservations on this derivation due to the wide semantic divergence of the PIE root's alleged descendants. [ 1 ] 

 Compare Northern Kurdish şûştin , Central Kurdish شتن ( ştin ) , Southern Kurdish شۊردن ( şürdin ) , Zazaki şutene , Gurani شتەی ( ştey ) , Gilaki شوردن ( šurdən ) , Mazanderani بشوردن ( bašurdan ) .

 Verb
 [ edit ] 

 شستن • ( šustan  / šostan ) ( present stem شوی ( šuy ) or شور ( šur ) , Tajik spelling шустан ) 

 to wash 
 او دارد دستش را می‌شوید . ( more literary ) u dârad dast-aš râ mi-šuyad . He/She is washing his/her hand. 

 اون داره دستش رو می‌شوره. ( more colloquial ) un dâre dast-aš o mi-šure . He/She is washing his/her hand. 

 Usage notes
 [ edit ] 

 The formal and literary present/imperfective stem is شوی ( šuy ) , but in colloquial speech, شور ( šur ) is more common.
