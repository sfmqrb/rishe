 Alternative forms
 [ edit ] 

 آونوس ( āwnūs  / âvnus ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐫀𐫛𐫗𐫇𐫘 ( ʾpnws /⁠abnūs⁠/ ) , from Ancient Greek ἔβενος ( ébenos ) , from Egyptian hbnj ( “ ebony ” ) .

 [ edit ]
