 Arabic

 Arabic Wikipedia has an article on: ببر 

 Wikipedia ar 

 بَبْرٌ 

 Etymology
 [ edit ] 

 Borrowed from Middle Persian bpl ( babr , “ tiger, lion, panther ” ) ; see there for more. Semitic cognates include Classical Syriac ܒܒܪܐ ( bbrʾ ) , and possibly Akkadian 𒌨𒁇𒊏 ( barbarum , “ wolf ” ) if ultimate origin is from Sumerian .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /babr/ 

 Noun
 [ edit ] 

 بَبْر • ( babr )  m ( plural بُبُور ( bubūr ) ) 

 tiger 
 a. 869 C.E. , Al-Jāḥiẓ , edited by Ḥasan Ḥusnī ʕAbd Al-Wahhāb At-Tūnisiyy, ‎ كتاب التبصر بالتجارة , ‎3rd edition, Cairo, Egypt: ‎ مكتبة الخانجي , published 1994 , →OCLC , pages 25–26 : يُجْلَبُ مِنَ ٱلهِنْدِ ٱلبُبُورُ ، وَٱلنُّمُورُ، وَٱلفِيَلَةُ، وَجُلُودُ ٱلنُّمُورِ، وَٱليَاقُوتُ ٱلأَحْمَرُ، وَٱلصَّنْدَلُ ٱلأَبْيَضُ، وَٱلآبَنُوسُ، وَجَوْزُ ٱلهِنْدِ. yujlabu mina l-hindi l-bubūru , wa-n-numūru, wa-l-fiyalatu, wa-julūdu n-numūri, wa-l-yāqūtu l-ʔaḥmaru, wa-ṣ-ṣandalu l-ʔabyaḍu, wa-l-ʔābanūsu, wa-jawzu l-hindi.  Etymology 1
 [ edit ] 

 Borrowed from Greek πιπέρι ( pipéri , “ pepper ” ) , itself from Ancient Greek πέπερι ( péperi ) .

 Alternative forms
 [ edit ] 

 بابری ( beberi ) , بوبر ( büber ) 

 Noun
 [ edit ] 

 ببر • ( biber ) ( definite accusative ببری ( biberi ) , plural ببرلر ( biberler ) ) 

 pepper 
 Synonyms: ایصی اوت ( ısı ot ) , فلفل ( fülfül )

 Etymology 2

 [ edit ] 

 بابر ( baber ) 

 Noun
 [ edit ] 

 ببر • ( bebr or bebir ) ( definite accusative ببری ( bebri ) , plural ببرلر ( bebrler, bebirler ) ) 

 tiger 
 Synonyms: پلنك ( peleng ) , قپلان ( kaplan ) 

 leopard 
 Synonyms: بارس ( bars ) , پلنك ( peleng ) , قپلان ( kaplan ) , یوز ( yuz )
