 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ottoman Turkish پاپوش ( papuş, papuç ) , from Classical Persian پاپوش ( pāpōš ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /paˈpu.t͡si/ 

 Hyphenation: πα‧πού‧τσι 

 Noun
 [ edit ] 

 παπούτσι • ( papoútsi )  n ( plural παπούτσια ) 

 ( footwear ) shoe 

 ( colloquial ) aubergine , eggplant
