 Etymology
 [ edit ] 

 Borrowed from Dravidian , compare Old Tamil 𑀅𑀓𑀺𑀮𑁰 ( akil , “ eagle-wood ” ) . [ 1 ] [ 2 ] Doublet of अगुरु ( aguru ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɐ.ɡɐ.ɾu/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɐ.ɡɐ.ɾu/
