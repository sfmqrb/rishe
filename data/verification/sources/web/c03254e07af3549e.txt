 Alternative forms
 [ edit ] 

 افریشم ( afrēšam  / afrišam ) , فریشم ( farēšam  / farišam ) , پریشم ( parēšam  / parišam ) , ابرشم ( abrišam  / abrešam ) , ابیشم ( abēšam  / abišam ) , بریشم ( barēšam  / barišam ) , ریشم ( rēšam  / rišam ) ( archaic or poetic ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( ʾp̄lyšwm, ʾp̄lyšm /⁠abrēšōm, abrēšom⁠/ , “ silk ” ) , from Proto-Iranian *upawraišamah . Compare Luri ڢریشم ( wrişem ) and Old Armenian loanword ապրիշում ( aprišum , “ silk ” ) .
