 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 نیکو ( niku ) , نکو ( neku ) , نیوکو ( nivaku ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( nywk' /⁠nēk⁠/ ) , [script needed] ( nywkwk' /⁠nēkōg⁠/ ) , the diminutive form of [Term?] ( /⁠nēw⁠/ ) , [ 1 ] from Old Persian *naibakah , from 𐎴𐎡𐎲 ( n-i-b /⁠naibaʰ⁠/ ) , from Proto-Iranian *naybah . Equivalent to نیو ( niv , “ brave, valiant ” ) +‎ ـک ( -ak , diminutive suffix ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈneːk/ 

 ( Dari, formal ) IPA ( key ) : [neːk] 

 ( Dari, formal ) IPA ( key ) : [neːk]

 ( Hazaragi ) IPA ( key ) : [neːk] 

 ( Iran, formal ) IPA ( key ) : [niːkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [nek] 

 Rhymes: -eːk
