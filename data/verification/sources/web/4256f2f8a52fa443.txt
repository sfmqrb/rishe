 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 σάμβαλον ( sámbalon ) — Aeolic 

 Etymology
 [ edit ] 

 Likely from Pre-Greek or some other foreign source, in view of the alternation "νδ/μβ". [ 1 ] Compare also Middle Persian [script needed] ( cndl /⁠čandal⁠/ , “ sandalwood ” ) , from Sanskrit चन्दन ( candana , “ sandalwood ” ) .

 Pronunciation
 [ edit ]

 Noun
 [ edit ] 

 σάνδᾰλον • ( sándălon )  n ( genitive σανδάλου ) ; second declension 

 sandal 

 a flat fish similar to ψῆττα ( psêtta ) 

 Declension
 [ edit ] 

 Second declension of τὸ σάνδᾰλον ; τοῦ σανδᾰ́λου ( Attic )
