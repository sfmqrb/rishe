 Latin
 [ edit ] 

 Alternative forms
 [ edit ] 

 voltur 

 Etymology
 [ edit ] 

 Perhaps from the same source as vellere ( “ to tear, pluck ” ) , but the ending is unclear. De Vaan, despite noting Muller's observation of it maybe being a rhyming word with turtur ( “ dove ” ) , expresses doubt about a hypothetical proto-form *u̯elH-tor- . [ 1 ]

 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈwʊɫ.tʊr] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈvul.tur]
