 Etymology
 [ edit ] 

 From Middle Persian nylw(k)pl ( nīlōpal , “ lotus, water-lily ” ) , ultimately from Sanskrit नीलोत्पल ( nīlotpala , “ blue lotus ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /niː.luː.ˈfar/ 

 ( Dari, formal ) IPA ( key ) : [niː.luː.fäɾ] 

 ( Dari, formal ) IPA ( key ) : [niː.luː.fäɾ] 
 ( Kabuli ) IPA ( key ) : [niː.luː.fäɾ] 

 ( Hazaragi ) IPA ( key ) : [nu.lu.fäɾ] 

 ( Iran, formal ) IPA ( key ) : [niː.luː.fæɹ] 

 ( Tajik, formal ) IPA ( key ) : [ni.lu.fäɾ]

 Noun
 [ edit ] 

 نیلوفر • ( nīlūfar / nilufar ) ( plural نیلوفرها ( nīlūfar-hā / nilufar-hâ ) , Tajik spelling нилуфар ) 

 Ipomoea barbatisepala 
 water lily 

 Ipomoea 
 982 , Hudud al-'Alam :
 از وی ترنج و نارنج و نیشکر و نیلوفر خیزد. az vey toranj o nârenj o neyšekar o nilufar xizad. Bergamot orange, bitter orange, sugarcanes, and Ipomoea grow over there [Balkh].

 Proper noun
 [ edit ] 

 نیلوفر • ( nīlūfar  / nilufar ) ( Tajik spelling Нилуфар ) 

 a female given name , Nilufar and Niloofar , from Middle Persian
