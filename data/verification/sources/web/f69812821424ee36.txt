 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( ystn', yh- /⁠jastan, jah-⁠/ , “ to happen, occur, chance ” ) , [ 1 ] from Proto-Iranian *zgad- ( “ to go on, gallop, mount ” ) . Cognate with Northern Luri جستێ ( cestı ) , Baluchi جہگ ( jihag , “ to flee, escape ” ) , Pashto زغلېدل ( zğaledəl , “ to run ” ) , with no further cognates outside of Iranian.

 Verb
 [ edit ] 

 جستن • ( jastan ) ( present stem جه ( jah ) , Tajik spelling ҷастан ) 

 to jump , leap 
 Synonym: پریدن ( paridan ) 
 c. 1520 , Selim I of the Ottoman Empire , edited by Benedek Péri, The Persian Dīvān of Yavuz Sulṭān Selīm , Budapest, Hungary: Research Centre for the Humanities, Eötvös Loránd Research Network, →ISBN , page 122 : شبم ز روزن اگر ماه آسمان آید
 جهم ز جای تصور کنم که ماه منست šabam zi rōzan agar māh-i āsmān āyad
 jaham zi jāy tasawwur kunam ki māh-i man ast At night, if the moon of the heavens comes to me through the window,
I leap forth from my place, imagining that it is my moon[-like beloved]. (Classical Persian transliteration)

 Etymology 2
 [ edit ] 

 From Proto-Iranian *Hyawd- ( “ to fight, struggle (for something), strive, seek ” ) , from Proto-Indo-Iranian *Hyawdʰ- ( “ to fight, struggle ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /d͡ʒus.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒʊs.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒʊs.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [d͡ʒʊs.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [d͡ʒus.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒos.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [d͡ʒus.t̪ʰán] 

 Rhymes: -an

 Verb
 [ edit ] 

 جستن • ( justan  / jostan ) ( present stem جو ( ju ) , Tajik spelling ҷустан ) 

 to search ; to seek ; to look for 
 c. 1520 , Selim I of the Ottoman Empire , edited by Benedek Péri, The Persian Dīvān of Yavuz Sulṭān Selīm , Budapest, Hungary: Research Centre for the Humanities, Eötvös Loránd Research Network, →ISBN , page 122 : ای دل از غیر مجو یاری واز خصم مترس
دولت و سلطنت آنست که الله دهد ay dil az ġayr majō yārī w-az xasm matars
dawlat u saltanat ān ast ki allāh dihad O heart, seek no support from others and fear not the adversary;
Sovereignty and kingship are what is given by Allah. (Classical Persian transliteration)
