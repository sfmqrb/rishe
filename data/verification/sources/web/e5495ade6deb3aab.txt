 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ha.ˈraːs/ 

 ( Dari, formal ) IPA ( key ) : [hä.ɾɑːs] 

 ( Dari, formal ) IPA ( key ) : [hä.ɾɑːs] 
 ( Kabuli ) IPA ( key ) : [ʔä.ɾɑːs] 

 ( Hazaragi ) IPA ( key ) : [ʔä.ɾɔːs] 

 ( Iran, formal ) IPA ( key ) : [hæ.ɹɒːs] 

 ( Tajik, formal ) IPA ( key ) : [hä.ɾɔs] 

 Rhymes: -aːs
