 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 A variant of کنیزک ( kanizak ) , from Middle Persian [script needed] ( knyck' /⁠kanīzag⁠/ ) , diminutive of [script needed] ( knyk' /⁠kanīg⁠/ , “ maid ” ) from Proto-Iranian *kanyáH ( “ small girl; maiden ” ) , from Proto-Indo-Iranian *kanyáH . Cognate with Sanskrit कन्या ( kanyā ) .

 Noun
 [ edit ] 

 کنیز • ( kaniz ) 

 maidservant

 [ edit ]

 → Punjabi:

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کنیز ( kaniz ) , from Proto-Iranian *kanyáH ( “ small girl; maiden ” ) , from Proto-Indo-Iranian *kanyáH . Doublet of کنّیا ( kannayā ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /kə.niːz/ 

 Rhymes: -iːz 

 Noun
 [ edit ] 

 کَنِیز • ( kanīz )  f ( Hindi spelling कनीज़ ) 

 maid , slave-girl 
 Synonyms: لونڈی ( launḍī ) , باندی ( bāndī )
