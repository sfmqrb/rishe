 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Italian Asia , from {{der|ota|la|Asia]], from Ancient Greek Ᾰ̓σῐ́ᾱ ( Ăsĭ́ā , “ Asia ” ) , from Mycenaean Greek 𐀀𐀯𐀹𐀊 ( a-si-wi-ja /⁠aswijaː⁠/ ) , from Hittite 𒀸𒋗𒉿 ( Aššuwa , “ northwest Anatolia ” ) .

 Proper noun
 [ edit ] 

 آسیا • ( asiya ) 

 Asia (the largest continent , located between Europe and the Pacific Ocean ) 

 ( historical ) Asia (an ancient province of the Roman Empire in western Anatolia , existing between 133 BC (during the Roman Republic ) and the 7th century AD) 

 Derived terms
 [ edit ] 

 آسیالو ( Asyalı , “ Asiatic ” ) 

 Descendants
 [ edit ] 

 Turkish: Asya

 Etymology 2
 [ edit ] 

 Borrowed from Classical Persian آسیا ( āsiyā ) .

 Noun
 [ edit ] 

 آسیا • ( asya ) 

 mill , a grinding apparatus for substances such as grains or seeds 
 Synonyms: دگرمن ( değirmen ) , رحی ( raha ) 

 mill , a building housing such a grinding apparatus 

 Derived terms
 [ edit ] 

 آسیاب ( asyab , “ watermill ” ) 
 آسیابان ( asyaban , “ miller ” ) 
 آسیازنه ( asyazene , “ pick for sharpening millstones ” ) 

 Descendants
 [ edit ]

 Proper noun
 [ edit ] 

 آسیا • ( āsiyā  / âsiyâ ) ( Tajik spelling Осиё ) 

 Asia (the largest continent , located between Europe and the Pacific Ocean ) 
 Meronyms: آسیای جنوبی ( âsiyâ-ye jonubi ) , آسیای شرقی ( âsiyâ-ye šarqi ) , آسیای غربی ( âsiyâ-ye ġarbi ) 

 ( historical ) Asia (an ancient province of the Roman Empire in western Anatolia , existing between 133 BC (during the Roman Republic ) and the 7th century AD)
