 Etymology
 [ edit ] 

 From Hebrew זְכַרְיָה ( zəḵaryā ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /za.xaˈri.as/ → /za.xaˈri.as/ 

 ( 4 th CE Koine ) IPA ( key ) : /za.xaˈri.as/ 

 ( 10 th CE Medieval ) IPA ( key ) : /za.xaˈri.as/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /za.xaˈri.as/ 

 Proper noun
 [ edit ] 

 Ζαχαρίᾱς • ( Zakharíās )  m ( genitive Ζαχαρίου ) ; first declension 

 Zechariah , Zachary , a male given name from Hebrew 
 93 CE – 94 CE , Josephus , Antiquities of the Jews 9.169

 Usage notes
 [ edit ] 

 While some sources refer to the Old Testament figure as Zechariah and the New Testament figure as Zacharias, the Greek makes no distinction between the two. Also note that Ζαχαρίας has no accentuation in the LXX .
