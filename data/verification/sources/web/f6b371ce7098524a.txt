 Etymology
 [ edit ] 

 Learned borrowing from Late Latin sarcasmus .

 Pronunciation
 [ edit ] 

 IPA ( key ) : ( Northern , Balearic , Central ) [sərˈkaz.mə] 

 IPA ( key ) : ( Valencia ) [saɾˈkaz.me] 

 IPA ( key ) : ( Northwestern ) [sarˈkaz.me] 

 Audio ( Barcelona ) : ( file ) 

 Noun
 [ edit ]

 sarcasm
