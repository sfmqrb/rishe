 Persian آتش 

 From Middle Persian 𐫀𐫤𐫍𐫢 ( ʾthš /⁠ātaxš⁠/ , “ fire ” ) , borrowed from Avestan 𐬁𐬙𐬀𐬭𐬱 ( ātarš , “ fire ” ) for its special meaning in Zoroastrianism and well preserved unlike the other word آذر ( âzar , “ fire ” ) . [ 1 ] Doublet of آذر . Ultimately from Proto-Iranian *HáHtr̥š ; see there for further information.

 Urdu
 [ edit ] 

 آتش 
 Etymology
 [ edit ] 

 Borrowed from Classical Persian آتش ( ātaš ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɑː.t̪ɪʃ/ , /ɑː.t̪əʃ/ 

 Noun
 [ edit ] 

 آتِش or آتَش • ( ātiś or ātaś )  f ( Hindi spelling आतिश or आतश ) 

 fire ; flame 
 Synonym: آگ ( āg ) 

 anger ; rage 

 passion , zeal 

 Derived terms
 [ edit ] 

 آتش گاہ ( ātiś/ātaś gāh , “ fireplace ” ) 

 آتش دان ( ātiś/ātaś dān , “ fireplace ” ) 

 آتش زنہ ( ātiś/ātaś zana , “ flint ” ) 

 آتش کَدَہ ( ātiś/ātaś kada , “ fire-temple ” )
