 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European *werǵ- ( “ work ” ) , formed similarly to ξόᾰνον ( xóănon , “ statue, xoanon ” ) ; compare ἔργον ( érgon , “ work, deed ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ór.ɡa.non/ → /ˈor.ɣa.non/ → /ˈor.ɣa.non/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ór.ɡa.non/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈor.ɡa.non/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈor.ɣa.non/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈor.ɣa.non/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈor.ɣa.non/ 

 Noun
 [ edit ] 

 ὄργᾰνον • ( órgănon )  n ( genitive ὀργᾰ́νου ) ; second declension 

 instrument , implement , tool 

 sense organ

 musical instrument 

 the material of a work (e.g. timber )

 the product of a work (e.g. lumber )
