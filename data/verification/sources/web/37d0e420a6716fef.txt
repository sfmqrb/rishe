 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 اسپهبد ( espahbod ) , سپاهبد ( sepâhbad ) , سپاهبذ ( sepâhbaz ) , اسپاهبذ ( espâhbaz, espâhboz ) , اسپهبذ ( espahbaz, espahboz ) , اسبهبد ( esbahbad ) , اسبهبد ( esbahbaz ) , اسفهبد ( esfahbad, esfahbod ) , اسفهبذ ( esfahbaz ) , اصفهبد ( esfahbad ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐭮𐭯𐭠𐭧𐭯𐭲𐭩 ( spāhbed ) , from Old Persian *spādapatiš , from Proto-Iranian *cwaHdapatiš ( “ commander of the army ” ) . By surface analysis , سپاه ( sepâh , “ army ” ) +‎ ـبد ( -bod , “ lord, master ” ) .

 Noun
 [ edit ] 

 سپهبد • ( sepahbod ) ( plural سپهبدها , or سپهبدان ) 

 ( historical ) commander of army, especially in the Sassanian army

 spahbed ; a rank in Iranian army equivalent to lieutenant general
