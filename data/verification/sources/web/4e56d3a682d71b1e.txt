 From Wiktionary, the free dictionary

 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Etymology
 [ edit ] 

 Possibly extended from *sten- ( “ to groan ” ) . [ 1 ] 

 Root
 [ edit ] 

 *(s)tenh₂- [ 2 ] [ 3 ] 

 to thunder 

 Derived terms
 [ edit ] 

 ? *(s)ténh₂-e-ti ( thematic root present ) 
 Proto-Italic: *tenō [ 4 ] 
 Latin: tonō ( “ to thunder ” ) ( readjusted to iterative [ 4 ] ) ( see there for further descendants )

 *(s)ténh₂-t ~ (s)tn̥h₂-ént ( athematic root aorist ) [ 2 ] 
 Proto-Indo-Iranian: *HástanHt 
 Proto-Indo-Aryan: *HástanHt 
 Sanskrit: *अस्तनीत् ( *ástanīt ) [ 2 ] 
 ⇒ Sanskrit: स्तन् ( stan , 3sg.inj.act ) , स्तनिहि ( stanihi , “ to thunder ” , 2sg.impv.act. ) 

 *(s)tén-ye-ti ( ye-present ) [ 2 ] ( < *(s)ténh₂-ye-ti [ 2 ] with Pinault's law ) 
 Proto-Indo-Iranian: *tányati 
 Proto-Indo-Aryan: *tányati 
 Sanskrit: तन्यति ( tanyati , “ to thunder ” ) 

 *(s)tonh₂-éye-ti ( iterative ) [ 2 ] [ 4 ] 
 Proto-Indo-Iranian: *stanHáyati 
 Proto-Indo-Aryan: *stanHáyati 
 Sanskrit: स्तनयति ( stanáyati , “ to thunder ” ) 

 Proto-Italic: *tonaō [ 4 ] 
 Latin: tonō ( “ to thunder ” ) ( see there for further descendants )

 *(s)ténh₂-tr̥ ~ *(s)tn̥h₂-tén-s 
 Proto-Indo-Iranian: *tánHtā ( “ thunder ” ) ( see there for further descendants )

 Proto-Italic: *tenatrus 
 Latin: tonitrus ( “ thunder ” ) ( readjusted to iterative ) ( see there for further descendants )

 *(s)tónh₂-r̥ ~ *(s)ténh₂-n̥s, *(s)ténh₂-r̥ ~ *(s)tn̥h₂-éns 
 Proto-Celtic: *toranos ( “ thunder ” ) ( < *tonaros < *(s)tónh₂r-os [ 5 ] ) ( see there for further descendants )

 Proto-Germanic: *þun(a)raz ( “ thunder ” ) ( < *(s)tn̥h₂r-os [ 5 ] ) ( see there for further descendants )
