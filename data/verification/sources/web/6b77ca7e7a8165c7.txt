 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Usually said to be from Latin sāpō , but borrowing from Galatian is also possible. Ultimately from Proto-Germanic *saipǭ ( “ soap ” ) , from Proto-Indo-European *seyp- , *seyb- ( “ to pour, strain, trickle ” ) . Cognate with Old English sāpe ( “ soap ” ) . More at soap .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈsa.pon/ → /ˈsa.pon/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈsa.pon/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈsa.pon/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈsa.pon/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈsa.pon/ 

 Noun
 [ edit ] 

 σᾱ́πων • ( sā́pōn )  m ( genitive σᾱ́πωνος ) ; third declension 

 ( Koine ) soap 
 Aretaeus of Cappadocia, De Curatione Diuturnorum Morborum 2.13

 77 CE , Pliny the Elder , Natural History 28.12

 Serenus Sammonicus 158

 Inflection
 [ edit ]

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek σᾱ́πων ( sā́pōn , “ soap ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈsapon/ 

 Hyphenation: σά‧πων 

 Noun
 [ edit ] 

 σάπων • ( sápon )  m ( plural σάπωνες ) 

 Katharevousa form of σαπούνι ( sapoúni , “ soap ” )
