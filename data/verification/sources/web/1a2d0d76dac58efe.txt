 Alternative forms
 [ edit ] 

 دیویست ( divist ) ( colloquial , Tehrani ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Term?] ( /⁠duwēst⁠/ ) , from Avestan 𐬛𐬎𐬎𐬈𐬯𐬀𐬙𐬈 ( duuesate ) . [ 1 ] Cognate with Sogdian [script needed] ( dwyst ) . Displaced by دوصد ( do-sad ) in eastern dialects of Persian.
