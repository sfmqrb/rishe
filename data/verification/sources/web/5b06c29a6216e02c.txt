 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit रहस्य ( rahasya ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ɾə.ɦəs.jᵊ/ , [ɾɛ.ɦɛs.jᵊ] 

 Noun
 [ edit ] 

 रहस्य • ( rahasya )  m ( Urdu spelling رہسیہ ) 

 secret , mystery 
 Synonyms: राज़ ( rāz ) , भेद ( bhed ) 
 उसके स्वास्थ्य का रहस्य क्या है? uske svāsthya kā rahasya kyā hai? What is the secret to his health? 

 थानेदार ने रहस्य झट से खोल दिया। thānedār ne rahasya jhaṭ se khol diyā. The police inspector quickly solved the mystery .

 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *raȷ́ʰ- ( “ secret, mystery; to abandon ” ) , and cognate with Persian راز ( râz ) , with further origin uncertain. Mayrhofer tentatively derived the root from Proto-Indo-European *legʰ- ( “ to lay ” ) originally, but later doubts this derivation. [ 1 ] Also related to रहति ( rahati , “ to abandon ” ) . By surface analysis , रह् ( rah ) +‎ -अस्य ( -asya ) . [ 2 ]
