 Etymology
 [ edit ] 

 Etymology tree

 Arabic دُوَل ( duwal ) bor.

 Proto-Indo-European *bʰendʰ- der. 
 Proto-Indo-Iranian *bʰandʰás 
 Proto-Iranian *bandáh 
 Persian بند ( band ) 

 Persian دولبند 

 From دول ( dōl, dawl , “ revolving ” ) , + بند ( band , “ band, tie ” ) , [ 1 ] compare دوربند ( dōrband  / durband , “ band, belt ” ) . Cognate with Northern Kurdish dorbend ( “ frame ” ) .

 Noun
 [ edit ] 

 دولبند • ( dōlband / dulband ) ( Tajik spelling дӯлбанд ) 

 ( archaic ) turban , sash of a turban 
 Synonyms: دستار ( dastâr ) , عمامه ( 'ammâme ) , بست ( bast ) , ساره ( sâra ) 

 ( archaic ) diadem 
 Synonyms: تاج ( tâj ) , دیهیم ( deyhim ) 

 ( archaic ) hat
