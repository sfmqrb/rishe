 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic مُضْحِك ( muḍḥik ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /muz.ˈhik/ 

 ( Dari, formal ) IPA ( key ) : [mʊz.hɪk] 

 ( Dari, formal ) IPA ( key ) : [mʊz.hɪk] 
 ( Kabuli ) IPA ( key ) : [mʊ.zɪk] 

 ( Hazaragi ) IPA ( key ) : [mu.zik] 

 ( Iran, formal ) IPA ( key ) : [moz.hekʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [muz.hik] 

 Rhymes: -ik

 Adjective
 [ edit ] 

 مضحک • ( mozhek ) ( comparative مضحک‌تَر , superlative مضحک‌تَرین ) 

 ( formal ) provoking laughter , funny 
 Synonym: خنده‌دار ( xande-dâr )
