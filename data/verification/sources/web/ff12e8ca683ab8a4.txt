 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 From From Classical Persian شیر ( šīr ) , from Middle Persian [Book Pahlavi needed] ( HLḆA ) .

 Noun
 [ edit ] 

 شیر • ( şir ) 

 milk , a white liquid produced by the mammary glands of female mammals 
 Synonyms: حلیب ( halib ) , سوت ( süt ) , لبن ( leben ) 

 Etymology 2
 [ edit ] 

 From Classical Persian شیر ( šēr ) , from Middle Persian 𐫢𐫃𐫡 ( šgr /⁠šagr, šēr⁠/ , “ lion; (astronomy) Leo ” ) .

 Noun
 [ edit ] 

 شیر • ( şir ) ( definite accusative شیری ( şiri ) , plural شیرلر ( şirler ) ) 

 lion , any large felid of the species Panthera leo 
 Synonyms: آرسلان ( arslan ) , اسد ( esed ) , غضنفر ( gazanfer ) , هزبر ( hizebr ) 

 ( figuratively ) lion , a strong , brave and valiant man

 Noun
 [ edit ] 

 شیر • ( šēr / šir ) ( plural شیرها ( šēr-hā / šir-hâ ) , or شیران ( šērān / širân ) , Tajik spelling шер ) 

 lion 
 Synonyms: ارسلان ( arsalān  / arsalân ) , اسد ( asad ) , هزبر ( hizabr  / hezabr ) , هژبر ( hižabr  / hežabr ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume II, verse 751: چون رسد آن جا ببیند گرگ و شیر 
عمر ضایع راه دور و روز دیر čūn rasad ān-jā bibīnad gurg u šēr 
 umr-i zāyi' rāh-i dūr u rōz-i dēr When he reaches the spot, he sees wolves and lions ,
his life lost, the road far off, and the day late. ( Classical Persian transliteration ) 

 faucet , tap 

 ( Indo-Persian ) tiger ( sometimes also applied to the leopard )
