 Arabic قنديل 

 Borrowed from Classical Syriac ܩܢܕܠܐ ( qandēlā ) , borrowed from Ancient Greek κανδήλη ( kandḗlē ) .

 [ edit ]

 Noun
 [ edit ] 

 قِنْدِيل • ( qindīl )  m ( plural قَنَادِيل ( qanādīl ) ) 

 lamp 
 Synonyms: مِصْبَاح ( miṣbāḥ ) , سِرَاج ( sirāj ) , نِبْرَاس ( nibrās ) , لَمْبَة ( lamba ) , وَابُور ( wābūr ) , بَابُور ( bābūr ) , فَانُوس ( fānūs ) , مِشْعَل ( mišʕal ) , ( obsolete ) زُجَاجَة ( zujāja ) , مِسْرَجَة ( misraja ) , قِرَاط ( qirāṭ ) 
 1996 , Ibrahim Abdel Meguid , لَا أَحَدَ يَنَامُ فِي ٱلْإِسْكَنْدَرِيَّة [ No One Sleeps in Alexandria ]: هَٰذَا ٱبْنُ آدَمَ حَقِيقِيٌّ. اِقْتَرَبَ أَكْثَرَ وَقَرَّبَ ٱلْقِنْدِيلَ إِلَى وَجْهِ ٱلْإِنْسَانِ وَهَتَفَ hāḏā bnu ʔādama ḥaqīqiyyun. iqtaraba ʔakṯara waqarraba l-qindīla ʔilā wajhi l-ʔinsāni wahatafa This is a real human being! He came closer and shone the lamp in the human's face and exclaimed: 

 candlestick , candelabrum 

 thorny broom ( Calicotome )
