 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کینه ( kīna  / kine ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( kyn' /⁠kēn⁠/ , “ hate, malice, revenge ” ) , from Old Persian *kainah , from Proto-Iranian *kaynáH , from Proto-Indo-Iranian *kaynáH , from Proto-Indo-European *kʷoynéh₂ ( “ revenge, punishment; redemption price; price; honor ” ) . Akin to Sanskrit चयते ( cayate ) , Avestan 𐬐𐬀𐬉𐬥𐬁 ( kaēnā , “ punishment, revenge ” ) and Old Armenian քէն ( kʻēn ) .

 Noun
 [ edit ] 

 کین • ( kīn / kin ) ( Tajik spelling кин ) 

 ( archaic ) hatred , enmity , rancour , malice ; revenge
