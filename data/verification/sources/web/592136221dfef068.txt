 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian پاجامه ( pâjâme ) . By surface analysis , پا ( pa ) + جامه ( came ) .

 Noun
 [ edit ] 

 پاجامه • ( pacame ) 

 trousers 
 Synonyms: طون ( don ) , شلوار ( şelvar ) 

 Descendants
 [ edit ] 

 Turkish: pacame 

 Further reading
 [ edit ] 

 Mehmed Salâhî ( 1897–1906 ), “ پاجامه ”, in Kâmûs-ı Osmânî , volume 2, page 272

 Etymology
 [ edit ] 

 From پا ( pâ , “ leg ” ) +‎ جامه ( jâme , “ garment ” ) .
