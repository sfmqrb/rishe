 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian دشوار ( došvâr , “ difficult, hard ” ) , from Middle Persian [script needed] ( dwšw'l /⁠dušwār⁠/ ) .

 Adjective
 [ edit ] 

 دشوار • ( düşvâr ) 

 difficult , hard , cumbersome , demanding to handle or get around with
 Synonyms: چتین ( çetin ) , سخت ( saht ) , گوچ ( güç ) , مشكل ( müşkil ) 

 Derived terms
 [ edit ] 

 دشوار پسند ( düşvâr pesend , “ hard to please ” ) 
 دشوارلق ( düşvârlık , “ difficulty, hardness ” ) 
 دشواری ( düşvârî , “ difficulty, hardness ” ) 

 Descendants

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 دشخوار ( došxvâr ) , دژوار ( dožvâr ) 

 Etymology
 [ edit ] 

From Middle Persian [script needed] ( dwšw'l /⁠dušwār⁠/ ) , from Old Persian [Term?] . By surface analysis , دش ( duš- , “ bad ” ) +‎ خوار ( xvâr , “ easy; mean, abject ” ) , denoting the opposite of easy; [ 1 ] see Proto-Iranian *duš- ( “ bad ” ) for more on the prefix. Compare Old Armenian դժուար ( džuar ) , an Iranian borrowing.
