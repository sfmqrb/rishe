 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( HYMNN-stn' /⁠wurrōyistan⁠/ ) , 𐫇𐫡𐫇𐫏𐫘𐫤 ( wrwyst /⁠wurrōyist[an]⁠⁠/ , “ to believe; to choose ” ) ; regularized based on the present stem 𐫇𐫡𐫇 ( wrw /⁠wurrōy-⁠/ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡi.ra.wiː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾä.wiː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾä.wiː.d̪án] 
 ( Kabuli ) IPA ( key ) : [ɡɪ.ɾä.wiː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [ɡi.ɾä.wi.d̪án] 

 ( Iran, formal ) IPA ( key ) : [ɡʲe.ɹæ.viː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [ɡi.ɾä.vi.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 گرویدن • ( geravidan ) ( present stem گرو ( gerow ) ) 

 ( intransitive ) to convert , come to faith 
 به اسلام گرویدند . ― be eslâm geravidand . ― They converted to Islam.
