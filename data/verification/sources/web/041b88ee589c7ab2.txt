 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic دِيبَاجَة ( dībāja ) , from Middle Persian [script needed] ( dypʾk' /⁠dēbāg⁠/ , “ brocade ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /deː.baː.ˈt͡ʃa/ 

 ( Dari, formal ) IPA ( key ) : [d̪eː.bɑː.t͡ʃʰä] 

 ( Dari, formal ) IPA ( key ) : [d̪eː.bɑː.t͡ʃʰä] 
 ( Kabuli ) IPA ( key ) : [d̪eː.bɑː.t͡ʃʰä] 

 ( Hazaragi ) IPA ( key ) : [d̪eː.bɔː.t͡ʃʰä] 

 ( Iran, formal ) IPA ( key ) : [d̪iː.bɒː.t͡ʃʰe] 

 ( Tajik, formal ) IPA ( key ) : [d̪e.bɔ.t͡ʃʰä] 

 Rhymes: -a

 Noun
 [ edit ] 

 دیباچه • ( dēbāča / dibâče ) ( Tajik spelling дебоча ) 

 preface , introduction 
 Synonym: مقدمه ( muqaddama  / moġaddame )
