 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 πάλληξ ( pállēx ) 

 Etymology
 [ edit ] 

 Probably a back-formation from παλλακή ( pallakḗ , “ concubine ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pál.laːks/ → /ˈpal.laks/ → /ˈpa.laks/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pál.laːks/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈpal.laks/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈpal.laks/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈpal.laks/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈpa.laks/ 

 Noun
 [ edit ] 

 πάλλᾱξ • ( pállāx )  m or f ( genitive πάλλᾱκος ) ; third declension 

 youth ( young boy or girl )

 Inflection
 [ edit ] 

 Third declension of ὁ / ἡ πᾰ́λλᾱξ ; τοῦ / τῆς πᾰ́λλᾱκος ( Attic )
