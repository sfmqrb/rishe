 Etymology
 [ edit ] 

 Cognate with Persian رشک ( rešk ) . This etymology is incomplete. You can help Wiktionary by elaborating on the origins of this term. 

 Comparisons with रक्ष॑स् ( rákṣas , “ harm ” ) and to other Indo-European words for “nit; mite, tick” are problematic.

 Pronunciation
 [ edit ] 

 ( Classical Sanskrit ) IPA ( key ) : /l̪ik.ʂɑː/ 

 Noun
 [ edit ] 

 लिक्षा • ( likṣā ) stem ,  f 

 a nit (the egg of a louse )
