 Etymology 1
 [ edit ] 

 From Middle Persian [script needed] ( srēnōg ) , from Proto-Iranian *cráwniš , from Proto-Indo-European *ḱlównis .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /su.ˈreːn/ , /su.ˈriːn/ 

 ( Dari, formal ) IPA ( key ) : [sʊ.ɾéːn] , [sʊ.ɾíːn] 

 ( Dari, formal ) IPA ( key ) : [sʊ.ɾéːn] , [sʊ.ɾíːn] 
 ( Kabuli ) IPA ( key ) : [sʊ.ɾéːn] , [sʊ.ɾíːn] 

 ( Hazaragi ) IPA ( key ) : [su.ɾéːn] , [su.ɾín] 

 ( Iran, formal ) IPA ( key ) : [so.ɹíːn] , [seɹíːn] 

 ( Tajik, formal ) IPA ( key ) : [su.ɾén] , [su.ɾín] 

 Rhymes: -eːn , -iːn
