 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian swk' ( sōg , “ burn, burning ” ) , from Old Persian *θauga(h) , from Proto-Iranian *cawkah , from Proto-Indo-Iranian *ćawkas (compare Sanskrit शोक ( śoka , “ burning; grief ” ) , whence Hindustani सोग ( sog ) / سوگ ( sog ) and Punjabi ਸੋਗ ( sog ) / سوگ ( sog ) ), ultimately from Proto-Indo-European *ḱewk- .

 Related to سوختن ( sōxtan , “ to burn ” ) , سرخ ( surx , “ red ” ) , and سوگند ( sawgand , “ oath ” ) ; and also to Old Armenian սուգ ( sug , “ grief ” ) , an Iranian borrowing.

 grief , sorrow , affliction , mourning

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Sauraseni Prakrit 𑀲𑁄𑀕 ( soga ) , from Sanskrit शोक ( śoka ) . Also influenced by Classical Persian سوگ ( sōg ) . Doublet of شوک ( śok ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /soːɡ/ 

 Rhymes: -oːɡ 

 Noun
 [ edit ] 

 سوگ • ( sog )  m ( Hindi spelling सोग ) 

 grief , sorrow , affliction , mourning 
 Synonyms: غَم ( ġam ) , رَنْج ( ranj ) , شوک ( śok )
