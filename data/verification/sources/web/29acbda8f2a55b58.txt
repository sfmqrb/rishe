 Etymology
 [ edit ] 

 Borrowed from Classical Persian جادو ( jādū ) , from Proto-Indo-Iranian *yaHtúš . Doublet of यातु ( yātu ) . Compare Assamese যাদু ( zadu ) , Bengali জাদু ( jadu ) , Marathi जादू ( jādū ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /d͡ʒɑː.d̪uː/ , [d͡ʒäː.d̪uː] 

 Noun
 [ edit ] 

 जादू • ( jādū )  m ( Urdu spelling جادو ) 

 jadoo ; magic ; witchcraft 

 incantation 
 जादू चलाना ― jādū calānā ― to cast a spell 

 charm
