 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian wyrʾst, wyrʾy- ( wirāst, widrāy- , “ to arrange, prepare, cultivate, restore ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /wiː.raːs.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [wiː.ɾɑːs.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [wiː.ɾɑːs.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [wiː.ɾɑːs.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [wi.ɾɔːs.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [viː.ɹɒːs.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [vi.ɾɔs.t̪ʰán] 

 Rhymes: -an
