 Pahari-Potwari
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Prakrit 𑀓𑀫𑁆𑀫 ( kamma ) , from Sanskrit कर्म ( karma ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kəmːᵊ/ 

 Noun
 [ edit ] 

 کَمّ ( kamm )  m 

 work , job , task 

 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 Etymology tree

 Proto-Iranian *kamb- 
 Proto-Iranian *kam(b)-na- 
 Middle Persian 𐭪𐭬 ( km /⁠kam⁠/ ) 
 Persian کم 

 Inherited from Middle Persian 𐭪𐭬 ( km /⁠kam⁠/ , “ little, small ” ) , [ 1 ] from Proto-Iranian *kam(b)-na- ( “ small ” ) , from *kamb- ( “ small ” ) , from Proto-Indo-Iranian *kambʰ- ( “ few, small, insignificant ” ) . Probably further related to Proto-Indo-European *ken- ( “ to arise, begin; new, fresh ” ) . [ 2 ]

 Adjective
 [ edit ] 

 کم • ( kam ) ( comparative کم‌تَر , superlative کم‌تَرین ) 

 Dari

 کم 

 Iranian Persian

 Tajik

 кам 

 few , little 
 Synonyms: خجاره ( xojâre ) , اندک ( andak ) 
 Antonyms: زیاد ( ziyâd ) , خیلی ( xeyli ) 

 scarce , rare , lacking 

 Usage notes
 [ edit ] 

 Unlike most comparatives and superlatives, کم‌تر ( kam-tar ) , and کم‌ترین ( kam-tarin ) are frequently written joined, as کمتر ( kamtar ) and کمترین ( kamtarin )
