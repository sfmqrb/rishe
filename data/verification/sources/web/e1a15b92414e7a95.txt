 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit वन ( vana ) . Doublet of बन ( ban ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ʋən/ , [ʋɐ̃n] 

 Noun
 [ edit ] 

 वन • ( van )  m ( Urdu spelling ون ) 

 forest , jungle , woods 
 Synonyms: see Thesaurus: जंगल 
 यह भयानक वन सैकड़ों किलोमीटर तक फैला था । yah bhayānak van saikṛõ kilomīṭar tak phailā thā. This dreadful forest stretched for hundreds of kilometers.

 Etymology
 [ edit ] 

 Thematised from वन् ( ván , “ tree, wood ” ) , from Proto-Indo-Iranian *wán- ( “ tree, wood ” ) ; see the former for more. Cognate with Younger Avestan 𐬬𐬀𐬥𐬁   f ( vanā , “ tree ” ) , Pashto ونه ( wëna , “ tree ” ) , Sogdian wn ( “ tree ” ) , Middle Persian [script needed] ( wan /⁠wn'⁠/ , “ tree ” ) . [ 1 ] [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ʋɐ́.nɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /ʋɐ.n̪ɐ/ 

 Noun
 [ edit ] 

 वन॑ • ( vána ) stem ,  n 

 ( Vedic ) a tree 
 Synonym: वृक्ष ( vṛkṣa ) 

 a forest , wood , grove , thicket , quantity of lotuses or other plants growing in a thick cluster
 c. 1500 BCE – 1000 BCE , Ṛgveda 6.60.10 : तमी॑ळिष्व॒ यो अ॒र्चिषा॒ वना॒ विश्वा॑ परि॒ष्वज॑त्।
 कृ॒ष्णा कृ॒णोति॑ जि॒ह्वया॑॥ támīḷiṣva yó arcíṣā vánā víśvā pariṣvájat.
 kṛṣṇā́ kṛṇóti jihváyā. Glorify that Agni who envelopes all the forests with flame, who blackens them with (his) tongue. 

 a foreign or distant land

 wood , timber 

 a wooden vessel or barrel (for the soma juice)

 a cloud (as the vessel in the sky)

 (prob.) the body of a carriage

 abode 

 coco-grass ( Cyperus rotundus )

 a ray of light 
 Synonym: रश्मि ( raśmi ) 

 (prob.) longing, earnest desire
