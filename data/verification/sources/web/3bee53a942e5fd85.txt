 Karaim
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Turkic *kïĺ . Cognate to Karachay-Balkar къыш ( qış ) , Kumyk къыш ( qış ) , Crimean Tatar qış , etc.

 Noun
 [ edit ] 

 kyš 

 winter 

 References
 [ edit ] 

 N. A. Baskakov, S.M. Šapšala, editor ( 1973 ), “ kyš ”, in Karaimsko-Russko-Polʹskij Slovarʹ [ Karaim-Russian-Polish Dictionary ], Moscow: Moskva, →ISBN 

 Middle Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *kayšás , from Proto-Indo-Iranian *kayšás , from Proto-Indo-European *kʷoys-ó-s . ( Can this ( + ) etymology be sourced ?) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /keːʃ/ 

 Noun
 [ edit ] 

 kyš • ( kêš ) 

 dogma , faith (especially non-Mazdean)

 Descendants
 [ edit ] 

 Persian: کیش ( kiš ) 

 References
 [ edit ] 

 MacKenzie, D. N. ( 1971 ), “kēš”, in A concise Pahlavi dictionary , London, New York, Toronto: Oxford University Press
