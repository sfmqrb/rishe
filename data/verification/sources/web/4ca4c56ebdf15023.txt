 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 اریال ( iriyale ) [ 1 ] 

 Etymology
 [ edit ] 

 Borrowed from Italian reale , [ 2 ] from Spanish real . [ 3 ] 

 Noun
 [ edit ] 

 ریال • ( riyal ) 

 Any of various units of currency (Spanish dollar, French five franc piece, etc.) 

 Descendants
 [ edit ] 

 Turkish: riyal 

 References
 [ edit ]
