 Ottoman Turkish
 [ edit ] 

 اردو 
 Alternative forms
 [ edit ] 

 اوردو ( ordu ) 

 Etymology
 [ edit ] 

 Inherited from Proto-Turkic *ordu ( “ army camp ” ) .

 Noun
 [ edit ] 

 اردو • ( ordu ) ( definite accusative اردویی ( orduyu ) , plural اردولر ( ordular ) ) 

 military camp 
 Synonym: اردوكاه ( ordugâh ) 

 ( by extension ) army 
 Synonyms: جند ( cünd ) , جیش ( ceyiş ) , چری ( çeri ) , عسكر ( ʼasker ) , لشكر ( leşker ) 
 1911 , Ahmed Rafik [Altınay ], مختار تاريخ عمومى [ muhtar-i tarih-i umumi ]‎ [1] : ٤. پارلامنتونك رأیی اولمادن وقت حضرده اردو طوپلامق و دائمی ‌بولوندرمق ممنوعدر. 4. Parlamentonun reyi olmadan vakit-i hazarda ordu toplamak ve daimi bulundurmak memnudur. (please add an English translation of this quotation)

 Etymology 1
 [ edit ] 

 Shortened from اُرْدُوئے مُعَلّیٰ ( urdūe mu'allā ) , from زُبانِ اُرْدُوئے مُعَلّیٰ ( zubān-i urdūe mu'allā ) , borrowed from Classical Persian زُبَانِ اُرْدُویِ مُعَلّیٰ ( zubān-i urdū-yi mu'allā , “ language of the royal camp ” ) .

 Proper noun
 [ edit ] 

 اُرْدُو • ( urdū )  f ( Hindi spelling उर्दू ) 

 Terms Hindustani and Urdu were used synonymously during first decade of the 20th century.

 ( historical , obsolete ) Rekhta ( the Hindustani language ) 

 Etymology 2
 [ edit ] 

 Borrowed from Classical Persian اردو ( urdū ) , from Turkic .

 Noun
 [ edit ] 

 اُرْدُو • ( urdū )  f ( Hindi spelling उर्दू ) 

 ( military , rare ) army , camp
