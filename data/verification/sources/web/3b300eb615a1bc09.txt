 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Of the root ز م ن ( z m n ) from زَمَان ( zamān , “ time ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /muz.min/ 

 ( Kuwait ) IPA ( key ) : /mʊzmɪn/ 

 Adjective
 [ edit ] 

 مُزْمِن • ( muzmin ) ( feminine مُزْمِنَة ( muzmina ) ) 

 chronic
