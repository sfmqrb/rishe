 Hebrew
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Tiberian ) IPA ( key ) : /kəˈruːβ/ 

 ( Modern Israeli ) IPA ( key ) : /ˈkʁuv/ , /ˈkʀuv/ 

 ( reconstructed Biblical ) IPA ( key ) : /kaˈruːb/ , /kaˈruːβ/ 

 Etymology 1
 [ edit ] 

 Root 

 כ־ר־ב ( k-r-b ) 

 2 terms 

 From Ancient Greek κράμβη ( krámbē , “ cabbage ” ) . 

 Noun
 [ edit ] 

 כְּרוּב • ( kruv )  m ( plural indefinite כְּרוּבִים , singular construct כְּרוּב־ ) 

 cabbage 

 Derived terms
 [ edit ]

 Etymology 2
 [ edit ] 

 From a Proto-Semitic source akin to Akkadian 𒅗𒊒𒁍 ( “ to bless ” ) , 𒅗𒊑𒁍 ( “ one who blesses ” ) .

 Noun
 [ edit ] 

 כְּרוּב • ( kruv )  m ( plural indefinite כְּרוּבִים ) 

 cherub , griffin
