 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 چمه‌دان ( čame-dân ) 

 چمدون ( čamedun ) ( colloquial Tehrani ) 

 Etymology
 [ edit ] 

 Borrowed from Russian чемода́н ( čemodán ) , from Persian جامه‌دان ( jâme-dân , “ suitcase ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /t͡ʃa.ma.ˈdaːn/ 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.mä.d̪ɑːn] 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.mä.d̪ɑːn] 
 ( Kabuli ) IPA ( key ) : [t͡ʃʰä.mä.d̪ɑːn] 

 ( Hazaragi ) IPA ( key ) : [t͡ʃʰä.mä.d̪ɔːn] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰæ.me.d̪ɒːn] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰæ.me.d̪ɒːn]
