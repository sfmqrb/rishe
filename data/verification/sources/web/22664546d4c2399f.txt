 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐭣𐭩𐭣𐭩𐭬𐭩 ( dīyēm, dīdēm , “ diadem ” ) from Parthian 𐭃𐭉𐭃𐭉𐭌 ( dīδēm, dīdēm , “ half-crown, flower-crown ” ) . Ultimately from Ancient Greek διάδημα ( diádēma ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /daj.ˈhiːm/ 

 ( Dari, formal ) IPA ( key ) : [d̪äj.hiːm] 

 ( Dari, formal ) IPA ( key ) : [d̪äj.hiːm] 
 ( Kabuli ) IPA ( key ) : [d̪ä.jiːm] 

 ( Hazaragi ) IPA ( key ) : [d̪ä.jim] 

 ( Iran, formal ) IPA ( key ) : [d̪ej.hiːm] 

 ( Tajik, formal ) IPA ( key ) : [d̪äj.him] 

 Rhymes: -iːm

 دیهیم • ( dayhīm ) ( plural دیهیم‌ها ) 

 ( archaic ) diadem 
 10th Century CE , Ferdowsi , Shahnameh 
 که بوُد آنْکه دَیْهیم بَر سَر نِهاد
نَدارَد کَس آن روزگاران بِیاد kē būd ān-kē dayhīm bar sar nihād
nadārad kas ān rōzgārān bi-yād who was he wore the diadem ?!
No one remembers those days (No one remembers the epoch of the olden kings).
