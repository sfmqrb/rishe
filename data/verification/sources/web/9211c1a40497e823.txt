 Etymology
 [ edit ] 

 From Proto-Indo-European *h₂werg- ( “ to turn ” ) . Cognate with Latin vergō , the source of English converge etc. 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ʋr̩d͡ʑ/ 

 ( Classical Sanskrit ) IPA ( key ) : /ʋr̩d͡ʑ/ 

 Root
 [ edit ] 

 वृज् • ( vṛj ) 

 to bend , turn , twist 

 to pluck , gather 

 to wring off
