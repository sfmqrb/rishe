 Tamil
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /t̪oːɡɐɪ̯/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 தோகை • ( tōkai ) 

 plumage , feathers 

 tail of a peacock 
 Synonym: பீலி ( pīli ) 

 peacock 
 Synonym: மயில் ( mayil ) 

 tail of an animal 
 Synonym: வால் ( vāl ) 

 Synonyms
 [ edit ] 

 சிறகு ( ciṟaku ) , முடி ( muṭi ) , உரோமம் ( urōmam ) , செட்டை ( ceṭṭai )
