 Arabic صراط 

 Variant of سِرَاط ( sirāṭ ) . From Classical Syriac ܐܣܛܪܛ ( ˀesṭrāṭ ) , from Latin strāta .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sˤi.raːtˤ/ , /si.raːtˤ/ 

 Rhymes: -aːtˤ 

 Noun
 [ edit ] 

 صِرَاط • ( ṣirāṭ )  m ( plural صُرُط ( ṣuruṭ ) ) 

 path , way , road 
 Synonyms: طَرِيق ( ṭarīq ) , سَبِيل ( sabīl ) , طَرِيقَة ( ṭarīqa ) , دَرْب ( darb ) , سِرَاط ( sirāṭ ) , شَرِيعَة ( šarīʕa ) , شَارِع ( šāriʕ ) , مَسْلَك ( maslak ) , سَمْت ( samt ) 
 609–632 CE , Qur'an , 1:6 : اِهْدِنَا ٱلصِّرَٰطَ ٱلْمُسْتَقِيمَ ihdinā ṣ-ṣirāṭa l-mustaqīma Guide us to the straight path
