 Portuguese
 [ edit ] 

 monção

 Alternative forms
 [ edit ] 

 moução , mouçaõ , mouçam , monçaõ , monçam ( obsolete ) 

 Etymology
 [ edit ] 

 Borrowed from Arabic مَوْسِم ( mawsim ) . [ 1 ] [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Brazil ) IPA ( key ) : /mõˈsɐ̃w̃/ [mõˈsɐ̃ʊ̯̃] 

 ( Portugal ) IPA ( key ) : /mõˈsɐ̃w̃/ 

 Audio ( Portugal ) : ( file ) 

 Homophone : Monção 

 Hyphenation: mon‧ção 

 Noun
 [ edit ] 

 monção   f ( plural monções ) 

 monsoon (tropical rainy season)

 ( figurative ) opportunity , occasion 

 each of the several fluvial expeditions by 17th century Brazilian explorers
