 Hindi
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /d͡ʒɑː.mɑː/ , [d͡ʒäː.mäː] 

 Etymology 1
 [ edit ] 

 Borrowed from Classical Persian جامه ( jāma ) . Compare Bengali জামা ( jama ) , Punjabi ਜਾਮਾ ( jāmā ) .

 Noun
 [ edit ] 

 जामा • ( jāmā )  m ( Urdu spelling جامہ )

 garment 

 robe 

 gown 

 vest

 Etymology 2
 [ edit ] 

 Borrowed from Classical Persian جَامِع ( jāmi' ) , from Arabic جَامِع ( jāmiʕ ) .

 Alternative forms
 [ edit ] 

 जामिया ( jāmiyā ) 

 Noun
 [ edit ] 

 जामा • ( jāmā )  m ( Urdu spelling جَامِع ) 

 ( Islam ) jamia , congregational mosque

 Noun
