 Chagatai
 [ edit ] 

 Alternative forms
 [ edit ] 

 𐽷𐽶𐾁𐽶𐾀 ( kylyt /⁠kilīd⁠/ ) — Old Uyghur script 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کِلِید ( kilīd ) .

 Noun
 [ edit ] 

 کلید • ( klyd / kilīd /) 

 key 
 Synonyms: قفل ( qfl /⁠qüfl⁠/ ) , مفتاح ( mftʾḥ /⁠miftāh⁠/ ) 
 1484 , Ali-Shir Nava'i , فرهاد و شیرین [ Farhad and Shirin ], page 250b : اچیب اول کنج قفلین بو کلیدیم 
نصیبیم ایلا نی کیم بار امیدیم ʾčyb ʾwl knj qflyn bw klydym 
nṣybym ʾylʾ ny kym bʾr ʾmydym / ačıp ol gänj-i quflın bu kilīdim 
näsībim äylä ne kim bar ümīdim / (please add an English translation of this quotation)

 Alternative forms
 [ edit ] 

 کیلیت ( kilit ) ( dialectal , Tehrani ) 

 کلیل ( kelil ) ( dialectal , Dezfuli )

 Etymology
 [ edit ] 

 Inherited from Middle Persian *kilēd , from Ancient Greek κλείς, κλειδός ( kleís, kleidós ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ka.ˈliːd/ , /ki.ˈliːd/ 

 ( Dari, formal ) IPA ( key ) : [kʰä.liːd̪] , [kʰɪ.liːd̪] 

 ( Dari, formal ) IPA ( key ) : [kʰä.liːd̪] , [kʰɪ.liːd̪] 
 ( Kabuli ) IPA ( key ) : [kʰɪ.liː] 

 ( Hazaragi ) IPA ( key ) : [kʰi.li] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæ.liːd̪̥] , [kʰʲe.liːd̪̥] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæ.liːd̪̥] , [kʰʲe.liːd̪̥] 
 ( Tehrani ) IPA ( key ) : [kʰʲiː.liːt̪ʰ] 

 ( Tajik, formal ) IPA ( key ) : [kʰä.lid̪]
