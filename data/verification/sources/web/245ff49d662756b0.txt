 Alternative forms
 [ edit ] 

 स्वेत ( svet ) — colloquial 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit श्वेत ( śveta ) . Doublet of सफ़ेद ( safed ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ʃʋeːt̪/ 

 Adjective
 [ edit ] 

 श्वेत • ( śvet ) ( indeclinable , Urdu spelling شویت ) 

 white 
 उस वृद्ध की दाढ़ी सम्पूर्ण रूप से श्वेत है। us vŕddh kī dāṛhī sampūrṇ rūp se śvet hai. That old man's beard is completely white .

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *ḱweyt- 
 Proto-Indo-Iranian *ćwaytás 
 Sanskrit श्वेत 

 From Proto-Indo-Iranian *ćwaytás ( “ white ” ) , from Proto-Indo-European *ḱweyt-ó-s , from *ḱweyt- ( “ bright; shine ” ) .

 Cognate with Avestan 𐬯𐬞𐬀𐬉𐬙𐬀 ( spaēta ) , Classical Persian سفید ( safēd ) , Old Church Slavonic свѣтъ ( světŭ ) , Russian свет ( svet ) , Old English hwīt (whence English white ). Related to Sanskrit श्वित्र ( śvitrá ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɕʋɐi̯.tɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɕʋeː.t̪ɐ/ 

 Adjective
 [ edit ] 

 श्वे॒त • ( śvetá ) stem 

 white , bright , dressed in white 
 c. 1500 BCE – 1000 BCE , Ṛgveda 8.55.2 : श॒तं श्वे॒तास॑ उ॒क्षणो॑ दि॒वि तारो॒ न रो॑चंते । śatáṃ śvetā́sa ukṣáṇo diví tā́ro ná rocaṃte. One hundred white bulls shine like the stars in the sky.
