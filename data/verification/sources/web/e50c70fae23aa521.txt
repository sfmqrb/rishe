 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 سودن ( sudan ) , ساویدن ( sâvidan ) , پسودن ( pasudan ) 

 سابیدن ( sâbidan ) ( colloquial ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( swtn' /⁠sūdan⁠/ , “ to rub ” ) , present stem [Book Pahlavi needed] ( sʾd- /⁠sāy-⁠/ ) ; regularized from the older infinitive سودن ( sūdan / sudan ) with ـیدن ( -īdan  / -idan ) . Ultimately from Proto-Iranian *sauH- ( “ to rub ” ) , from Proto-Indo-European *ḱeh₃(i)- ( “ to sharpen ” ) . Compare Central Kurdish سوون ( sûn , “ to rub; to sharpen ” ) , Sanskrit शा ( śā , “ to sharpen ” ) , Latin catus ( “ clever ” ) , English hone .

 Verb
 [ edit ] 

 ساییدن • ( sāyīdan  / sâyidan ) ( present stem سای ( sāy  / sây ) , Tajik spelling соидан ) 

 to rub , grind 

 to pulverise 

 to wear away , erode
