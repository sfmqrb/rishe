 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *tyegʷ- ( imperfective ) [ 1 ] [ 2 ] 

 to leave alone, give up

 to retreat 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *tyegʷ- (20 c, 0 e) 

 *tyégʷ-e-tor ( thematic present ) [ 3 ] 
 Proto-Hellenic: *tségʷomai ( see there for further descendants )

 Proto-Indo-Iranian: *tyáǰatay 
 Proto-Indo-Aryan: *tyáȷ́atay 
 Sanskrit: त्यजते ( tyájate ) 

 *tyégʷ-e-ti ( present ) 
 Proto-Indo-Iranian: *tyáǰati 
 Proto-Indo-Aryan: *tyáȷ́ati 
 Sanskrit: त्यजति ( tyájati ) ( see there for further descendants )

 *te-tyógʷ-e ~ *te-tigʷ-ḗr ( perfect ) 
 Proto-Indo-Iranian: *tityā́ǰa 
 Proto-Indo-Aryan: *tityā́ȷ́a 
 Vedic Sanskrit: तित्याज ( tityā́ja ) 
 ⇒ Sanskrit: तत्याज ( tatyāja ) 

 *tyogʷ-éye-ti ( causative ) [ 3 ] 
 Proto-Hellenic: *tsogʷéyō 
 Ancient Greek: σοβέω ( sobéō ) 

 Proto-Indo-Iranian: *tyāǰáyati 
 Proto-Indo-Aryan: *tyāȷ́áyati 
 Sanskrit: त्याजयति ( tyājáyati ) 

 *tyégʷ-os ~ *tyégʷ-es- [ 4 ] 
 ( perhaps ) Hellenic: *tségʷos 
 Ancient Greek: σέβας ( sébas ) 

 Proto-Indo-Iranian: *tyáǰas ( see there for further descendants )
