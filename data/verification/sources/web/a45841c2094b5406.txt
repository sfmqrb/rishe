 Etymology
 [ edit ] 

 From Middle Persian nibeg ( “ book ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ni.ˈbeːɡ/ 

 ( Dari, formal ) IPA ( key ) : [nɪ.beːɡ] 

 ( Dari, formal ) IPA ( key ) : [nɪ.beːɡ] 
 ( Kabuli ) IPA ( key ) : [nɪ.beːɡ] 

 ( Hazaragi ) IPA ( key ) : [ni.beːɡ̥] 

 ( Iran, formal ) IPA ( key ) : [ne.biːɡʲ̥] 

 ( Tajik, formal ) IPA ( key ) : [ni.beɡ] 

 Rhymes: -eːɡ

 Noun
 [ edit ] 

 نبیگ • ( nebig, nebêg ) 

 Book ( not limited to a collection of sheets of paper bound together like the given definition, can also indicate a collection of "books" all being continuous to one another, like a dictionary. For the mentioned definition above, see نسک )
