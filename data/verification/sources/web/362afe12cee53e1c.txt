 Noun
 [ edit ] 

 ژاژ • ( žāž / žâž ) ( Tajik spelling жож ) 

 ( archaic ) A tough, insipid variety of artichoke which cannot be chewed or swallowed by the camel

 ( figurative ) idle talk , nonsense 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume II, verse 420: مصطفی مه میشکافد نیم شب
 ژاژ میخاید ز کینه بو لهب Mustafa mah mē-šikāfad nīm šab
 žāž mē-xāyad za kīna Bū Lahab Mustafá (Mohammed) splits the moon at midnight;
Abú Lahab from hatred talks drivel .

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian ژاژ ( žāž ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ʒɑːʒ/ 

 Adjective
 [ edit ] 

 ژاژ • ( źāź ) ( indeclinable , Hindi spelling झ़ाझ़ ) ( dated or literary ) 

 trivial , frivolous , trifling 
 Synonym: لَغْو ( laġv ) 

 absurd , nonsensical ; untrue 

 Noun
 [ edit ] 

 ژاژ • ( źāź )  m ( Hindi spelling झ़ाझ़ ) ( dated or literary ) ( uncountable ) 

 the Indian globe thistle ( Echinops echinatus )
 Synonym: اُون٘ٹ کَٹارا ( ū̃ṭ kaṭārā ) 

 nonsense , absurdity 
 Synonyms: اُوٹ پَٹان٘گ ( ūṭ paṭāṅg ) , ہَرزَہ گوئِی ( harza goī ) , بَکْواس ( bakvās ) , بَکَیتی ( bakaitī ) , زَٹَل ( zaṭal ) , لَغْوِیات ( laġviyāt ) 

 obscene or indecent speech 
 Synonym: فُحش گوئِی ( fuhś goī )
