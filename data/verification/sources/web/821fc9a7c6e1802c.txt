 Etymology
 [ edit ] 

 From Middle Persian 𐫗𐫖𐫏𐫍𐫐 ( namak ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /na.ˈmak/ 

 ( Dari, formal ) IPA ( key ) : [nä.mák]

 ( Kabuli ) IPA ( key ) : [nä.mák] 

 ( Hazaragi ) IPA ( key ) : [nä.mäk] , [ni.mɔ́ːk] 

 ( Iran, formal ) IPA ( key ) : [næ.mǽkʰʲ]

 Noun
 [ edit ] 

 نمک • ( namak ) ( Tajik spelling намак ) 

 salt 

 charm ; attractive or delightful quality 

 ( figurative ) Used as a metonymy for hospitality .
