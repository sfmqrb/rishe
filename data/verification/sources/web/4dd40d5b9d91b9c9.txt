 Ancient Greek

 Alternative forms
 [ edit ] 

 πόρδᾰλῐς ( pórdălĭs ) 

 Etymology
 [ edit ] 

 Borrowed from a foreign eastern language. Compare various Indo-Iranian terms like Sogdian 𐼾𐼴𐽀𐼹𐼻𐼸 ( pwrδnk ) , Bactrian πορλαγγο-ζινο ( porlango-zino ) , Pashto پړانګ ( pṛāng ) , Persian پلنگ ( palang ) , and Sanskrit पृदाकु ( pṛ́dāku ) . See also πάνθηρ ( pánthēr ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pár.da.lis/ → /ˈpar.ða.lis/ → /ˈpar.ða.lis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pár.da.lis/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈpar.da.lis/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈpar.ða.lis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈpar.ða.lis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈpar.ða.lis/ 

 Noun
 [ edit ] 

 πᾰ́ρδᾰλῐς • ( pắrdălĭs )  f ( genitive πᾰρδᾰ́λεως ) ; third declension 

 leopard 

 panther

 [ edit ]
