 وزیر • ( vezir ) ( plural وزیرلر ( vezirler ) ) 

 minister , cabinet minister

 vizier 

 helper , assistant 

 ( chess ) queen

 Etymology
 [ edit ] 

 Etymology tree

 Urdu وزیر 

 Borrowed from Classical Persian وَزیر ( vazīr ) , borrowed from Arabic وَزِير ( wazīr ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ʋə.ziːɾ/ 

 Noun
 [ edit ] 

 وَزِیر • ( vazīr )  m ( formal plural وُزَرا ( vuzarā ) or وَزِیران ( vazīrān ) , Hindi spelling वज़ीर ) 

 ( government ) minister 
 وَزِیرِ تِجارَت ― vazīr-i tijārat ― minister of commerce 

 vizier 

 ( chess ) queen / fers 
 Synonym: فَرْزِین ( farzīn )
