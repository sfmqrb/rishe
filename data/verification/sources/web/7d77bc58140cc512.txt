 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *mátsyas . Cognate with Persian ماهی ( māhī ) . 

 Noun
 [ edit ] 

 ماهی ( māhī ) 

 fish 

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian ماهی ( mâhi ) .

 Noun
 [ edit ] 

 ماهی • ( mahi ) 

 fish , a cold-blooded animal that lives in water 
 Synonyms: بالق ( balık ) , حوت ( hut ) , سمك ( semek ) 

 ( astronomy ) Pisces , a constellation of the zodiac 

 ( astrology ) Pisces , the zodiac sign for the fish 

 Derived terms
 [ edit ] 

 ماهیانه ( mahiyane , “ fish-broth ” ) 
 ماهیدان ( mahidan , “ fishpond ” ) 
 ماهیدانه ( mahidane , “ Indian berry ” ) 
 ماهیپین ( mahiçin , “ kind of fish-eating bird ” ) 
 ماهیچه ( mahiçe , “ little fish ” ) 

 Descendants
 [ edit ] 

 Turkish: mahi
