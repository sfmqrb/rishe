 Alternative forms
 [ edit ] 

 آذینه ( āḏēna ) ( Early New Persian ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ʾdynk' /⁠ādēnag ~ āyēnag⁠/ ) (in Pazand texts mentioned as 𐬁𐬛𐬉𐬥𐬀 ( ādēna ) and 𐬁𐬜𐬉𐬥𐬀 ( āδēna ) ) perhaps from Parthian. Akin to Northern Kurdish eynî , în , Central Kurdish هەینی ( heynî ) , Zazaki îne , Manichean Sogdian 𐫀𐫀𐫔𐫏𐫗𐫀𐫆 ( ʾʾδynʾẖ /⁠āδēnē⁠/ ) , 𐫀𐫀𐫔𐫏𐫗𐫏 ( ʾʾδyny /⁠āδēnē⁠/ , “ Friday ” ) and Khwarezmian آذینک ( ʾδynk /⁠āδēnek⁠/ , “ Friday ” ) .

 Noun
 [ edit ] 

 آدینه • ( ādīna / âdine ) ( plural آدینه‌ها ( ādīna-hā / âdine-hâ ) , Tajik spelling одина ) 

 Friday 
 Synonym: جمعه ( jum'a  / jom'e )
