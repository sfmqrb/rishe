 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *h₂elgʷʰ- [ 1 ] [ 2 ] 

 to cost , have value, be worth

 Derived terms
 [ edit ] 

 *h₂élgʷʰ-e-ti ( root thematic ) 
 Proto-Indo-Iranian: *Hárǰʰati ( see there for further descendants )

 *h₂élgʷʰ-t ~ *h₂l̥gʷʰ-ént ( athematic root aorist ) 
 Proto-Hellenic: 
 Ancient Greek: ἦλφον ( êlphon ) 
 ⇒ Ancient Greek: ἀλφάνω ( alphánō ) 

 *h₂elgʷʰ-ós 
 Proto-Indo-Iranian: *Hargʰás ( “ price ” ) ( see there for further descendants )

 *h₂elgʷʰ-éh₂ [ 3 ] 
 Proto-Balto-Slavic: *algā́ˀ ( see there for further descendants )

 Proto-Hellenic: 
 > ? Ancient Greek: ἀλφή ( alphḗ ) ( probably an independent formation ) 

 *h₂l̥gʷʰ- 
 Proto-Anatolian: 
 ⇒ Hittite: 𒄬𒆪𒂊𒌍𒊬 ( ḫal-ku-e-eš-šar /⁠ḫalkuēššar⁠/ , “ supplies (for festivals) ” ) 

 Descendants
 [ edit ] 

 Proto-Indo-Iranian: 
 Sanskrit: अर्ह् ( arh ) ( see there for further descendants )
