 Alternative forms

 سپرز ( seporz ) 

 Etymology
 [ edit ] 

 Inherited from Proto-Iranian *spr̥jā́ .

 Noun
 [ edit ] 

 اسپرز • ( esporz ) ( plural اسپرزها ) 

 ( anatomy ) spleen , milt 
 Synonym: طحال ( tahâl )
