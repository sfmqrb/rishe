 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European * yúHs -meh₂ ( “ fermentation, soup ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /zdy̌ː.mɛː/ → /ˈzy.mi/ → /ˈzi.mi/ 

 ( 5 th BCE Attic ) IPA ( key ) : /zdy̌ː.mɛː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈzy.me̝/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈzy.mi/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈzy.mi/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈzi.mi/ 

 Noun
 [ edit ] 

 ζῡ́μη • ( zū́mē )  f ( genitive ζῡ́μης ) ; first declension 

 leaven 
 c.  1st century A.D. , “ 1 Corinthians 5:6-8”, in New Testament : Οὐ καλὸν τὸ καύχημα ὑμῶν. οὐκ οἴδατε ὅτι μικρὰ ζύμη ὅλον τὸ φύραμα ζυμοῖ; ἐκκαθάρατε οὖν τὴν παλαιὰν ζύμην , ἵνα ἦτε νέον φύραμα, καθώς ἐστε ἄζυμοι. καὶ γὰρ τὸ πάσχα ἡμῶν ὑπὲρ ἡμῶν ἐτύθη Χριστός· ὥστε ἑορτάζωμεν μὴ ἐν ζύμῃ παλαιᾷ, μηδὲ ἐν ζύμῃ κακίας καὶ πονηρίας, ἀλλ’ ἐν ἀζύμοις εἰλικρινείας καὶ ἀληθείας. Ou kalòn tò kaúkhēma humôn. ouk oídate hóti mikrà zúmē hólon tò phúrama zumoî? ekkathárate oûn tḕn palaiàn zúmēn , hína ête néon phúrama, kathṓs este ázumoi. kaì gàr tò páskha hēmôn hupèr hēmôn etúthē Khristós; hṓste heortázōmen mḕ en zúmēi palaiāî, mēdè en zúmēi kakías kaì ponērías, all’ en azúmois eilikrineías kaì alētheías. Your boasting is not a good thing. Do you not know that a little yeast leavens all of the dough? Clean out the old yeast so that you may be a new batch of dough, as you really are unleavened. For our paschal lamb, Christ, has been sacrificed. Therefore, let us celebrate the festival, not with the old yeast , the yeast of malice and evil, but with the unleavened bread of sincerity and truth.
