 Persian بازو 

 From Old Persian 𐎲𐎠𐏀𐎢 ( bāzu ) , from Proto-Indo-Iranian *bʰaHȷ́ʰúš , from Proto-Indo-European *bʰeh₂ǵʰús ( “ arm ” ) . Cognate with Avestan 𐬠𐬁𐬰𐬬𐬋 ( bāzvō ) , Khotanese bāysū , Sanskrit बाहु ( bāhu ) and Ancient Greek πῆχυς ( pêkhus , “ forearm ” ) . Also akin to Old Armenian բազուկ ( bazuk ) , an Iranian borrowing.

 Etymology
 [ edit ] 

 Etymology tree

 Urdu بازو 

 Borrowed from Classical Persian بَازُو ( bāzū ) . Doublet of بَان٘ہہ ( bā̃h ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /bɑː.zuː/ 

 Audio ( Pakistan ) : ( file ) 

 Rhymes: -uː 

 Noun
 [ edit ] 

 بازُو • ( bāzū )  m ( Hindi spelling बाज़ू ) 

 ( anatomy ) arm 
 اس کے بازو پر ایک نشان ہے۔ ― He has a scar on his arm. 

 ( anatomy ) wing of a bird, etc.

 ( military ) flank of an army

 ( figuratively ) supporter or companion

 side of a framework or a door, doorpost 

 sleeve of a garment
