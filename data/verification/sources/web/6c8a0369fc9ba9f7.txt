 Mazanderani
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian 𐭥𐭠𐭭𐭢 ( ʿʾng /⁠vāng⁠/ ) , probably from Proto-Indo-European *wṓkʷs ( “ voice, speech ” ) . 

 Noun
 [ edit ] 

 ونگ ( vang ) 

 voice , sound , noise 

 Derived terms
 [ edit ] 

 ونگ وا ( vang-e vā ) 

 References
 [ edit ] 

 حسن‌دوست، واژه‌نامه ریشه‌شناسی ۵ جلدی (Persian)

 Punjabi
 [ edit ] 

 Etymology
 [ edit ] 

 From Prakrit 𑀯𑀗𑁆𑀕 ( vaṅga ) .

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /ʋəŋɡ/ , [ʋə̃ŋɡ(ə̆)] 

 Rhymes: -əŋɡ 

 Noun
 [ edit ] 

 وَن٘گ • ( vaṉg )  f ( Gurmukhi spelling ਵੰਗ ) 

 bangle ( made out of glass or plastic )
