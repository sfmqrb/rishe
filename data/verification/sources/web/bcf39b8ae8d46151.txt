 Etymology
 [ edit ] 

 Borrowed from Arabic نُقْرَة ( nuqra ) .

 Pronunciation
 [ edit ]

 Noun
 [ edit ] 

 نقره • ( nuqra / noġre ) ( Tajik spelling нуқра ) 

 silver ( metal ) 
 Synonym: ( literary ) سیم ( sīm  / sim ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 178: زر و نقره گر نبودندی نهان / پرورش کی یافتندی زیر کان zarr u nuqra gar nabūdanī nihān / parwariš kay yāftandī zēr-i kān If gold and silver were not hidden, how would they get nourishment [grow and ripen] in the mine? ( Classical Persian transliteration )
