 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *ǵem- der. 
 Proto-Indo-Iranian *ȷ́ā́mātā 
 Sanskrit जामा॑तृ 

 Inherited from Proto-Indo-Iranian *ȷ́ā́mātā ( “ son-in-law ” ) , from Proto-Indo-European *ǵem- . Cognate with Avestan 𐬰𐬁𐬨𐬁𐬙𐬀𐬭 ( zāmātar , “ son-in-law ” ) , Persian داماد ( dâmâd ) , Ancient Greek γαμβρός ( gambrós , “ any relative by marriage ” ) , γάμος ( gámos ) (whence English -gamy ).

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /d͡ʑɑ́ː.mɑː.tr̩/ 

 ( Classical Sanskrit ) IPA ( key ) : /d͡ʑɑː.mɑː.t̪r̩/ 

 Noun
 [ edit ] 

 जामा॑तृ • ( jā́mātṛ ) stem ,  m 

 a son-in-law 
 c. 1500 BCE – 1000 BCE , Ṛgveda 8.26.21 : तव॑ वायव् ऋतस्पते॒
त्वष्टु॑र् जामातर् अद्भुत।
 अवां॒स्य् आ वृ॑णीमहे॥ táva vāyav ṛtaspate
tváṣṭur jāmātar adbhuta.
 ávāṃsy ā́ vṛṇīmahe. Wonderful Vāyu, Lord of the Order,
O thou who art Tvaṣṭar's son-in-law ,
Thy saving succour we elect.
