 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 شالوار ( şalvar ) 

 Etymology
 [ edit ] 

 Borrowed from Persian شلوار ( šalvâr ) .

 Noun
 [ edit ] 

 شلوار • ( şelvar ) ( plural شلوارلر ) 

 shalwar , loose trousers worn in some South Asian or Islamic countries
 Synonyms: ( trousers ) ایچ طون ( iç don ) , طومان ( tuman ) 

 Derived terms
 [ edit ]

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( šlwʾl /⁠šalwār⁠/ , “ trousers ” ) , borrowed from Proto-Scythian *šalawāri .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʃal.ˈwaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʃäl.wɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [ʃäl.wɑ́ːɾ]

 ( Hazaragi ) IPA ( key ) : [ʃäl.wɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [ʃæl.vɒ́ːɹ]

 Noun

 Tajik

 شلوار • ( šalwār / šalvâr ) ( plural شلوارها ( šalwār-hā / šalvâr-hâ ) , Tajik spelling шалвор ) 

 trousers , pants 
 Synonyms: ازار ( ezâr ) ; پاجامه ( pâjâme ) ; ( Dari ) پتلون ( patlûn ) ; ( archaic ) سروال ( servâl ) ; ( dated ) تنبان ( tonbân )
