 Persian

 Persian Wikipedia has an article on: چکش

 Alternative forms
 [ edit ] 

 چکوچ ( čakuč ) , چاکوچ ( čâkuč ) , چکوج ( čakuj ) , چلوچ ( čaluč, čoluč ) 

 چَکّوش ( čakkuš ) — dialectal, Feyzabad 

 Etymology
 [ edit ] 

 From earlier چکوچ ( čakuč ) , from Middle Persian ckwc ( čakuč , “ hammer ” ) , from Avestan 𐬗𐬀𐬐𐬎𐬱 ( cakuš , “ battle-axe ” ) , from Proto-Indo-European *keku- ( “ cudgel, hammer shaped stick ” ) . Doublet of چاقو ( čâqu ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /t͡ʃa.ˈkuʃ/ 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.kʰʊ́ʃ] 

 ( Dari, formal ) IPA ( key ) : [t͡ʃʰä.kʰʊ́ʃ] 
 ( Kabuli ) IPA ( key ) : [t͡ʃʰä.kʰʊ́ʃ] 

 ( Hazaragi ) IPA ( key ) : [t͡ʃʰä.kʰúʃ] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰækʰʲ.kʰóʃ] 

 ( Tajik, formal ) IPA ( key ) : [t͡ʃʰä.kʰúʃ]
