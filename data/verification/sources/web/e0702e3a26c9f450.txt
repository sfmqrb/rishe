 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Egyptian zšn . Compare also Biblical Hebrew שׁוֹשַׁנָּה ( šōšannā , “ lily ” ) and Coptic ϣⲱϣⲉⲛ ( šōšen ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sûː.son/ → /ˈsu.son/ → /ˈsu.son/ 

 ( 5 th BCE Attic ) IPA ( key ) : /sûː.son/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈsu.son/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈsu.son/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈsu.son/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈsu.son/ 

 Noun
 [ edit ] 

 σοῦσον • ( soûson )  n ( genitive σούσου ) ; second declension 

 lily (plant of the genus Lilium )
 Synonym: κρίνον ( krínon ) 

 Declension
 [ edit ] 

 Second declension of τὸ σοῦσον ; τοῦ σούσου ( Attic )
