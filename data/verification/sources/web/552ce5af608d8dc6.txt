 English
 [ edit ] 

 Etymology
 [ edit ] 

 From French bardache , from Italian bardassa , perhaps from Arabic بَرْدَج ( bardaj , “ slave ” ) . Doublet of berdache .

 Pronunciation
 [ edit ] 

 ( Received Pronunciation ) IPA ( key ) : /bɑːˈdæʃ/ 

 ( General American ) IPA ( key ) : /bɑɹˈdæʃ/ , /ˈbɑɹˌdæʃ/ 

 Rhymes: -æʃ 

 Noun
 [ edit ] 

 bardash ( plural bardashes ) 

 A homosexual kept boy or young man ; a catamite .
 Synonyms: gunsel ; see also Thesaurus: male homosexual
