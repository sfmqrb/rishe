 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 جلیتقه ( jelitqe ) , جلیدقه ( jelidqe ) ( archaic ) 

 جلزقه ( jelezqe ) ( dialectal ) 

 Etymology
 [ edit ] 

 Borrowed from Arabic جَلِيقَة ( jalīqa ) , from Turkish yelek ( “ waistcoat ” ) , modeled after corset , mantelet etc. Compare Greek γιλέκο ( giléko ) , Spanish chaleco .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒe.liː.ʁé] 

 Readings

 Iranian reading ? 

 jeliġe

 Noun
 [ edit ] 

 جلیقه • ( jeliqe ) ( plural جلیقه‌ها ( jeliqe-hâ ) ) 

 waistcoat , vest 

 Derived terms
 [ edit ] 

 جلیقه ضد گلوله ( jeliqe-ye zedd-e golule , “ bulletproof vest ” ) 
 جلیقه نجات ( jeliqe-ye nejât , “ life vest ” ) 

 Further reading
 [ edit ] 

 Dehkhoda, Ali-Akbar ( 1931– ), “ جلیقه ”, in Dehkhoda Dictionary Institute , editors, Dehkhoda Dictionary (in Persian), Tehran: University of Tehran Press .
