 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian kntn' ( kantan , “ to dig ” ) , from Proto-Iranian *kánHati ( “ to dig ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kan.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [kʰän̪.d̪án] 

 ( Dari, formal ) IPA ( key ) : [kʰän̪.d̪án] 
 ( Kabuli ) IPA ( key ) : [kʰän̪.d̪án] 

 ( Hazaragi ) IPA ( key ) : [kʰän̪.d̪án] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæn̪.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [kʰän̪.d̪án]

 Verb
 [ edit ] 

 کندن • ( kandan ) ( present stem کَن , Tajik spelling кандан ) 

 to dig 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume V, verse 2072: هر طرف کندند و جستند آن فریق، حفره‌ها کردند و گوهای عمیق. har taraf kandand o jostand ân fariq, hofre-hâ kardand o gow-hâ-ye 'amiq. The [searching] party dug and searched in every direction: they dug holes and deep cavities. 

 ( of clothes, etc. ) to take off 

 ( of hair, teeth, etc. ) to tear out 

 to inscribe , to carve
