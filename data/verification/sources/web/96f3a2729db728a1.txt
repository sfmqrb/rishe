 Proto-Oghuz 
 Ottoman Turkish بوی 

 Inherited from Proto-Oghuz , borrowed from Classical Persian بوی ( bôy , “ smell ” ) , from Middle Persian 𐫁𐫇𐫏 ( bwy /⁠bōy⁠/ , “ smell, scent; incense ” ) .

 Noun
 [ edit ] 

 بوی • ( boy ) 

 ( only constructed with اوتی ( otu ) , تخمی ( tohumu ) , or چیچگی ( çiçeği ) ) fenugreek 
 Synonyms: چمن ( çemen ) , حلبت ( hulbet ) , حلبه ( hulbe ) 

 Descendants
 [ edit ] 

 Turkish: boy
