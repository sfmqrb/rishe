 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( plwʾhl /⁠frawahr⁠/ ) , from Old Persian *fravarti- . Compare Avestan 𐬟𐬀𐬭𐬎𐬎𐬀𐬵𐬀𐬭𐬀 ( faruuahara ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /far.wa.ˈhar/ 

 ( Dari, formal ) IPA ( key ) : [fäɾ.wä.ɦáɾ] 

 ( Dari, formal ) IPA ( key ) : [fäɾ.wä.ɦáɾ] 
 ( Kabuli ) IPA ( key ) : [fäɾ.wɑːáɾ] 

 ( Hazaragi ) IPA ( key ) : [fäɾ.wɔːáɾ] 

 ( Iran, formal ) IPA ( key ) : [fæɹ.væ.ɦǽɹ] 

 ( Tajik, formal ) IPA ( key ) : [fäɾ.vä.ɦáɾ] 

 Rhymes: -ar

 Noun
 [ edit ] 

 فروهر • ( farvahar ) 

 faravahar , fravashi (Zoroastrian and Iranian symbol)

 Etymology 2
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( plwʾhl /⁠frawahr⁠/ ) , via its later form frōhr (attested in Pazend as 𐬟𐬭𐬋𐬵𐬀𐬭 ( frōhar ) ).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /fu.roː.ˈhar/ 

 Rhymes: -ar 

 Readings

 Classical reading ? 

 furōhar

 Noun
 [ edit ] 

 فروهر • ( foruhar ) 

 ( obsolete , rare ) spirit , essence 

 Proper noun
 [ edit ] 

 فروهر • ( foruhar ) 

 a surname , Forouhar and Foroohar
