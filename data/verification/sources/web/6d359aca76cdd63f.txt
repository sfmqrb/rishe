 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian بَالِش ( bāliš ) , from Middle Persian 𐭡𐭠𐭫𐭱𐭭 ( bʾlšn' /⁠bālišn⁠/ ) , from Proto-Iranian *barjíš , from Proto-Indo-Iranian *bʰarȷ́ʰíš , from Proto-Indo-European *bʰelǵʰ- .

 Noun
 [ edit ] 

 بالش • ( baliş ) 

 bolster , pillow , a soft cushion used to support the head in bed 
 Synonym: یاصدق ( yasdık ) 

 Derived terms
 [ edit ] 

 بالشچه ( balişçe , “ small pillow ” ) 

 Descendants
 [ edit ] 

 Turkish: baliş

 Noun
 [ edit ] 

 بالش • ( bāliš / bâleš ) ( plural بالش‌ها ( bāliš-hā / bâleš-hâ ) , Tajik spelling болиш ) 

 pillow , cushion 
 Synonyms: بالین ( bālīn  / bâlin ) , ( Iran ) کوسَن ( kusan )
