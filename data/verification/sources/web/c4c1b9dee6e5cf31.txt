 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Possibly a cognate of Latin taxus or borrowed from Iranian : compare Persian تخش ( taxš , “ crossbow ” ) .

 Compare typologically English yew ( “ Taxus; a bow for archery, made of yew wood ” ) , which is cognate with Proto-Slavic *jьva , which is synonymous with *orkyta , which is possibly cognate with Latin arcus .

 Noun
 [ edit ] 

 τόξον • ( tóxon )  n ( genitive τόξου ) ; second declension 

 ( archery ) bow (weapon for shooting arrows)

 rainbow 

 arc 

 anything which is bowed or arched 

 Inflection
 [ edit ] 

 Second declension of τὸ τόξον ; τοῦ τόξου ( Attic )
