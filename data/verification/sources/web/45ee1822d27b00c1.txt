 Etymology
 [ edit ] 

 Root 

 כ־נ־ס ( k-n-s ) 

 14 terms 

 See כנס ( “ conference ” ) , כ־נ־ס .

 Pronunciation
 [ edit ] 

 ( Modern Israeli ) IPA ( key ) : /ˈkneset/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 כְּנֶסֶת • ( k'néset )  f ( plural indefinite כְּנֵסִיּוֹת , singular construct כְּנֶסֶת־ , plural construct כְּנֵסִיּוֹת־ ) [pattern: קְטֶלֶת ] 

 A coming together, a congregating, an assembly , a meeting .

 A synagogue , a congregation .
 Synonym: בַּיִת כְּנֶסֶת ( bet k'néset ) 

 ( Mishnaic ) the Sanhedrin , historical Jewish, judicial congregation of wise men.
 Synonym: סַנְהֶדְרִין ( sanhedrín )
