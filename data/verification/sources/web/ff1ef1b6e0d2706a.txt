 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( gwmʾn' /⁠gumān⁠/ , “ doubt ” ) , from Proto-Iranian *wimānah , from Proto-Indo-Iranian . Compare Avestan 𐬬𐬍𐬨𐬀𐬥𐬋 ( vīmanō , one of the Ahrimanic plagues : doubt? ) , Sanskrit विमनस् ( vimanas , “ sad, disconsolate ” ) Northern Luri گمو ( gemo ) .

 Pronunciation

 ( Classical Persian ) IPA ( key ) : /ɡu.ˈmaːn/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.mɑːn] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.mɑːn] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.mɑːn] 

 ( Hazaragi ) IPA ( key ) : [ɡu.mɔːn] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.mɒːn] , [ɡʲæ.mɒːn] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.mɒːn] , [ɡʲæ.mɒːn] 
 ( Tehrani ) IPA ( key ) : [ɡʲæ.muːn] 

 ( Tajik, formal ) IPA ( key ) : [ɡu.mɔn] 

 Rhymes: -aːn

 Noun
 [ edit ] 

 گُمان • ( gomân ) 

 assumption ; supposition ; opinion ; conjecture ; suspicion

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian گُمان ( gumān ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɡʊ.mɑːn/ 

 Noun
 [ edit ] 

 گُمان • ( gumān )  m ( Hindi spelling गुमान ) 

 mistrust , doubt ; uncertainty 
 Synonyms: شَک ( śak ) , سَنْشَیَہ ( sanśaya ) , سَنْدیہ ( sandeh ) , شُبَہ ( śuba ) , رَیب ( raib ) , بھَرَم ( bharam )
