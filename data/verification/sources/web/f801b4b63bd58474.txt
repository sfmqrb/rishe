 Ancient Greek
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /as.pʰá.ra.ɡos/ → /asˈɸa.ra.ɣos/ → /asˈfa.ra.ɣos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /as.pʰá.ra.ɡos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /asˈpʰa.ra.ɡos/ 

 ( 4 th CE Koine ) IPA ( key ) : /asˈɸa.ra.ɣos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /asˈfa.ra.ɣos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /asˈfa.ra.ɣos/ 

 Etymology 1
 [ edit ] 

 Furnée connects the word with φάραγξ ( pháranx , “ gorge, ravine ” ) and μάραγοι ( máragoi , “ overhanging places ” ) , suggesting a Pre-Greek origin. [ 1 ] 

 Alternative forms

 σφάραγγος ( sphárangos ) 

 Noun
 [ edit ] 

 ἀσφάρᾰγος • ( asphárăgos )  m ( genitive ἀσφᾰράγου ) ; second declension 

 ( anatomy , Homeric ) throat , gullet 
 c. 800 BCE – 600 BCE , Homer , Iliad 22.328 

 300 CE – 400 CE , Quintus Smyrnaeus , Posthomerica 11.82

 c. 450 CE – 470 CE , Nonnus , Dionysiaca 37.767

 Etymology 2
 [ edit ] 

 Being the name of a cultivated plant, yet still revealing its general meaning as “shoots” of plants, a borrowing from Old Persian *spargah as a descendant from widely attested Proto-Iranian *spr̥Hgah ( “ sprout ” )  can be maintained.

 Beekes could, of course, declare the term of Pre-Greek origin, like its homonym, due to the presence of the variation π/φ —which is paralleled in Iranian in this environment—rejecting an Indo-Europeanist connection to Proto-Indo-European *(s)pregʰ- ( “ to jerk, to scatter ” ) (whence σφαραγέομαι ( spharagéomai , “ to burst with a noise, teem ” ) , disputed, see also Latin spargō ( “ to scatter ” ) ). [ 2 ]

 ἀσπάραγος ( aspáragos ) 

 Noun
 [ edit ] 

 ἀσφάρᾰγος • ( asphárăgos )  m ( genitive ἀσφᾰράγου ) ; second declension 

 asparagus ( Asparagus officinalis )
 Synonym: ἀκᾰνθῐ́ᾱς ( akănthĭ́ās ) 

 ( botany ) shoots of other plants
