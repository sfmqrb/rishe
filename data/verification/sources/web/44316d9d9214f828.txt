 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Iranian *rarz- . Compare Zazaki lerz ( “ shaking, quake ” ) , Northern Luri ڵںرز ( llərz ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈlarz/ 

 ( Dari, formal ) IPA ( key ) : [läɹz] 

 ( Dari, formal ) IPA ( key ) : [läɹz] 
 ( Kabuli ) IPA ( key ) : [läɹz] 

 ( Hazaragi ) IPA ( key ) : [läɹz] 

 ( Iran, formal ) IPA ( key ) : [læɹz] 

 ( Tajik, formal ) IPA ( key ) : [läɹz] 

 Rhymes: -arz

 Noun
 [ edit ] 

 لرز • ( larz ) 

 shaking 
 Synonyms: رَعْشَه ( ra'ša ) , لرزش ( larziš ) , لرزه ( larza ) 

 temblor 

 quake 

 shivering

 [ edit ]
