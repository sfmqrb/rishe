 Etymology
 [ edit ] 

 From Persian زمرد ( zumurrud  / zomorrod ) , from earlier ازمرد ( uzmurud  / ozmorod ) , from Middle Persian [Book Pahlavi needed] ( ʾwzmbwlt /⁠uzumburd⁠/ ) , from Ancient Greek σμάραγδος ( smáragdos ) . Doublet of زَبَرْجَد ( zabarjad ) .

 [ edit ] 

 IPA ( key ) : /zu.mur.rud/

 [ edit ]

 Etymology
 [ edit ] 

 From Early New Persian ازمرد ( uzmurud ) , from Middle Persian [Book Pahlavi needed] ( ʾwzmbwlt /⁠uzumburd⁠/ ) , from Ancient Greek σμάραγδος ( smáragdos ) . Compare Old Armenian զմրուխտ ( zmruxt ) , Old Georgian ზურმუხტი ( zurmuxṭi ) , Iranian borrowings.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /zu.mur.ˈrud/ 

 ( Dari, formal ) IPA ( key ) : [zä.mär.rʊ́d̪] 

 ( Dari, formal ) IPA ( key ) : [zä.mär.rʊ́d̪] 
 ( Kabuli ) IPA ( key ) : [zä.mär.rʊ́d̪] 

 ( Hazaragi ) IPA ( key ) : [zä.mär.rúd̪̥] 

 ( Iran, formal ) IPA ( key ) : [zo.moɹ.ɹód̪̥] 

 ( Tajik, formal ) IPA ( key ) : [zu.muɾ.ɾád̪] , [zum.ɾád̪] 

 Rhymes: -ud
