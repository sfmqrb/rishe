 Etymology
 [ edit ] 

 Inherited from Ancient Greek Ἀλέξανδρος ( Aléxandros ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /aˈle.ksan.ðɾos/ 

 Proper noun
 [ edit ] 

 Αλέξανδρος • ( Aléxandros )  m 

 a male given name , Alexandros , equivalent to English Alexander
