 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From ناف ( nâf , “ navel ” ) , as the glands are located around the deer’s navel.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /naː.ˈfa/ 

 ( Dari, formal ) IPA ( key ) : [nɑː.fá] 

 ( Dari, formal ) IPA ( key ) : [nɑː.fá] 
 ( Kabuli ) IPA ( key ) : [nɑː.fá] 

 ( Hazaragi ) IPA ( key ) : [nɔː.fá] 

 ( Iran, formal ) IPA ( key ) : [nɒː.fé] 

 ( Tajik, formal ) IPA ( key ) : [nɔ.fá] 

 Rhymes: -a
