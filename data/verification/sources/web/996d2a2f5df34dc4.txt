 Etymology
 [ edit ] 

 Borrowed from Arabic كَانُون .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kaː.ˈnuːn/ 

 ( Dari, formal ) IPA ( key ) : [kʰɑː.núːn] 

 ( Dari, formal ) IPA ( key ) : [kʰɑː.núːn] 
 ( Kabuli ) IPA ( key ) : [kʰɑː.núːn] 

 ( Hazaragi ) IPA ( key ) : [kʰɔː.nún] 

 ( Iran, formal ) IPA ( key ) : [kʰɒː.núːn] 

 ( Tajik, formal ) IPA ( key ) : [kʰɔ.nún] 

 Rhymes: -uːn

 Noun
 [ edit ] 

 کانون • ( kânun ) 

 hearth , fireplace 
 Synonyms: اجاق ( ojâq ) , دیگدان ( digdân ) 

 brazier 
 Synonyms: منقل ( menqal ) , آتشدان ( âtašdân ) 

 society , association , club 
 Synonyms: انجمن ( anjoman ) , جمعیت ( jam'iyat ) , کلوب ( kolub ) 

 focus , center (of an activity)
 Synonym: مرکز ( markaz ) 
 دانشگاه‌ها از مهم‌ترین کانون‌ها ی اصلی حضور مخالفان علیه نظام بودند. dânešgâh-hâ az mohemm-tarin kânun-hâ -ye asli-ye hozur-e moxâlefân aleyh-e nezâm budand. The universities were among the most important centers of the presence of opponents to the system. 

 ( geometry , optics ) focus (of a curve)
