 Ottoman Turkish
 [ edit ] 

 دیوار 
 Etymology
 [ edit ] 

 Inherited from Old Anatolian Turkish دیوار ( dīvār ) , from Classical Persian دِیوَار ( dīwār , “ wall ” ) , from Middle Persian dywʾl ( dēwār , “ wall ” ) .

 Noun
 [ edit ] 

 دیوار • ( dîvâr or duvar ) ( definite accusative دیواری ( dîvârı ) , plural دیوارلر ( dîvârlar ) ) 

 wall 
 Synonym: جدار ( cidar ) 

 wall , ( any structure built with stones, earth etc. built for defensive pruposes, surrounding a place ) 
 Synonym: سور ( sur )

 Persian دیوار 

 Inherited from Middle Persian dywʾl ( /⁠dēwār⁠/ , “ wall ” ) , from Old Persian 𐎮𐎡𐎭𐎠 ( di-i-d-a /⁠didā-⁠/ , “ wall, fortress ” ) + *-wāra . Compare Avestan 𐬛𐬀𐬉𐬰𐬀 ( daēza , “ wall ” ) , Ancient Greek τεῖχος ( teîkhos , “ wall, fortifications ” ) .
