 Arabic فرن 

 From Aramaic פורנא / ܦܘܪܢܐ ( pūrnā ) , from Ancient Greek φοῦρνος ( phoûrnos ) , from Latin furnus .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /furn/ 

 Audio : ( file ) 

 ( Kuwait ) IPA ( key ) : /fɪrɪn/ 

 Noun
 [ edit ] 

 فُرْن • ( furn )  m ( plural أَفْرَان ( ʔafrān ) ) 

 oven , furnace 
 Synonym: كُور ( kūr ) 
 فُرْن ذَرِّيّ ― furn ḏarriyy ― nuclear reactor 

 bakery
