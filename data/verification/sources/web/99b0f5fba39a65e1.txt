 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Etymology
 [ edit ] 

 If a native formation, possibly from a root *h₂ey- ( “ to burn; fire ” ) found also in *h₂ey-dʰh₁- ( “ to set fire ” , literally “ *put to fire ” ) [ 1 ] or perhaps *h₂ey- ( “ day, morning ” ) . Martirosyan suggests a possible connection with Abkhaz ajḫa ( “ iron ” ) . [ 2 ] 

 Noun
 [ edit ] 

 *h₂éyos   n [ 1 ] [ 3 ] [ 4 ] [ 2 ] 

 a metal , copper , bronze 

 Usage notes
 [ edit ] 

 In the early Indo-European languages, this word refers to “copper” (and “bronze”), and the Proto-Indo-European word refers with absolute certainty to one of these metals, or both. This shows that the Indo-European language was spoken during a time when copper was used.
