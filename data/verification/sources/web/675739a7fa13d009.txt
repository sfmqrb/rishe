 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Serbo-Croatian Niš / Ниш .

 Proper noun
 [ edit ] 

 نیش • ( niş ) 

 Niš (a city in Nišava district, Serbia )

 Descendants
 [ edit ] 

 Turkish: Niş 

 Further reading
 [ edit ] 

 Sezen, Tahir ( 2017 ), “Niş”, in Osmanlı Yer Adları [ Ottoman Place Names ]‎ [1] , 2nd edition, Ankara: T.C. Başbakanlık Devlet Arşivleri Genel Müdürlüğü, page 581 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( nēš ) , from Old Median , from Proto-Iranian *náyjam , from Proto-Indo-Iranian *náyȷ́žʰam .

 Noun
 [ edit ] 

 نیش • ( niš ) 

 sting , bite

 [ edit ]
