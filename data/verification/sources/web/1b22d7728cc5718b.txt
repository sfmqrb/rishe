 Old Anatolian Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian همان ( hamân ) . [ 1 ] 

 Adverb
 [ edit ] 

 هَمَانْ • ( hemān ) 

 at that moment 

 right now , quickly , immediately 

 Descendants
 [ edit ] 

 Azerbaijani: həman , haman , həmən 

 Gagauz: hemen , emen 

 Ottoman Turkish: همان ( heman, hemen ) Turkish: hemen , ( dialectal, archaic ) heman 
 → Armenian: հէմէն ( hēmēn ) , համան ( haman ) 

 References
 [ edit ] 

 ^ Nişanyan, Sevan ( 2002– ), “ hemen ”, in Nişanyan Sözlük 

 Further reading
 [ edit ] 

 “heman”, in XIII. Yüzyılından Beri Türkiye Türkçesiyle Yazılmış Kitaplarından Toplanan Tanıklarıyle Tarama Sözlüğü (Türk Dil Kurumu yayınları; 212 )‎ [1] (in Turkish), Ankara: Türk Dil Kurumu, 1963–1977 , page 70 

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Old Anatolian Turkish هَمَانْ ( hemān ) , from Classical Persian همان ( hamân ) 

 Adverb
 [ edit ] 

 همان • ( heman, hemen ) 

 immediately , right now 

 Descendants
 [ edit ] 

 Turkish: hemen , ( dialectal, archaic ) heman 

 → Armenian: հէմէն ( hēmēn ) , համան ( haman )

 Etymology 1
 [ edit ] 

 Etymology tree

 Proto-Iranian *hamHáh 
 Old Persian 𐏃𐎶 ( h-m ) 
 Middle Persian hm 
 Persian هم ( ham ) 

 Persian آن ( ân ) 

 Persian همان 

 From هم ( ham , “ also, too, similarly, same ” ) + آن ( ân , “ that ” ) .

 Adjective
 [ edit ] 

 همان • ( hamân ) 

 that/those very

 the same 

 Alternative forms
 [ edit ]

 Etymology 2
 [ edit ] 

 Shortening of همان دم ( hamân dam , “ simultaneously ” ) , from همان ( hamân , “ that very, the same ” ) + دم ( dam , “ moment ” ) .

 Adjective
 [ edit ] 

 همان • ( hamân ) 

 simultaneously
