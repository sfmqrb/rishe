 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 گرته ( garte ) ( colloquial Tehrani ) 

 Etymology 1
 [ edit ] 

 Noun
 [ edit ] 

 گرده • ( garde ) 

 pollen 

 Etymology 2
 [ edit ] 

 Ultimately from the Proto-Indo-European root *wer- .

 Noun
 [ edit ] 

 گرده • ( gerde ) 

 bread roll 

 loaf 

 Etymology 3
 [ edit ] 

 From Middle Persian gwltk’ ( gurdag , “ kidney ” ) , from Proto-Indo-Iranian *wr̥tkás ( “ kidney ” ) ; compare Avestan 𐬬𐬆𐬭𐬆𐬜𐬐𐬀 ( vər ə δka ) and Sanskrit वृक्क ( vṛkka ) , Northern Luri گۏردالٱ ( gördāla ) .

 Noun
 [ edit ] 

 گرده • ( gorde ) 

 kidney 

 reins 

 loin 

 References
 [ edit ]
