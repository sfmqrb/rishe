 Arabic

 زَوْرَق 

 Arabic Wikipedia has an article on: زورق 

 Wikipedia ar 

 Etymology
 [ edit ] 

 Borrowed from Persian زورق ( zowraq , “ skiff, lake-boat ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /zaw.raq/ 

 Noun
 [ edit ] 

 زَوْرَق • ( zawraq )  m ( plural زَوَارِق ( zawāriq ) ) 

 boat , dinghy , skiff

 Etymology
 [ edit ] 

 From Middle Persian *zōwrak . Maybe cognate with Latin galea ( “ helmet ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /zaw.ˈraq/ 

 ( Dari, formal ) IPA ( key ) : [zäw.ɾäq] 

 ( Dari, formal ) IPA ( key ) : [zäw.ɾäq] 
 ( Kabuli ) IPA ( key ) : [zäw.ɾäq] 

 ( Hazaragi ) IPA ( key ) : [zäw.ɾäq] 

 ( Iran, formal ) IPA ( key ) : [zow.ɹæɢ̥] 

 ( Tajik, formal ) IPA ( key ) : [zäw.ɾäq] 

 Rhymes: -aq

 Noun
 [ edit ] 

 زورق • ( zawraq / zowraġ ) ( Tajik spelling заврақ ) 

 skiff , lake-boat , boat
