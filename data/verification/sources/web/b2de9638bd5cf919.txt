 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Etymology tree

 Middle Persian d(p)ywʾn' ( dēwān ) 
 Classical Persian دِیوَان ( dīwān ) bor. 
 Ottoman Turkish دیوان 

 Borrowed from Classical Persian دِیوَان ( dīwān ) .

 Noun
 [ edit ] 

 دیوان • ( dîvân ) 

 divan ( collection of poems )

 divan ( council of state )

 court , tribunal 

 An administrative unit consisting of a few villages in the Ottoman Empire .

 Noun
 [ edit ] 

 دیوان • ( dēwān, dīwān / divân ) ( plural دیوان‌ها ( dēwān-hā, dīwān-hā / divân-hâ ) , Tajik spelling девон , or дивон ) 

 divan ( collection of poems ) 

 divan ( council ) 

 bureau 

 court , tribunal 

 a muster roll , a register of soldiers

 sofa , couch
