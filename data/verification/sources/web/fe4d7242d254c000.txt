 Etymology 1
 [ edit ] 

 From Middle Iranian (compare Middle Persian [script needed] ( gāl , “ following ” ) ).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡal.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [ɡäl.lá] 

 ( Dari, formal ) IPA ( key ) : [ɡäl.lá] 
 ( Kabuli ) IPA ( key ) : [ɡäl.lá] 

 ( Hazaragi ) IPA ( key ) : [ɡäl.lá] 

 ( Iran, formal ) IPA ( key ) : [ɡʲæl.lé] 

 ( Tajik, formal ) IPA ( key ) : [ɡäl.lá] 

 Rhymes: -a

 Noun

 گله • ( galla / galle ) ( Tajik spelling галла ) 

 flock , herd

 Etymology 2
 [ edit ] 

 From Middle Persian [script needed] ( g(y)lk’ /⁠gilag⁠/ , “ complaint, lamentation ” ) . Compare Baluchi گِلَگ ( gilag , “ complaint ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡi.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.lá] 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.lá] 
 ( Kabuli ) IPA ( key ) : [ɡɪ.lá] 

 ( Hazaragi ) IPA ( key ) : [ɡi.lá] 

 ( Iran, formal ) IPA ( key ) : [ɡʲe.lé] 

 ( Tajik, formal ) IPA ( key ) : [ɡi.lá] 

 Rhymes: -a 

 Readings

 gila

 Tajik reading ? 

 gila

 Noun
 [ edit ] 

 گله • ( gila / gele ) ( Tajik spelling гила ) 

 complaint , grievance 

 Alternative forms
