 Burushaski
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Urdu ناخُن ( nāxun ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [naːqʰun] 

 Noun
 [ edit ] 

 ناخن ( naaqhun ) 

 ( anatomy ) fingernail , toenail 
 Synonym: اور ( uuri ) 

 References
 [ edit ]
