 Hebrew
 [ edit ] 

 Root 

 שׁ־מ־ע ( sh-m-ʿ ) 

 11 terms 

 Etymology 1.1
 [ edit ] 

 From Proto-Semitic *šamiʕ- . Cognate with Arabic سَمِعَ ( samiʕa , “ to hear ” ) .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /ʃaːˈmaʕ/ 

 ( Tiberian ) IPA ( key ) : /ʃɔːˈmaʕ/ , [ʃɔˑˈmaː.aʕ] 

 ( Yemenite ) IPA ( key ) : /ʃɔˈmaʕ/ , [ʃɔ(ː)ˈmaːʕ] 

 ( Sephardi ) IPA ( key ) : /ʃaˈmaʕ/ ( East ) , /ʃaˈma/ ( West ) 

 ( Ashkenazi ) IPA ( key ) : /ʃɔˈma/ 

 ( Modern Israeli ) IPA ( key ) : /ʃaˈma/ 

 Verb
 [ edit ] 

 שָׁמַע • ( shamá ) ( pa'al construction , passive counterpart נִשְׁמַע , Biblical Hebrew pausal form שָׁמֵעַ ) 

 to hear , to be able to hear 
 1994 , איפה הילד , מישהו שומע אותי : מישהו שומע אותי? mishéhu shoméa otí? Can anybody hear me? 

 to listen 
 Synonym: הִקְשִׁיב ( hikshív )

 Proper noun
 [ edit ] 

 שְׁמַע • ( sh'má ) 

 the Shema 
 a. 217 C.E. , Mishnah . Berachot , section 1.1 : מ אימתי קורין את שמע ב ערבית me'ematáy kor[']ín et sh'má b'ar'vít From what time do we recite the Shema in the evening?
