 Konkani
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Maharastri Prakrit 𑀓𑀢𑁆𑀢𑀭𑀻 ( kattarī ) , from Sanskrit कर्तरि ( kartari ) , कर्तरी ( kartarī ) . Cognate with Gujarati કાતર ( kātar ) , Marathi कात्री ( kātrī ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [kɑːtəɾ] 

 Noun
 [ edit ] 

 कातर • ( kātar )  f ( Latin script kator , Kannada script ಕಾತರ್ ) 

 a pair of scissors 

 Sanskrit
 [ edit ] 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *kʷ-

 Proto-Indo-European *-teros 

 Proto-Indo-European *kʷóteros 
 Sanskrit क॒त॒र ( katará ) vṛd. ? 
 Sanskrit कातर 

 Uncertain.

 Perhaps vṛddhi derivative of क॒त॒र ( katará , “ which of two? ” ) ; see there for more. [ 1 ] 

 However, some descendants point to a form *काथर ( *kāthara ) or *काथल ( *kāthala ) , with the unusual phonological variation and late attestation suggesting the term is borrowed from substrate . Compare Prakrit 𑀓𑀢𑁆𑀢𑀭 ( kattara , “ rubbish ” ) , as well as the pejorative prefix Sanskrit कद्- ( kad- ) . [ 2 ] [ 3 ] 

 Pronunciation
 [ edit ] 

 ( Classical Sanskrit ) IPA ( key ) : /kɑː.t̪ɐ.ɾɐ/ 

 Adjective
 [ edit ] 

 कातर • ( kātara ) stem [ 4 ] 

 cowardly , faint-hearted 

 confused
