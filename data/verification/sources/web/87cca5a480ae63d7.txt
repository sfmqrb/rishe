 Pashto

 Etymology
 [ edit ] 

 Borrowed from Classical Persian شغال ( šaġāl ) , from Middle Persian 𐬱𐬖𐬀𐬮 ( šγal /⁠šaγāl⁠/ ) , [ 1 ] in turn borrowed from Sanskrit शृगाल ( śṛgāla , “ jackal ” ) , the alternative form of सृगाल ( sṛgāla ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʃaˈɣɑl/ 

 Noun
 [ edit ] 

 شغال • ( šaǧâl )  m 

 jackal

 Pronunciation
 [ edit ]

 Adjective
 [ edit ] 

 شغّال • ( šaḡḡāl ) ( feminine شغّالة ( šaḡḡāle ) , common plural شغّالين ( šaḡḡālīn ) ) 

 working , busy , occupied 
 Synonym: مشغول ( mašḡūl ) 
 Antonym: فاضي ( fāḍi ) 

 in action , in motion , running ( e.g. a machine )
