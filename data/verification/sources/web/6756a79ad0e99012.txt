 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *pelh₁- [ 1 ] [ 2 ] 

 to swing 

 chaff 

 Derived terms
 [ edit ] 

 *pl̥-né-h₁-ti ~ *plé-n-h₁-ónti ( nasal-infix present ) [ 3 ] 
 Proto-Hellenic: *pə́l͏̌l͏̌ō 
 Ancient Greek: πᾰ́λλω ( pắllō , “ to sway, swing ” ) 

 *pelh₁-ōw [ 2 ] 
 Sanskrit: प॒लाव॑ ( palā́va , “ chaff ” ) 

 *pelh₁-w- ~ *polh₁-w- [ 4 ] [ a ] 
 Proto-Balto-Slavic: *pelˀus , *pelˀwāˀ 
 Latvian: pęlus 

 Lithuanian: pẽlūs 

 Proto-Slavic: *pèlva ( see there for further descendants )

 Proto-Italic: *pelawis ~ *polawis 
 Latin: pulvis ( “ dust ” , i -stem adopted after cinis ) 

 *pl̥h₁-éyeh₂ [ 1 ] 
 Proto-Italic: *pale(j)ā 
 Latin: palea ( “ chaff ” ) 

 Notes
 [ edit ] 

 ^ Ablaut is necessary to explain why the laryngeal was not deleted by Saussure's effect ( *oCHC > *oCC ) in Proto-Italic, where *-lw- supposedly yields Latin -ll- .
