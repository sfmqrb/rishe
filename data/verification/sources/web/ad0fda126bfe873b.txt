 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *wayǰ- , from Proto-Indo-European *weyg- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.weːx.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.weːx.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.weːx.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.weːx.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.weːx.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.viːx.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [ʔɔ.veχ.t̪ʰán] 

 Rhymes: -an 

 Readings

 Verb
 [ edit ] 

 Dari

 آویختن 

 Iranian Persian

 Tajik

 овехтан 

 آویختَن • ( âvixtan ) ( present stem آویز ( âviz ) ) 

 to hang , to suspend
