 Arabic spelling of hunduvâna , hunduvânə ( “ watermelon ” )

 Pashto
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian هِنْدُوَانَه ( hinduwāna ) .

 Noun
 [ edit ] 

 هندوانه • ( hindvāná )  f 

 watermelon 

 References
 [ edit ] 

 “ هندوانه ”, in Pashto Dictionary , Peshawar, Pakistan: Pukhtoogle, 2020 .

 Alternative forms
 [ edit ] 

 هندانه ( hendâne ) 

 هندونه ( hendune ) ( colloquial , Fars province ) 

 Etymology
 [ edit ] 

 By surface analysis , هندو ( hendu , “ Indian ” ) +‎ ـانه ( -âne ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /hin.du.waː.ˈna/ 

 ( Dari, formal ) IPA ( key ) : [hɪn̪.d̪ʊ.wɑː.nä] 

 ( Dari, formal ) IPA ( key ) : [hɪn̪.d̪ʊ.wɑː.nä] 
 ( Kabuli ) IPA ( key ) : [ʔɪn̪.d̪ʊ.wɑː.nä] 

 ( Hazaragi ) IPA ( key ) : [ʔin̪.d̪u.wɔː.nä] 

 ( Iran, formal ) IPA ( key ) : [hen̪.d̪e.vɒː.ne] 

 ( Tajik, formal ) IPA ( key ) : [hin̪.d̪u.vɔ.nä] 

 Rhymes: -a

 Noun
 [ edit ] 

 هندوانه • ( hendevâne ) ( plural هندوانه‌ها ( hendevâne-hâ ) ) 

 watermelon 
 Synonyms: تربز ( tarboz ) , بطیخ هندی ( bettix-e hendi ) 

 Derived terms
 [ edit ] 

 دو تا هندوانه را با یک دست برداشتن ( do tâ hendevâne râ bâ yek dast bardâštan , “ to lift two watermelons with one hand ” )
