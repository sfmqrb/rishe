 Arabic
 [ edit ] 

 Root 

 و ض ء ( w ḍ ʔ ) 

 6 terms 

 Etymology
 [ edit ] 

 Compare Hebrew יצא ( yatsá ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /wa.dˤu.ʔa/ 

 Verb
 [ edit ] 

 وَضُؤَ • ( waḍuʔa ) I ( non-past يَوْضُؤُ ( yawḍuʔu ) , verbal noun وَضَاءَة ( waḍāʔa ) or وُضُوء ( wuḍūʔ ) ) 

 to be cleanly , to exhibit polish
