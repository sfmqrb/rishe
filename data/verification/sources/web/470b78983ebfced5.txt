 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پیرامن ( pērāmun  / pirâmon, pērāman  / pirâman ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( pylʾmwn' /⁠pērāmōn⁠/ ) , 𐫛𐫏𐫡𐫀𐫖𐫇𐫗 ( pyrʾmwn /⁠pērāmōn⁠/ , “ around, vicinity ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /peː.raː.ˈmuːn/ 

 ( Dari, formal ) IPA ( key ) : [pʰeː.ɾɑː.múːn] 

 ( Dari, formal ) IPA ( key ) : [pʰeː.ɾɑː.múːn] 
 ( Kabuli ) IPA ( key ) : [pʰeː.ɾɑː.múːn] 

 ( Hazaragi ) IPA ( key ) : [pʰeː.ɾɔː.mún] 

 ( Iran, formal ) IPA ( key ) : [pʰiː.ɹɒː.múːn] 

 ( Tajik, formal ) IPA ( key ) : [pʰe.ɾɔ.mún] 

 Rhymes: -uːn 

 Readings

 pērāmūn

 Dari reading ? 

 pērāmūn

 Tajik reading ?

 Noun
 [ edit ] 

 پیرامون • ( pērāmūn / pirâmun ) ( Tajik spelling перомун ) 

 vicinity , environs 

 ( with ezâfe ) around , surrounding 

 Descendants
 [ edit ] 

 → Chagatai: پیرامن ( pyrʾmn /⁠pīrāmän⁠/ ) 
 Uzbek: piramon
