 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 Nominalization of vīneus ( “ of or relating to wine ” ) , from vīnum ( “ wine ” ) + -eus .

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈwiː.ne.a] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈviː.ne.a] 

 Noun
 [ edit ] 

 vīnea   f ( genitive vīneae ) ; first declension 

 vineyard 

 A vine , especially a grapevine 

 ( military ) a moveable bower used as a shelter, see testudo
