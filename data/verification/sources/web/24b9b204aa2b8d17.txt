 Etymology
 [ edit ] 

 Inherited from Malay tembaga , from Prakrit *𑀢𑀁𑀩𑀕 ( *taṃbaga ) , from Sanskrit ताम्रक ( tāmraka , “ copper ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Indonesian ) IPA ( key ) : /təmˈbaɡa/ [t̪əmˈba.ɡa] 

 Audio : ( file ) 

 Rhymes: -aɡa 

 Syllabification: tem‧ba‧ga 

 Noun
 [ edit ] 

 têmbaga ( plural tembaga - tembaga ) 

 copper ( chemical element )
