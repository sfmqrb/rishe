 Etymology
 [ edit ] 

 From Ancient Greek ἄγκῡρα ( ánkūra ) .

 Alternately of Iranian origin, cognate with Sanskrit लङ्गल ( laṅgala ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /lan.ˈɡar/ 

 ( Dari, formal ) IPA ( key ) : [läŋ.ɡáɾ]
