 Root

 [ edit ]

 [ edit ]

 place , spot

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic مَطْرَح ( maṭraḥ , “ place where something is thrown ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /mat.ˈrah/ 

 ( Dari, formal ) IPA ( key ) : [mät̪.ɾáʱ] 

 ( Dari, formal ) IPA ( key ) : [mät̪.ɾáʱ] 
 ( Kabuli ) IPA ( key ) : [mät̪.ɾá] 

 ( Hazaragi ) IPA ( key ) : [mät̪.ɾá] 

 ( Iran, formal ) IPA ( key ) : [mæt̪ʰ.ɹǽʱ] 

 ( Tajik, formal ) IPA ( key ) : [mät̪.ɾáʱ] 

 Rhymes: -ah 

 Readings

 Classical reading ? 

 matrah

 Dari reading ? 

 matrah

 Iranian reading ? 

 matrah

 Tajik reading ? 

 matrah

 Adjective
 [ edit ] 

 مطرح • ( matrah ) 

 under discussion ; raised (as a subject of discussion)

 famous , prominent , distinguished , preeminent 
 ابن سینا یکی از فیلسوفان مطرح دوران طلایی اسلام بود. Avicenna was one of the prominent philosophers of the Islamic Golden Age . 

 Derived terms
 [ edit ] 

 مطرح شدن ( matrah šodan , “ to be discussed ” ) 
 مطرح کردن ( matrah kardan , “ to raise a subject ” )
