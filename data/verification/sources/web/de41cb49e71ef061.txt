 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 βιστάκιον ( bistákion ) , φιττάκια ( phittákia ) , ψιττάκια ( psittákia ) 

 Etymology
 [ edit ] 

 From πιστάκη ( pistákē , “ pistachio tree ” ) +‎ -ιον ( -ion , diminutive suffix ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pis.tá.ki.on/ → /pisˈta.ci.on/ → /pisˈta.ci.on/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pis.tá.ki.on/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /pisˈta.ki.on/ 

 ( 4 th CE Koine ) IPA ( key ) : /pisˈta.ci.on/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /pisˈta.ci.on/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /pisˈta.ci.on/ 

 Noun
 [ edit ] 

 πιστάκῐον • ( pistákĭon )  n ( genitive πιστᾰκίου ) ; second declension 

 pistachio 

 Declension
 [ edit ] 

 Second declension of τὸ πῐστᾰ́κῐον ; τοῦ πῐστᾰκῐ́ου ( Attic )
