 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 νοῦμμος ( noûmmos ) — Doric 

 Etymology
 [ edit ] 

 From νέμω ( némō , “ to distribute ” ) +‎ -ος ( -os ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /nó.mos/ → /ˈno.mos/ → /ˈno.mos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /nó.mos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈno.mos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈno.mos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈno.mos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈno.mos/ 

 Noun
 [ edit ] 

 νόμος • ( nómos )  m ( genitive νόμου ) ; second declension 

 usage ; custom 

 law ; ordinance 

 melody ; strain 

 ( music ) an ancient type of song 

 a type of coin 

 course of masonry

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from the Ancient Greek νόμος ( nómos ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈno.mos/ 

 Noun
 [ edit ] 

 νόμος • ( nómos )  m ( plural νόμοι ) 

 law , rule , code 
 Ο λόγος της ήταν νόμος O lógos tis ítan nómos Her word was law . 

 nome ( type of musical composition in ancient Greece )
