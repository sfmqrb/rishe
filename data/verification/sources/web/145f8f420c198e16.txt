 Etymology
 [ edit ]

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /t̪ən/ 

 Noun
 [ edit ] 

 تَن • ( tan )  m ( Hindi spelling तन ) 

 body 

 straw 

 trunk
