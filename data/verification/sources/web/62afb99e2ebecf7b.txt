 Etymology 1.1
 [ edit ] 

 Etymology tree

 Akkadian 𒎎𒋆𒁉𒍣𒁕 ( guḫlum ) bor. 
 Aramaic כוחלא ( kuḥlā ) bor. 
 Arabic كحل 

 Borrowed from Aramaic כוחלא / ܟܘܚܠܐ ( kuḥlā ) , from Akkadian 𒎎𒋆𒁉𒍣𒁕 ( guḫlum , “ antimony, stibium ” ) . Compare Hebrew כָּחָל ( kakhál , “ kohl ” ) .

 Noun
 [ edit ] 

 كُحْل • ( kuḥl )  m ( plural أَكْحَال ( ʔakḥāl ) ) 

 antimony 

 kohl , stibnite (pulverized antimony)

 Descendants
 [ edit ]

 Egyptian Arabic: كحول ( kuḥūl, kuḥull ) , كحل ( kuḥl )

 → Afar: kucúl 

 → Classical Persian: کُحْل ( kuhl ) 

 → English: kohl 

 → Ge'ez: ኵሕል ( kʷəḥəl ) 

 → Kurdish: 
 Northern Kurdish: kil 
 Central Kurdish: کِل ( kil )

 → Medieval Latin: alcohol ( see there for further descendants )

 Andalusian Arabic: كُحُول 
 → Old Navarro-Aragonese: alchofol , alcoffol , alcofoll , alcofol 

 → Spanish: alcohol
