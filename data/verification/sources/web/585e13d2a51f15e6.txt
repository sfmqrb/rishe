 Etymology
 [ edit ] 

 From Ancient Greek σμᾰ́ρᾰγδος ( smắrăgdos ) , itself from a Semitic source.

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [smaˈraɡ.dʊs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [zmaˈraɡ.dus] 

 Noun
 [ edit ] 

 smaragdus   m or f ( genitive smaragdī ) ; second declension 

 emerald
