 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭠𐭭𐭠𐭥 ( ʾnʾl /⁠anār⁠/ ) . Arguably, ultimately related to the pomegranate terms under Arabic رُمَّان ( rummān ) .

 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔa.ˈnaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʔä.nɑ́ːɾ]
