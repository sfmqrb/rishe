 Ancient Greek
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /a.lé.ɔː/ → /aˈle.o/ → /aˈle.o/ 

 ( 5 th BCE Attic ) IPA ( key ) : /a.lé.ɔː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /aˈle.o/ 

 ( 4 th CE Koine ) IPA ( key ) : /aˈle.o/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /aˈle.o/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /aˈle.o/ 

 Etymology 1
 [ edit ] 

 From Proto-Indo-European *h₂elh₁- ( “ to grind ” ) . Cognate with Old Armenian աղամ ( ałam , “ grind; pound ” ) , Sanskrit *आ॒र्त ( *ārtá , “ flour ” , whence Hindi आटा ( āṭā ) / Urdu آٹا ( āṭā ) ) , Avestan 𐬀𐬴𐬀 ( aṣ̌a , “ ground ” ) , Classical Persian آرد ( ārd , “ flour ” ) . [ 1 ] 

 Alternative forms
 [ edit ] 

 ᾰ̓́λημῐ ( ắlēmĭ ) — Epic 

 Verb
 [ edit ] 

 ᾰ̓λέω • ( ăléō ) 

 ( transitive ) to grind ; to bruise ; to pound ; to mill
