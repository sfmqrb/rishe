 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 مادامه ( madama ) 

 Etymology
 [ edit ] 

 From French madame .

 Noun
 [ edit ] 

 مادام • ( madam ) 

 madam ( form of address for a European lady ) 

 Descendants
 [ edit ] 

 Turkish: madam 

 Further reading
 [ edit ] 

 Kélékian, Diran ( 1911 ), “ مادام ”, in Dictionnaire turc-français ‎ [1] (in French), Constantinople: Mihran, page 1089b 

 South Levantine Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Arabic مَا دَامَ ( mā dāma ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ma.daːm/ , [maˈdæːm] 

 Audio ( Jerusalem ) : ( file ) 

 Conjunction
 [ edit ] 

 مادام • ( mā-dām ) 

 while , as long as 
 Synonyms: طالما ( ṭāla-ma ) , بينما ( beyna-ma ) 

 See also
 [ edit ] 

 لمّا ( lamma , “ when; as soon as ” )
