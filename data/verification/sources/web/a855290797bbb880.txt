 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit तुल्य ( tulya , “ equivalent, comparable ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /t̪ʊl.jᵊ/ 

 Adjective
 [ edit ] 

 तुल्य • ( tulya ) ( indeclinable ) 

 equal , equivalent , comparable , alike 
 Synonym: तुलित ( tulit )

 Adjective
 [ edit ] 

 तुल्य 

 Devanagari script form of tulya , gerundive of तुलेति ( tuleti , “ to weigh ” )

 Etymology
 [ edit ] 

 From तु॒ला ( tulā́ , “ balance, scales ” ) +‎ -य ( -ya ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /tul.jɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /t̪ul̪.jɐ/ 

 Adjective
 [ edit ] 

 तुल्य • ( tulya ) stem 

 equal to

 of the same kind or class or number or value 

 similar 

 comparable 

 like
