 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 رش ( raš ) 

 رشت ( rašt ) ( dialectal , Sistan ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ”ryšn /⁠ārešn⁠/ ) , from Old Persian 𐎠𐎼𐏁𐎴𐎡 ( a-r-š-n-i /⁠arašni⁠/ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔa.ˈraʃ/ 

 ( Dari, formal ) IPA ( key ) : [ʔä.ɾáʃ] 

 ( Dari, formal ) IPA ( key ) : [ʔä.ɾáʃ] 
 ( Kabuli ) IPA ( key ) : [ʔä.ɾáʃ] 

 ( Hazaragi ) IPA ( key ) : [ʔä.ɾáʃ] 

 ( Iran, formal ) IPA ( key ) : [ʔæ.ɹǽʃ] 

 ( Tajik, formal ) IPA ( key ) : [ʔä.ɾáʃ] 

 Rhymes: -aʃ

 Noun
 [ edit ] 

 ارش • ( araš ) 

 cubit ( unit of measurement ) 
 Synonym: ذراع ( zerâ' ) 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit अर्शस् ( arśas ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /əɾʃ/ 

 Noun
 [ edit ] 

 ارش • ( arś )  m ( Hindi spelling अर्श ) 

 ( rare ) piles , hemorrhoids 
 Synonym: بواسير ( bavāsīr )
