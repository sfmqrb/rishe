 Arabic

 Alternative forms
 [ edit ] 

 إِسْحَٰق ( ʔisḥāq ) 

 Etymology
 [ edit ] 

 Etymology tree

 Biblical Hebrew צָחַק ( tsakhák ) 
 Biblical Hebrew יִצְחָק ( yiṣḥāq ) bor. 
 Arabic إسحاق 

 Borrowed from Biblical Hebrew יִצְחָק ( yiṣḥāq ) . Comparable to Arabic يَضْحَكُ ( yaḍḥaku ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔis.ħaːq/ 

 Proper noun
 [ edit ] 

 إِسْحَاق • ( ʔisḥāq )  m 

 Isaac (prophet)

 a male given name , Ishaq and Ishak , equivalent to English Isaac or Yitzchak
