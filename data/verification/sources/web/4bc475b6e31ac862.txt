 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic الْفُرَات ( al-furāt ) , ultimately from Akkadian 𒀀𒇉𒌓𒄒𒉣 ( ÍD< Purattu ) .

 Proper noun
 [ edit ] 

 فرات • ( furat or fırat ) 

 Euphrates (a river in West Asia , 2780 kilometers in length, flowing southwest from Turkey , then southeast, and uniting with the Tigris before entering the Persian Gulf ) 

 Descendants
 [ edit ] 

 > Turkish: Fırat , Furat ( inherited )

 [ edit ]

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /fʊ.ɾɑːt̪/ ,

 ( Standard Urdu ) IPA ( key ) : /fə.ɾɑːt̪/ 

 Proper noun
 [ edit ] 

 فُرات or فَرات • ( furāt or farāt )  m ( Hindi spelling फ़रात ) 

 Euphrates (a river in West Asia , 2780 kilometers in length, flowing southwest from Turkey , then southeast, and uniting with the Tigris before entering the Persian Gulf )
