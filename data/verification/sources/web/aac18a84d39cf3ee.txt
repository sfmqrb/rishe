 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 According to Beekes, the suffix clearly points to a Pre-Greek word. The connection with νάρκη ( nárkē , “ numbness ” ) is due to folk etymology.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /nár.kis.sos/ → /ˈnar.cis.sos/ → /ˈnar.ci.sos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /nár.kis.sos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈnar.kis.sos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈnar.cis.sos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈnar.cis.sos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈnar.ci.sos/ 

 Noun
 [ edit ] 

 νάρκισσος • ( nárkissos )  m or f ( genitive ναρκίσσου ) ; second declension 

 daffodil , narcissus
