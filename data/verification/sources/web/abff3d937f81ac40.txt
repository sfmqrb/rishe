 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Verbal noun of سَفْسَطَ ( safsaṭa , “ to be a sophist, to deliver a specious argument ” ) , denominal from سَفْسَطَائِيّ ( safsaṭāʔiyy , “ sophist ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /saf.sa.tˤa/ 

 Noun
 [ edit ] 

 سَفْسَطَة • ( safsaṭa )  f 

 ( philosophy ) sophism , sophistry ( fallacious reasoning or argumentation )
