 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek φανός ( phanós , “ lantern ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /faː.nuːs/ 

 Noun
 [ edit ] 

 فَانُوس • ( fānūs )  m ( plural فَوَانِيس ( fawānīs ) ) 

 lantern 
 أَضَاءَ الرَّجُلُ الفَانُوسَ لِيَرَى الطَّرِيقَ فِي الظَّلَامِ. ʔaḍāʔa r-rajulu l-fānūsa li-yarā ṭ-ṭarīqa fī ẓ-ẓalāmi. The man lit the lantern to see the way in the dark.

 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 ֆանուս ( fanus ) — Armeno-Turkish 

 Etymology
 [ edit ] 

 Borrowed from Arabic فَانُوس ( fānūs ) , which in turn derives from Ancient Greek φανός ( phanós , “ lantern ” ) .

 Noun
 [ edit ] 

 فانوس • ( fanus ) 

 lantern , a glass or gauze case for a lamp 
 Synonym: فنار ( fenar, fener ) 

 Descendants
 [ edit ] 

 Turkish: fanus

 Pronunciation

 ( Standard Urdu ) IPA ( key ) : /fɑː.nuːs/

 Hyphenation: فا‧نُوس 

 Noun
 [ edit ] 

 فانُوس • ( fānūs )  m ( Hindi spelling फ़ानूस ) 

 chandelier 

 lamp 

 glass cover , plant cover 

 ( figuratively ) open-minded person
