 Etymology
 [ edit ] 

 Root 

 ف ل س ف ( f l s f ) 

 5 terms 

 Verbal noun of فَلْسَفَ ( falsafa , “ to philosophize ” ) , either constructed based on فَيْلَسُوف ( faylasūf , “ philosopher ” ) , or based directly on Ancient Greek φιλοσοφία ( philosophía ) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /fal.sa.fa/ 

 Noun
 [ edit ] 

 فَلْسَفَة • ( falsafa )  f ( plural فَلْسَفَات ( falsafāt ) ) 

 philosophy
