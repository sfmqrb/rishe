 Etymology
 [ edit ] 

 Borrowed from a Dravidian language; compare Tamil கூகை ( kūkai ) , Telugu గూబ ( gūba ) , Kannada ಗೂಬೆ ( gūbe ) . Originally onomatopoeic .

 Pronunciation
 [ edit ] 

 ( Classical Sanskrit ) IPA ( key ) : /ɡʱuː.kɐ/ 

 Noun
 [ edit ] 

 घूक • ( ghūka ) stem ,  m 

 owl ( Pañcad. I, 42, Subh. )
