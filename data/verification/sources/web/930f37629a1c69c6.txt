 Root 

 ء ب و ( ʔ b w ) 

 7 terms 

 Inherited from Proto-Semitic *ʔabw- . Cognate with Hebrew אָב ( 'áv ) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔab/

 [ edit ]

 father 

 ancestor , forefather

 [ edit ]

 Verb
 [ edit ] 

 أَبَّ • ( ʔabba ) I ( first-person singular past أَبِبْتُ ( ʔabibtu ) , non-past يَؤُبُّ ( yaʔubbu ) , verbal noun أَبّ ( ʔabb ) or أَبَاب ( ʔabāb ) or أَبَابَة ( ʔabāba ) ) 

 to put the hand to (as "to the sword")

 to move , agitate 

 to long , yearn [ with إِلَى ‘ for something’ ]
 أَبّ إِلَى وَطَنِهِ ― ʔabb ʔilā waṭanihi ― to yearn for one’s homeland, be homesick 
 Synonyms: حَنَّ ( ḥanna ) , تَشَوَّقَ ( tašawwaqa ) , تَاقَ ( tāqa ) 

 to prepare for a journey

 to intend 

 to be straight , upright (as a road, conduct)

 to defeat

 أَبْ ( ʾb / ap /) 

 not , neither , nor 
 اَبْ بُو اَبْ اُولْ ― ʾb bv ʾb ʾvl / Ap bū ap ol. / ― Neither this nor that.

 Noun
 [ edit ] 

 أب • ( ʔabb )  m ( construct state أبو ( ʔabu ) , plural أبات ( ʔabbāt ) or أبهات ( ʔabbahāt ) or أبوات ( ʔabbawāt ) ) 

 ( Syria ) father 
 Synonym: بي ( bayy ) ( Lebanon ) 
 Coordinate term: إم ( ʔimm , “ mother ” ) 

 Usage notes
 [ edit ] 

 When a suffix pronoun is added, either أب ( ʔab- ) or the construct form is used, e.g. أب ي / أبو ي ( ʔabi / ʔabūy , “ my father ” ) .
