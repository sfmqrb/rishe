 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( nērōg /⁠nylwk’, nyrwg⁠/ ) , from Proto-Iranian *naryawa-ka- ( “ valor, strength ” ) , from Proto-Indo-Iranian *Hnā́ ( “ man ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /neː.ˈroː/ 

 ( Dari, formal ) IPA ( key ) : [neː.ɾuː] , [niː.ɾuː] 

 ( Dari, formal ) IPA ( key ) : [neː.ɾuː] , [niː.ɾuː] 
 ( Kabuli ) IPA ( key ) : [neː.ɾuː] , [niː.ɾuː] 

 ( Hazaragi ) IPA ( key ) : [nu.ɾu] , [nu.ɾu] 

 ( Iran, formal ) IPA ( key ) : [niː.ɹuː] 

 ( Tajik, formal ) IPA ( key ) : [ne.ɾɵ] 

 Rhymes: -oː

 Noun
 [ edit ] 

 نیرو • ( nērō / niru ) ( plural نیروها ( nērō-hā / niru-hâ ) , Tajik spelling нерӯ ) 

 force , power , strength 

 ( military ) force
