 Alternative forms
 [ edit ] 

 شَا۟يْء ( šayʔ ) — pre-classical spelling 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʃajʔ/ 

 Noun
 [ edit ] 

 شَيْء • ( šayʔ )  m ( plural أَشْيَاء ( ʔašyāʔ ) ) 

 thing 
 609–632 CE , Qur'an , 13:16 : قُلِ اللّٰهُ خَالِقُ كُلِّ شَيْءٍ وَهُوَ الْوَاحِدُ الْقَهَّارُ quli llāhu ḵāliqu kulli šayʔin wa-huwa l-wāḥidu l-qahhāru Say, "God is Creator of all things , and He is the One, the Prevailing." 

 little ; some (+ مِنْ ( min ) )
