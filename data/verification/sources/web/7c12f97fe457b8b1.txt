 Avestan
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *wástram , from Proto-Indo-European *wést-ro-m . Cognate with Sanskrit वस्त्र ( vástra ) .

 Noun
 [ edit ] 

 𐬬𐬀𐬯𐬙𐬭𐬀 • ( vastra )  n 

 clothing , garment 

 cloth 

 References
 [ edit ]
