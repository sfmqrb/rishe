 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ʾnʾlgyl /⁠anārgēl⁠/ , “ coconut ” ) , from Sanskrit नारिकेल ( nārikela ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /naːr.ˈɡeːl/ , /naːr.ˈɡiːl/ 

 ( Dari, formal ) IPA ( key ) : [nɑːɾ.ɡíːl] 

 ( Dari, formal ) IPA ( key ) : [nɑːɾ.ɡíːl] 
 ( Kabuli ) IPA ( key ) : [nɑːɾ.ɡíːl] 

 ( Hazaragi ) IPA ( key ) : [nɔːɾ.ɡíl̥] 

 ( Iran, formal ) IPA ( key ) : [nɒːɹ.ɡʲíːl̥] 

 ( Tajik, formal ) IPA ( key ) : [nɔɾ.ɡíl] 

 Rhymes: -eːl , -iːl

 نارگیل • ( nārgēl / nârgil ) ( plural نارگیل‌ها ) 

 ( dated in Dari , normal elsewhere ) coconut
