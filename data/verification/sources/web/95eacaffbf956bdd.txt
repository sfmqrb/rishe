 Etymology
 [ edit ] 

 From Biblical Hebrew יוֹחָנָן ( yōḥɔnɔn ) , the masculine form of יוֹחָנָה ( yōḥānā ) , whence also Ῐ̓ωᾰ́ννᾱ ( Ĭōắnnā ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /i.oˈan.nis/ → /i.oˈa.nis/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /i.oˈan.ne̝s/ 

 ( 4 th CE Koine ) IPA ( key ) : /i.oˈan.nis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /i.oˈan.nis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /i.oˈa.nis/ 

 Proper noun
 [ edit ] 

 Ῐ̓ωᾰ́ννης • ( Ĭōắnnēs )  m ( genitive Ῐ̓ωᾰ́ννου ) ; first declension 

 ( Koine ) a male given name from Hebrew, equivalent to English John
