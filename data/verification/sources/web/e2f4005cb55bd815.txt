 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From مست ( most ) +‎ ـمند ( -mand ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /must.ˈmand/ 

 ( Iran, formal ) IPA ( key ) : [mos.t̪ʰæ.mǽn̪d̪̥] 

 Rhymes: -and 

 Readings

 Classical reading ? 

 mustmand

 Iranian reading ? 

 mostamand

 Adjective
 [ edit ] 

 مستمند • ( mostamand ) 

 afflicted , needy 

 Further reading
 [ edit ] 

 Hayyim, Sulayman ( 1934 ), “ مستمند ”, in New Persian–English dictionary , Teheran: Librairie-imprimerie Béroukhim
