 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( pdk' /⁠payg⁠/ , “ foot-soldier, courier ” ) , ultimately from Proto-Iranian *pā́dah ( “ foot ” ) . Cognate with Sanskrit पदिक ( padika , “ going on foot, pedestrian ” ) . Compare the Iranian borrowings: Old Armenian պայիկ ( payik ) , Georgian პაიკი ( ṗaiḳi ) , Classical Syriac ܦܱܝܓܳܐ ( faygā ) , Arabic فَيْج ( fayj ) , فَوْج ( fawj ) . Doublet of فوج ( fowj ) .

 Alternative forms
 [ edit ] 

 پیگ ( peyg ) 

 Noun
 [ edit ] 

 پیک • ( peyk ) ( plural پیک‌ها , or پیکان ) 

 messenger , courier
