 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 κάλπᾰσος ( kálpăsos ) 

 Etymology
 [ edit ] 

 Borrowed from Biblical Hebrew כַּרְפַּס ( karpás , “ a type of expensive fabric made of cotton ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kár.pa.sos/ → /ˈkar.pa.sos/ → /ˈkar.pa.sos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /kár.pa.sos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈkar.pa.sos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈkar.pa.sos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈkar.pa.sos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈkar.pa.sos/ 

 Noun
 [ edit ] 

 κάρπᾰσος • ( kárpăsos )  f ( genitive καρπᾰ́σου ) ; second declension 

 flax ( Linum usitatissimum or Linum bienne )

 cotton 

 Declension
 [ edit ] 

 Second declension of ἡ κάρπᾰσος ; τῆς καρπᾰ́σου ( Attic )
