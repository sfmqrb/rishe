 Aramaic

 Verb
 [ edit ] 

 מַלַח or מְלַח • ( mālaḥ or mlaḥ ) 

 to salt 

 to steer , to guide , to sail 

 Noun
 [ edit ] 

 מֶלַח or מְלַח • ( melaḥ or məlaḥ )  m 

 absolute state of מִלְחָא ( milḥā , “ salt ” ) 

 Hebrew
 [ edit ] 

 Etymology 1
 [ edit ] 

 מֶלַח 

 Root 

 מ־ל־ח ( m-l-kh ) 

 3 terms 

 From Proto-West Semitic *milḥ- . Compare Aramaic מִלְחָא ( milḥā ) , Classical Syriac ܡܠܚܐ ( milḥā ) , Arabic مِلْح ( milḥ ) , Maltese melħ .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /mɛlħ/ 

 ( Samaritan ) IPA ( key ) : /ˈmeːla/ 

 ( Tiberian ) IPA ( key ) : /ˈmɛ.laħ/ [ˈmɛː.laħ] 

 ( Yemenite ) IPA ( key ) : /ˈma.laħ/ [ˈmæː.læħ] 

 ( Sephardi ) IPA ( key ) : /ˈme.laħ/ , /ˈme.laχ/ 

 ( Ashkenazi ) IPA ( key ) : /ˈmɛ.laχ/

 Etymology 2
 [ edit ] 

 מַלָּחִים 

 Root 

 מ־ל־ח ( m-l-kh ) 

 3 terms 

 From Akkadian 𒈣𒁻 ( malāḫum , “ shipman , sailor ” ) , from Sumerian 𒈣𒁻 ( ma₂-laḫ₄ /⁠malaḫ⁠/ , “ shipman , sailor ” ) . Cognate with Arabic مَلَّاح ( mallāḥ ) .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /malˈlaːħ/ 

 ( Tiberian ) IPA ( key ) : /malˈlɔːħ/ [malˈlɔːħ] 

 ( Yemenite ) IPA ( key ) : /malˈlɔħ/ [mælˈlɔːħ] 

 ( Modern Israeli ) IPA ( key ) : /maˈlaχ/ 

 Noun
 [ edit ] 

 מַלָּח • ( mallā́ḥ )  m ( plural indefinite מַלָּחִים , feminine counterpart מַלָּחִית ) [pattern: קַטָּל ] 

 sailor , mariner
