 See also: Reconstruction:Proto-Indo-European/bʰewgʰ- 

 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Etymology 1
 [ edit ] 

 Apparently originally the same root as the synonymous *bʰegʷ- . [ 1 ] 

 Root
 [ edit ] 

 *bʰewg- ( perfective ) [ 2 ] [ 3 ] 

 to flee 
 Synonym: *bʰegʷ- 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *bʰewg- (flee) (14 c, 0 e)

 Proto-Hellenic: 
 Ancient Greek: ἔφυγον ( éphugon ) ( thematized from weak stem ) 

 ⇒ Proto-Hellenic: *pʰéugō ( present from strong stem ) ( see there for further descendants )

 Proto-Italic: *fougom 
 Latin: fūgī 

 *bʰu-né-g-ti ~ *bʰu-n-g-énti ( nasal-infix present ) [ 2 ] 
 Proto-Indo-Iranian: 
 Proto-Indo-Aryan: 
 ⇒ Pali: paribhuñjati ( “ to clean ” ) 

 Proto-Iranian:

 *bʰug-éh₂ 

 *bʰug-tós 
 Proto-Indo-Iranian: *bʰuǰtás

 Ossetian: ( “ open (of space), not enclosed, laid bare ” )
