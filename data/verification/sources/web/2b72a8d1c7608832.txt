 English Wikipedia has an article on: Baghdad 

 Wikipedia 

 Alternative forms
 [ edit ] 

 Bagdad , Bagdat 

 Etymology
 [ edit ] 

 Borrowed from Arabic بَغْدَاد ( baḡdād ) , from Classical Persian بَغْدَاد ( baġdād ) (see there for more). Doublet of Bhagadatta (derived from Sanskrit भगदत्त ( bhagadatta ) ).

 Pronunciation
 [ edit ] 

 IPA ( key ) : /bæɡˈdæd/ , /ˈbæɡdæd/ 
 Audio ( Southern England ) : ( file ) 

 Rhymes: -æd 

 Proper noun
 [ edit ] 

 Baghdad 

 The capital city of Iraq .
 ( metonymic ) The Iraqi government .

 A governorate of Iraq .
