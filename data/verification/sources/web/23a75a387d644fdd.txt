 Etymology
 [ edit ] 

 Derived from Ancient Greek ὑάκινθος ( huákinthos ) , possibly via Sogdian [script needed] ( yγwth /⁠yaγūt⁠/ , “ ruby ” ) .

 Noun
 [ edit ] 

 يَاقُوت • ( yāqūt )  m ( plural يَوَاقِيت ( yawāqīt ) ) 

 ruby 

 sapphire
