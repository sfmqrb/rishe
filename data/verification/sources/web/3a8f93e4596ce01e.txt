 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Root 

 ر ف ء ( r f ʔ ) 

 2 terms 

 Inherited from Proto-West Semitic *rpʔ ( “ to heal, protect ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ra.fa.ʔa/ 

 Verb
 [ edit ] 

 رَفَأَ • ( rafaʔa ) I ( non-past يَرْفَأُ ( yarfaʔu ) , verbal noun رَفْء ( rafʔ ) ) 

 ( transitive ) to bring ship near to the bank of a river, to land at a harbour , to dock 
 قَدْ عَادَ البَحَّارُونَ وَ رَفَأُوا السَفِينَةَ qad ʕāda l-baḥḥārūna wa rafaʔū as-safīnata The sailors have returned and docked the ship.
