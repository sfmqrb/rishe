 Ottoman Turkish
 [ edit ] 

 دره 
 Etymology 1
 [ edit ] 

 Borrowed from Classical Persian دَرَه ( dara , “ valley; crack, fissure ” ) .

 Noun
 [ edit ] 

 دره • ( dere ) 

 valley , dale , vale 
 Synonym: وادی ( vadi ) 

 rivulet , brook 
 Synonyms: جدول ( cedvel ) , چای ( çay ) 

 ravine , gorge , canyon , gully 
 Synonyms: بوغاز ( boğaz ) , حلق ( halk ) 

 Derived terms
 [ edit ] 

 بورغاج دره ( burgac dere , “ sinuous valley ” ) 
 دره اوتی ( dere otu , “ dill ” ) 
 دره بكی ( dere beği , “ sort of lord ” ) 
 دره تپه ( dere tepe , “ steep and difficult ” ) 
 طام دره‌سی ( dam deresi , “ hollow between two slopes of a roof ” ) 
 یابان دره اوتی ( yaban dere otu , “ wild dill ” ) 

 Descendants
 [ edit ] 

 Turkish: dere 

 → Armenian: տէրէ ( tērē ) , դա̈րա̈ ( därä )

 Etymology 2
 [ edit ] 

 Borrowed from Arabic دُرَّة ( durra , “ single pearl ” ) . 

 Noun
 [ edit ] 

 دره • ( dürre ) ( plural درر ( dürer ) or درات ( dürrât ) ) 

 pearl - grain , a single bead made of pearl

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Uncertain, possibly from Proto-Indo-European *der- ( “ to tear, split ” ) or *dʰel(h₂)- ("valley"), the existence of which is uncertain, see Proto-Germanic *dalą for more. Cognate with Avestan 𐬛𐬀𐬭𐬈𐬥𐬁 ( darenā ) and Sogdian 𐫔‎𐫡 ( δar- ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /da.ˈra/ , /dar.ˈra/ 

 ( Dari, formal ) IPA ( key ) : [d̪ä.ɾá] , [d̪är.rá] 

 ( Dari, formal ) IPA ( key ) : [d̪ä.ɾá] , [d̪är.rá] 
 ( Kabuli ) IPA ( key ) : [d̪ä.ɾá] , [d̪är.rá]
