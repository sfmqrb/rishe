 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Persian Wikipedia has an article on: دژ 

 Wikipedia fa 

 Iranian (Parthian?), ultimately from Proto-Indo-European *dʰoyǵʰhos ( “ wall ” ) , from the root *dʰeyǵʰ- ; see there for further information.

 The less common form دز ( dez ) is from Middle Persian KLYTA / dc ( diz , “ fortress ” )

 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈdiʒ/
