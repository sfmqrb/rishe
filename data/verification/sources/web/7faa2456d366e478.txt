 Etymology
 [ edit ] 

 Etymology tree

 Proto-Germanic *frankô 
 Frankish *Frankō bor. 
 Latin francus 
 Old French franc bor. 
 Arabic إفرنجي 

 Borrowed from Old French franc . First attested in 1895.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔif.ran.d͡ʒijj/ 

 Noun
 [ edit ] 

 إِفْرَنْجِيّ • ( ʔifranjiyy )  m ( plural إِفْرَنْج ( ʔifranj ) , feminine إِفْرَنْجِيَّة ( ʔifranjiyya ) ) 

 Frank 

 ( by extension ) any white European
