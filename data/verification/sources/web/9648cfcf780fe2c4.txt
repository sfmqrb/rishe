 Pashto
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian ترش ( turš ) .

 Adjective
 [ edit ] 

 ترش • ( turš ) 

 sour 

 ( figurative ) unsatisfied ; irritable 

 ( figurative ) gloomy ; morose 

 References
 [ edit ] 

 Pashtoon, Zeeya A. ( 2009 ), “ ترش ”, in Pashto–English Dictionary , Hyattsville: Dunwoody Press, page 184

 sour , tart ( tasting acidic ) 

 morose , stern 

 fermented
