 Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 تَوْءَم ( tawʔam ) 

 Etymology
 [ edit ] 

 Compare Akkadian 𒊕𒌋𒌋 ( tu'amu ) , Aramaic תְּיוֹמָא ( təyōmā ) , Classical Syriac ܬܐܡܐ ( təʾāmā ) and Hebrew תְּאוֹם ( təʾôm ) .

 Root 

 و ء م ( w ʔ m ) 

 6 terms 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /taw.ʔam/ 

 Noun
 [ edit ] 

 تَوْأَم • ( tawʔam )  m ( plural تَوائِم ( tawāʔim ) ) 

 one who was born of a multiple birth , i.e. a twin , triplet , quadruplet , etc.
 هٰذَا تَوْأَمِي. ― hāḏā tawʔamī. ― This is my twin. 

 ( sometimes proscribed ) a pair of twins ( two persons collectively ) 
 نَحْنُ تَوْأَم. ― naḥnu tawʔam. ― We are twins.
