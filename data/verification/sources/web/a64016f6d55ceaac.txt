 [ edit ] 

 Learned borrowing from Classical Sanskrit हिमालय ( himālaya ) . By surface analysis , हिम ( him ) +‎ -आलय ( -ālay ) .

 [ edit ] 

 हिमालय • ( himālay )  m ( Urdu spelling ہمالیہ )

 Etymology
 [ edit ] 

 Compound of हिम ( hima , “ snow, frost ” ) +‎ आलय ( ālaya , “ house, dwelling ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Sanskrit ) IPA ( key ) : /ɦi.mɑː.l̪ɐ.jɐ/ 

 Proper noun
 [ edit ] 

 हिमालय • ( himālaya ) stem ,  m ( Classical Sanskrit ) 

 the Himalayas 

 ( Hinduism , mythology ) Himalaya , the personified range , husband of Menaka and father of Parvati ( wife of Shiva ) and Ganga (the personified Ganges )
