 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 By surface analysis , نـ ( na- , “ un- ” ) +‎ ستوه ( sutōh  / sotuh , “ defeated, beaten ” ) 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /nas.ˈtoːh/ 

 ( Dari, formal ) IPA ( key ) : [näs.t̪ʰóːʱ] 

 ( Dari, formal ) IPA ( key ) : [näs.t̪ʰóːʱ] 
 ( Kabuli ) IPA ( key ) : [näs.t̪ʰóː] 

 ( Hazaragi ) IPA ( key ) : [näs.t̪ʰʊ́ː] 

 ( Iran, formal ) IPA ( key ) : [næs.t̪ʰúːʰ] 

 ( Tajik, formal ) IPA ( key ) : [näs.t̪ʰɵ́ʰ] 

 Rhymes: -oːh

 Adjective
 [ edit ] 

 نستوه • ( nastōh / nastuh ) 

 ( archaic ) undefeatable 

 indefatigable
