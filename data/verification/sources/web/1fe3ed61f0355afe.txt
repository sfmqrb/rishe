 Alternative forms

 بربت ( barbat ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( blbwt' /⁠barbut⁠/ , “ lyre ” ) , from Ancient Greek βάρβιτος ( bárbitos ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bar.ˈbut/ 

 ( Dari, formal ) IPA ( key ) : [bäɾ.bát̪] 

 ( Dari, formal ) IPA ( key ) : [bäɾ.bát̪] 
 ( Kabuli ) IPA ( key ) : [bäɾ.bát̪] 

 ( Hazaragi ) IPA ( key ) : [bäɾ.bát̪] 

 ( Iran, formal ) IPA ( key ) : [bæɹ.bǽt̪ʰ] 

 ( Tajik, formal ) IPA ( key ) : [bäɾ.bát̪] 

 Rhymes: -ut

 بربط • ( barbat ) ( plural بربط‌ها ) 

 barbat (a type of lute )
 Synonyms: عود ( ud ) , لوت ( lut ) 
 c. 1911 , Mohammad Hossein Âğuli Torki-ye Shirâzi, دیوان ترکی شیرازی ‎ [1] : از درس و بحث و مدرسه شد خاطرم ملول
مطرب بیار بربط و چنگ و رباب را az dars o bahs o madrese šod xâter-am malul
motrab biyâr barbat o čang o robâb râ I am fed up with classes and discussions and schools;
Singer, bring the barbat and the harp and the rubab .
