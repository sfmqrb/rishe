 Noun
 [ edit ] 

 لیمو • ( līmū, līmō / limu ) ( plural لیموها ( līmū-hā, līmō-hā / limu-hâ ) , Tajik spelling лиму , or лимӯ ) 

 لِیمُو 
 lemon ; lime 
 Synonyms: بادرنگ ( bādrang  / bâdrang ) , ترنج ( turanj  / toranj )
