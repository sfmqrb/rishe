 This Proto-Germanic entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Germanic
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European *mréǵʰus ~ *mr̥ǵʰéws ( “ short ” ) . Cognate with Latin brevis ( “ short, small, narrow, shallow ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈmur.ɣuz/ 

 Adjective
 [ edit ] 

 *murguz 

 ( of time or duration ) short ; brief 

 slow ; leisurely
