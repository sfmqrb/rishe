 English anguine 

 From Latin anguinus , from anguis ( “ snake ” ) .

 Pronunciation
 [ edit ] 

 ( without æ-raising ) IPA ( key ) : /ˈæŋ.ɡwɪn/ , [ˈæŋ.ɡwɪn]

 Adjective
 [ edit ] 

 anguine ( comparative more anguine , superlative most anguine ) 

 Pertaining to snakes or serpents 

 Snakelike .

 Synonyms
 [ edit ] 

 ( pertaining to snakes ) : ophidian 

 ( snakelike ) : serpentine , snakelike
