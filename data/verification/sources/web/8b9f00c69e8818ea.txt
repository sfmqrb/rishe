 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Through Aramaic ܛܘܦܢܐ / טוֹפָנָא ( ṭōpānā ) ( Classical Syriac ܛܲܘܦܵܢܵܐ ( ṭawpānā ) ), probably from a Sinitic language, though it has also been suggested that the term could be natively Semitic: see typhoon for more. Compare Cantonese 大風  / 大风 ( daai 6 fung 1 , “ big wind ” ) and Ancient Greek τυφῶν ( tuphôn ) .

 Etymology
 [ edit ] 

 Borrowed from Arabic طُوفَان ( ṭūfān ) . Folk etymology incorrectly derives it from توفیدن ( tōfīdan  / tufidan ) .

 Noun

 طوفان • ( tūfān / tufân ) ( plural طوفان‌ها ( tūfān-hā / tufân-hâ ) , Tajik spelling тӯфон ) 

 storm , tempest 

 flood , deluge , inundation 

 typhoon , hurricane
