 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 βρόδον ( bródon ) , ϝρόδον ( wródon ) — Aeolic 

 Etymology
 [ edit ] 

 From Proto-Hellenic *wródon , borrowed from some Eastern language, most likely Proto-Iranian *wardah ( “ flower, rose ” ) (compare Mycenaean Greek 𐀺𐀈𐀸 ( wo-do-we ) , Old Persian *vr̥dah , Aramaic 𐡅𐡀𐡓𐡃𐡀 ( warda ) , Classical Syriac ܘܪܕܐ ( wardā ) , Old Armenian վարդ ( vard ) , Demotic Egyptian wrṱ , Arabic وردة ( warda ) , Persian گل ( gol ) – all from the same source). [ 1 ] An alternative source could possibly be as a Pre-Greek loan, such as Thracian (the rose was native to Thrace). [ 2 ] Rüdiger Schmitt believes that, based on phonological and historical grounds, borrowing from Iranian is unlikely. [ 3 ] 

 Latin rosa ( “ rose ” ) is likely a loanword from Ancient Greek.

 Noun
 [ edit ] 

 ῥόδον • ( rhódon )  n ( genitive ῥόδου , diminutive ῥοδάριον ) ; second declension 

 rose (usually Rosa gallica )

 ( in phrases ) 
 423 BCE , Aristophanes , The Clouds 910 : ῥόδα μ’ εἴρηκας rhóda m’ eírēkas You've said roses about me. 

 Crates Comicus, 4 : ὗς διὰ ῥόδων hûs dià rhódōn pig among roses ( bull in a china shop )
