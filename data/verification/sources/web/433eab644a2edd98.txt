 Root

 Etymology
 [ edit ] 

 Related to مَسَحَ ( masaḥa , “ to anoint ” ) . Cognate to Aramaic ܡܫܺܝܚܳܐ ( m'šīḥāʿ ) and Hebrew מָשִׁיחַ ( mashíakh ) , whence the Ancient Greek borrowing Μεσσίας ( Messías ) and the Greek calque Χριστός ( Christós ) , thus the English terms " Messiah " and " Christ ".

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ma.siːħ/ 

 Rhymes: -iːħ

 [ edit ] 

 مَسِيح • ( masīḥ ) ( masculine plural مُسَحَاء ( musaḥāʔ ) or مَسْحَى ( masḥā ) )
