 Latin
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈkɫu.oː] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈkluː.o] 

 Hyphenation: clu‧ō 

 Etymology 1
 [ edit ] 

 Inherited from Proto-Indo-European *ḱlewH- . Cognates include Gothic 𐌷𐌻𐌿𐍄𐍂𐍃 ( hlūtrs ) , Welsh clir , and Ancient Greek κλῠ́δων ( klŭ́dōn , “ billow ” ) .

 Verb
 [ edit ] 

 cluō ( present infinitive cluere ) ; third conjugation , no perfect or supine stems 

 ( Old Latin ) synonym of pūrgō ( “ to purge , to clean ” )
