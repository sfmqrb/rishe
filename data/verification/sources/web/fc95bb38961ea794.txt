 Baluchi

 Etymology 1
 [ edit ] 

 (This etymology is missing or incomplete. Please add to it, or discuss it at the Etymology scriptorium .) . Cognate with Persian ور ( var ) , Talysh ور ( var ) , Mazanderani ور ( var ) , Pashto ور ( war ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡwəɾ/ , [ɡwəɾ] 

 Rhymes: -wəɾ 

 Noun
 [ edit ] 

 گور • ( gwar ) 

 side 
 Synonyms: کر ( kirr ) , کچ ( kucc ) , کش ( kaš ) , کنک ( kanik ) , پلو ( pallaw ) , پہناد ( pahnád ) , لمب ( lamb ) , نیمگ ( nemag ) 
 ءِ گور ءَ ― 'i gwar 'a ― be side 

 Derived terms
 [ edit ]

 گورءَ دیگ ( gwar'a dayag , “ to help wear ” )

 [ edit ] 

 Ultimately derived from Aramaic 𐡂𐡁𐡓𐡀 ( gbrʾ /⁠gaḇrā⁠/ , “ man; person ” ) . See Persian گبر ( gabr ) for more.

 Pronunciation
 [ edit ]

 Rhymes: -əʊɾ , -ɔːɾ 

 Noun
 [ edit ] 

 گور • ( gawr ) 

 a Zoroastrian 
 Synonym: زرتشتی ( zartuští ) 

 a Hindu 
 Synonym: ہندو ( hindú ) 

 ( loosely ) a non-Muslim 

 a wealthy man
 Synonym: سیٹ ( seť )

Have you seen how the grave has hunted down Bahrām? (Classical Persian transliteration)
