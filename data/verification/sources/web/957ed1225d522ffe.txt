 [ edit ] 

 Alternative forms
 [ edit ] 

 چفتن 

 Etymology
 [ edit ] 

 Inherited from Classical Persian چسپیدن ( časpīdan ) .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [t͡ʃʰæs.biː.d̪ǽn] 

 Readings

 Iranian reading ? 

 časbidan

 Verb
 [ edit ] 

 Dari

 چسپیدن 

 Iranian Persian

 چسبیدن 

 Tajik

 часпидан 

 چسبیدن • ( časbidan ) ( Iran ) 

 to stick , to be stuck , to adhere 

 to cling , to grasp
