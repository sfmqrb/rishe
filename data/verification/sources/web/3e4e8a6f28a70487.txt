 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( hamwar , “ level , abreast ” ) [ 1 ] , Northern Luri هومار ( homar ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ham.ˈwaːr/ 

 ( Dari, formal ) IPA ( key ) : [häm.wɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [häm.wɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔä.wɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔäm.wɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [hæɱ.vɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [häɱ.vɔ́ɾ] 

 Rhymes: -aːr 

 Readings

 Classical reading ? 

 hamwār

 Dari reading ? 

 hamwār

 Iranian reading ? 

 hamvâr

 Tajik reading ? 

 hamvor

 Adjective
 [ edit ] 

 هموار • ( hamvâr ) 

 smooth 

 flat 
 Synonym: مستوی 

 Derived terms
 [ edit ] 

 همواری ( hamvâri , “ smoothness ” ) 

 هموار کردن ( hamvâr kardan , “ to smooth out, flatten, pave ” ) 

 Descendants
 [ edit ] 

 → Azerbaijani: hamar 

 → Urdu: ہَمْوار ( hamvār )
