 Gulf Arabic
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Arabic أَشَالَ ( ʔašāla , “ to raise ” ) , form IV causative of شَالَ ( šāla , “ to rise ” ) , from the root ش و ل ( š w l ) .

 Pronunciation
 [ edit ] 

 ( Kuwait ) IPA ( key ) : /ʃɑl/ 

 Verb
 [ edit ] 

 شال • ( ʃal ) ( present يِشِيل ( ɪʃil ) , verbal noun شيلة ( ʃelə ) ) 

 to remove 
 شيل الببسي من الصفرة ― Remove the Pepsi/soft drink from the tablecloth 

 to lift 
 تشيل حديد ولا كأنما! ― She lifts weight as if (it is nothing)! 

 to carry 
 يا حلات منظر الأهل وُهُم شايلين عيالهم How beautiful is the scene of parents carrying their children 

 ( figuratively , by extension ) to carry responsibility
 هالبنية بروحها شايلة بيتهم بكبره This girl alone is carrying (the responsibility of) her house(hold) in its entirety 

 مو قادر يشيل روحه ويقولي بيتزوج! (He) cannot carry (the responsibility of) himself and he is telling me he wants to get married!

 Etymology 1
 [ edit ] 

 From Arabic أَشَالَ ( ʔašāla , “ to raise ” ) , form IV causative of شَالَ ( šāla , “ to rise ” ) , from the root ش و ل ( š w l ) .

 Verb
 [ edit ] 

 شال • ( šāl ) I ( non-past يشيل ( yšīl ) , passive participle شايل ( šāyel ) ) 

 to remove , to take off, away
 Synonym: قام ( ʔām ) 
 ما فيي شيل الغطا عن هاي القنينة. ma fiyyi šīl l-ḡaṭa ʕan hāy l-ʔannīne. I can't get the lid off this bottle. 

 شيل عينيك عن غير نسوان. ― šīl ʕaynayk ʕan ḡayr niswān. ― Take your eyes off other women. 

 ( slang , Lebanon ) to be down , to be up for ( used either alone or governing a subjunctive-verb phrase ) 
 مولعينها بطرابلس، بتشيلي ننزل؟ — ايه بشيل mwallʕīna b ṭrāblus, bitšīli ninzal? — ʔē bšīl They're going wild in Tripoli, you want to head down? — Yeah, I'm down to.

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from an Indo-Aryan language. Compare Hindi दुशाला ( duśālā ) , from Sanskrit शाटी ( śāṭī ) , feminine of शाट ( śāṭa , “ clothing ” ) . [ 1 ] [ 2 ] Sometimes said to be from or influenced by Chāliāt, a Persian pronunciation of Chaliyam in India, supposedly where they were first made. [ 3 ] [ 4 ] [ 5 ] Doublet of سَارِی ( sārī  / sâri ) .

 Tunisian Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 An adaptation from Eastern Arabic varieties; ultimately from Arabic أَشَالَ ( ʔašāla ) . Compare North Levantine Arabic شال 

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ʃe̞ːl] 

 Verb
 [ edit ] 

 شال ( šeel ) 

 ( humorous , nonstandard ) to remove , move away 
 " شِيل عيُونَك عَنِّي!""
"بِاش نِتشِالُوا الكُلّ!!" " šīl ʕyūnak ʕanni!"
"bēš netšēlu lkoll!!" " Move your eyes away from me!"
"We're definitely going to be removed altogether!!" 

 Responding to a passage from a Middle Eastern song by repurposing that loanverb according Tunisian grammar 
 Synonym: نَحَّى ( naḥḥa )
