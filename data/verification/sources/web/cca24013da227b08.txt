 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( ʾmʾl /⁠āmār⁠/ , “ reckoning, consideration ” ) , from Old Persian ; see *hammārakarah for more.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ˈmaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.mɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.mɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.mɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.mɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.mɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [ʔɔ.mɔ́ɾ]
