 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 ساروان ( sârevân ) 

 Etymology
 [ edit ] 

 Borrowed from either Parthian 𐫘𐫀𐫡𐫤 ( sʾrt /⁠sārt⁠/ , “ caravan ” ) or Sogdian [script needed] ( sʾrth /⁠sārt⁠/ , “ caravan ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /saː.ri.ˈbaːn/ 

 ( Dari, formal ) IPA ( key ) : [sɑː.ɾɪ.bɑ́ːn] 

 ( Dari, formal ) IPA ( key ) : [sɑː.ɾɪ.bɑ́ːn] 
 ( Kabuli ) IPA ( key ) : [sɑː.ɾɪ.bɑ́ːn] 

 ( Hazaragi ) IPA ( key ) : [sɔː.ɾi.bɔ́ːn] 

 ( Iran, formal ) IPA ( key ) : [sɒː.ɹe.bɒ́ːn] 

 ( Tajik, formal ) IPA ( key ) : [sɔ.ɾi.bɔ́n] 

 Rhymes: -aːn

 Noun
 [ edit ] 

 ساربان • ( sârebân ) ( plural ساربانان , or ساربان‌ها ) 

 ( archaic ) caravanner , caravaneer ( leader of caravan ) 
 12th century, Saadi , Divan (Ghazaliyyat), 268 :
 ای ساربان آهسته رو کآرام جانم می‌رود 
 وآن دل که با خود داشتم با دلستانم می‌رود ay sāribān āhista rān k-ārām-i jānam mē-rawad 
 w-ān dil ki bā xud dāštam bā dilsitānam mē-rawad (please add an English translation of this quotation) 

 ( archaic ) camel - keeper 
 11th century, Abulfazl Bayhaqi , Tarikh-i Bayhaqi , Adib, page 453, cited in "ساربان", Dehkhoda Dictionary :
 امیر حاجب سباشی را گفت ساربانان را بباید گفت تا اشتران دوردست تر نبرند. amir hājib sabāšī rā goft sāribānān rā bibāyad goft tā ušturān dur-dast-tar nabarand. Amir Hajib told Sabashi that the camel-keepers should be told not to bring the camels any farther.
