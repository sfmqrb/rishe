 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 استرون ( astarwan  / astarvan ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( stlwn' /⁠starwan⁠/ , “ barren, childless ” ) , perhaps from Proto-Indo-European *str̥-wénts ( “ barren, sterile ” ) . A common folk etymology derives it from ستر ( satar ) , variant of استر ( astar , “ mule ” ) , because mules can’t reproduce. [ 1 ]

 Adjective
 [ edit ] 

 سترون • ( satarwan / satarvan ) ( Tajik spelling сатарван ) 

 Unable to reproduce or procreate ; barren 

 germless , sterile ; free from all living or viable microorganisms.
