 Pashto
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کدخدا .

 Noun
 [ edit ] 

 کدخدا • ( kadxudā́ )  m 

 village elder , village headman , head of a family 

 Derived terms
 [ edit ] 

 کدخدايي ( kadxudājí ) 

 References
 [ edit ] 

 Pashtoon, Zeeya A. ( 2009 ), “ کدخدا ”, in Pashto–English Dictionary , Hyattsville: Dunwoody Press 

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کدخدای ( kadxudāy  / kadxodây ) , کدخداه ( kadxudāh  / kadxodâh ) , کتخدا ( katxudā  / katxodâ ) , کتخدای ( katxudāy  / katxodây ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭪𐭲𐭪𐭧𐭥𐭲𐭠𐭩 ( ktkhwtʿy /⁠kadag-xwadāy⁠/ , “ householder, master of the house ” ) . [ 1 ] Northern Luri کںخا ( kəxa ) , By surface analysis , کده ( kada  / kade , “ house, village ” ) +‎ خدا ( xudā  / xodâ , “ master, lord ” ) .

 ( Dari, formal ) IPA ( key ) : [kʰäd̪.xʊ.d̪ɑː] 
 ( Kabuli ) IPA ( key ) : [kʰäd̪.xʊ.d̪ɑː]

 Noun
 [ edit ] 

 کدخدا • ( kadxudā / kadxodâ ) ( Tajik spelling кадхудо ) 

 village headman , mayor 
 Synonym: دهخدا ( dihxudā  / dehxodâ ) 

 ( archaic ) master of the house , husband 
 Coordinate term: کدبانو ( kadbānū  / kadbânu ) 

 ( historical ) tithe officer
