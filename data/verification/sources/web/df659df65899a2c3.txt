 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *ksweybʰ- or *kʷsweybʰ- or *kʷseybʰ- [ 1 ] [ 2 ] 

 to move swiftly , make a swift movement 

 to swing , shake , to be swinging 

 to whip , cast , throw 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *ksweybʰ- (18 c, 0 e) 

 *kswéybʰ-e-ti ( thematic root present ) [ 3 ] 
 Proto-Germanic: *swībaną ( “ to revolve, sway, sweep ” ) [ 3 ] ( see there for further descendants )

 Proto-Indo-Iranian: *kšwáypati , *kšwáybʰati 
 Proto-Iranian: *xšwáypati , *xšwáybati ( “ to vibrate, tremble, shake ” ) [ 4 ] ( see there for further descendants )

 *ksweybʰ-eh₂ye-ti [ 3 ] 
 Proto-Slavic: *šibati ( “ to whip ” ) [ 5 ] ( see there for further descendants )

 *kswip-é-ti ( zero-grade thematic root present ) [ 3 ] 
 Proto-Indo-Iranian: *kšwipáti 
 Proto-Indo-Aryan: *kṣipáti

 Proto-Germanic: *swaipijaną ( see there for further descendants )

 *kswibʰ-éh₁-ti ( *éh₁-stative )
