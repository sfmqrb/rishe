 Verb
 [ edit ] 

 گنجیدن • ( gonjidan ) ( present stem گنج ( gonj ) ) 

 ( intransitive ) to be contained ; to be held 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 20: گر بریزی بحر را در کوزه‌‌ای 
چند گنجد قسمت یک روزه‌‌ای gar birēzī bahr rā dar kūza'ē
čand gunjad qismat-i yak rōza'ē If thou pour the sea into a pitcher, how much will it hold [lit. how much is contained ]? One day's store.
