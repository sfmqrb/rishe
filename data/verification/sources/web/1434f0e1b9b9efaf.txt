 Etymology
 [ edit ] 

 Etymology tree

 Biblical Hebrew אַבְרָהָם ( ʔaḇrɔhɔm ) bor. 
 Aramaic אַבְרָהָם ( ʾaḇrāhām ) bor. 
 Arabic إِبْرَاهِيم ( ʔibrāhīm ) bor. 
 Classical Persian اِبْرَاهِیم ( ibrāhīm ) bor. 
 Chagatai ابراهیم 

 Borrowed from Classical Persian اِبْرَاهِیم ( ibrāhīm ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : ( most common ) [ibraːhim] , [ivraːhim] , [ivrahim] , [urˈajim] 

 Proper noun
 [ edit ] 

 ابراهیم • ( ʾbrʾhym / ibrāhim, iwrāhim, iwrahim, urayim /) 

 ( biblical , Islam ) Abraham 

 a male given name , Ibrahim , from Arabic, equivalent to English Abraham 

 Descendants
 [ edit ] 

 Uyghur: ئىبراھىم ( ibrahim ) 

 Uzbek: Ibrohim
