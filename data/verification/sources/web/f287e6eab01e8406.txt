 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 ویدستر ( vidastar ) 

 Etymology
 [ edit ] 

 Perhaps a compound word from Proto-Indo-European *widʰu- ( “ tree, beam ” ) and *h₁ed- ( “ to eat ” ) , literally means a "wood-eater".

 Noun
 [ edit ] 

 بیدستر • ( bidastar ) ( plural بیدستران ( bidastarân ) , or بیدسترها ( bidastar-hâ ) ) 

 beaver
