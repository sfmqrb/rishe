 Alternative forms

 اڤزودن ( aḇzūdan ) ( Early New Persian ) 

 فزودن ( fuzūdan  / fozudan ) 

 Etymology
 [ edit ] 

 From Early New Persian اڤزودن ( aḇzūdan ) , inherited from Middle Persian [Book Pahlavi needed] ( ʾpzwtn' /⁠abzūdan⁠/ ) , from Proto-Iranian *Habigaw- ( “ to increase ” ) . The prefix is from Proto-Indo-Iranian *Habʰí ( “ to, against, for ” ) , while the root is of unclear origin, and possibly related to Lithuanian gáuti ( “ to obtain ” ) . [ 1 ] [ 2 ]

 [ edit ]

 Verb
 [ edit ] 

 افزودن • ( afzūdan / afzudan ) ( present stem افزا ( afzā / afzâ ) , or افزای ( afzāy / afzây ) , Tajik spelling афзудан ) 

 to increase ; to add 
 Synonym: اضافه کردن ( izāfa kardan  / ezâfe kardan ) 
 Antonym: کاستن ( kāstan  / kâstan )
