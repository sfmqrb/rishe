 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit शर्करा ( śárkarā ) . Doublet of शक्कर ( śakkar ) and सकर ( sakar ) . Cognate of English sugar .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ʃəɾ.kə.ɾɑː/ , [ʃɐɾ.kɐ.ɾäː] 

 Noun
 [ edit ] 

 शर्करा • ( śarkarā )  f ( Urdu spelling شرکرا ) 

 ( formal ) sugar ( granulated or candied ) 
 Synonyms: चीनी ( cīnī ) , शक्कर ( śakkar ) 

 ( chemistry ) glucose , saccharose

 Etymology
 [ edit ] 

 From Proto-Indo-Aryan *śárkaraH , from Proto-Indo-Iranian *ćárkaraH , from Proto-Indo-European *ḱorkeh₂ ( “ gravel, boulder ” ) . Cognate with Ancient Greek κρόκη ( krókē , “ pebbles ” ) , whence English crocodile . [ 1 ] [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɕɐ́ɾ.kɐ.ɾɑː/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɕɐɾ.kɐ.ɾɑː/ 

 Noun
 [ edit ] 

 शर्क॑रा • ( śárkarā ) stem ,  f 

 gravel , grit , pebbles , shingle , gravelly mould or soil (mostly plural)

 gravel (as a disease )

 hardening of the flesh 

 hardening of the ear-wax 

 ground or candied sugar 

 a fragment or piece of broken earthenware , potsherd 

 cotton sugar , sugarmaple
