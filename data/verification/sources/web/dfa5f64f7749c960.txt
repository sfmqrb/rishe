 Ancient Greek
 [ edit ] 

 Etymology 1
 [ edit ] 

 According to Beekes, related to Old Armenian մոզի ( mozi , “ calf ” ) and maybe from a Proto-Indo-European *mosǵʰ-o- ( “ young of an animal; young shoot ” ) . The appurtenance of Lithuanian mãzgas ( “ bud of a tree; knot ” ) to the Greco-Armenian terms is less certain and straightforward. [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /mós.kʰos/ → /ˈmos.xos/ → /ˈmos.xos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /mós.kʰos/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈmos.kʰos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈmos.xos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈmos.xos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈmos.xos/ 

 Noun
 [ edit ] 

 μόσχος • ( móskhos )  m ( genitive μόσχου ) ; second declension 

 young shoot or twig 

 ( botany ) leafstalk ; petiole 

 calf ; young bull 

 any young animal 

 Declension
 [ edit ] 

 Second declension of ὁ μόσχος ; τοῦ μόσχου ( Attic )

 Etymology 2
 [ edit ] 

 From Middle Persian [script needed] ( mwšk' /⁠*mušk⁠/ ) , itself from Sanskrit मु॒ष्क ( muṣká , “ testicle ” ) ; compare also μύσχον ( múskhon , “ genitalia ” ) . [ 2 ]

 [ edit ] 

 IPA ( key ) : /mós.kʰos/ → /ˈmos.xos/ → /ˈmos.xos/

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈmos.kʰos/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈmos.xos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈmos.xos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈmos.xos/ 

 Noun
