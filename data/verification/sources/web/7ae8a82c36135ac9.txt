 Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Ottoman Turkish چبوق ( çibuk, çıbuk, çubuk ) , from Proto-Turkic *čöpik ( “ stick, twig ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [tʃubuk] 

 Noun
 [ edit ] 

 çubuk ( definite accusative çubuğu , plural çubuklar ) 

 stick ( twig or small branch )
