 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 وارونه ( varune ) 

 Etymology
 [ edit ] 

 Borrowed from Persian وارون ( vârun , “ upside down, inverted ” ) .

 Adjective
 [ edit ] 

 وارون • ( varun ) 

 upside down , inverted , reverse , upturned 
 Synonym: ترس ( ters ) 

 ( of a building ) thrown down , demolished 

 inauspicious , ill-omened , unfortunate , unfavorable 

 Descendants
 [ edit ] 

 Turkish: varun

 Persian

 Etymology
 [ edit ]

 Adjective
 [ edit ] 

 وارون • ( wārūn / vârun ) ( Tajik spelling ворун ) 

 alternative form of وارونه ( wārūna  / vârune , “ inverted ” ) 

 ( Classical Persian , figurative ) 
 wicked , evil 

 pitiful
