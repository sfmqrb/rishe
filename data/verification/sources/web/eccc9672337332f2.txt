 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *danHáyati , from Proto-Indo-Iranian *dʰanHáyati , from Proto-Indo-European *dʰenh₂- . Cognate with Sanskrit धन् ( dhan , “ to cause to move ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /dæniːˈdæn/ 

 Verb
 [ edit ] 

 دنیدن • ( danidan ) ( present stem دن ( dan ) ) [ 2 ] 

 to walk with pomposity 

 to boil with rage

 to run with alacrity and joy
