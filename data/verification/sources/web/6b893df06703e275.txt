 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Middle Mongol ᠪᠠᠭ᠋ᠠᠲᠤᠷ ( baɣatur ) , attested after the Mongol conquest in the 1200s.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ba.haː.ˈdur/ 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑː.d̪ʊ́ɾ] 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑː.d̪ʊ́ɾ] 
 ( Kabuli ) IPA ( key ) : [bɑːɑː.d̪ʊ́ɾ] 

 ( Hazaragi ) IPA ( key ) : [bɔː.t̪ʰúɾ] 

 ( Iran, formal ) IPA ( key ) : [bæ.ɦɒː.d̪óɹ] 

 ( Tajik, formal ) IPA ( key ) : [bä.ɦɔ.d̪úɾ] 

 Rhymes: -ur

 Noun
 [ edit ] 

 بهادر • ( bahādur / bahâdor ) ( plural بهادران ( bahādurān / bahâdorân ) , Tajik spelling баҳодур ) 

 paladin , champion , hero 
 Synonyms: قهرمان ( qahremân ) , دلاور ( delâvar ) , یل ( yal ) , گرد ( gord ) , پهلوان ( pahlavân ) , گوانجی ( gavânji ) 
 c. 1520 , Selim I of the Ottoman Empire , edited by Benedek Péri, The Persian Dīvān of Yavuz Sulṭān Selīm , Budapest, Hungary: Research Centre for the Humanities, Eötvös Loránd Research Network, →ISBN , page 74 : بهادران و دلیرند خیل مژگانت
که وقت معرکه هستند هر یکی صفدر bahādurān u dalēr-and xayl-i mužagānat
ki waqt-i ma'rakā hastand har yakē safdar The army of your eyelashes are valiant paladins ,
Each of whom break the enemy's ranks at the time of war. (Classical Persian transliteration) 

 Adjective
 [ edit ] 

 بهادر • ( bahādur / bahâdor ) ( Tajik spelling баҳодур ) 

 brave , valiant , courageous 
 Synonyms: شجاع ( šojâ' ) , دلیر ( dalir ) , دلاور ( delâvar ) 
 1510s , Faẓlullāh Rōzbihān Khunjī , سلوک الملوک : با یکدیگر مصافی دادند بر لب کول
هر دو جوان پرزور هر دو یل بهادر bā yakdīgar masāffē dādand bar lab-i kūl
har du jawān-i pur-zōr har du yal-i bahādur They fought each other in battle on the banks of the Kūl,
Both of them strong young men, both valiant heroes. (Classical Persian transliteration) 

 Proper noun
 [ edit ] 

 بهادر • ( bahādur  / bahâdor ) ( Tajik spelling Баҳодур ) 

 a male given name , Bahador and Bahadur
