 Alternative forms
 [ edit ] 

 στύμα ( stúma ) — Aeolic 

 Etymology
 [ edit ] 

 From Proto-Indo-European *stéh₃mn̥ ( “ mouth; muzzle ” ) . Cognate with Avestan 𐬯𐬙𐬀𐬨𐬀𐬥 ( staman , “ mouth [of a dog] ” ) , Welsh safn ( “ mouth; jaws ” ) , Hittite 𒅖𒋫𒈪𒈾𒀸 ( iš-ta-mi-na-aš /⁠ištāman-⁠/ , “ ear ” ) , as well as, despite Beekes's objections, Proto-Germanic *stebnō ( “ voice; sound ” ) . [ 1 ] 

 Compare typologically Russian у́стье ( ústʹje ) , у́стьице ( ústʹice ) (akin to уста́ ( ustá ) ).

 Noun
 [ edit ] 

 στόμᾰ • ( stómă )  n ( genitive στόμᾰτος ) ; third declension 

 mouth ( especially as the organ of speech ) 

 face 

 source of a river or stream 

 opening or fissure in the earth 

 frontmost part of something

 Etymology
 [ edit ] 

 From Ancient Greek στόμα ( stóma ) , from Proto-Indo-European *stomn̥ , *stomen- ( “ mouth, muzzle ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈsto.ma/ 

 Noun
 [ edit ] 

 στόμα • ( stóma )  n ( plural στόματα ) 

 ( anatomy ) mouth 

 ( synecdochic ) person 
 Η μάνα του είχε δέκα στόματα να θρέψει. I mána tou eíche déka stómata na thrépsei. His mother had ten mouths to feed.
