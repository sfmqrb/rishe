 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit व्रण ( vraṇa ) . Doublet of वण ( vaṇ , colloquial, dialectal ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʋɾəɳ/

 Etymology
 [ edit ] 

 Perhaps from Proto-Indo-European *wer- ( “ to cut, scratch, tear, sketch an outline ” ) . Possible cognates include Armenian գիր ( gir , “ letter ” ) , Ancient Greek ῥινός ( rhinós , “ skin ” ) , Russian рана ( rana , “ wound ” ) , Old High German rīzan (German reißen ) and Old English wrītan (English write ).

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ʋɾɐ.ɳɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /ʋɾɐ.ɳɐ/ 

 Noun
 [ edit ] 

 व्रण • ( vraṇa ) stem ,  m 

 wound , sore , ulcer , abscess , tumour , cancer , boil , scar , cicatrix , crack
