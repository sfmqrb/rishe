 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 αὐτοέντης ( autoéntēs ) 

 Etymology
 [ edit ] 

 From αὐτο- ( auto- , “ self ” ) +‎ *ἕντης ( *héntēs ) , from the full-grade of Proto-Indo-European *senh₂- ( “ to prepare, work on, succeed ” ) +‎ -της ( -tēs , masculine agentive suffix ) , whence also ἀνύω ( anúō , “ I effect, accomplish ” ) , συνέντης ( sunéntēs , “ helper, accomplice ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /au̯.tʰén.tɛːs/ → /aɸˈθen.tis/ → /afˈθen.dis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /au̯.tʰén.tɛːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /aʍˈtʰen.te̝s/ 

 ( 4 th CE Koine ) IPA ( key ) : /aɸˈθen.tis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /afˈθen.tis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /afˈθen.dis/ 

 Noun
 [ edit ] 

 αὐθέντης • ( authéntēs )  m ( genitive αὐθέντου ) ; first declension 

 an autonomous actor 
 a self-controlled , self-directed , or self-governed person

 a sovereign , a master 

 ( with semantic narrowing , post-Classical, Hellenistic ) : one who acts with volition but without any supposed right
 a volitional ruler through usurpation , an absolute ruler , an autocrat , a tyrant , dictator or despot 

 a perpetrator of any act, especially one which commits murder with his own hand or suicide
