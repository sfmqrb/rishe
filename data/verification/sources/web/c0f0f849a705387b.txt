 Ancient Greek

 Alternative forms
 [ edit ] 

 ἐλέφαις ( eléphais ) — Aeolic 

 Etymology
 [ edit ] 

Earlier form: Mycenaean Greek 𐀁𐀩𐀞 ( e-re-pa /⁠elephās⁠/ ) . Probably borrowed from Egyptian ꜣbw 

 (reconstructed as earlier /ˈʀuːbaw/, later /ˈjuːbə/). [ 1 ] . Cognate with Latin ebur ( “ ivory ” ) and Sanskrit इभ ( íbha ) . For the first half compare Hittite 𒆷𒄴𒉺𒀸 ( laḫpaš , “ ivory ” ) , Proto-Berber *eləw , Hebrew פיל , possibly also Ancient Greek ἔλαφος ( élaphos , “ deer ” ) .

 ( Can this ( + ) etymology be sourced ? Particularly: “Sources for the first half”) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /e.lé.pʰaːs/ → /eˈle.ɸas/ → /eˈle.fas/ 

 ( 5 th BCE Attic ) IPA ( key ) : /e.lé.pʰaːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /eˈle.pʰas/ 

 ( 4 th CE Koine ) IPA ( key ) : /eˈle.ɸas/ 

 ( 10 th CE Medieval ) IPA ( key ) : /eˈle.fas/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /eˈle.fas/ 

 Noun
 [ edit ] 

 ἐλέφᾱς • ( eléphās )  m or f ( genitive ἐλέφαντος ) ; third declension 

 elephant 

 ( masculine ) ivory 

 Usage notes
 [ edit ] 

 Two irregular forms are attested:
 A genitive singular ἐλεφάντου in an inscription found in Delos from the 2nd cent. BCE :
 Bulletin de Correspondance Hellénique 35.286: ἐλεφάντου λεπτοῦ τάλαντον δαψιλές elephántou leptoû tálanton dapsilés a full talent of finely worked ivory 

 A dative plural ἐλεφάντοις in the , 1 Maccabees 1.17 , as a variant reading for regular ἐλέφασι(ν) .
