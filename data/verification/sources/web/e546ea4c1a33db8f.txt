 Alternative forms

 Etymology
 [ edit ] 

 Etymology tree

 Middle Persian nʾw 
 Persian ناو ( nâv ) 

 Middle Persian YDOYTWN-stn' 
 Persian دان ( dân ) 

 Persian ناودان 

 From ناو ( nâv ) + دان ( dân ) .
