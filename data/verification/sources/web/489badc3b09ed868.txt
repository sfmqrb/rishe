 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 As this word is also Doric and Aeolic , the connection with ῐ̔́στημῐ ( hĭ́stēmĭ , “ to stand ” ) must be given up. The similarity to στήνιον ( stḗnion ) , Old Armenian ստին ( stin , “ breast ” ) and Sanskrit स्तन॑ ( stána , “ female breast ” ) is hardly coincidental. If cognate, the relation between this word and στήνιον ( stḗnion ) would be like that of Latin plēnus ( “ full ” ) to πλῆθος ( plêthos , “ multitude ” ) .

 Noun
 [ edit ] 

 στῆθος • ( stêthos )  n ( genitive στήθεος or στήθους ) ; third declension 

 breast (of both sexes )

 breast as the seat of emotions , feelings 

 ball of the foot or thumb 

 ( oncology ) swelling , tumour 

 breast -shaped hill or mound 

 Declension
 [ edit ] 

 Third declension of τὸ στῆθος ; τοῦ στήθους ( Attic )
