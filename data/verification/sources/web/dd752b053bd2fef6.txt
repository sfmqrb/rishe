 Baluchi
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *mayšáh , from Proto-Indo-Iranian *mayšás , from Proto-Indo-European *moysós ( “ sheep, skin of sheep ” ) . Cognate with Sanskrit मेष ( meṣá ) , Avestan 𐬨𐬀𐬉𐬱𐬀 ( maēša ) and Persian میش ( miš ) .

 Noun
 [ edit ] 

 میش • ( meš ) 

 sheep 

 Derived terms
 [ edit ] 

 میش مرگ ( meš murg , “ goose ” ) 

 Descendants
 [ edit ] 

 → Brahui: میڷ ( meł ) 

 See also
 [ edit ] 

 پس ( pas ) 

 Further reading
 [ edit ] 

 Uppsala University ( 2026 ), “ میش ”, in Southern Baluchi Dictionary (Webonary) (in Baluchi), Dallas, Texas, USA: SIL International, published 2019 . 

 Muhammad Abd-al-Rahman ( 1969 ), “ meš ”, in A course in Baluchi , Montreal: Institute of Islamic Studies, McGill University 

 Dames, Mansel Longsworth ( 1922 ), “ Mesh ”, in A text book of the Balochi language : consisting of miscellaneous stories, legends, poems and Balochi-English vocabulary , Lahore: Government Printing Press, Punjab

 Persian

 Etymology
 [ edit ] 

 From Middle Persian 𐭬𐭩𐭱 ( mēš ) , from Old Persian *maišah , from Proto-Iranian *mayšáh , from Proto-Indo-Iranian *mayšás , from Proto-Indo-European *moysós ( “ sheep, skin of sheep ” ) . Cognate with Sanskrit मेष ( meṣá ) and Avestan 𐬨𐬀𐬉𐬱𐬀 ( maēša ) .

 ( Tajik, formal ) IPA ( key ) : [meʃ]
