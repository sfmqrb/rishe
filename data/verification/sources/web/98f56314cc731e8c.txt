 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 From Arabic مَادَّة ( mādda ) .

 Noun
 [ edit ] 

 ماده • ( madde ) ( plural مواد ( mevad ) ) 

 matter 

 article ; paragraph 

 subject ; topic 

 pus 

 ( vulgar ) penis 

 Related terms
 [ edit ] 

 مادةً ( maddeten ) 

 Descendants
 [ edit ]

 → Romanian: madea

 Etymology 1
 [ edit ] 

 From Middle Persian NKḆ , mʾtk' ( mādag ) , from Proto-Iranian *māta-ka- ( “ female creature ” ) , from *māta- ( “ female ” ) , from *máHtā ( “ mother ” ) . [ 1 ] Northern Luri ما ( ma , “ female ” ) , Northern Kurdish mê ( “ female ” ) . Compare Old Armenian մատակ ( matak ) , an Iranian borrowing.
