 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Term?] ( /⁠griyistan⁠/ ) . Compare Northern Kurdish girîn , Northern Luri گرێڤسن ( gerêvesen ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡi.riːs.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾiːs.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾiːs.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [ɡɪ.ɾiːs.t̪ʰán]

 Tajik

 گریستن • ( girīstan  / geristan ) ( present stem گری ( girī  / geri ) , Tajik spelling гиристан ) 

 ( intransitive ) to cry , to weep 
 Synonyms: گریه کردن ( gerye kardan ) , اشک ریختن ( ašk rixtan )
