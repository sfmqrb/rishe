 Italian
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈtraf.fi.ko/ 

 Rhymes: -affiko 

 Hyphenation: tràf‧fi‧co 

 Etymology 1
 [ edit ] 

 Potentially from Vulgar Latin *trānsfrīcō ( “ to rub across ” ) , from trans- + frico ; Klein instead suggests the Italian has ultimate origin in Arabic تَفْرِيق ( tafrīq , “ distribution, dispersion ” ) , reshaped to match the native prefix tra- ( “ trans- ” ) . 

 Cognate with Piedmontese tràfich / tràfic and Sicilian tràficu .

 Noun
 [ edit ]

 activity , rush
