 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Ultimately from Ancient Greek Ἀλέξανδρος ( Aléxandros ) . The initial syllable in the original form الْإِسْكَنْدَر ( al-ʔiskandar ) was lost due to rebracketing as the definite article الْ ( al- ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔis.kan.dar/ , ( dialectal ) /skan.dar/ 

 Proper noun
 [ edit ] 

 إسْكَنْدَر • ( ʔiskandar )  m 

 a male given name , Iskandar , from Ancient Greek, equivalent to English Alexander 

 Related terms
 [ edit ] 

 الْإِسْكَنْدَرِيَّة ( al-ʔiskandariyya )
