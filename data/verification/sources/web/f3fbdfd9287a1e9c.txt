 ع ب ر ( ʕ b r ) 

 16 terms 

 Etymology
 [ edit ] 

 Verbal noun of عَبَرَ ( ʕabara , “ to cross ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕu.buːr/ 

 Rhymes: -uːr 

 Noun
 [ edit ] 

 عُبُور • ( ʕubūr )  m 

 verbal noun of عَبَرَ ( ʕabara )   ( form I ) 

 crossing , passing 

 ( transgender ) clipping of عُبُور جِنْدَرِيّ ( ʕubūr jindariyy , “ gender transition ” )
