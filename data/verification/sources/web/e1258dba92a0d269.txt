 Arabic
 [ edit ] 

 Root 

 ل ب ب ( l b b ) 

 4 terms 

 Etymology
 [ edit ] 

 Inherited from Proto-Semitic *libb- ( “ heart ” ) , from Proto-Afroasiatic *lib- .
Cognate with Hebrew לב ( lev ) and Classical Syriac ܠܒܐ ( lebbā ) .

 Noun
 [ edit ] 

 لُبّ • ( lubb )  m ( plural لُبُوب ( lubūb ) ) 

 pulp , backlog , marrow , core , heart 
 Synonym: ( heart ) قَلْب ( qalb )

 Noun
 [ edit ] 

 لب • ( lab ) ( plural لب‌ها ( lab-hā / lab-hâ ) , or لبان ( labān / labân ) , Tajik spelling лаб ) 

 ( anatomy ) lip 
 اگه گفتی دوستت دارم فقط بازی لب‌هات بود. ( colloquial Iran ) Age gofti duset dâram faqat bâziye labhât bud. If (when) you said you love me, you weren't serious. (literally, “ it was only your lip play. ”) 

 edge 
 Synonym: کنار ( kinār  / kenâr )
