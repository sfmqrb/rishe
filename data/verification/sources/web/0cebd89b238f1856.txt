 Adjective
 [ edit ] 

 πέτᾰλον • ( pétălon )  n 

 inflection of πέταλος ( pétalos ) : 
 masculine accusative singular 

 neuter nominative / accusative / vocative singular 

 Etymology 2
 [ edit ] 

 From Proto-Hellenic *pétalon , from Proto-Indo-European *péth₂lom , [ 1 ] from *peth₂- . Compare Old High German fedelgold   n ( “ leaf-gold ” ) . [ 2 ] 

 Noun
 [ edit ] 

 πέτᾰλον • ( pétălon )  n ( genitive πετᾰ́λου ) ; second declension 

 leaf of plant, flower, or tree

 thin plate of metal, leaf of metal

 slice
