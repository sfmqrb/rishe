 Etymology 1
 [ edit ] 

 From Middle Persian pnd ( pand , “ path; counsel, advice ” ) (compare Parthian 𐫛𐫗𐫅 ( pnd /⁠pand⁠/ , “ counsel ” ) , 𐫛𐫗𐫅𐫀𐫗 ( pndʾn /⁠pandān⁠/ , “ path ” ) ), from Proto-Iranian *pántaHs ( “ path, road ” ) , from Proto-Indo-Iranian *pántaHs ( “ path ” ) . [ 1 ] Cognate with Old Armenian հուն ( hun ) , Ancient Greek πάτος ( pátos ) , πόντος ( póntos ) , Latin pons , and Old Church Slavonic пѫть ( pǫtĭ ) .

 Noun
 [ edit ] 

 پند • ( pand ) ( plural پندها ) [ 2 ] [ 3 ] [ 4 ] 

 advice , counsel , guidance
