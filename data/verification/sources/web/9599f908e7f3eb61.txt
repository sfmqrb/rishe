 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈjuː.tə.ɹəs/ 

 Audio ( US ) : ( file ) 

 Hyphenation: u‧ter‧us 

 Noun
 [ edit ] 

 uterus ( plural uteri or uteruses ) 

 ( anatomy , countable ) A reproductive organ of therian mammals in which the young are conceived and develop until birth.
 Synonyms: womb , belly , matrix ( now archaic ) , metra 
 ( zoology ) A similar part in some non- mammals .
