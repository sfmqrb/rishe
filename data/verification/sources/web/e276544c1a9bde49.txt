 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From قوز ( quz , “ hump ” ) +‎ ـک ( -ak , diminutive suffix ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /quː.ˈzak/ 

 ( Dari, formal ) IPA ( key ) : [quː.zák] 

 ( Dari, formal ) IPA ( key ) : [quː.zák] 
 ( Kabuli ) IPA ( key ) : [quː.zák] 

 ( Hazaragi ) IPA ( key ) : [qu.zák] 

 ( Iran, formal ) IPA ( key ) : [quː.zǽkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [qu.zák] 

 Rhymes: -ak
