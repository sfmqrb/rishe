 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 زاقدان ( zâqdân ) , زیدون ( zeydun ) 

 Etymology
 [ edit ] 

 From زه ( zah, zih ) +‎ ـدان ( -dân ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /zah.ˈdaːn/ 

 ( Dari, formal ) IPA ( key ) : [ze̞ɦ.d̪ɑ́ːn] 

 ( Dari, formal ) IPA ( key ) : [ze̞ɦ.d̪ɑ́ːn] 
 ( Kabuli ) IPA ( key ) : [zɪ.d̪ɑ́ːn] 

 ( Hazaragi ) IPA ( key ) : [zi.d̪ɔ́ːn] 

 ( Iran, formal ) IPA ( key ) : [zeɦ.d̪ɒ́ːn] 

 ( Tajik, formal ) IPA ( key ) : [zeɦ.d̪ɔ́n] 

 Rhymes: -aːn

 زهدان • ( zehdân ) 

 ( dated )   uterus , womb
