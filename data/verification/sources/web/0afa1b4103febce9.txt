 Persian افیون 

 The forms with /f/ and /b/ are from Arabic أَفْيُون ( ʔafyūn ) and أَبْيُون ( ʔabyūn ) , that with /p/ is via Middle Persian directly from Ancient Greek ὄπιον ( ópion ) .

 Noun

 افیون • ( afyūn / afyun ) ( Tajik spelling афюн ) 

 opium , poppy - juice

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian اَفْیُون ( afyūn ) , from Arabic أَفْيُون ( ʔafyūn ) , ultimately from Ancient Greek ὄπιον ( ópion ) . Doublet of اَفِیم ( afīm ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /əf.juːn/ 

 Noun
 [ edit ] 

 اَفْیُون • ( afyūn )  f ( Hindi spelling अफ़्यून ) 

 ( formal ) opium 
 Synonym: ( common ) اَفِیم ( afīm )
