 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( HCDLWN-tn' /⁠drūdan⁠/ , “ to reap; to mow ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /du.ruː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [d̪ʊ.ɾuː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [d̪ʊ.ɾuː.d̪án]

 Verb
 [ edit ] 

 درودن • ( dorudan ) ( present stem درو ( derav ) ) 

 to reap , to mow , to harvest 
 Synonym: درو کردن ( derow kardan ) 
 c. 1390 , Hafez , “Ghazal 486”, in دیوان حافظ [ The Divan of Hafez ]‎ [1] : دهقان سال‌خورده چه خوش گفت با پسر
کای نور چشم من! به‌جز از کشته ن دروی dihqān-i sāl-xwarda či xwaš guft bā pisar
k-ay nūr-i čašm-i man! ba joz az kišta na- dirawī How well the aged peasant spoke to his son:
"O light of my eyes! You reap nothing but what was planted." (Classical Persian romanization)
