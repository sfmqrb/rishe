 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Arabic زَيْن ( zayn ) .

 Noun
 [ edit ] 

 زین • ( zeyn ) 

 ornament , adornment , embellishment 

 Derived terms
 [ edit ] 

 زین العابدین ( zeyn’el-ʿâbidîn ) 

 Etymology 2
 [ edit ] 

 Borrowed from Persian زین ( zîn , “ saddle ” ) , itself from Middle Persian [script needed] ( zyn' /⁠zēn⁠/ , “ saddle ” ) .

 Noun
 [ edit ] 

 زین • ( zîn ) 

 saddle , a seat for a rider placed on the back of a horse or other animal 
 Synonyms: ایر ( eyer ) , سرج ( serc )

 زینپوش ( zinpuş , “ saddle-cloth ” ) 
 زینگر ( zinger , “ saddler ” )

 [ edit ] 

 Inherited from Middle Persian [script needed] ( zyn' /⁠zēn⁠/ , “ saddle ” ) , originally meaning something to make ready or fitted, armament, harness. See Old Armenian զէն ( zēn ) , an Iranian loanword.
