 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from a Middle Iranian word of the form srādak , same as later سَرَاي ( sarāy ) with one suffix less.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /su.raː.diq/ 

 Noun
 [ edit ] 

 سُرَادِق • ( surādiq )  m ( plural سُرَادِقَات ( surādiqāt ) ) 

 awning , tent , marquee , canopy , pavilion 
 609–632 CE , Qur'an , 18:29 : إِنَّا أَعْتَدْنَا لِلظَّالِمِينَ نَارًا أَحَاطَ بِهِمْ سُرَادِقُهَا ʔinnā ʔaʕtadnā li-ẓ-ẓālimīna nāran ʔaḥāṭa bihim surādiquhā (please add an English translation of this quotation)
