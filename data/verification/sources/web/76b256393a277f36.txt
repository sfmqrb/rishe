 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( čang , “ harp ” ) , Modern Persian چنگ ( čang , “ harp ” ) , from which later borrowed again جَنْك ( jank ) , جُنْك ( junk , “ harp ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sˤand͡ʒ/ 

 Noun
 [ edit ] 

 صَنْج • ( ṣanj )  m ( plural صُنُوج ( ṣunūj ) ) 

 ( obsolete ) harp 

 cymbal
