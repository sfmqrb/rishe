 Ancient Greek

 Alternative forms
 [ edit ] 

 μαργᾰρῑ́δης ( margărī́dēs ) — Ionic 

 Etymology
 [ edit ] 

 Borrowed from Indo-Iranian . [ 1 ] According to Beekes, possibly from Proto-Iranian *mŕ̥ga-ahri-ita- ( “ oyster ” , literally “ born from the shell of a bird ” ) , [ 2 ] in which case ultimately related to *mr̥gáh ( “ bird ” ) , Avestan 𐬨𐬆𐬭𐬆𐬖𐬀 ( mər ə γa ) .

 Compare Middle Persian [script needed] ( mwlwʾlyt' /⁠morwārīd⁠/ ) (whence Persian مروارید ( marvârid ) ), Sogdian [script needed] ( marγārt ) , Sanskrit मञ्जरी ( mañjarī ) .

 [ edit ]

 Noun
 [ edit ] 

 μαργᾰρῑ́της • ( margărī́tēs )  m ( genitive μαργᾰρῑ́του ) ; first declension 

 pearl 

 a type of Egyptian plant . Further details are uncertain.
