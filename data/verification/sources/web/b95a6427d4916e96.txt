 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( kpwtl ) , 𐫐𐫁𐫇𐫤𐫡 ( kbwtr /⁠kabōtar⁠/ , “ pigeon ” ) , from Old Persian *kapautah , from Proto-Indo-Iranian *kapáwtas ( “ pigeon ” ) . Cognate with Baluchi کپوت ( kapōt ) , Sanskrit कपोत ( kapota ) . 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ka.boː.ˈtar/ , /ka.buː.ˈtar/ 

 ( Dari, formal ) IPA ( key ) : [kʰä.buː.t̪ʰáɾ] 

 ( Dari, formal ) IPA ( key ) : [kʰä.buː.t̪ʰáɾ] 
 ( Kabuli ) IPA ( key ) : [kʰä.buː.t̪ʰáɾ] , [kʰäf.t̪ʰáɾ] 

 ( Hazaragi ) IPA ( key ) : [kʰä.bu.t̪ʰáɾ] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæ.buː.t̪ʰǽɹ] 

 ( Tajik, formal ) IPA ( key ) : [kʰä.bɵ.t̪ʰáɾ] 

 Rhymes: -ar

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کَبُوتَر ( kabūtar , “ pigeon; dove ” ) .

 Adjective
 [ edit ] 

 کَبُوتَر • ( kabūtar ) ( Hindi spelling कबूतर ) 

 ( figuratively ) innocent 

 Noun
 [ edit ] 

 کَبُوتَر • ( kabūtar )  m ( Hindi spelling कबूतर ) 

 pigeon , dove 
 Synonym: کَپوت ( kapot ) 

 ( figurative ) beloved ; a young maiden
