 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( ’cltn' or ’c’l-tn' /⁠āzardan, āzārdan, āzār⁠/ , “ Torment, injure ” ) ; see آزار ( âzâr , “ trouble ” ) for more.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɒːzoɾˈdæn/ 

 Audio ( Iran ) : ( file ) 

 Verb
 [ edit ] 

 آزردن • ( âzordan ) ( present stem آزار ( âzâr ) ) 

 to annoy , to torment 

 Related terms
 [ edit ] 

 آزردگی 

 References
 [ edit ]
