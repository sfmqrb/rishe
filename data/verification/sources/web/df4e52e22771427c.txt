 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 خوشنود ( hoşnud ) 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian خشنود ( xušnūd , “ content, satisfied ” ) , from Middle Persian [script needed] ( hwšnwt' /⁠hušnūd⁠/ , “ contented, happy ” ) .

 Adjective
 [ edit ] 

 خشنود • ( hoşnud ) 

 satisfied , pleased , content , contented , in a state of satisfaction 
 Synonym: راضی ( razı ) 

 Derived terms
 [ edit ] 

 خشنود اولمق ( hoşnud olmak , “ to be pleased ” ) 
 خشنود ایتمك ( hoşnud etmek , “ to content, gratify ” ) 
 خشنودلق ( hoşnudluk , “ satisfaction, contentment ” ) 
 خشنودی ( hoşnudî , “ satisfaction, contentment ” ) 
 خشنودیت ( hoşnudiyet , “ satisfaction, contentment ” ) 

 Descendants
 [ edit ] 

 Turkish: hoşnut 

 → Armenian: խօշնիտ ( xōšnit ) , խօշնուտ ( xōšnut ) 

 → Crimean Tatar: hoşnut

 Adjective
 [ edit ] 

 خشنود • ( xušnūd / xošnud ) ( Tajik spelling хушнуд ) 

 content , satisfied 
 Synonym: راضی ( rāzī/râzi ) 
 Antonyms: ناخشنود ( nāxušnūd/nâxošnud ) , ناراضی ( nārāzī/nârâzi )
