 Alternative forms
 [ edit ] 

 کرواس ( karvâs ) , کرپاس ( karpâs ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian , from Sanskrit कर्पास ( karpāsa ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kar.ˈbaːs/ 

 ( Dari, formal ) IPA ( key ) : [kʰäɾ.bɑːs] 

 ( Dari, formal ) IPA ( key ) : [kʰäɾ.bɑːs] 
 ( Kabuli ) IPA ( key ) : [kʰäɾ.bɑːs] 

 ( Hazaragi ) IPA ( key ) : [kʰäɾ.bɔːs] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæɹ.bɒːs] 

 ( Tajik, formal ) IPA ( key ) : [kʰäɾ.bɔs]
