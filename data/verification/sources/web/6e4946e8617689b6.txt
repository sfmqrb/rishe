 English Wikipedia has an article on: pilus 

 Wikipedia 

 Etymology
 [ edit ] 

 Learned borrowing from Latin pilus ( “ hair ” ) . Doublet of pile .

 Pronunciation
 [ edit ] 

 enPR : pī ′ ləs 

 ( Received Pronunciation , General American , Canada ) IPA ( key ) : /ˈpaɪ̯.ləs/ ; ( also Received Pronunciation ) /ˈpʌɪ̯.ləs/ 

 Audio ( Southern England ) : ( file ) 

 ( Australia , New Zealand ) IPA ( key ) : /ˈpɑe̯.ləs/ 

 ( Scotland ) IPA ( key ) : /ˈpʌi̯.ləs/ , /ˈpəi̯-/ , /-lʌs/ 

 ( India ) IPA ( key ) : /ˈpəj.lus/ , /ˈpɑːj.lus/ 

 Rhymes: -aɪləs 

 Hyphenation: pi‧lus 

 Noun
 [ edit ] 

 pilus ( plural pili ) 

 ( biology ) A hair .

 ( microbiology ) A hairlike appendage found on the cell surface of many bacteria .
 Synonym: fimbria 

 ( biochemistry ) A bacterial protein that has several biochemical functions.

 Latin

 Etymology 1
 [ edit ] 

 Latin Wikipedia has an article on: pilus 

 Wikipedia la 

 Uncertain. Older sources reconstruct Proto-Indo-European *pilo- ( “ hair ” ) , with Latin pilleus ( “ felt cap ” ) , Ancient Greek πῖλος ( pîlos , “ wool or hair wrought into felt ” ) , Proto-Slavic *pь̑lstъ ( “ felt ” ) as cognates, [ 1 ] [ 2 ] but this is no longer accepted. [ 3 ] [ 4 ] [ 5 ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈpɪ.ɫʊs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈpiː.lus] 

 Hyphenation: pi‧lus 

 Noun
 [ edit ] 

 pilus   m ( genitive pilī ) ; second declension 

 ( literally , anatomy ) a hair 
 Synonym: capillus 

 ( figuratively ) an insignificant amount; iota ; least amount
