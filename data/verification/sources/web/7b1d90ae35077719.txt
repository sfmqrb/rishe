 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From the root of σκέπτομαι ( sképtomai , “ to observe ” ) + -ός ( -ós ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sko.pós/ → /skoˈpos/ → /skoˈpos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /sko.pós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /skoˈpos/ 

 ( 4 th CE Koine ) IPA ( key ) : /skoˈpos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /skoˈpos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /skoˈpos/ 

 Noun
 [ edit ] 

 σκοπός • ( skopós )  m ( genitive σκοποῦ ) ; second declension 

 watcher , lookout 
 Homeric Hymns 2. To Demeter 63: Ἠέλιον δ’ ἵκοντο θεῶν σκοπὸν ἠδὲ καὶ ἀνδρῶν Ēélion d’ híkonto theôn skopòn ēdè kaì andrôn Translation by Martin L. West They came to Helios, the watcher of gods and men 

 protector , guardian 

 spy , scout 

 mark , target 

 goal , aim

 Etymology
 [ edit ]

 Noun
 [ edit ] 

 σκοπός • ( skopós )  m ( plural σκοποί ) 

 goal ( aim, desired result ) 

 guard ( occupation ) 

 tune , melody
