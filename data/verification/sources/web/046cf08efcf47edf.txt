 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Ultimately from Old Iranian *vršna- . Cognate with Classical Syriac ܐܘܫܢܐ , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈɡuʃn/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊʃn] 

 ( Dari, formal ) IPA ( key ) : [ɡʊʃn] 
 ( Kabuli ) IPA ( key ) : [ɡʊʃn] 

 ( Hazaragi ) IPA ( key ) : [ɡuʃn] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥oʃn] 

 ( Tajik, formal ) IPA ( key ) : [ɡuʃn] 

 Rhymes: -uʃn

 Noun
 [ edit ] 

 گشن • ( gošn ) 

 ( obsolete ) male , man 
 Synonyms: مرد ( mard ) , نر ( nar ) 

 conception 
 Synonym: جنین ( janin ) 

 population 
 Synonym: مردم ( mardom ) 

 ( obsolete ) stallion 
 Synonyms: نریان ( nariyân ) , نر ( nar ) 

 Adjective
 [ edit ] 

 گشن • ( gošn ) 

 ( obsolete ) masculine , male
 Synonym: مردانه ( mardâne ) 

 fertile ; pretaining to male sexuality , vitality , and potency
