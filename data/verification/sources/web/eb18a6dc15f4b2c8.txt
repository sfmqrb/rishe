 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Traditionally related to δέρκομαι ( dérkomai , “ to see ” ) [ 1 ] with the literal meaning of “one who stares” or, alternatively, “sharp-sighted”. [ 2 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /drá.kɔːn/ → /ˈðra.kon/ → /ˈðra.kon/ 

 ( 5 th BCE Attic ) IPA ( key ) : /drá.kɔːn/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈdra.kon/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈðra.kon/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈðra.kon/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈðra.kon/ 

 Noun
 [ edit ] 

 δρᾰ́κων • ( drắkōn )  m ( genitive δρᾰ́κοντος , feminine δρᾰ́καινᾰ ) ; third declension 

 dragon ; serpent 

 serpent-shaped bracelet 

 Declension
 [ edit ] 

 Third declension of ὁ δρᾰ́κων ; τοῦ δρᾰ́κοντος ( Attic )
