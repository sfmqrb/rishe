 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian pyšk' ( pēšag , “ trade, craft; guild ” ) , from Proto-Iranian *pais- ( “ to adorn, paint, write ” ) , from Proto-Indo-European *peyḱ- ( “ to mark, paint; spot, color ” ) . [ 1 ] [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /peː.ˈʃa/ 

 ( Dari, formal ) IPA ( key ) : [pʰeː.ʃä] 

 ( Dari, formal ) IPA ( key ) : [pʰeː.ʃä] 
 ( Kabuli ) IPA ( key ) : [pʰeː.ʃä] 

 ( Hazaragi ) IPA ( key ) : [pʰeː.ʃä] 

 ( Iran, formal ) IPA ( key ) : [pʰiː.ʃe] 

 ( Tajik, formal ) IPA ( key ) : [pʰe.ʃä]

 Noun
 [ edit ] 

 پیشه • ( pēša / piše ) ( Tajik spelling пеша ) 

 skill , craft 

 trade , profession , calling 

 habit , regular practice
