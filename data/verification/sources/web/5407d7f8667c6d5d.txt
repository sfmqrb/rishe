 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( ʾyc /⁠ēč⁠/ , “ not any ” ) .

 This etymology is missing or incomplete. Please add to it, or discuss it at the Etymology scriptorium . 
Particularly: “The č is probably from Proto-Indo-European *kʷís, *kʷos ( “ who, which, what ” ) . Is the hi a phonetic shift from Proto-Indo-European *né ( “ not ” ) ?”

 Adjective
 [ edit ] 

 هیچ • ( hēč / hič ) ( Tajik spelling ҳеч ) 

 tiny , insignificant , inconsiderable 

 no 
 هیچ کس نمی‌دونست اون کجاست. ( colloquial Tehrani Persian ) hič kas nemi-dunest un kojāst. No one knew where he was.

 [ edit ] 

 هیچ • ( hēč  / hič ) ( Tajik spelling ҳеч )
