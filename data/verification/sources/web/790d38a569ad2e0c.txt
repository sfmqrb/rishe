 Crimean Tatar

 Balalaika. 
 Noun
 [ edit ] 

 балалайка ( balalayka ) 

 Cyrillic spelling of balalayka : balalaika (a Russian stringed musical instrument with a triangular body) .

 Russian
 [ edit ] 

 Парень с балалайкой 
 Etymology
 [ edit ] 

 From dialectal балаба́йка ( balabájka ) , from onomatopoeic балабай- ( balabaj- ) +‎ -ка ( -ka ) . Compare with балабо́нить ( balabónitʹ ) , балагу́рить ( balagúritʹ ) , бала́кать ( balákatʹ ) .

 [ edit ]
