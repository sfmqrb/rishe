 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کبسته ( kabasta ) , کبستو ( kabastō ) 

 Etymology
 [ edit ] 

 Unknown. Questionable if attested in the Greater Bundahishn listing a flowering plant  [Book Pahlavi needed] ( kawastīg ) . Since Spiegel , dubiously connected to the Avestan name of an infectious disease 𐬐𐬀𐬞𐬀𐬯𐬙𐬌𐬱 ( kapastiš ) (which Latin pestis ( “ plague, pestilence ” ) has also been connected to), owing to the Persian term’s dictionary gloss “deadly poison”. Reasonably, though this was before it was demonstrated that Armenian is no Iranian language, Lagarde deemed either term suffixed from a stem surfacing as Old Armenian կապեմ ( kapem , “ to bind ” ) , by reason that the colocynth, like all cucurbitaceous plants, is creeping.
