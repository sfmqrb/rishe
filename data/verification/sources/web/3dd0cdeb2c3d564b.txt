 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( ptwstn' /⁠paywastan⁠/ ) , [Book Pahlavi needed] ( ptwnd- /⁠paywand-⁠/ , “ to join, to connect ” ) , from Proto-Iranian *pati- + *bándati ( “ to bind ” ) ; see بستن ( bastan ) for the latter element.

 پیوستن • ( peyvastan ) ( present stem پیوند ( peyvand ) ) 

 to join ; to unite with
 به دشمن پیوسته‌اند. be došman peyvaste-and . They have joined the enemy.
