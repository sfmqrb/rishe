 Etymology
 [ edit ] 

 Borrowed from French aorte , from Ancient Greek ἀορτή ( aortḗ ) .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.ʔóɹt̪ʰ] 

 Readings

 Iranian reading ? 

 â'ort

 Rhymes: -urt 

 Noun
 [ edit ] 

 آئورت • ( â'ort ) ( Tajik spelling оурт , or аорта ) 

 ( anatomy ) aorta ( great artery )
