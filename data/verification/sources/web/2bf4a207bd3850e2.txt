 Persian

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /si.ˈpihr/ 

 ( Dari, formal ) IPA ( key ) : [sɪ.pʰɪ́ɦɾ] 

 ( Dari, formal ) IPA ( key ) : [sɪ.pʰɪ́ɦɾ] 
 ( Kabuli ) IPA ( key ) : [sɪ.pʰɪ́ɾ] 

 ( Hazaragi ) IPA ( key ) : [si.pʰíɾ] 

 ( Iran, formal ) IPA ( key ) : [se.pʰéɦɹ]

 Rhymes: -ihr

 Etymology 1
 [ edit ] 

 Inherited from Middle Persian [script needed] ( spyhl ) , [script needed] ( spyyhl ) , 𐫙𐫘𐫛𐫏𐫡 ( ʿspyr /⁠spihr⁠/ , “ sphere, sky ” ) , from Old Persian *spiθrah .

 Noun
 [ edit ] 

 سپهر • ( sipihr / sepehr ) ( Tajik spelling сипеҳр ) 

 ( literary ) sky , heaven 
 Synonym: آسمان ( āsmān, āsimān ) 

 Proper noun
 [ edit ] 

 سپهر • ( sipihr  / sepehr ) ( Tajik spelling Сипеҳр ) 

 a male given name from Middle Persian 

 Derived terms
 [ edit ] 

 سپهری ( sipihri ) 

 سپهرداد ( sipihrdād ) 

 Descendants
 [ edit ] 

 Tajik: сипеҳр ( sipehr ) 

 → Hindustani: 
 Hindi: सिपिह्र ( sipihr ) , सिपिहर ( sipihar ) , सिपेह्र ( sipehr ) , सिपेहर ( sipehar ) 
 Urdu: سِپِہْر ( sipihr ) 

 Etymology 2
 [ edit ] 

 Phono-semantic matching of French sphère and/or English sphere , from Ancient Greek σφαῖρα ( sphaîra ) , which is not originally related to etymology 1 above. ( Can this ( + ) etymology be sourced ?) 

 Noun
 [ edit ] 

 سپهر • ( sipihr / sepehr ) ( Tajik spelling сипеҳр ) 

 ( physics , in compounds ) sphere (as in stratosphere )
