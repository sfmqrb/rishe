 Arabic

 Etymology
 [ edit ] 

 Derived from the verbal noun of خَسَفَ ( ḵasafa ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /xu.suːf/ 

 Noun
 [ edit ] 

 خُسُوف • ( ḵusūf )  m 

 ( astronomy ) lunar eclipse
