 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Of uncertain origin.

 Traditionally taken as a poetic compound, from Proto-Indo-European *neḱ- ( “ to perish; to disappear ” ) + *-tr̥h₂ ( “ overcoming ” ) , from *terh₂- ( “ to overcome; to pass through; to cross over ” ) ; thus, literally, “ overcoming death ” , so-called because it purportedly granted immortality.

 However, other theories involving a non-Indo-European borrowing have been proposed. Furnée compares νῑκᾰ́ρῐον ( nīkắrĭon , “ eye salve ” ) , suggesting a possible Pre-Greek origin for both, while Griffith and Levin have suggested borrowings from Egyptian and Semitic, respectively. Beekes appears to be split between the Indo-European and Pre-Greek theories, while expressing skepticism about the Afro-Asiatic proposals. [ 1 ]

 [ edit ] 

 νέκτᾰρ • ( néktăr )  n ( genitive νέκτᾰρος ) ; third declension 

 nectar ( the drink of the gods ) 
 Coordinate term: ᾰ̓μβροσῐ́ᾱ ( ămbrosĭ́ā )

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek νέκταρ ( néktar ) .

 Noun
 [ edit ] 

 νέκταρ • ( néktar )  n ( uncountable ) 

 ( Greek mythology ) nectar ( the drink of the gods ) 

 ( by extension ) an especially delicious drink
