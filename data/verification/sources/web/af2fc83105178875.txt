 Central Kurdish
 [ edit ] 

 Alternative forms
 [ edit ] 

 ئەستاندن ( estandin ) , ساندن ( sandin ) , سەندن ( sendin ) 

 Etymology
 [ edit ] 

 From Proto-Iranian *staHn- ( “ to take ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /staːndən/ 

 Verb
 [ edit ] 

 Northern Kurdish

 standin 

 Central Kurdish

 ستاندن ( standin ) 

 ستاندن ( standin ) ( present stem ستێن- ( stên- ) ) 

 ( transitive ) to take , obtain 
 Synonym: وەرگرتن ( wergirtin ) 

 ( transitive ) to buy 
 Synonym: کڕین ( kirrîn )
