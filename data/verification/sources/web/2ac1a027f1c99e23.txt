 Etymology
 [ edit ] 

 Extension of *bʰer- ( “ to boil ” ) . [ 1 ] 

 Root
 [ edit ] 

 *bʰrewh₁- [ 2 ] [ 3 ] [ 4 ] 

 to boil 

 to brew 

 Alternative reconstructions
 [ edit ] 

 *bʰrew- [ 2 ] 

 *bʰerw- [ 5 ] ( this root structure is probably not possible [ 6 ] )
