 Alternative forms
 [ edit ] 

 گشتاسب ( goštâsb ) , گشتاسف ( goštâsf ) , بشتاسب ( beštâsb ) , بشتاسف ( beštâsf ) , وشتاسب ( veštâsb ) , وشتاسف ( veštâsf ) , گشاسب ( gošâsb ) , گشسب ( gošasb ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭢𐭥𐭱𐭲𐭮𐭯 ( gwštsp /⁠guštāsp⁠/ ) , from Old Persian 𐎻𐏁𐎫𐎠𐎿𐎱 ( vi-š-t-a-s-p /⁠vištāspaʰ⁠/ ) , borrowed from Avestan 𐬬𐬌𐬱𐬙𐬁𐬯𐬞𐬀 ( vištāspa ) .
