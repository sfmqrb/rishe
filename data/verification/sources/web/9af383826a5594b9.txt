 See also: كاش , گاش , كأس , and کاس 

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کاچ ( kâč ) 

 Etymology 1
 [ edit ] 

 Likely borrowed from a Indo-Aryan language; probably from Hindustani (see Hindi काँच ( kā̃c ) / Urdu کان٘چ ( kā̃c ) ), ultimately from Sanskrit काच ( kāca ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈkaːʃ/ 

 ( Dari, formal ) IPA ( key ) : [kʰɑːʃ] 

 ( Dari, formal ) IPA ( key ) : [kʰɑːʃ] 
 ( Kabuli ) IPA ( key ) : [kʰɑːʃ] 

 ( Hazaragi ) IPA ( key ) : [kʰɔːʃ] 

 ( Iran, formal ) IPA ( key ) : [kʰɒːʃ] 

 ( Tajik, formal ) IPA ( key ) : [kʰɔʃ] 

 Rhymes: -aːʃ

 Noun
 [ edit ] 

 کاش • ( kāš / kâš ) 

 ( obsolete ) glass 

 Etymology 2
 [ edit ] 

 Inherited from Middle Persian kʾc ( kāč ) .
