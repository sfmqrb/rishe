 Ottoman Turkish
 [ edit ] 

 Alternative forms
 [ edit ] 

 جارو ( caru ) , چاروب ( çarub ) 

 Etymology
 [ edit ] 

 Borrowed from Persian جَارُوب ( “ broom ” ) , from the combination of Middle Persian gywʼk' ( gyāg , “ place ” ) + lwp- ( rōb , “ rub, sweep ” ) .

 Noun
 [ edit ] 

 جاروب • ( carub ) ( definite accusative جاروبی ( carubu ) , plural جاروبلر ( carublar ) ) 

 broom 
 Synonyms: سوپوركه ( süpürge ) , مكنسه ( miknese ) 

 Derived terms
 [ edit ] 

 جاروب زن ( carub zen , “ sweeper ” ) 
 جاروب كش ( carub keş , “ sweeper ” )

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 جارو ( jâru ) 

 Etymology
 [ edit ] 

 Middle Persian [Book Pahlavi needed] ( gywʼk'-rōb /⁠gyāg-rōb⁠/ , “ broom ” ) . By surface analysis , جا ( jâ , “ place ” ) +‎ روب ( rub , present stem of روبیدن ( rubidan , “ to sweep ” ) ) . Unrelated to Hindi झाड़ू ( jhāṛū ) / Urdu جھاڑُو ( jhāṛū ) .

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [d͡ʒɑː.ɾúːb] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒɑː.ɾúːb]
