 Alternative forms

 Etymology
 [ edit ] 

 From Hindi सितार ( sitār ) / Urdu ستار ( sitār ) , from Classical Persian سه‌تار ( si-tār , literally “ three strings ” ) . [ 1 ] [ 2 ] Doublet of setar .

 Pronunciation
 [ edit ] 

 ( General American ) IPA ( key ) : /ˈsɪtɑɹ/ , /sɪˈtɑɹ/ 

 Audio ( US ) : ( file ) 

 Rhymes: -ɑː(ɹ) 

 Noun
 [ edit ] 

 sitar ( plural sitars ) 

 ( music ) A Hindustani / Indian classical stringed instrument , typically having a gourd as its resonating chamber .
