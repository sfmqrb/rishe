 Alternative forms
 [ edit ] 

 گامیش ( gâmiš ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( TWRAmyš /⁠gāw-mēš⁠/ , literally “ cow-sheep ” ) ; compare Persian گاو ( gâv , “ cow ” ) and میش ( miš , “ ewe ” ) for the constituents. Old Armenian գոմէշ ( gomēš ) , Classical Syriac ܓܡܘܫܐ ( gāmōšā ) and Old Georgian კამბეჩი ( ḳambeči ) are borrowed from Middle Iranian languages.
