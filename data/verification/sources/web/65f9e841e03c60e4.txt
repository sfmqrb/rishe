 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ɣiʃ.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ɣɪʃ.t̪ʰän]

 ( Kabuli ) IPA ( key ) : [ʔɑː.ɣɪʃ.t̪ʰän] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.ɣiʃ.t̪ʰän] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.ɢeʃ.t̪ʰæn]

 Verb
 [ edit ] 

 آغشتن • ( âġeštan ) ( present stem آغار ( âġâr ) ) 

 ( transitive ) to soak , steep 

 to infuse 

 to imbrue 

 to smear 

 to indoctrinate 

 to inoculate 

 to saturate 

 to impregnate 
 Synonym: گشنیدن
