 Etymology
 [ edit ] 

 From Middle Persian 𐭣𐭱𐭰𐭪 ( dwšyck' /⁠dōšīzag⁠/ ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /doː.ʃiː.ˈza/ 

 ( Dari, formal ) IPA ( key ) : [d̪oː.ʃiː.zä] 

 ( Dari, formal ) IPA ( key ) : [d̪oː.ʃiː.zä] 
 ( Kabuli ) IPA ( key ) : [d̪oː.ʃiː.zä] 

 ( Hazaragi ) IPA ( key ) : [d̪u.ʃi.zä] 

 ( Iran, formal ) IPA ( key ) : [d̪uː.ʃiː.ze] 

 ( Tajik, formal ) IPA ( key ) : [d̪ɵ.ʃi.zä] 

 Rhymes: -a

 Noun
 [ edit ] 

 دوشیزه • ( dōšīza / dušize ) ( Tajik spelling дӯшиза ) 

 virgin 

 girl , damsel , maiden
