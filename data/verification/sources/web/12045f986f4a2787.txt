 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic وُضُوء ( wuḍūʔ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /wu.ˈðuː/ , /wu.ˈzuː/ 

 ( Dari, formal ) IPA ( key ) : [wä.zúː] 

 ( Dari, formal ) IPA ( key ) : [wä.zúː] 
 ( Kabuli ) IPA ( key ) : [wä.zúː] 

 ( Hazaragi ) IPA ( key ) : [wä.zú] 

 ( Iran, formal ) IPA ( key ) : [vo.zúː] 

 ( Tajik, formal ) IPA ( key ) : [vu.zɵ́] 

 Rhymes: -uː 

 Readings

 Noun
 [ edit ] 

 وضو • ( wazū / vozu ) ( Tajik spelling вузӯ ) 

 ( Islam ) wudu ( a ritual washing of the forearms , head , and feet , required after minor impurity , frequently performed immediately before prayer )
