 Alternative forms
 [ edit ] 

 ریباس ( rēbās  / ribâs ) , ریواج ( rēwāj  / rivâj ) , ریباج ( rēbāj  / ribâj ) , ریویج ( rēwēj  / rivij ) , ریویز ( rēwēz  / riviz ) , ریوا ( rēwā  / rivâ ) , ریونج ( rēwanj  / rivanj ) 

 رواش ( rawāš ) ( Dari ) 

 ریواش ( rēwāš  / rivâš ) , لواس ( lawās  / lavâs ) ( dialectal ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( lypʾs /⁠rēbās⁠/ , “ rhubarb ” ) , from Middle Persian [Book Pahlavi needed] ( lypʾs /⁠rēbās, rēbāh⁠/ ) , ultimately from Proto-Iranian *(h)rabā́š ~ *(h)rabacáh .

 Noun
 [ edit ] 

 ریواس • ( rēwās / rivâs ) ( Tajik spelling ревос ) 

 rhubarb 
 Synonym: چکری ( čukrī  / čokri )
