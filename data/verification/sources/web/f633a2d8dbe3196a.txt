 Old Armenian
 [ edit ] 

 Alternative forms
 [ edit ] 

 աշտէ ( aštē ) , աշտէն ( aštēn ) ( post-Classical ) 

 Etymology
 [ edit ] 

 An Iranian borrowing: compare Old Persian 𐎠𐎼𐏁𐎫𐎡𐏁 ( a-r-š-t-i-š /⁠r̥štiš⁠/ , “ spear ” ) , Avestan 𐬀𐬭𐬱𐬙𐬌 ( aršti , “ spear, lance ” ) , Sanskrit ऋष्टि ( ṛṣṭí , “ spear, lance ” ) , and more distantly Persian خشت ( xešt , “ javelin, dart, spear ” ) , Northern Kurdish ئەرش ( erş , “ spear, lance ” ) , ھەش ( heş , “ javelin ” ) . Also from Iranian: Avar гӏащтӏи ( ʻašštʼi ) .

 Noun
 [ edit ] 

 աշտեայ • ( ašteay ) 

 short javelin for throwing from a distance, a dart
