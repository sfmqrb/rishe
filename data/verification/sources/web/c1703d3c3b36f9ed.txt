 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian pwtk' ( pūdag , “ foul, rotten ” ) . Akin to Old Armenian փուտ ( pʻut ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /puːˈdæ/ 

 ( Iran ) IPA ( key ) : [pʰuːˈde] 

 Adjective
 [ edit ] 

 پوده • ( pude ) 

 rubbed , worn ; fallen to pieces

 foul , rotten 

 empty , hollow 

 References
 [ edit ]
