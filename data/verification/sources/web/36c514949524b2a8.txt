 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کیک ( kik ) 

 Etymology
 [ edit ] 

 Akin to Gilaki کاکا ( káká , “ a kind of cookie ” ) , Kurdish , Arabic كعك ( kaʕk ) , and Classical Syriac ܟܥܟܐ ( kaʿkā ) .

 Pronunciation
 [ edit ] 

 ( Iran ) IPA ( key ) : [kʰɒːkʰ] 

 Noun
 [ edit ] 

 کاک • ( kâk ) ( plural کاک‌ها ) 

 a kind of layered pastry 

 ( archaic ) a kind of bread 

 ( archaic ) dry bread
 Synonym: نان خشک ( nân-e xošk ) 

 ( archaic , anatomy ) pupil 
 Synonyms: مردمک ( mardomak ) , گوهرک ( gowharak ) , حدقه ( hadaqe ) , انگورک ( angurak ) 

 ( archaic ) full moon 
 Synonym: قرص ماه ( qors-e mâh ) 

 Descendants
 [ edit ] 

 → Middle Armenian: քաք ( kʻakʻ ) 

 → Ottoman Turkish: كاك ( kāk ) 

 References
 [ edit ] 

 Dehkhoda, Ali-Akbar ( 1931– ), “ کاک ”, in Dehkhoda Dictionary Institute , editors, Dehkhoda Dictionary (in Persian), Tehran: University of Tehran Press .
