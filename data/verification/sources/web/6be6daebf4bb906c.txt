 Etymology
 [ edit ] 

 Borrowed from Proto-Iranian *Hángwr̥ ( “ extract, resin ” ) , with an unexpected shift from *a to i , from the derivation *Hanguǰatu of which Iranian terms for asafoetida derive.

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɦiŋ.ɡú/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɦiŋ.ɡu/ 

 Noun
 [ edit ] 

 हि॒ङ्गु • ( hiṅgú ) stem ,  m [ 1 ] 

 asafoetida ( Ferula assa-foetida )
 c. 700 CE – 900 CE , Bhāgavata Purāṇa 

 a kind of liquid made from the roots of asafoetida
