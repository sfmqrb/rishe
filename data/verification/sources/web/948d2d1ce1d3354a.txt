 Alternative forms

 افتو ( aftow ) ( dialectal , Khesht , Konartakhteh , Dashtestan , southwestern Fars ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐭠𐭯𐭲𐭠𐭡 ( ʾptʾb /⁠āftāb⁠/ , “ sunshine ” ) (compare 𐮀𐮎𐮃𐮀𐮁 ( ʾpdʾb /⁠ābdāb⁠/ ) ), from Proto-Iranian *abi-tāpáh [ 1 ] Equivalent to آف ( âf ) +‎ تاب ( tâb ) .

 Iranian Persian

 آفتاب • ( âftâb ) 

 sunlight , sunshine 
 Coordinate term: مهتاب ( mahtâb , “ moonlight ” ) 

 sun 
 Synonym: خورشید ( xoršid ) 
 Coordinate term: ماه ( mâh , “ moon ” ) 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 3779: از ره پنهان که دور از حس ماست
آفتاب چرخ را بس راههاست az rah-i pinhān ki dūr az hiss-i mā-st
 āftāb -i čarx rā bas rāh-hā-st By the hidden way that is remote from our sense-perception.
The sun in heaven hath many ways

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian آفْتَاب ( āftāb ) . First attested in c. 1635 as Middle Hindi آفتاب ( āftab /⁠ãftāb⁠/ ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɑːf.t̪ɑːb/ 

 Rhymes: -ɑːb 

 Hyphenation: آف‧تاب 

 Noun
 [ edit ] 

 آفْتاب • ( āftāb )  m ( Hindi spelling आफ़ताब ) ( chiefly literary or poetic ) 

 Sun 
 Synonyms: سُورَج ( sūraj ) , شَمْس ( śams ) , خورْشِید ( xorśīd ) , سُورِیَہ ( sūriya ) 

 sunshine ; sunlight 
 Synonym: دُھوپ ( dhūp ) 

 ( obsolete ) wine ; goblet 

 ( figuratively , poetic ) beauty
