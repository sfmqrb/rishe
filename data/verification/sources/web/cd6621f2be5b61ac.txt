 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic مَأْمُور ( maʔmūr , “ officer; magistrate ” ) . 

 Noun
 [ edit ] 

 مأمور • ( meʼmur ) ( plural مأمورین ( me'murin ) ) 

 officer , official , agent , somebody charged with an office 

 Derived terms
 [ edit ] 

 ضبطیه مأموری ( zabtiye meʼmuru , “ any official of the police department ” ) 
 مأموریت ( meʼmuriyet , “ official duty, charge ” ) 
 پولیتیقه مأموری ( politika meʼmuru , “ political agent ” )

 Noun
 [ edit ] 

 مأمور • ( ma'mūr / ma'mur ) ( plural مأموران ( ma'mūrān / ma'murân ) , or مأمورین , Tajik spelling маъмур ) 

 official , officer , delegate , functionary , agent 
 مأمور مخفی ― ma'mur -e maxfi ― undercover agent 
 مأموران وزارت اطلاعات ma'murân -e vezârat-e ettelâ'ât agents of the Ministry of Intelligence 

 Adjective
 [ edit ] 

 مأمور • ( ma'mūr / ma'mur ) ( Tajik spelling маъмур ) 

 ordered , commanded , commissioned , appointed
