 Alternative forms

 روبَهْ ( rōbah  / rubah ) ( poetic ) 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( lwpʾh /⁠rōbāh⁠/ , “ fox ” ) , from Old Persian *raupāθah ( “ fox ” ) , from Proto-Iranian *Hrawpācáh . Cognate with Baluchi روپاسک ( ròpàsk ) .

 Noun
 [ edit ] 

 روباه • ( rōbāh / rubâh ) ( plural روباهان ( rōbāhān / rubâhân ) , or روباه‌ها ( rōbāh-hā / rubâh-hâ ) , Tajik spelling рӯбоҳ ) 

 fox 

 ( figurative ) fox ; cunning and sly person
 من عمراً به این روباهِ پیر اعتماد نمی‌کنم! man 'umran ba ēn rōbāh -i pīr i'timād ni-mē-kunam! I absolutely won't trust this old fox ! 

 ( Should we delete ( + ) this sense?) ( figurative , derogatory ) The British Empire , the United Kingdom , or England 
 انگلیس یه روباه حقّه‌بازه! ingilīs-yi rōbāh -i huqqa-bāza! England ( UK ) is a sly fox !
