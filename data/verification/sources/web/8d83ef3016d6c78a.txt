 Noun
 [ edit ] 

 گل • ( gul / gol ) ( plural گل‌ها ( gul-hā / gol-hâ ) , Tajik spelling гул ) 

 flower 

 ( archaic , literary ) rose 
 Synonyms: گل سرخ ( gul-i surx  / gol-e sorx ) , رز ( ruz  / roz ) 
 940-1020 , فردوسی [ firdawsī ], شهنامه [ šahnāma ]: زن شیر از آن نامه شهریار 
 چو رخشنده گل شد به وقت بهار zan-i šēr az ān nāma-yi šahryār 
 čū raxšanda- gul šud ba waqt-i bahār (please add an English translation of this quotation) (Classical Persian transliteration) 

 1325-1389 , حافظ [ hāfiz ], دیوان حافظ [ dēwān-i hāfiz ]: صبحدم مرغ چمن با گل نوخاسته گفت 
 ناز کم کن که در این باغ بسی چون تو شکفت subhdam murġ-i čaman bā gul-i nawxāsta guft 
 nāz kam kun ki dar īn bāġ basē čūn tū šukuft (please add an English translation of this quotation) (Classical Persian transliteration) 

 the core of a watermelon ( the sweetest part ) 

 ( slang ) cannabis , marijuana 
 Synonym: بنگ ( bang )
