 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( tnwk' /⁠tanuk⁠/ , “ thin, shallow ” ) , from Proto-Iranian *tanúkakah , from Proto-Indo-European *tn̥h₂ukos ~ ténh₂ukos ( “ thin ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ta.ˈnuk/ , /tu.ˈnuk/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊ.nʊk] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊ.nʊk] 
 ( Kabuli ) IPA ( key ) : [t̪ʰʊ.nʊk] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰu.nuk] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰo.nokʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [t̪ʰu.nuk] 

 Rhymes: -uk 

 Readings

 Classical reading ? 

 tanuk, tunuk

 Dari reading ? 

 tunuk

 Iranian reading ? 

 tonok

 Tajik reading ? 

 tunuk

 Adjective
 [ edit ] 

 تنک • ( tonok ) 

 thin 

 sparse , porous (not- dense )

 Derived terms
 [ edit ] 

 تنکه ( toneke , “ underwear ” ) 

 تنک‌بیز ( tanuk-bēz ) , also تنگ‌بیز ( tang-bēz , “ sieve ” ) 

 تنک‌ظرف ( tanuk-zarf , “ dimwit; tattler ” ) 

 Related terms
 [ edit ] 

 تنگ ( tang , “ narrow ” ) 

 Antonym 

 چگال (dense)

 ستبر (thick)
