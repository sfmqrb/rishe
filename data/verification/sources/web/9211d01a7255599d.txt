 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit श्वि॒त्र ( śvitrá ) . Related to Classical Persian سِپِهْر ( sipihr ) and English white . Doublet of चिट्टी ( ciṭṭī ) and सिपिह्र ( sipihr ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ʃʋɪt̪.ɾᵊ/ 

 Rhymes: -ɪt̪ɾ 

 Noun
 [ edit ] 

 श्वित्र • ( śvitra )  m 

 ( dermatology ) vitiligo , leucoderma 
 Synonyms: धवल रोग ( dhaval rog ) , श्वेत कुष्ट ( śvet kuṣṭ ) , सफ़ेद दाग़ ( safed dāġ )

 Etymology
 [ edit ] 

 Inherited from Proto-Indo-Aryan *świtrás , from Proto-Indo-Iranian *ćwitrás , from Proto-Indo-European *ḱwitrós . Doublet of सीस ( sīsa ) , an Old Persian borrowing.

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɕʋit.ɾɐ́/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɕʋit̪.ɾɐ/ 

 Noun
 [ edit ] 

 श्वि॒त्र • ( śvitrá ) stem ,  m 

 leprosy 

 white leprosy 

 ( dermatology ) vitiligo , leucoderma
