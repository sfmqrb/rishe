 Etymology
 [ edit ] 

 Inherited from Middle Persian pwst' ( pōst , “ skin, hide, shell ” ) , from Old Persian 𐎱𐎺𐎿𐎫𐎠 ( pavastā ) , ultimately from Proto-Indo-Iranian *pawástam ( “ covering, envelope ” ) .
See also Sanskrit पुस्तक ( pustaka ) .

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian پوسْت ( pōst , “ skin, hide, rind, shell, cover, poppy-head ” ) , from Old Persian 𐎱𐎠𐎺𐎿𐎫𐎠 ( p-a-v-s-t-a /⁠pavastā⁠/ ) , ultimately from Proto-Indo-Iranian *pawástam ( “ covering, envelope ” ) . Cognate to Gujarati પોસ ( pos ) . See also Sanskrit पुस्तक ( pustaka ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /poːst̪/ 

 Noun
 [ edit ] 

 پوسْت • ( post )  m ( Hindi spelling पोस्त ) 

 skin ; hide 

 crust , bark ; layer 

 shell ; rind , peel 

 Derived terms
 [ edit ] 

 پوست بَرْ پوست ( pōst-bar-pōst , “ layer upon layer ” , adverb ) 
 پوست پَرَست ( pōst-parast , “ superficial-minded person ” ) 
 پوست کُن ( pōst-kun , “ flayer ” ) 
 پوسْتِین ( pōstīn , “ leather ” ) 
 پوسْتِین دوز ( pōstīn-dōz , “ furrier ” ) 
 گوشْت پوسْت ( gōšt-pōst , “ flesh and skin ” )
