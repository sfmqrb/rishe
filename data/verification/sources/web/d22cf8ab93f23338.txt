 Arabic
 [ edit ] 

 Etymology 1.1
 [ edit ] 

 Root 

 د ء ب ( d ʔ b ) 

 3 terms 

 Probably back-formed singular from آدَاب ( ʔādāb ) , a plural of the verbal noun دَأْب ( daʔb ) , 
“persistence, perseverance”. (For the plural type, compare آبَار ( ʔābār , “ wells ” ) , آثَار ( ʔāṯār , “ revenges, retaliations ” ) , آرَاء ( ʔārāʔ , “ views, opinions ” ) .

 Various influences from Iranian at least for semantics are often claimed, surely inspired by some general idea of Abbasid cultural supremacy, and present Iranian patriotism hurt by the pervasiveness of Arabic-origin words in the Persian tongue.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔa.dab/ 

 Noun
 [ edit ] 

 أَدَب • ( ʔadab )  m ( plural آدَاب ( ʔādāb ) ) 

 discipline 

 courtesy , etiquette 
 8th century, Ibn al-Muqaffaʿ : الآداب الكبير Al-ʔādāb al-kabīr [A book on] Persian etiquette 

 civility 

 literature , belles-lettres 
 10th century , Al-Mutanabbi : أَنَا الَّذِي نَظَرَ الْأَعْمَى إِلَى أَدَبِي / وَأَسْمَعَتْ كَلِمَاتِي مَنْ بِهِ صَمَمُ ʔanā llaḏī naẓara l-ʔaʕmā ʔilā ʔadabī / waʔasmaʕat kalimātī man bihi ṣamamu I am the one whose literature can be seen (even) by the blind / And whose words are heard (even) by the deaf. 

 politeness 

 decency 

 culture

 Verb
 [ edit ] 

 أدب ( form I ) 

 أَدِبُّ ( ʔadibbu ) /ʔa.dib.bu/ : first-person singular non-past active indicative of دَبَّ ( dabba ) 

 أَدِبَّ ( ʔadibba ) /ʔa.dib.ba/ : first-person singular non-past active subjunctive / jussive of دَبَّ ( dabba ) 

 أَدِبِّ ( ʔadibbi ) /ʔa.dib.bi/ : first-person singular non-past active jussive of دَبَّ ( dabba )
