 Verb
 [ edit ] 

 دَاوَرَ • ( dāwara ) III ( non-past يُدَاوِرُ ( yudāwiru ) , verbal noun مُدَاوَرَة ( mudāwara ) or دِوَار ( diwār ) ) 

 to walk around with (someone)

 to ensnare , inveigle 

 to cheat , deceive , trick 

 to try to ensnare , deceive

 Alternative forms
 [ edit ] 

 دادور ( dâdvar ) 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( dʾtwbl /⁠dādwar⁠/ , “ judge ” ) . By surface analysis , داد ( dâd , “ justice ” ) +‎ ـور ( -var ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /daː.ˈwar/ 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.wáɾ] 

 ( Dari, formal ) IPA ( key ) : [d̪ɑː.wáɾ] 
 ( Kabuli ) IPA ( key ) : [d̪ɑː.wáɾ] 

 ( Hazaragi ) IPA ( key ) : [d̪ɔː.wáɾ] 

 ( Iran, formal ) IPA ( key ) : [d̪ɒː.vǽɹ] 

 ( Tajik, formal ) IPA ( key ) : [d̪ɔ.váɾ] 

 Rhymes: -ar 

 Readings

 Classical reading ? 

 dāwar

 Dari reading ? 

 dāwar

 Iranian reading ? 

 dâvar

 Tajik reading ? 

 dovar

 Noun
 [ edit ] 

 داور • ( dâvar ) ( plural داوران , or داورها ) 

 ( sports ) referee , ref 

 ( archaic ) judge 
 Synonym: قاضی ( qâzi ) 

 Derived terms
 [ edit ] 

 داوری ( dâvari )
