 [ edit ] 

 From م ي ل ( m y l ) , meaning to incline, to bend, to lean.

 Verb
 [ edit ] 

 مَيَّلَ • ( mayyala ) II ( non-past يُمَيِّلُ ( yumayyilu ) , verbal noun تَمْيِيل ( tamyīl ) ) 

 ( transitive ) to bend , to tilt 

 to make (someone) inclined or sympathetic [ with accusative ‘someone’ , along with نَحْوَ ( naḥwa ) or إِلَى ( ʔilā ) ‘towards someone/something’ ]

 to make (someone) disinclined , to alienate [ with accusative ‘someone’ and عَنْ ( ʕan ) ‘towards/from someone/something’ ]

 Etymology 2
 [ edit ] 

 From Latin mīlle passuum ( literally “ a thousand of paces ” ) ; compare Classical Syriac ܡܝܠܐ ( mīlā ) and Hebrew מַיְל ( mayl ) .
The reach of an eye originates from a folk etymology explaining the distance of a mile, literally the distance to which the eye reaches along land before the horizon curves out of sight.

 Noun
 [ edit ] 

 مِيل • ( mīl )  m ( plural أَمْيَال ( ʔamyāl ) or مُيُول ( muyūl ) ) 

 reach of the eye , as far as one can see

 mile 

 milestone , column , obelisk , boundary stone 

 hand of a sundial

 Etymology 3
 [ edit ] 

 From Ancient Greek μήλη ( mḗlē , “ probe ” ) .

 Noun
 [ edit ] 

 مَيْل • ( mayl )  m ( plural مُيُول ( muyūl ) ) ( obsolete ) 

 a kind of metal probe in form of a needle for applying collyrium or other treatments
