 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 چکاده ( čakâde, čekâde ) 

 چکاذ ( čakâz ) 

 Etymology
 [ edit ] 

 Akin to Old Armenian ճակատ ( čakat , “ forehead ” ) , an Iranian borrowing. Note also Lithuanian kaktà ( “ forehead, brow ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian , Dari ) IPA ( key ) : [tʃæˈkɒːd] 

 ( Iran ) IPA ( key ) : [tʃeˈkɒːd] 

 Noun
 [ edit ] 

 چکاد • ( čakâd, čekâd ) 

 top , crown of the head

 summit of a mountain

 top of the forehead 

 shield 

 References
 [ edit ] 

 Steingass, Francis Joseph ( 1892 ), “ چکاد ”, in A Comprehensive Persian–English dictionary (overall work in English), London: Routledge & K. Paul
