 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit दस्यु ( dasyu ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /d̪əs.juː/ , [d̪ɐs.juː] 

 Noun
 [ edit ] 

 दस्यु • ( dasyu )  m 

 bandit , dacoit , outlaw 
 Synonym: डाकू ( ḍākū ) 

 barbarian

 Etymology
 [ edit ] 

 Inherited from Proto-Indo-Iranian *dásyuš ( “ enemy, foreigner, foreign people, foreign land ” ) , [ 1 ] from Proto-Indo-European *des- ( “ enemy, foreigner ” ) . [ 2 ] See दास ( dā́sa , “ demon, slave, foreigner ” ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /dɐ́s.ju/ 

 ( Classical Sanskrit ) IPA ( key ) : /d̪ɐs̪.ju/ 

 Noun
 [ edit ] 

 दस्यु॑ • ( dásyu ) stem ,  m 

 impious man

 barbarian
