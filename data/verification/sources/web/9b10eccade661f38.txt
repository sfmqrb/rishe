 Arabic
 [ edit ] 

 سُور 
 Etymology 1
 [ edit ] 

 Argued to be a loan from Aramaic שׂוּרָא / ܫܘܪܐ ( šūrā ) , but other cognates such as Sabaean 𐩣𐩬𐩪𐩥𐩧𐩩 ( mns¹wrt , “ walls ” ) and Tigre ሶር ( sor , “ partition wall ” ) (unless that form is itself borrowed from Arabic) suggest that it may in fact be inherited.

 Noun
 [ edit ] 

 سُور • ( sūr )  m ( plural أَسْوَار ( ʔaswār ) or سِيرَان ( sīrān ) ) 

 wall that encloses and protects a building
 سُورُ ٱلصِّينِ ٱلْعَظِيمُ sūru ṣ-ṣīni l-ʕaẓīmu Great Wall of China

 Etymology 2
 [ edit ] 

 Noun
 [ edit ] 

 سُوَر • ( suwar )  f   pl 

 plural of سُورَة ( sūra ) 

 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Arabic سُور ( sūr , “ wall ” ) , argued to be a loan from Aramaic שׂוּרָא ( šūrā , “ wall, fortification ” ) .

 Noun
 [ edit ] 

 سور • ( sur ) ( definite accusative سوری ( surı ) , plural اسوار ( esvar ) or سیران ( sirân ) ) 

 wall , any structure built with stones , earth etc. built for defensive purposes, surrounding a place
 Synonym: دیوار ( duvar ) 

 Descendants
 [ edit ] 

 Turkish: sur

 Etymology 2
 [ edit ] 

 Borrowed from Persian سور ( sur , “ nuptials ” ) , from Old Persian *θūryas ( “ banquet, feast ” ) .

 Noun
 [ edit ] 

 سور • ( sur ) 

 wedding , nuptials , the ceremony that marks the beginning of a marriage 
 Synonyms: دوگون ( düğün ) , عرس ( ʼurs ) 

 Descendants
 [ edit ] 

 Turkish: sur

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Old Persian *θūryas ( “ banquet, feast ” ) , from Proto-Iranian *cuHryás , from Proto-Indo-Iranian *ćuHryás , from Proto-Indo-European *ḱewH- ( “ to shine ” ) , see also Sanskrit श्वस् ( śvas , “ tomorrow ” ) . [ 1 ] [ 2 ] Possibly further related to Northern Kurdish sor ( “ red ” ) .

 Noun
 [ edit ] 

 سور • ( sur ) 

 nuptials 

 banquet , feast , entertainment
