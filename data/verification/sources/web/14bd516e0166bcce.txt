 Etymology
 [ edit ] 

 From Hebrew הָגָר ( Hagar , “ stranger ” ) . Compare Arabic هَاجَر ( hājar ) , Tiberian Hebrew הָגָר ( Hāḡār ) .

 Pronunciation
 [ edit ] 

 ( Received Pronunciation ) IPA ( key ) : /ˈheɪɡɑː/ 

 Audio ( Southern England ) : ( file ) 

 ( US ) IPA ( key ) : /ˈheɪɡɑːɹ/ 

 Proper noun
 [ edit ] 

 Hagar ( plural Hagars ) 

 ( biblical ) The Egyptian concubine of Abraham , mother of Ishmael .

 A female given name from Hebrew .

 [ edit ]
