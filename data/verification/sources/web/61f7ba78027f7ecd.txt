 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *pačati , from Proto-Indo-Iranian *páčati , from Proto-Indo-European *pekʷ- ( “ to cook, become ripe ” ) . [ 1 ] 

 Cognates with Mazanderani بپتن ( bapeten ) , Baluchi پچگ ( pačag , “ to fry, bake ” ) , Northern Kurdish pêtin , Yaghnobi пухсак ( puxsak ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /pux.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [pʰʊx.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [pʰʊx.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [pʰʊx.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [pʰux.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [pʰox.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [pʰuχ.t̪ʰán] 

 Rhymes: -an

 Verb
 [ edit ] 

 پختن • ( puxtan  / poxtan ) ( present stem پز ( paz ) , Tajik spelling пухтан ) [ 2 ] 

 to cook 

 to bake 

 to broil 

 to make ready 

 to ripen 

 to render well disposed towards, canvass for, gain for one's interests
