 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek πιστάκῐον ( pistákĭon ) . See also πιστάκη ( pistákē ) .

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [pɪsˈta.ki.ũː] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [pisˈtaː.t͡ʃi.um] 

 Note: the single poetic attestation in Late Latin displays a long /ā/.

 Noun
 [ edit ] 

 pistacium   n ( genitive pistaciī or pistacī ) ; second declension 

 A pistachio nut

 [ edit ]
