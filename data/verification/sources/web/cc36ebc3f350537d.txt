 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *(s)teg- 
 Proto-Indo-Iranian *táktas 
 Proto-Iranian *táxtah 
 Middle Persian tʾht' ( /⁠taxt⁠/ ) 
 Classical Persian تخت ( taxt ) bor. 
 Ottoman Turkish تخت 

 Borrowed from Classical Persian تخت ( taxt ) .

 Noun
 [ edit ] 

 تخت • ( taht ) 

 any raised structure used for sitting or reclining on, such as a bench , sofa or bier , but especially:
 throne , an impressive seat used by a monarch 
 Synonyms: اَوْرَنْك ( evrenk ) , كُرْسِی ( kürsî )

 Noun

 تخت • ( taxt ) ( plural تخت‌ها ( taxt-hā / taxt-hâ ) , Tajik spelling тахт ) 

 throne

kī gazāfa bar čunīn taxt -ē nišast This love, moreover, is the result of knowledge:
who (ever) sat in foolishness on such a throne ?
