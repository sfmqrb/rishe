 Hindi

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit कर्पूर ( karpū́ra ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /kəɾ.puːɾ/ , [kɐɾ.puːɾ] 

 Noun
 [ edit ] 

 कर्पूर • ( karpūr )  m ( Urdu spelling کَرْپُور ) 

 synonym of कपूर ( kapūr , “ camphor ” )

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Austronesian *qapuʀ 
 Proto-Malayo-Polynesian *qapuʀ 
 Proto-Malayic *kapur bor. ? 
 Sanskrit कर्पूर 

 Probably of Austroasiatic origin. [ 1 ] Alternatively a borrowing from Proto-Malayic *kapur , from Proto-Malayo-Polynesian *qapuʀ , from Proto-Austronesian *qapuʀ ( “ lime, calcium ” ) , whence Malay kapur .
