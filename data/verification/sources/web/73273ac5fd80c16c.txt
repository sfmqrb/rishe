 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From the Middle Persian ancestor of Classical Persian تنبور ( tanbūr ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /tˤun.buːr/ 

 Noun
 [ edit ] 

 طُنْبُور • ( ṭunbūr )  m ( plural طَنَابِير ( ṭanābīr ) ) 

 tanbur 

 Archimedes' screw 

 ( printing ) cylinder
