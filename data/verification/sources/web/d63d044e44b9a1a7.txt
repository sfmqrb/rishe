 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭪 ( k /⁠-ak⁠/ ) .

 Suffix
 [ edit ] 

 Dari

 Tajik

 -ак 

 ـک • ( -ak ) 

 suffix which forms diminutives 
 Synonyms: ـچه ( -če ) , ـیزه ( ize ) 

 alternative form of ـه ( -e , suffix which forms words with the meaning of “pertaining to, related to” ) 

 ( dialectal , Yazd ) suffix marking nouns as definite
