 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Hellenic *térpō , from Proto-Indo-European *terp- ( “ to satisfy ” ) , cognate with German dürfen ( “ to need ” ) and obsolete and dialectal British English tharf ( “ to need ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /tér.pɔː/ → /ˈter.po/ → /ˈter.po/ 

 ( 5 th BCE Attic ) IPA ( key ) : /tér.pɔː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈter.po/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈter.po/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈter.po/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈter.po/ 

 Verb
 [ edit ] 

 τέρπω • ( térpō ) 

 to delight 

 ( passive voice and middle voice ) to enjoy , to revel 
 c. 800 BCE – 600 BCE , Homer , Iliad 24.633–634 : αὐτὰρ ἐπεὶ τάρπησαν ἐς ἀλλήλους ὁρόωντες,
τὸν πρότερος προσέειπε γέρων Πρίαμος θεοειδής· autàr epeì tárpēsan es allḗlous horóōntes,
tòn próteros proséeipe gérōn Príamos theoeidḗs; Translation by Samuel Butler When they had gazed their fill Priam spoke first. (literally, “they enjoyed seeing him (Priam)”)

 Etymology
 [ edit ] 

 From Ancient Greek τέρπω .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈteɾ.po/ 

 Hyphenation: τέρ‧πω 

 Verb
 [ edit ] 

 τέρπω • ( térpo ) ( past έτερψα , passive τέρπομαι )

 ( formal ) to regale , please , delight 
 Τέρπω τους καλεσμένους με ιστορίες. Térpo tous kalesménous me istoríes. I regale the guests with stories.
