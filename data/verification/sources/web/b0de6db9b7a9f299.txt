 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From an Indo-Aryan source; compare Sanskrit पिप्पलि ( pippali , “ long pepper ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /pé.pe.ri/ → /ˈpe.pe.ri/ → /ˈpe.pe.ri/ 

 ( 5 th BCE Attic ) IPA ( key ) : /pé.pe.ri/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈpe.pe.ri/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈpe.pe.ri/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈpe.pe.ri/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈpe.pe.ri/ 

 Noun
 [ edit ] 

 πέπερῐ • ( péperĭ )  n ( genitive πεπέρεως or πεπέρῐος , diminutive πεπέρῐον ) ; third declension 

 pepper ( plant of the family Piperaceae ) 

 black pepper ( Piper nigrum ) 

 pepper ( spice ) 

 Declension
 [ edit ] 

 Third declension of τὸ πεπέρῐ ; τοῦ πεπέρεως ( Attic )
