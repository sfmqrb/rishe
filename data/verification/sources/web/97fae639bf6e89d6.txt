 French
 [ edit ] 

 Etymology
 [ edit ] 

 Earlier bredaiche , borrowed from Italian bardassa , from Arabic بَرْدَج ( bardaj , “ captive ” ) , from Persian بَرْدَه ( “ slave, captive ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /baʁ.daʃ/ 

 Audio ( France ( Toulouse ) ) : ( file ) 

 Audio ( France ) : ( file ) 

 Audio ( France ( Agen ) ) : ( file ) 

 Noun
 [ edit ] 

 bardache   m ( plural bardaches ) 

 ( dated ) berdache ( third-gender Native (North) American ) 

 ( obsolete ) passive homosexual 
 Synonym: giton 

 Descendants
 [ edit ] 

 → English: bardash , berdache 

 → Portuguese: berdache
