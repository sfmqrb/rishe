 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 پساک ( pasâk ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐫛𐫇𐫘𐫃 ( pwsg /⁠pusag, pūsag⁠/ , “ garland ” ) . Cognate with Parthian 𐫛𐫇𐫘𐫃 ( pwsg /⁠pusag, pūsag⁠/ ) , Sogdian [script needed] ( ʾpsʾk ) , Avestan 𐬞𐬏𐬯𐬀 ( pūsa , “ plait, head dress ” ) , Sanskrit पुट ( puṭa , “ plait ” ) , Old Armenian պսակ ( psak ) , Tocharian A [Term?] ( psuk ) , Tocharian B [Term?] ( pässakw ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ba.ˈsaːk/ 

 ( Dari, formal ) IPA ( key ) : [bä.sɑ́ːk] 

 ( Dari, formal ) IPA ( key ) : [bä.sɑ́ːk] 
 ( Kabuli ) IPA ( key ) : [bä.sɑ́ːk] 

 ( Hazaragi ) IPA ( key ) : [bä.sɔ́ːk] 

 ( Iran, formal ) IPA ( key ) : [bæ.sɒ́ːkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [bä.sɔ́k]

 wreath , garland
