 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from French eau de Cologne .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [ʔod̪.kʰo.lón] , [ʔo.d̪e.kʰo.lón] , [ʔo.d̪o.kʰo.lón] 

 Readings

 Iranian reading ? 

 odkolon, odekolon, odokolon

 Noun
 [ edit ] 

 ادکلن • ( odkolon ) 

 ( Iran ) cologne , (man's) perfume
