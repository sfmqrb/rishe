 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Adverb
 [ edit ] 

 *úd [ 1 ] [ 2 ] [ 3 ] 

 upwards , away , out , outward 

 Derived terms
 [ edit ] 

 *úd-s ( prep. ) [ 1 ] ( < genitive [ 4 ] ) 
 Proto-Balto-Slavic: *uź Latvian: uz 
 Lithuanian: už 
 Samogitian: už 
 Proto-Slavic: *vъz ( see there for further descendants )

 Proto-Celtic: *uss- ( prep. ) [ 5 ] 
 Old Irish: uss- ( “ up, off ” ) , oss- ( GOI ) , od- ( before a stop or m ) , ó- , úa- ( before a liquid or n ) 

 Proto-Germanic: *uz ( “ out (of) ” , prep. ) [ 4 ] ( see there for further descendants )

 *úd-s-kʷe ( “ above ” , prep. ) [ 1 ] 
 Proto-Indo-Iranian: *utˢčáH ( “ above, upwards ” , adverb ) ( < *úds-kʷeh₁ ( instr. ) ) ( see there for further descendants )

 Proto-Italic: *ū̆skʷe [ 5 ] 
 Latin: ū̆sque ( “ all the way, up to ” , adverb ) ( see there for further descendants )

 *úd-ter-o-s ( “ higher, outer ” , contrastive ) [ 6 ] 

 *ud-tm̥m-ó-s ( “ highest, most outer ” , superl. ) [ 1 ] [ 7 ] 
 Proto-Hellenic: *ústəmos [ 1 ] 
 Ancient Greek: ὕστᾰτος ( hústătos , “ latest, last ” , superl. ) 

 Proto-Indo-Iranian: *utˢtamás ( “ highest, most elevated ” ) ( see there for further descendants )

 *úd-er-o-s ( “ abdomen, stomach ” ) [ 8 ] [ 9 ] ( deadjectival of original superlative ) 

 Descendants
 [ edit ] 

 Terms derived from the Proto-Indo-European word *úd 

 Proto-Balto-Slavic: *ū́ ( < *úd via Winter's law , or *ū́ˀ < already PIE *úh₁ ) 
 Proto-Slavic: *vy- ( “ out ” , prefix ) [ 10 ] ( see there for further descendants )

 Proto-Celtic: *ud- ( pref. ) 
 Old Irish: od- 

 Proto-Germanic: *ūt ( “ out, outward ” , adverb ) [ 11 ] ( lengthened due to monosyllabicity [ 11 ] ) ( see there for further descendants )

 Proto-Hellenic: *u 
 Ancient Greek: ὑ- ( hu- , pref. ) , ὑ ( hu , prep.. ) 

 Proto-Indo-Iranian: *ud- [ 12 ] ( see there for further descendants )
