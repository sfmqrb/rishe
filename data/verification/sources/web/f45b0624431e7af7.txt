 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Iranian , from Proto-Indo-Iranian , ultimately from Proto-Indo-European *glew- . Cognate with Northern Kurdish girover, gilover ( “ round ” ) , Northern Luri گوڶٮه ( gollə , “ bullet ” ) , Sanskrit ग्लौ ( glau , “ lump ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡu.luː.ˈla/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.luː.lá] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.luː.lá] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.luː.lá] 

 ( Hazaragi ) IPA ( key ) : [ɡu.lu.lá] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.luː.lé] 

 ( Tajik, formal ) IPA ( key ) : [ɡu.lɵ.lá] 

 Rhymes: -a

 Noun
 [ edit ] 

 گلوله • ( gulūla / golule ) ( plural گلوله‌ها ( gulūla-hā / golule-hâ ) , Tajik spelling гулӯла ) 

 bullet 

 pellet , ball , spherical object
