 Alternative forms
 [ edit ] 

 ماهتاب ( māhtāb  / mâhtâb ) 

 Etymology
 [ edit ] 

 From مه ( mah ) + تاب ( tâb ) . Compare Northern Kurdish taveheyv .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /mah.ˈtaːb/ 

 ( Dari, formal ) IPA ( key ) : [mäɦ.t̪ʰɑ́ːb] 

 ( Dari, formal ) IPA ( key ) : [mäɦ.t̪ʰɑ́ːb] 
 ( Kabuli ) IPA ( key ) : [mä.t̪ʰáw] , [mɑː.t̪ʰáw] 

 ( Hazaragi ) IPA ( key ) : [mɔː.t̪ʰɔ́ːb̥] 

 ( Iran, formal ) IPA ( key ) : [mæɦ.t̪ʰɒ́ːb̥] 

 ( Tajik, formal ) IPA ( key ) : [mäɦ.t̪ʰɔ́b] 

 Rhymes: -aːb

 Noun
 [ edit ] 

 مهتاب • ( mahtāb / mahtâb ) ( Tajik spelling маҳтоб ) 

 moonlight 
 Nima Yooshij "Mi-tarâvad Mahtâb"
 می‌ترواد مهتاب 
 می‌درخشد شب‌تاب
 نیست یک‌دَم شکند خواب به چشمِ کَس و لیک
 غم این خفتهٔ چند
 خواب در چشمِ تَرَم می‌شکند. (please add an English translation of this quotation)
