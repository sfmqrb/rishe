 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 دگر ( digar  / degar ) ( poetic ) 

 دیگه ( dīga  / dige ) ( colloquial ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( dtykl /⁠dūdīgar⁠/ , “ second ” ) , [ 1 ] from Proto-Iranian *dwitī́yakarah . [ 2 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /diː.ˈɡar/ 

 ( Dari, formal ) IPA ( key ) : [d̪iː.ɡáɾ] 

 ( Dari, formal ) IPA ( key ) : [d̪iː.ɡáɾ] 
 ( Kabuli ) IPA ( key ) : [d̪iː.ɡá] 

 ( Hazaragi ) IPA ( key ) : [d̪i.ɡá] 

 ( Iran, formal ) IPA ( key ) : [d̪iː.ɡʲǽɹ] 

 ( Iran, formal ) IPA ( key ) : [d̪iː.ɡʲǽɹ] 
 ( Tehrani ) IPA ( key ) : [d̪iː.ɡʲé] 

 ( Tajik, formal ) IPA ( key ) : [d̪i.ɡáɾ] 

 Rhymes: -ar

 Adverb
 [ edit ] 

 دیگر • ( dīgar  / digar ) ( Tajik spelling дигар ) 

 other 
 یه گوشواره رو پیدا کردم، اون یکی دیگه کجاست؟ ye gušvâre ro peidâ kardam, un yeki dige kojâst? I found one earring, where's that other one? 

 another , more 
 گذرنامه من پنج سال دیگه اعتبار داره gozarnâme man panj sâl dige etebâr dâre. My passport will stay valid for five more years. 

 next 
 آلبوم جدیدش سال دیگه منتشر میشه âlbume jadideš sâle dige montašer miše. His/Her new album will be released next year. 

 no more 

 anymore 

 any longer 

 already ( An intensifier used to emphasize impatience or express exasperation )
