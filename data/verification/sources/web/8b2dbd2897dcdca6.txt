 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Ancient Greek ἄγκυρα ( ánkura ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈa(ŋ).ɟi.ra/ 

 Hyphenation: ά‧γκυ‧ρα 

 Noun
 [ edit ] 

 άγκυρα • ( ágkyra )  f ( plural άγκυρες ) 

 ( nautical ) anchor 
 ρίχνω άγκυρα ― ríchno ágkyra ― to drop anchor 
 σηκώνω άγκυρα ― sikóno ágkyra ― to weigh/raise anchor
