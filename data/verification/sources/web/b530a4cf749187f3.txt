 Noun
 [ edit ] 

 اختاپوس • ( uxtāpūs / oxtâpus ) ( plural اختاپوس‌ها ( uxtāpūs-hā / oxtâpus-hâ ) , Tajik spelling ухтопӯс ) 

 ( less common ) octopus ( any of several marine molluscs of the family Octopodidae ) 
 Synonym: ( more common ) هَشْت‌پَا ( hašt-pâ )
