 Egyptian Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 أبو ( alternative spelling ) 

 بو ( bu ) ( alternative form ) 

 Etymology
 [ edit ] 

 From Arabic أَبُو ( ʔabū ) , construct state of أَب ( ʔab ) . The adjective usurped the usages of ذُو ( ḏū ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /(ʔ)abu/ , [ˈæbu] 

 Noun
 [ edit ] 

 ابو • ( abu )  m

 Adjective
 [ edit ]

 ( construct only , singular only , informal ) which is with , which has

 [ edit ] 

 Borrowed from Arabic أَبُو ( ʔabū ) , nominative construct state of أَب ( ʔab , “ father ” ) .

 Pronunciation

 ( Classical Persian ) IPA ( key ) : /ʔa.ˈbuː/ 

 ( Dari, formal ) IPA ( key ) : [ʔä.buː]

 Noun
 [ edit ] 

 ابو • ( abū / abu ) ( Tajik spelling абу ) 

 only used in kunyas ( teknonyms ) borrowed from Arabic and kunya-like Arabic loanwords or pseudo-Arabisms 
 Coordinate term: ام ( ummu  / ommo ) 

 Usage notes
 [ edit ] 

 As in Arabic, the final vowel is shortened before any Arabic word starting with a wasla . Such is the case when ابو (abū  / abu) is followed by the Arabic definite article اَلـ ( al- ) , together forming ابو الـ (abu-l-  / abo-l-).
