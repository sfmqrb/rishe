 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( pwd- /⁠pōy-⁠/ , “ to run ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 Vocalised Persian: پویِیدَنْ 

 ( Classical Persian ) IPA ( key ) : /poː.jiː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [pʰoː.jiː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [pʰoː.jiː.d̪án] 
 ( Kabuli ) IPA ( key ) : [pʰoː.jiː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [pʰʊː.ji.d̪án] 

 ( Iran, formal ) IPA ( key ) : [pʰuː.jiː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [pʰɵ.ji.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 پوییدن • ( pōyīdan  / puyidan ) ( Tajik spelling пӯидан ) 

 to trot ( walk rapidly ) 

 to jog 

 to pace ( walk at a steady and consistent speed ) 

 to search , examine
