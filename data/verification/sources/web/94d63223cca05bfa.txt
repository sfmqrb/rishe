 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( xvarōfrān /⁠xwarwarān⁠/ , “ west ” ) . Akin to Old Armenian խաւար ( xawar ) ; an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /xaː.ˈwar/ 

 ( Dari, formal ) IPA ( key ) : [xɑː.wäɾ] 

 ( Dari, formal ) IPA ( key ) : [xɑː.wäɾ] 
 ( Kabuli ) IPA ( key ) : [xɑː.wäɾ] 

 ( Hazaragi ) IPA ( key ) : [xɔː.wäɾ] 

 ( Iran, formal ) IPA ( key ) : [xɒː.væɹ] 

 ( Tajik, formal ) IPA ( key ) : [χɔ.väɾ] 

 Rhymes: -ar
