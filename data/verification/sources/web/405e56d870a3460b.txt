 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 اسپاه ( espâh ) , اسپه ( espah ) , سپه ( sepah ) 

 Etymology
 [ edit ] 

 From Middle Persian spʿh  / 𐭮𐭯𐭠𐭧 ( spāh ) , borrowed from Northwestern Iranian , from Proto-Indo-Iranian *ćwáHdʰaH , from Proto-Indo-European *ḱwéh₁-dʰ-o-h₁ ( dual ) , from *ḱweh₁- , *ḱewh₁- ( “ to swell, be great ” ) . Possible cognate with Avestan 𐬯𐬏𐬌𐬛𐬌𐬌𐬁𐬌 ( sūidiiāi , “ to swell, increase ” , inf. ) , Bactrian σοδο ( sodo /⁠sūdo⁠/ , “ plenty ” ) , Middle Persian [script needed] ( swd /⁠sūd⁠/ ) , [script needed] ( swwd /⁠sūd⁠/ , “ profit, advantage ” ) , Sanskrit शवस् ( śavas , “ strength, superiority ” ) .

 Noun
 [ edit ] 

 سپاه • ( sipāh / sepâh ) ( plural سپاه‌ها ( sipāh-hā / sepâh-hâ ) , Tajik spelling сипоҳ ) 

 army 
 Synonyms: لشکر ( laškar ) , ارتش ( arteš ) , ( Dari ) اردو ( urdū ) 

 ( Iran ) short for سپاه پاسداران انقلاب اسلامی ( sepâh-e pâsdârân-e enqelâb-e eslâmi , “ Islamic Revolutionary Guard Corps ” )
