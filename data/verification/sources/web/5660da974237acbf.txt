 Arabic

 Verb
 [ edit ] 

 بُرْنَا • ( burnā ) ( form I ) /bur.naː/ 

 first-person plural past active of بَارَ ( bāra ) 

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 برنای ( burnāy  / bornây ) , برناه ( burnāh  / bornâh ) 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( ʾpwlnʾd /⁠aburnāy⁠/ , “ underage, youth ” ) , a Zoroastrian legal term borrowed from Avestan 𐬀𐬞𐬆𐬭𐬆𐬥𐬁𐬌𐬌𐬎 ( apər ə nāiiu , “ underage ” ) , the negative of 𐬞𐬆𐬭𐬆𐬥𐬁𐬌𐬌𐬎 ( pər ə nāiiu , “ adult ” ) , from Proto-Iranian *pr̥Hnáh ( “ full, filled ” ) .

 Adjective
 [ edit ] 

 برنا • ( burnā / bornâ ) ( Tajik spelling барно ) 

 ( poetic ) adolescent , young 
 ز دانش دل پیر برنا بود. ( proverb ) zi dāniš dil-i pīr burnā buwad. The aged heart becomes young from knowledge. 

 Noun
 [ edit ] 

 برنا • ( burnā / bornâ ) ( Tajik spelling барно ) 

 ( poetic ) youth 
 c. 1011 , Abu'l-Qāsim Firdawsī , “The Tale of Rustam and Isfandiyār”, in شاهنامه [ Book of Kings ]‎ [1] : بیفشارد چنگش میان سخن
ز برنا بخندید مرد کهن
ز ناخن فرو ریختش آب زرد
همانا نجنبید زان‌ درد مرد biyafšārd čang-aš miyān-i suxan
zi burnā bixandīd mard-i kuhan
zi nāxun furō rēxt-aš āb-i zard
hamānā na-jombīd z-ān dard mard He [Isfandiyār] pressed his [Rustam's] hand hard as he spoke,
But the ancient man [Rustam] smiled at the youth ;
Yellow gall dripped down from his [Rustam's] fingernails,
indeed, the man never jolted from the pain. (Classical Persian romanization)
