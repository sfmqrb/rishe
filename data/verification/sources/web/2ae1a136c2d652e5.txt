 Hebrew
 [ edit ] 

 Etymology
 [ edit ] 

 Roots 

 ב־ן ( b-n ) 

 3 terms 

 י־מ־ן ( y-m-n ) 

 8 terms 

 From בן and ימין ; son of (the) right hand; Binjamin, youngest son of Jacob; also the tribe descended from him, and its territory.

 Pronunciation
 [ edit ] 

 ( Tiberian ) IPA ( key ) : /bin.jɔːˈmiːn/ 

 ( Modern Israeli ) IPA ( key ) : /bin.jaˈmin/ 
 Audio : ( file ) 

 Proper noun
 [ edit ] 

 בִּנְיָמִין • ( binyamín )  m 

 a male given name , Binyamin and Binyomin , equivalent to English Benjamin 

 ( biblical ) Benjamin ( the youngest of the sons of Jacob and Rachel in the Bible ) 

 References
 [ edit ] 

 Strong, James ( 1979 ), “ H1144 ”, in Strong’s Exhaustive Concordance to the Bible
