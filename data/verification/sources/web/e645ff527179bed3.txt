 Middle Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Proto-Iranian *cwaytáh , from Proto-Indo-Iranian *ćwaytás , from Proto-Indo-European *ḱweyt- . Cognate to Avestan 𐬯𐬞𐬀𐬉𐬙𐬀 ( spaēta ) , Sanskrit श्वेत ( śvetá ) .

 Adjective
 [ edit ] 

 spyt' • ( spēd ) 

 white 

 Descendants
 [ edit ] 

 Classical Persian: سَفید ( safēd ) , سَپید ( sapēd )
