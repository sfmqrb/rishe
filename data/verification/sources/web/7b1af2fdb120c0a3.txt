 Etymology
 [ edit ] 

 From French côtelette (“cutlet”).

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kut.ˈlit/ 

 ( Dari, formal ) IPA ( key ) : [kʰʊt̪.lɪ́t̪]

 Noun
 [ edit ] 

 کتلت • ( kotlet ) ( Iran ) 

 cutlet 

 ( slang , derogatory , politics ) a recently deceased individual with significant ties to the Islamic Republic of Iran and IRGC (especially officials, security figures, or hardliners); used humorously to refer to high-profile deaths by airstrikes or explosions
