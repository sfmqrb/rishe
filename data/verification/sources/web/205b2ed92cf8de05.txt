 Avestan
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Iranian *máHtā (compare Old Persian 𐎶𐎠𐎫𐎠 ( mātā ) ), from Proto-Indo-Iranian *máHtā (compare Sanskrit मातृ ( mā́tṛ ) , from Proto-Indo-European *méh₂tēr (compare Old Armenian մայր ( mayr ) , Ancient Greek μήτηρ ( mḗtēr ) , Old Church Slavonic мати ( mati ) , Latin māter , Old English mōdor (whence English mother ).

 Noun
 [ edit ] 

 𐬨𐬁𐬙𐬀𐬭 • ( mātar )  f
