 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian hwnydʾkl ( huniyāgar , “ entertainer, musician ” ) , equivalent to خنیا +‎ ـگر .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /xu.ni.jaː.ˈɡar/ 

 ( Dari, formal ) IPA ( key ) : [xʊ.ni.jɑː.ɡäɾ] 

 ( Dari, formal ) IPA ( key ) : [xʊ.ni.jɑː.ɡäɾ] 
 ( Kabuli ) IPA ( key ) : [xʊ.ni.jɑː.ɡäɾ] 

 ( Hazaragi ) IPA ( key ) : [xu.ni.jɔː.ɡäɾ] 

 ( Iran, formal ) IPA ( key ) : [xo.ni.jɒː.ɡʲæɹ] 

 ( Tajik, formal ) IPA ( key ) : [χu.ni.jɔ.ɡäɾ] 

 Rhymes: -ar

 Noun
 [ edit ] 

 خنیاگر • ( xoniyâgar ) ( plural خنیاگران , or خنیاگرها ) 

 entertainer 

 musician 

 singer
