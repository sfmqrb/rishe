 Kashmiri
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian ریش ( rīš ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : [reːʃ] 

 Noun
 [ edit ] 

 ریش • ( rēś )  m ( Devanagari रेश ) 

 beard 
 Synonym: دٲر ( dạ̄r ) 

 Derived terms
 [ edit ] 

 ریشَل ( rēśal ) 

 References
 [ edit ]

 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Persian ریش ( riš , “ beard ” ) .

 Noun
 [ edit ] 

 ریش • ( riş ) 

 beard , facial hair on the chin , cheeks , jaw and neck 
 Synonym: صقال ( sakal ) 

 Etymology 2
 [ edit ] 

 Borrowed from Persian ریش ( riš , “ wound ” ) .

 Noun
 [ edit ] 

 ریش • ( riş ) 

 wound , sore 

 Etymology 3
 [ edit ] 

 Borrowed from Arabic رِيش ( rīš , “ feathering, plumage ” ) .

 Noun
 [ edit ] 

 ریش • ( riş ) ( plural ریاش ) 

 ( zoology ) plumage , feathering 

 chattel property 

 means of subsistence 

 finery

 Persian
 [ edit ] 

 یک مرد با ریش کوتاه ― A man with a short beard 

 Etymology 1
 [ edit ] 

 Derived from Middle Persian [script needed] ( lyš /⁠rēš⁠/ , “ beard ” ) , probably from Proto-Iranian *xraiša- , from Proto-Indo-European *kreyso- , itself from Proto-Indo-European *(s)kre-i-s- , an extension of *(s)ker- ( “ to turn, bend ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈreːʃ/ , /ˈriːʃ/ 

 ( Dari, formal ) IPA ( key ) : [riːʃ] 

 ( Dari, formal ) IPA ( key ) : [riːʃ] 
 ( Kabuli ) IPA ( key ) : [riːʃ] 

 ( Hazaragi ) IPA ( key ) : [riʃ] 

 ( Iran, formal ) IPA ( key ) : [ɹiːʃ] 

 ( Tajik, formal ) IPA ( key ) : [ɾiʃ] 

 Rhymes: -eːʃ , -iːʃ 

 Readings

 Classical reading ? 

 rēš, rīš

 Dari reading ? 

 rīš

 Iranian reading ? 

 riš

 Tajik reading ? 

 riš

 Noun
 [ edit ] 

 ریش • ( rīš, rēš / riš ) ( plural ریش‌ها ( rīš-hā, rēš-hā / riš-hâ ) , Tajik spelling риш ) 

 beard 
 c. 16th–17th century , Baha al-Din al-Amili , “ شمارهٔ ۱ [ šumāra-yi 1 ]”, in دیوان اشعار [ dēwān-i aš'ār ]‎ [5] : شانه عاج ار نبود بهر ریش 
شانه توان کرد به انگشت خویش šāna-yi āj ar nabuwad bahr-i rēš 
šāna tawān kard ba angušt-i xwēš If there is no ivory comb for one's beard ,
It can be combed with one's own fingers.

 Etymology 2
 [ edit ] 

 Inherited from Middle Persian lyš ( rēš ) , from Proto-Indo-Iranian *rayšás ( “ injury, wound ” ) from the root *rayš- ( “ to be wounded, hurt; to suffer injury ” ) . [ 2 ] [ 3 ]

 ( Hazaragi ) IPA ( key ) : [reːʃ] 

 ( Iran, formal ) IPA ( key ) : [ɹiːʃ] 

 ( Tajik, formal ) IPA ( key ) : [ɾeʃ] 

 Rhymes: -eːʃ

 Noun
 [ edit ] 

 ریش • ( rēš / riš ) ( plural ریش‌ها ( rēš-hā / riš-hâ ) , Tajik spelling реш ) 

 ( Iran or uncommon ) wound 
 Synonyms: جراحت ( jirāhat  / jerâhat ) ( Iran ) , زخم ( zaxm ) 

 scar 

 ulcer
