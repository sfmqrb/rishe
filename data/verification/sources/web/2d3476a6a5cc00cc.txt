 Etymology
 [ edit ] 

 Etymology tree

 Arabic اَلْيَمَن ( al-yaman ) bor. 
 Ottoman Turkish یمن ( yemen ) bor. 
 English Yemen 

 Borrowed from Ottoman Turkish یمن ( yemen ) , from Arabic اَلْيَمَن ( al-yaman ) , from Proto-Semitic *yamīn- ( “ right; right hand ” ) .

 Pronunciation
 [ edit ] 

 ( Received Pronunciation , General American ) IPA ( key ) : /ˈjɛmən/ 
 Audio ( US ) : ( file ) 

 Audio ( UK ) : ( file ) 

 ( US , pin – pen merger ) IPA ( key ) : /ˈjɪmən/ 

 ( Australia , New Zealand ) IPA ( key ) : /ˈjemən/ 

 Rhymes: -ɛmən 

 Proper noun
 [ edit ] 

 Yemen ( plural Yemens ) 

 A country in West Asia in the Middle East . Official name: Republic of Yemen . Capital: Sanaa .
 2012 April 30, Ghaith Abdul-Ahad, “Al-Qaida's wretched utopia and the battle for hearts and minds”, in The Guardian ‎ [1] : Unlike in Somalia, Iraq and Afghanistan, in Yemen they are trying to implement sharia by winning over the hearts and minds of the people. 

 ( historical ) A region in the southern Arabian Peninsula ; the Arabia Felix .

 ( historical ) A province of the Ottoman Empire : the Yemen eyalet , later Yemen vilayet .

 Usage notes
 [ edit ] 

 The country is traditionally referred to with the definite article the , though this construction has declined in use. [ 1 ]
