 Etymology
 [ edit ] 

 Variant of तित्तिर ( tittirá ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /tit.ti.ɾi/ , [tit̚.ti.ɾi] 

 ( Classical Sanskrit ) IPA ( key ) : /t̪it̪.t̪i.ɾi/ , [t̪it̪̚.t̪i.ɾi] 

 Noun
 [ edit ] 

 ति॒त्तिरि॑ or ति॒त्ति॒रि • ( tittíri or tittirí ) stem ,  m 

 partridge 

 ( dance ) kind of step

 the school of the तैत्तिरीय ( Taittirīya ) 

 name of a pupil of यास्क ( Yāska ) (first teacher of the तैत्तिरीय ( Taittirīya ) school of the black YV.)

 name of a नाग ( Nāga )
