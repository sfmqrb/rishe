 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European *h₂léh₁wr̥ . Cognate with Old Armenian ալեւր ( alewr ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /á.leu̯.ron/ → /ˈa.le.βron/ → /ˈa.le.vron/ 

 ( 5 th BCE Attic ) IPA ( key ) : /á.leu̯.ron/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈa.lew.ron/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈa.le.βron/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈa.le.vron/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈa.le.vron/ 

 Noun
 [ edit ] 

 ᾰ̓́λευρον • ( ắleuron )  n ( genitive ἀλεύρου ) ; second declension ( chiefly in the plural ) 

 wheat flour , wheatmeal 
 Synonym: ᾰ̓́λειᾰρ ( ắleiăr ) 
 460 BCE – 430 BCE , Herodotus , Histories 7.119 : Οἱ ἀστοὶ ἄλευρά τε καὶ ἄλφιτα ἐποίευν πάντες ἐπὶ μῆνας συχνούς. Hoi astoì áleurá te kaì álphita epoíeun pántes epì mênas sukhnoús. The citizens continued to make wheatmeal and barleymeal for many months. 

 meal 

 Usage notes
 [ edit ] 

 Particularly differentiated from ᾰ̓́λφῐτον ( ắlphĭton , “ barley flour ” ) .

 Declension
 [ edit ] 

 Second declension of τὸ ᾰ̓́λευρον ; τοῦ ᾰ̓λεύρου ( Attic )
