 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 نی ( ney ) 

 Etymology
 [ edit ] 

 From Middle Persian nʾd ( nāy , “ reed, cane; tube, pipe, flute, clarion ” ) , from Proto-Indo-Iranian *nada (compare Sanskrit नड ( naḍá ) ), from Proto-Indo-European *nedo- ( “ reed ” ) ; See Old Armenian նետ ( net , “ arrow ” ) for more.
