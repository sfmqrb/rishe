 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 From the Middle Persian equivalent of Persian اوگ ( owg ) , ultimately from Proto-Indo-European *h₂ewg- ( “ related to increasement ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔawd͡ʒ/
