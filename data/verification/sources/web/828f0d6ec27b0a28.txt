 Pashto
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Pathan *day < *dáγ , from an ancestral Middle Iranian form *idág , [ 1 ] from Proto-Iranian *Haytákah .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /d̪aɪ/ 

 Pronoun
 [ edit ] 

 دی • ( day ) 

 he ( visible masculine singular third person )

 [ edit ]
