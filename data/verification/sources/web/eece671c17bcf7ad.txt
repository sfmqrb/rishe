 Russian

 Pronunciation
 [ edit ] 

 IPA ( key ) : [ˈkaplʲə] 

 Audio : ( file ) 

 Etymology 1
 [ edit ] 

 Inherited from Old East Slavic каплꙗ ( kaplja ) , from Proto-Slavic *kapľa , from *kapati + *-ja .

 [ edit ]
