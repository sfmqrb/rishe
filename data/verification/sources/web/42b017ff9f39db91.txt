 Persian
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /xa.ˈdanɡ/ 

 ( Dari, formal ) IPA ( key ) : [xä.d̪áŋɡ] 

 ( Dari, formal ) IPA ( key ) : [xä.d̪áŋɡ] 
 ( Kabuli ) IPA ( key ) : [xä.d̪áŋɡ] 

 ( Hazaragi ) IPA ( key ) : [xä.d̪áŋɡ̥] 

 ( Iran, formal ) IPA ( key ) : [xæ.d̪ǽɲɡʲ̥] 

 ( Tajik, formal ) IPA ( key ) : [χä.d̪áŋɡ] 

 Rhymes: -anɡ

 Etymology 1
 [ edit ] 

 Perhaps related to Ancient Greek κάττα ( kátta ) , Classical Syriac ܩܛܘ ( qaṭṭu ) .

 Noun
 [ edit ] 

 خدنگ • ( xadang ) 

 mongoose 

 Etymology 2
 [ edit ] 

 Possibly borrowed from Turkic , ultimately from Proto-Turkic *kadïŋ ( “ birch ” ) . [ 1 ] 

 Noun
 [ edit ] 

 خدنگ • ( xadang ) 

 ( obsolete ) birch 
 Synonyms: غان ( ġân ) , توسکا ( tuskâ ) 

 ( obsolete ) a type of arrow made of birch

 [ edit ]
