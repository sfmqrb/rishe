 Etymology
 [ edit ] 

 From Middle Persian 𐭡𐭠𐭬𐭣𐭠𐭲 ( bāmdād , “ dawn, morning ” ) . Compare Baluchi باندات ( bāndāt , “ tomorrow, future ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /baːm.ˈdaːd/ 

 ( Dari, formal ) IPA ( key ) : [bɑːm.d̪ɑ́ːd̪] 

 ( Dari, formal ) IPA ( key ) : [bɑːm.d̪ɑ́ːd̪] 
 ( Kabuli ) IPA ( key ) : [bɑːm.d̪ɑ́ːd̪] 

 ( Hazaragi ) IPA ( key ) : [bɔːm.d̪ɔ́ːd̪̥] 

 ( Iran, formal ) IPA ( key ) : [bɒːm.d̪ɒ́ːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [bɔm.d̪ɔ́d̪]
