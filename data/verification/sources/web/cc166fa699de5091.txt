 Catalan
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Andalusian Arabic , from Arabic بَلُّوطَة ( ballūṭa , “ oak, acorn ” ) , from Syriac ܒܠܘܛܐ .

 Pronunciation
 [ edit ] 

 IPA ( key ) : ( Northern ) [bəˈʎo̞.tə] 

 IPA ( key ) : ( Balearic , Central ) [bəˈʎɔ.tə] 

 IPA ( key ) : ( Valencia , Northwestern ) [beˈʎɔ.ta] 

 Noun
 [ edit ] 

 bellota   f ( plural bellotes ) 

 acorn ( fruit of the oak ) 
 Synonyms: gla , aglà 

 Alternative forms
 [ edit ] 

 abellota 

 See also
 [ edit ] 

 roure 

 alzina

 Pronunciation
 [ edit ]

 IPA ( key ) : /beˈʒota/ [beˈʒo.t̪a] ( central Ecuador , Santiago del Estero and environs, elsewhere in Pampas and southern Argentina , Uruguay )
