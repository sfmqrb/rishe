 Pronunciation
 [ edit ] 

 Vocalised Persian: گُشادَن 

 ( Classical Persian ) IPA ( key ) : /ɡu.ʃaː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.ʃɑː.d̪än] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.ʃɑː.d̪än] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.ʃɑː.d̪än] 

 ( Hazaragi ) IPA ( key ) : [ɡu.ʃɔː.d̪än] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.ʃɒː.d̪æn] 

 ( Tajik, formal ) IPA ( key ) : [ɡu.ʃɔ.d̪än] 

 Rhymes: -an

 Verb
 [ edit ] 

 گشادن • ( gošâdan ) ( present stem گشای ( gošây ) ) 

 ( archaic ) alternative form of گشودن ( gošudan , “ to open ” ) 
 Synonym: باز کردن ( bâz kardan )
