 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 هندام ( handâm or hendâm ) 

 Etymology
 [ edit ] 

 Akin to Middle Persian hndʾm ( handām , “ member, limb ” ) (whence هندام ( handâm ) ), Manichaean Parthian 𐫍𐫗𐫅𐫀𐫖 ( hndʾm /⁠handām⁠/ , “ limb, member; part, section ” ) , Northern Kurdish hinav ( “ organ ” ) , Central Kurdish هەناو ( henaw , “ organ ” ) , Avestan 𐬵𐬀𐬧𐬛𐬁𐬨𐬀 ( haṇdāma , “ limb ” ) . Ultimately from Proto-Indo-European *sem- ( “ together ” ) + *dʰeh₁- ( “ to put ” ) + *-mn̥ .

 Compare also Arabic هِنْدَام ( hindām ) (whence هندام ( hendâm ) ), Old Armenian անդամ ( andam ) , Classical Mandaic ࡄࡀࡍࡃࡀࡌࡀ ( handāmā ) , Aramaic הדמא ( haddāmā ) , Classical Syriac ܗܕܡܐ ( haddāmā ) , Iranian borrowings.
