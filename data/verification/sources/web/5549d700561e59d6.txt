 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Hellenic *homós , from Proto-Indo-European *somHós ( “ same, alike ” ) . Cognate with εἷς ( heîs , “ one ” ) , as well as Old English sama ( English same ), Sanskrit सम ( sama ) , Old Persian 𐏃𐎶 ( hama ) , Old Church Slavonic самъ ( samŭ ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ho.mós/ → /oˈmos/ → /oˈmos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ho.mós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /(h)oˈmos/ 

 ( 4 th CE Koine ) IPA ( key ) : /oˈmos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /oˈmos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /oˈmos/ 

 Adjective
 [ edit ] 

 ὁμός • ( homós )  m ( feminine ὁμή , neuter ὁμόν ) ; first / second declension
