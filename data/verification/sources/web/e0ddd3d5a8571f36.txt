 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From ζώνη ( zṓnē , “ belt ” ) +‎ -άριον ( -árion , diminutive ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /zdɔː.ná.ri.on/ → /zoˈna.ri.on/ → /zoˈna.ri.on/ 

 ( 5 th BCE Attic ) IPA ( key ) : /zdɔː.ná.ri.on/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /zoˈna.ri.on/ 

 ( 4 th CE Koine ) IPA ( key ) : /zoˈna.ri.on/ 

 ( 10 th CE Medieval ) IPA ( key ) : /zoˈna.ri.on/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /zoˈna.ri.on/ 

 Noun
 [ edit ] 

 ζωνάρῐον • ( zōnárĭon )  n ( genitive ζωνᾰρίου ) ; second declension 

 diminutive of ζώνη ( zṓnē )
