 Etymology
 [ edit ] 

 See Old Armenian կարաս ( karas , “ water-jar ” ) for possible connections. Compare also Ancient Greek κύλιξ ( kúlix , “ a wine cup ” ) and Latin calix ( “ cup, chalice ” ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /kɐ.lɐ́.ɕɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /kɐ.l̪ɐ.ɕɐ/ 

 Noun
 [ edit ] 

 क॒लश॑ • ( kaláśa ) stem ,  m 

 a water-pot, pitcher, jar, dish (the breasts of a woman are frequently compared to jars)

 a butter-tub, churn

 a particular measure, same as a द्रोण ( droṇa ) 

 a round pinnacle on the top of a temple, especially the pinnacle crowning a Buddhist Caitya or stupa
