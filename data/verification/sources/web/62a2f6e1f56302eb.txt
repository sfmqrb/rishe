 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From مَغ ( maġ , “ hole ” ) +‎ ـاک ( -âk ) , from Middle Persian mγ ( maγ , “ hole, pit ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ma.ˈɣaːk/ 

 ( Dari, formal ) IPA ( key ) : [mä.ɣɑːk] 

 ( Dari, formal ) IPA ( key ) : [mä.ɣɑːk] 
 ( Kabuli ) IPA ( key ) : [mä.ɣɑːk] 

 ( Hazaragi ) IPA ( key ) : [mä.ɣɔːk] 

 ( Iran, formal ) IPA ( key ) : [mæ.ɢɒːkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [mä.ʁɔk] 

 Rhymes: -aːk 

 Readings

 mağāk

 Dari reading ? 

 mağāk

 Iranian reading ?

 Tajik reading ?

 Noun
 [ edit ] 

 مغاک • ( maġâk ) ( plural مغاک‌ها ) 

 hole 

 pit , ditch 
 ( Omar Khayyam , 11-12 c.) 
 از تن چو برفت جان پاک من و تو 
 خشتی دو نهند بر مغاک من و تو 
 وآنگاه برای خشت گور دگران 
 در کالبدی کشند خاک من و تو 
 az tan čo beraft jân-e pâk-e man o to 
 xešti do nehand bar mağâk-e man o to 
 v-ângâh barâye xešt-e gur-e degarân 
 dar kâlbodi kešand xâk-e man o to
 [translation needed]. 

 well (a hole dug for water and other resources)

 a deep , a trench 
 مغاک میلواکی نام ژرف‌ترین نقطه اقیانوس اطلس است 
 Mağâk-e Milvâki nâm-e žarf-tarin noqte-ye Oqyânus-e Atlas ast.
 The Milwaukee Deep is the name of the deepest point of the Atlantic Ocean. 

 Synonyms
 [ edit ] 

 (well) چاه ( čâh ) 

 (hole, pit) گودال ( gowdâl ) 

 Adjective
 [ edit ] 

 مغاک • ( maġâk ) ( comparative مغاک‌تَر , superlative مغاک‌تَرین ) 

 deep 
 Synonyms: عمیق ( 'amiq ) , ژرف ( žarf ) 

 Related terms
 [ edit ]
