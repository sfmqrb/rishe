 Pronunciation
 [ edit ] 

 IPA ( key ) : [ʃiʃ] 

 Audio : ( file ) 

 Etymology 1
 [ edit ] 

 From Proto-Turkic *sīĺ ( “ wedge, tooth ” ) .

 Noun
 [ edit ] 

 şiş ( definite accusative şişi , plural şişlər ) 

 skewer 
 a long pin, normally made of metal or wood, used to secure food during cooking.

 food served on a skewer.

 şiş ( comparative daha şiş , superlative ən şiş ) 

 tapered ( narrowing gradually towards a point ) 
 Synonyms: iti , sivri

 Etymology 2
 [ edit ] 

 From Proto-Turkic *sīĺč- ( “ to swell ” ) , whence also şişmək .

 Noun
 [ edit ] 

 şiş ( definite accusative şişi , plural şişlər ) 

 ( pathology ) tumour , tumor 

 ( pathology ) edema 

 swelling , bunion , bump

 Adjective
 [ edit ] 

 şiş ( comparative daha şiş , superlative ən şiş ) 

 puffy ( inflated in shape, as if filled with air; pillow-like ) 

 inflated , swollen ( of body parts )

 Etymology 1
 [ edit ] 

 From Ottoman Turkish شیش ( şiş , “ swollen ” ) . Related to the verb şişmek , cognate with Old Turkic [script needed] ( šïš ) .

 Adjective
 [ edit ] 

 şiş 

 swollen , swelled 
 şiş yara ― swollen wound 

 congested , puffy 

 Noun
 [ edit ] 

 şiş ( definite accusative şişi , plural şişler ) 

 neoplasm , tumor 
 Synonym: şişlik
