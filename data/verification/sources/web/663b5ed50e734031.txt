 Hindi
 [ edit ] 

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /məʃk/ , [mɐʃk] , /mə.ʃək/ , [mɐ.ʃɐk] 

 Etymology 1
 [ edit ] 

 Borrowed from Classical Persian مشک , from Middle Persian mšk' ( “ mussuck, skin bag ” ) , from Old Persian 𐎶𐏁𐎣𐎠 ( m-š-k-a , “ (inflated cow) skin ” ) . Compare Punjabi ਮਸ਼ਕ ( maśak ) .

 Noun
 [ edit ] 

 मशक • ( maśk or maśak )  f ( Urdu spelling مشک ) 

 hydration pack , waterskin , a kind of leather water -holding bag

 Etymology 2
 [ edit ] 

 Borrowed from Sanskrit मशक ( maśaka ) .

 Noun
 [ edit ] 

 मशक • ( maśak )  m ( Urdu spelling مشک ) 

 ( formal ) mosquito 
 Synonyms: ( more common ) मच्छर ( macchar ) , मश ( maś )

 [ edit ] 

 Metathesized from Proto-Indo-Aryan *makáśas , from Proto-Indo-Iranian *makáćas .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /mɐ.ɕɐ́.kɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /mɐ.ɕɐ.kɐ/ 

 Noun
 [ edit ] 

 मशक • ( maśaka ) stem ,  m 

 gnat , mosquito , fly 
 Synonym: मश ( maśa )
