 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit उच्च ( ucca ) . Doublet of ऊँचा ( ū̃cā ) , a tadbhava.

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /ʊt̪t͡ʃ/ , [ʊ(t̚)t͡ʃ] 

 Adjective
 [ edit ] 

 उच्च • ( ucc ) ( indeclinable , comparative उच्चतर , superlative उच्चतम ) 

 high , lofty 
 तुम्हारे विचार बहुत उच्च है। tumhāre vicār bahut ucc hai. You have lofty ideas. 

 loud 

 Synonyms
 [ edit ] 

 ऊंचा ( ūñcā )

 Etymology
 [ edit ] 

 Back-formed from उ॒च्चा ( uccā́ ) and उ॒च्चैस् ( uccáis ) ; [ 1 ] ultimately from Proto-Indo-European *úds -kʷeh₁ .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ut.t͡ɕɐ/ , [ut̚.t͡ɕɐ] 

 ( Classical Sanskrit ) IPA ( key ) : /ut̪.t͡ɕɐ/ , [ut̪̚.t͡ɕɐ] 

 Adjective
 [ edit ] 

 उच्च • ( ucca ) stem ( comparative उच्चतर , superlative उच्चतम ) 

 high ; elevated 

 tall 

 deep ( Caurap. )

 loud ( Bhartṛ. , VarBṛS. )

 intense ; violent
