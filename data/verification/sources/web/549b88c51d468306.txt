 Alternative forms
 [ edit ] 

 شناه ( šināh ) , شنار ( šinār ) , شناو ( šināw ) , شناب ( šināb ) , آشناه ( āšnāh ) , آشنه ( āšna ) , آشناب ( āšnāb ) , شیناب ( šīnāb ) , آشنا ( āšnā ) , اشنا ( ašna ) , شناز ( šināz ) 

 Etymology
 [ edit ] 

 Attested as Middle Persian [script needed] ( šnāz , “ swimming ” ) , from Proto-Indo-Iranian *snáHti , from Proto-Indo-European *(s)neh₂- ( “ to swim ” ) , compare Avestan 𐬯𐬥𐬁 ( snā ) and Sanskrit स्नान ( snāna , “ bathing ” ) .

 swimming 

 ellipsis of شنای سوئدی ( šenâ-ye su'edi , “ push-up ” , literally “ Swedish swimming ” )
