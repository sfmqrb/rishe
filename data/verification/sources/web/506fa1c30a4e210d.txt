 Egyptian Arabic
 [ edit ] 

 Alternative forms
 [ edit ] 

 دولا ( dōla ) 

 Etymology
 [ edit ] 

 From Arabic أولاءِ ( ʔulāʔi ) , plural of ذَا ( ḏā ) , apparently with ḏa- prefixed by analogy with the singular forms (thus *ḏaʾulāʾi > *ḏawla > dōla ). Compare the same in several other dialects.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /doːl/ 

 Determiner
 [ edit ] 

 دول • ( dōl )  pl 

 plural of ده and دي : those , these 

 Pronoun
 [ edit ] 

 دول • ( dōl )  pl 

 plural of ده and دي : those , these

 From Proto-Common Turkic *töl .
Compare Azerbaijani döl ( “ fetus ” ) .

 Noun

 دول • ( döl ) 

 fetus 

 child , young , offspring 

 lineage , descent 

 semen , sperm 

 Descendants

 Etymology 2
 [ edit ] 

 From Arabic دُوَل ( duwal ) , plural of دَوْلَة ( dawla , “ state ” ) . Arabic plural of دولت ( devlet ) .

 Noun
 [ edit ] 

 دول • ( düvel ) 

 states , powers , governments 

 Descendants
 [ edit ] 

 > Turkish: düvel ( inherited )

 Persian
