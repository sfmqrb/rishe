 Hebrew
 [ edit ] 

 Etymology 1
 [ edit ] 

 Root 

 שׁ־שׁ־ן ( sh-sh-n ) 

 2 terms 

 From Egyptian zšn . Compare Ancient Greek σοῦσον ( soûson , “ lily ” ) and Coptic ϣⲱϣⲉⲛ ( šōšen ) .

 Pronunciation
 [ edit ] 

 ( Tiberian ) IPA ( key ) : /ʃoːˈʃɔːn/ 

 ( Modern Israeli ) IPA ( key ) : /ʃoˈʃan/ 

 Noun
 [ edit ] 

 שׁוֹשָׁן • ( shoshán )  m ( plural indefinite שׁוֹשָׁנִים ) 

 lily 

 Synonyms
 [ edit ] 

 שׁוֹשַׁנָּה ( shoshaná ) 

 References
 [ edit ] 

 H7799 in Strong, James ( 1979 ), Strong’s Exhaustive Concordance to the Bible 

 Etymology 2
 [ edit ] 

 Ultimately from Elamite 𒀸𒋗𒊺𒂗 ( šušen ) . Compare Old Persian 𐏂𐎢𐏁𐎠 ( ç-u-š-a /⁠çūšā⁠/ ) and Ancient Greek Σοῦσα ( Soûsa ) .

 Pronunciation
 [ edit ] 

 ( Tiberian ) IPA ( key ) : /ʃuːˈʃɔːn/ 

 ( Modern Israeli ) IPA ( key ) : /ʃuˈʃan/
