 Gawar-Bati
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Pashto بستر , from Persian بستر .

 Noun
 [ edit ] 

 بستر ( bastar ) 

 the wooden base of a pillar ( plinth )

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian بستر ( bestar ) .

 Noun
 [ edit ] 

 بستر • ( bister ) 

 bed , a piece of furniture on which to rest or sleep 
 Synonym: یاتاق ( yatak ) 

 ( in general ) anything spread out on which one may lie or sleep 
 Synonyms: مرقد ( merkad ) , مهاد ( mihad ) , یاتاق ( yatak ) 

 Descendants
 [ edit ] 

 Turkish: bister , pister

 Persian بستر 

 From Middle Persian [script needed] ( wstl /⁠wistar⁠/ , “ bedding ” ) , from Proto-Iranian *Habí ( “ to, for ” ) + *starH- ( “ to spread ” ) , from Proto-Indo-Iranian *Habʰí ( “ to, for ” ) + Proto-Indo-European *sterh₃- ( “ to spread, stretch out ” ) . [ 1 ]
