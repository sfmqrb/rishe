 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Arabic إِقْلِيم ( ʔiqlīm ) , from Ancient Greek κλίμα ( klíma ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔiq.ˈliːm/ 

 ( Dari, formal ) IPA ( key ) : [ʔɪq.líːm] 

 ( Dari, formal ) IPA ( key ) : [ʔɪq.líːm] 
 ( Kabuli ) IPA ( key ) : [ʔɪq.líːm] 

 ( Hazaragi ) IPA ( key ) : [ʔiq.lím] 

 ( Iran, formal ) IPA ( key ) : [ʔeʁ.líːm] 

 ( Tajik, formal ) IPA ( key ) : [ʔiq.lím] 

 Rhymes: -iːm

 Noun
 [ edit ] 

 اِقْلِیم • ( iqlīm / eġlim ) ( Tajik spelling иқлим ) 

 climate

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian اِقْلِیم ( iqlīm ) , from Arabic إِقْلِيم ( ʔiqlīm ) , from Ancient Greek κλίμα ( klíma ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɪq.liːm/ 

 Noun
 [ edit ] 

 اِقْلِیم • ( iqlīm )  f ( Hindi spelling इक़्लीम ) 

 continent 

 realm , region ; clime 

 ( archaic ) country , dominion 

 a part of the body 

 Derived terms
 [ edit ] 

 ہَفْت اِقْلِیم ( haft iqlīm , “ the seven-realms ” )
