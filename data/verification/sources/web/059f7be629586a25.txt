 Ottoman Turkish
 [ edit ] 

 پاس 
 Etymology
 [ edit ] 

 Inherited from Proto-Turkic *bas ( “ residue ” ) ; cognate with Azerbaijani pas and Turkmen pos .

 Noun
 [ edit ] 

 پاس • ( pas ) ( definite accusative پاسی ( pası ) , plural پاسلر ( paslar ) ) 

 rust , tarnish , the deteriorated state of iron or steel due to oxidation 
 Synonyms: چرك ( çirk ) , ژنك ( jenk ) , صدا ( sada )

 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( pʾs /⁠pās⁠/ ) , from Old Persian *pāçah , from Proto-Iranian *páHθrah , from Proto-Indo-European *peh₂-tro- , from *peh₂- ( “ to protect ” ) ; see there for further information. Doublet of پهره ( pahre ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈpaːs/ 

 ( Dari, formal ) IPA ( key ) : [pʰɑːs]

 ( Kabuli ) IPA ( key ) : [pʰɑːs] 

 ( Hazaragi ) IPA ( key ) : [pʰɔːs] 

 ( Iran, formal ) IPA ( key ) : [pʰɒːs] 

 ( Tajik, formal ) IPA ( key ) : [pʰɔs]

 Noun
 [ edit ] 

 پاس • ( pâs ) 

 guard , watch 
 Synonyms: پهره ( pahre ) , کشک ( kešek ) , قراولی ( qarâvoli ) , پاسبانی ( pâsbâni ) , نگهبانی ( negahbâni ) 

 watch of the night 
 1258 , Shaykh Muṣliḥ-ud-Dīn Saʿdī of Shiraz , translated by Wheeler M. Thackston, The Gulistan (Rose Garden) of Sa’di: Bilingual English and Persian Edition with Vocabulary , Bethesda, MD: Ibex Publishers, published 2008 , →ISBN , page 15 : پاسی از شب بگذشت. pasē az šab biguḏašt. A portion of the night passed. (Classical Persian romanization) 

 ( chiefly as به پاس ) consideration , considering 
 به پاس خدمات شما ― be pâs -e xedmât-e šomâ ― in consideration of your service
