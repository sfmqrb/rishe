 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کنون ( kunūn ) , نون ( nūn ) 

 Etymology
 [ edit ] 

 From نون , ultimately from Proto-Indo-European *nu ( “ now ” ) . This etymology is incomplete. You can help Wiktionary by elaborating on the origins of this term. Particularly: “Where does the first element come from?” 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔak.ˈnuːn/ 

 ( Dari, formal ) IPA ( key ) : [ʔäk.núːn] 

 ( Dari, formal ) IPA ( key ) : [ʔäk.núːn] 
 ( Kabuli ) IPA ( key ) : [ʔäk.núːn] 

 ( Hazaragi ) IPA ( key ) : [ʔä.kʰú] 

 ( Iran, formal ) IPA ( key ) : [ʔækʰʲ.núːn] 

 ( Tajik, formal ) IPA ( key ) : [ʔäk.nún] 

 Rhymes: -uːn

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian اَکْنُون ( aknūn ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ək.nuːn/ 

 Adverb
 [ edit ] 

 اَکْنُون • ( aknūn ) ( Hindi spelling अकनून or अक्नून ) 

 now , at this moment , at present
