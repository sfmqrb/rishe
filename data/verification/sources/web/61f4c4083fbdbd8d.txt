 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 گسی ( gusē ) 

 Etymology
 [ edit ] 

 The additional 'l' phoneme most probably appeared due to influence from the present stem of گسستن ( gosastan , “ to separate, split, to disconnect, to take apart ” ) , i.e. گسل ( gosil ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡu.ˈsiːl/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.síːl] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.síːl] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.síːl] 

 ( Hazaragi ) IPA ( key ) : [ɡu.síl̥] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.síːl̥] 

 ( Tajik, formal ) IPA ( key ) : [ɡu.síl]

 Noun

 گسیل • ( gosîl ) 

 dispatching , sending away 
 Synonym: اعزام ( e'zâm )
