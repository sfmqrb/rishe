 Etymology 1
 [ edit ] 

 Inherited from Proto-Semitic *śamš- .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʃams/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 شَمْس • ( šams )  f ( plural شُمُوس ( šumūs ) ) 

 sun 
 تُشْرِقُ ٱلشَّمْسُ كُلَّ صَبَاحٍ وَتُنِيرُ ٱلْعَالَمَ بِنُورِهَا. tušriqu š-šamsu kulla ṣabāḥin watunīru l-ʕālama binūrihā. The sun rises every morning and illuminates the world with its light.
