 Etymology 1
 [ edit ] 

 השמש זורחת בשמיים 

 Root 

 שׁ־מ־שׁ ( sh-m-sh ) 

 10 terms 

 From Proto-Semitic *śamš- .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /ʃamʃ/ 

 ( Tiberian ) IPA ( key ) : /ˈʃɛmɛʃ/ , [ˈʃɛːmɛʃ] 

 ( Modern Israeli ) IPA ( key ) : /ˈʃemeʃ/ 

 Noun
 [ edit ] 

 שֶׁמֶשׁ • ( shémesh )  f ( plural indefinite שְׁמָשׁוֹת , Biblical Hebrew pausal form שָׁמֶש ) [pattern: קֶטֶל ] 

 sun 
 Synonym: חַמָּה ( khamá ) 
 Tanach , Ecclesiastes 1:5 , with the JPS 1917 translation ( Sefaria ): וְזָרַח הַשֶּׁמֶשׁ וּבָא הַשָּׁמֶשׁ וְאֶל־מְקוֹמוֹ שׁוֹאֵף זוֹרֵחַ הוּא שָׁם׃ v'zarákh hashémesh uva hashámesh v'el m'komó sho'éf zoréakh hu sham The sun also ariseth, and the sun goeth down, and hasteth to his place where he ariseth. 

 a. 500 C.E. , Babylonian Talmud . Ta'anit , 8b: וְאָמַר רַבִּי יִצְחָק: שֶׁמֶשׁ בְּשַׁבָּת — צְדָקָה לַעֲנִיִּים v'amár rabí yitskhák: shémesh b'shabát — ts'daká la'aniyím and R. Isaac said: Sabbath sun is charity for the poor.

 Etymology 2
 [ edit ] 

 Root 

 שׁ־מ־שׁ ( sh-m-sh ) 

 10 terms 

 Compare שימש / שִׁמֵּשׁ ( shimésh , “ to serve; to be used ” ) from the same root.

 Noun
 [ edit ] 

 שַׁמָּשׁ • ( shamásh )  m [pattern: קַטָּל ] 

 public servant 

 ( Judaism ) sexton , beadle 

 ( Judaism ) shamash ( the candle used to light the other eight candles of a Hanukkah menorah or hanukkiah ) 

 ( Mishnaic ) waiter 
 Synonym: מֶלְצַר ( meltsár )
