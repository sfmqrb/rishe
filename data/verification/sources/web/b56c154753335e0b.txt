 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( glʾmyk' /⁠grāmīg⁠/ , “ treasured, dear ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡa.raː.ˈmiː/ , /ɡi.raː.ˈmiː/ 

 ( Dari, formal ) IPA ( key ) : [ɡä.ɾɑː.míː] , [ɡɪ.ɾɑː.míː] 

 ( Dari, formal ) IPA ( key ) : [ɡä.ɾɑː.míː] , [ɡɪ.ɾɑː.míː] 
 ( Kabuli ) IPA ( key ) : [ɡä.ɾɑː.míː] , [ɡɪ.ɾɑː.míː] 

 ( Hazaragi ) IPA ( key ) : [ɡä.ɾɔː.mí] , [ɡi.ɾɔː.mí] 

 ( Iran, formal ) IPA ( key ) : [ɡʲæ.ɹɒː.míː] , [ɡʲe.ɹɒː.míː] 

 ( Tajik, formal ) IPA ( key ) : [ɡä.ɾɔ.mí] , [ɡi.ɾɔ.mí] 

 Rhymes: -iː 

 Readings

 Classical reading ? 

 garāmī, girāmī

 Dari reading ? 

 garāmī, girāmī

 Iranian reading ? 

 garâmi, gerâmi

 Tajik reading ? 

 garomi, giromi

 Adjective
 [ edit ] 

 گرامی • ( gerâmi ) 

 precious , excellent 

 dear , beloved , respected ; often used as an epithet of respect. 
 با تشکر از تمام اساتید گرامی و دانشجویان عزیز [ … ] bâ tašakkor az tamâm-e asâtid-e gerâmi va dânešjuyân-e aziz [ … ] with thanks to all of [our] respected professors and dear students [ … ] 

 Derived terms
 [ edit ] 

 گرامی داشتن ( gerâmi dâštan , “ to commemorate, to respect ” ) 

 Further reading
 [ edit ]
