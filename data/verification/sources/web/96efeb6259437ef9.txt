 Pronunciation

 ( Classical Persian ) IPA ( key ) : /paʒ.mur.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [pʰäʒ.mʊɾ.d̪án] 

 ( Dari, formal ) IPA ( key ) : [pʰäʒ.mʊɾ.d̪án] 
 ( Kabuli ) IPA ( key ) : [pʰäʒ.mʊɾ.d̪án] 

 ( Hazaragi ) IPA ( key ) : [pʰäʒ.muɾ.d̪án] 

 ( Iran, formal ) IPA ( key ) : [pʰæʒ.moɹ.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [pʰäʒ.muɾ.d̪án]

 Verb
 [ edit ] 

 پژمردن • ( pažmurdan  / pažmordan ) ( present stem پژمر ( pažmur  / pažmor ) , Tajik spelling пажмурдан ) 

 to wither , to fade 

 to blight
