 Etymology
 [ edit ] 

 Borrowed from Aramaic כִּבְּרִיתָא ( kiḇrīṯā ) / ܟܶܒܪܺܝܬܳܐ ( kĕḇrīṯā , “ sulfur ” ) , from Akkadian 𒆠𒀀𒀭𒀀𒇉 ( kibrītu , “ sulfur; firebrand ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kib.riːt/ 

 Noun
 [ edit ] 

 كِبْرِيت • ( kibrīt )  m 

 sulfur 

 match ( device to make fire )
