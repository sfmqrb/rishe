 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian mwšk' ( mušk , “ musk ” ) , from Sanskrit मुष्क ( muṣka ) . Compare Old Armenian մուշկ ( mušk ) , Old Georgian მუშკი ( mušḳi ) , Iranian borrowings and also English musk .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈmuʃk/ 

 ( Dari, formal ) IPA ( key ) : [mʊʃk] 

 ( Dari, formal ) IPA ( key ) : [mʊʃk] 
 ( Kabuli ) IPA ( key ) : [mʊʃk] 

 ( Hazaragi ) IPA ( key ) : [muʃk] 

 ( Iran, formal ) IPA ( key ) : [moʃkʰʲ] , [meʃkʰʲ] 

 ( Tajik, formal ) IPA ( key ) : [muʃk] 

 Rhymes: -uʃk

 Noun
 [ edit ] 

 مشک • ( mošk ) 

 musk 
 1259 , Saadi Shirazi , Gulistan ; also a Persian proverb:
 مشک آن است که خود ببوید، نه آنکه عطار بگوید. mošk ân ast ke xod bebuyad, na ânke 'attâr beguyad. [The good] musk is the one which smells by itself, not by the words [compliments] of the perfumer.

 Etymology 3
 [ edit ] 

 From Middle Persian mšk' ( mašk , “ mussuck, skin bag ” ) , from Old Persian 𐎶𐏁𐎣𐎠 ( maškā- , “ (inflated cow) skin ” ) , ultimately Semitic borrowing; compare Proto-Semitic *mašk- .
