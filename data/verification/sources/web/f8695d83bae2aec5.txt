 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 بغبور ( baġbur ) , بغپور ( baġpur ) , فغپور ( faġpur ) 

 Etymology
 [ edit ] 

 Borrowed from Sogdian 𐼱𐼲𐼾𐼰𐼴𐽀 ( βɣpʾwr /⁠βaγpūr⁠/ ) ; see there for further information.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /faɣ.ˈfuːr/ 

 ( Dari, formal ) IPA ( key ) : [fäɣ.fúːɾ] 

 ( Dari, formal ) IPA ( key ) : [fäɣ.fúːɾ] 
 ( Kabuli ) IPA ( key ) : [fäɣ.fúːɾ] 

 ( Hazaragi ) IPA ( key ) : [fäɣ.fúɾ] 

 ( Iran, formal ) IPA ( key ) : [fæɢ.fúːɹ] 

 ( Tajik, formal ) IPA ( key ) : [fäʁ.fúɾ] 

 Rhymes: -uːr

 Noun
 [ edit ] 

 فغفور • ( faġfūr / faġfur ) ( Tajik spelling фағфур ) [ 1 ] 

 emperor of China 

 Derived terms
 [ edit ] 

 فَغْفُورِی ( “ Chinese porcelain ” ) 
 Ottoman Turkish: فغفوری ( fağfuri ) 
 Turkish: fağfuri 

 → Greek: φαρφουρί ( farfourí , “ thin porcelain ” ) 

 → Russian: фарфо́р ( farfór , “ porcelain ” )
