 Arabic برقوق 

 Borrowed from Classical Syriac ܒܰܪܩܽܘܩܳܐ ( barqūqā ) , from Byzantine Greek βερικοκκῐ́ᾱ ( berikokkĭ́ā , “ apricot tree ” ) , from Ancient Greek βερίκοκκον ( beríkokkon ) + -ία ( -ía ) .

 Pronunciation
 [ edit ] 

 ( most common ) IPA ( key ) : /bar.quːq/ 

 ( classicized ) IPA ( key ) : /bur.quːq/ 

 Noun
 [ edit ] 

 بُرْقُوق or بَرْقُوق • ( burqūq or barqūq )  m ( collective , singulative بُرْقُوقَة   f ( burqūqa ) or بَرْقُوقَة   f ( barqūqa ) ) 

 plum , plums 
 Synonyms: ( Syria, Jordania, Oman ) خَوْخ ( ḵawḵ ) , ( Al-Andalus, Iraq ) إِجَّاص ( ʔijjāṣ ) , ( Tunisia, Libya, Al-Andalus ) عَيْن الْبَقَر ( ʕayn al-baqar ) , ( Al-Andalus ) عَبْقَر ( ʕabqar ) 

 ( West-Yemen , al-Andalus , Sicily , Mauritania , Western Sahara ) apricot , apricots 
 Synonym: ( elsewhere ) مِشْمِش ( mišmiš ) 

 ( Mauritania , Western Sahara ) peach , peaches 
 Synonyms: ( general ) خَوْخ ( ḵawḵ ) , ( Levant ) دُرَّاق ( durrāq ) , ( Southwest Arabia, Al-Andalus ) فِرْسِك ( firsik )
