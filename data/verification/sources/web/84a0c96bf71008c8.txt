 Noun
 [ edit ] 

 گوشواره • ( gōšwāra / gušvâre ) ( plural گوشواره‌ها ( gōšwāra-hā / gušvâre-hâ ) , Tajik spelling гӯшвора ) 

 earring 
 Synonym: منگوش ( manguš ) 

 squinch 
 Synonyms: گوشه ( guše ) , سکنج ( sekonj )
