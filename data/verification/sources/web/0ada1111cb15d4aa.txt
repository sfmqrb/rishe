 Alternative forms
 [ edit ] 

 پاشنا ( pāšnā  / pâšnâ ) 

 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *pā́ršniš , from Proto-Indo-European *tpḗrsneh₂ .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paːʃ.ˈna/ 

 ( Dari, formal ) IPA ( key ) : [pʰɑːʃ.ná] 

 ( Dari, formal ) IPA ( key ) : [pʰɑːʃ.ná] 
 ( Kabuli ) IPA ( key ) : [pʰɑːʃ.ná] 

 ( Hazaragi ) IPA ( key ) : [pʰɔːʃ.ná] 

 ( Iran, formal ) IPA ( key ) : [pʰɒːʃ.né] 

 ( Tajik, formal ) IPA ( key ) : [pʰɔʃ.ná] 

 Rhymes: -a
