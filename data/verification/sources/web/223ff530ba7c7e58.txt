 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ὀσχέα ( oskhéa ) , ὄσχεον ( óskheon ) , ὄσχεος ( óskheos ) 

 Etymology
 [ edit ] 

 Explained by Frisk as metaphorical use of ὄσχος ( óskhos , “ vine-branch ” ) . According to Beekes, the word may well be of Pre-Greek origin.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ós.kʰɛː/ → /ˈos.çi/ → /ˈos.çi/ 

 ( 5 th BCE Attic ) IPA ( key ) : /ós.kʰɛː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈos.kʰe̝/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈos.çi/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈos.çi/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈos.çi/ 

 Noun
 [ edit ] 

 ὄσχη • ( óskhē )  f ( genitive ὄσχης ) ; first declension 

 ( anatomy ) scrotum 

 Inflection
 [ edit ] 

 First declension of ἡ ὄσχη ; τῆς ὄσχης ( Attic )
