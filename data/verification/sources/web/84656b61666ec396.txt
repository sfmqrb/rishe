 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From نِیازْ ( niyâz , “ need ” ) +‎ ـمند ( mand ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ni.jaːz.ˈmand/ 

 ( Dari, formal ) IPA ( key ) : [ni.jɑːz.mán̪d̪] 

 ( Dari, formal ) IPA ( key ) : [ni.jɑːz.mán̪d̪] 
 ( Kabuli ) IPA ( key ) : [ni.jɑːz.mán̪d̪] 

 ( Hazaragi ) IPA ( key ) : [ni.jɔːz.mán̪d̪̥] 

 ( Iran, formal ) IPA ( key ) : [ni.jɒːz.mǽn̪d̪̥] 

 ( Tajik, formal ) IPA ( key ) : [ni.jɔz.mán̪d̪] 

 Rhymes: -and

 Noun
 [ edit ] 

 نیازمند • ( niyāzmand / niyâzmand ) ( plural نیازمند‌ان , or نیازمند‌ها , Tajik spelling ниёзманд ) 

 pauper 

 Adjective
 [ edit ] 

 نیازمند‌ • ( niyāzmand / niyâzmand ) ( comparative نیازمند‌تَر , superlative نیازمند‌تَرین , Tajik spelling ниёзманд ) 

 in need , indigent 

 Proper noun
 [ edit ] 

 نیازمند • ( niyāzmand  / niyâzmand ) ( Tajik spelling Ниёзманд ) 

 a surname , Niazmand
