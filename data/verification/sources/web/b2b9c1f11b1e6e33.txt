 Arabic
 [ edit ] 

 Root 

 ج ب ر ( j b r ) 

 13 terms 

 Alternative forms
 [ edit ] 

 جِبْرِيل ( jibrīl ) , جَبْرِيل ( jabrīl ) , جَبْرَئِيل ( jabraʔīl ) , جَبْرَئِل ( jabraʔil ) , جَبْرَئِلّ ( jabraʔill ) , جِبْرَايِيل ( jibrāyīl ) , جَبْرِين ( jabrīn ) , جِبْرِين ( jibrīn ) [ 1 ] 

 Etymology
 [ edit ] 

 From Hebrew גַּבְרִיאֵל ( gavri'él, gaḇrīʾēl ) , from גַּבְרִ י אֵל ( gavrí 'él, gaḇrī ʾēl , “ my hero is God ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /d͡ʒab.raː.ʔiːl/ , /d͡ʒib.raː.ʔiːl/ 

 Proper noun
 [ edit ] 

 جَبْرَائِيل or جِبْرَائِيل • ( jabrāʔīl or jibrāʔīl )  m 

 ( Islam , Christianity , Judaism ) the archangel Gabriel 

 a male given name , equivalent to English Gabriel
