 Wikipedia ar 

 Etymology
 [ edit ] 

 From a Middle Iranian past participle āfrīd ( “ created ” ) , originally an elliptic expression for *dīw afrīt ( “ demon’s creation ” ) , or from the root ع ف ر ( ʕ f r ) related to “ash”, compare for the derivation type عَكْرُوت ( ʕakrūt , “ scoundrel ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕif.riːt/ 
 ( Morocco ) IPA ( key ) : /ʕaf.riːt/ 

 Adjective
 [ edit ] 

 عِفْرِيت • ( ʕifrīt ) ( feminine عِفْرِيتَة ( ʕifrīta ) , masculine plural عَفَارِيت ( ʕafārīt ) , feminine plural عِفْرِيتَات ( ʕifrītāt ) ) ( Classical , formal , dialectal ) 

 malicious , mischievous , wicked , knave 

 crafty , cunning , sly , wily 

 clever , fast , strong

 Noun
 [ edit ] 

 عِفْرِيت • ( ʕifrīt )  m ( plural عَفَارِيت ( ʕafārīt ) , feminine عِفْرِيتَة ( ʕifrīta ) ) ( paganism , mythology ) 

 afreet , afrit , 'afrit , efreet , ifreet , ifrit ; Supernatural being from Arabian folklore.

 demon , devil , fiend , evil spirit ; Any infernal being regardless of its morals.
 Synonyms: شَيْطَان ( šayṭān ) , مَارِد ( mārid ) 

 goblin , sprite , genie , gremlin , elf ; Any supernatural being in general.
 Synonym: جَانّ ( jānn )
