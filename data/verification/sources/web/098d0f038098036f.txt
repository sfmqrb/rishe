 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 آیین ( âyin ) 

 Etymology
 [ edit ] 

 Akin to Old Armenian օրէն ( ōrēn ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔaː.ˈʔiːn/ , /ʔaː.ˈjiːn/ 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ʔiːn] , [ʔɑː.jiːn] 

 ( Dari, formal ) IPA ( key ) : [ʔɑː.ʔiːn] , [ʔɑː.jiːn] 
 ( Kabuli ) IPA ( key ) : [ʔɑː.jiːn] , [ʔɑː.jiːn] 

 ( Hazaragi ) IPA ( key ) : [ʔɔː.jin] , [ʔɔː.jin] 

 ( Iran, formal ) IPA ( key ) : [ʔɒː.ʔiːn] , [ʔɒː.jiːn] 

 ( Tajik, formal ) IPA ( key ) : [ʔɔ.ʔin] , [ʔɔ.jin] 

 Rhymes: -iːn 

 Readings

 Classical reading ? 

 ā'īn, āyīn

 Dari reading ? 

 ā'īn, āyīn

 Iranian reading ? 

 â'in, âyin

 Tajik reading ? 

 o'in, oyin

 Noun
 [ edit ] 

 Dari

 آئین , آیین 

 Iranian Persian

 Tajik

 оъин , оин 

 آئین • ( ā'īn, āyīn / â'in, âyin ) ( Tajik spelling оин , or оин ) 

 institution , rite , ceremony , custom , ordinance , canon , usage , prescription 

 common law (in contradistinction to Islamic sharia )

 mode , form , manner 

 ornament , decoration
