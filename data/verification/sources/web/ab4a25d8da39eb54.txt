 Etymology
 [ edit ] 

 From the root  ग्रन्थ् ( granth , “ to tie, string together ” ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɡɾɐn.tʰí/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɡɾɐn̪.t̪ʰi/ 

 Noun
 [ edit ] 

 ग्र॒न्थि • ( granthí ) stem ,  m 

 knot
