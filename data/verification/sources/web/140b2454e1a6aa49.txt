 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Present stem of فریفتن . From Middle Persian [script needed] ( plyp /⁠frēb⁠/ , “ deceit, deception ” ) , from Proto-Iranian *fra- ( “ toward ” , from Proto-Indo-European *pro- ) + *dab ( “ to deceive ” , from Proto-Indo-European *dʰebʰ- ( “ to deceive; to harm ” ) ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /fa.ˈreːb/ , /fi.ˈreːb/ 

 ( Dari, formal ) IPA ( key ) : [fä.ɾeːb] , [fɪ.ɾeːb] 

 ( Dari, formal ) IPA ( key ) : [fä.ɾeːb] , [fɪ.ɾeːb]

 ( Tajik, formal ) IPA ( key ) : [fä.ɾeb] , [fi.ɾeb]

 Noun
 [ edit ] 

 فریب • ( farēb, firēb / farib, ferib ) ( Tajik spelling фареб , or фиреб ) 

 deception ; deceit ; perfidy 
 Synonyms: نیرنگ ( neyrang ) , خدعه ( xod'e ) , مکر ( makr ) 
 c. 1390 , Hafez , “Ghazal 6”, in دیوان حافظ [ The Divān of Hafez ]‎ [1] : مژهٔ سیاهت ار کرد به خون ما اشارت
ز فریب او بیندیش و غلط مکن نگارا muža-yi sîyâh-at ar kard ba xûn-i mâ išârat
zi firêb -i ô biyandêš u ġalat ma-kun nigâr-â If [the arrow of] your black eyebrow should aim for my blood,
Consider its perfidy [i.e. the speaker hopes the eyebrow is “deceitful” and does not reflect the beloved’s real attitude towards him], and make no error, my love. (romanization in Classical Persian)

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian فریب ( fareb, firēb ) . First attested in c. 1692 as Middle Hindi فریب ( fryb ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /fə.ɾeːb/ 

 Rhymes: -eːb 

 Hyphenation: فَ‧ریب 

 Noun
 [ edit ] 

 فَریب • ( fareb )  m ( Hindi spelling फ़रेब ) 

 deceit , deception 
 Synonyms: دھوکَہ ( dhoka ) , دَغا ( daġā ) 

 ( in compounds ) used a suffix to indicate temptation
