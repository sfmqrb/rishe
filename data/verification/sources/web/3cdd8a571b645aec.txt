 Etymology
 [ edit ] 

 Compare to Bactrian πορλαγγο-ζινο ( porlango-zino ) , Pashto پړانګ ( pṙâng ) , Sanskrit पृदाकु ( pṛdāku , “ panther ” ) , and Ancient Greek πάρδαλις ( párdalis ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /pa.ˈlanɡ/ 

 ( Dari, formal ) IPA ( key ) : [pʰä.láŋɡ] 

 ( Dari, formal ) IPA ( key ) : [pʰä.láŋɡ] 
 ( Kabuli ) IPA ( key ) : [pʰä.láŋɡ] 

 ( Hazaragi ) IPA ( key ) : [pʰä.láŋɡ̥] 

 ( Iran, formal ) IPA ( key ) : [pʰæ.lǽɲɡʲ̥] 

 ( Tajik, formal ) IPA ( key ) : [pʰä.láŋɡ] 

 Rhymes: -anɡ
