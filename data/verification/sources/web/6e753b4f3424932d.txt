 Root
 [ edit ] 

 *sekʷ- [ 1 ] 

 to see 

 Notes
 [ edit ] 

 Some sources relate this root to the one above, suggesting that the meaning "see" derives from "follow with the eyes". It has been argued that this an unlikely development, given that "see" is a more basic and primary meaning than "follow", which is more abstract. [ 2 ] However, there is no constraint against basic meanings developing from abstract ones; compare e.g. Latvian redzēt ( “ see ” ) from *h₃reǵ- ( “ stretch, etc. ” ) , and Tocharian AB läk- ( “ see ” ) from *leǵ- ( “ gather ” ) . Compare Ancient Greek ἕπομαι ( hépomai , “ to watch another's movement ” ) .
