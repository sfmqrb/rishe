 Persian
 [ edit ] 

 Etymology 1
 [ edit ] 

 From Middle Persian [script needed] ( gndk' /⁠gandag⁠/ , “ foul, stinking ” ) , from Proto-Indo-Iranian *g(ʰ)andʰ- ( “ to smell ” ) ; see Sanskrit गन्ध ( gandhá ) for more. [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡan.ˈda/ 

 ( Dari, formal ) IPA ( key ) : [ɡän̪.d̪ä] 

 ( Dari, formal ) IPA ( key ) : [ɡän̪.d̪ä] 
 ( Kabuli ) IPA ( key ) : [ɡän̪.d̪ä] 

 ( Hazaragi ) IPA ( key ) : [ɡän̪.d̪ä] 

 ( Iran, formal ) IPA ( key ) : [ɡʲæn̪.d̪e] 

 ( Tajik, formal ) IPA ( key ) : [ɡän̪.d̪ä] 

 Rhymes: -a

 Adjective
 [ edit ] 

 گَنده • ( gande ) ( comparative گَنده‌تَر , superlative گَنده‌تَرین ) 

 fetid , stenchy 

 rotten , decayed , putrid 

 ( Tajik ) bad 

 Derived terms
 [ edit ] 

 گندگی ( gandegi, gandagi , “ stench, putridity ” ) 

 Descendants
 [ edit ]

 Uyghur: گەندە ( gende ) 

 Uzbek: ganda 

 → Turkmen: gende 

 Adverb
 [ edit ] 

 گَنده • ( ganda ) 

 ( Tajik ) very
