 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Sanskrit यवन ( yavana ) , itself from Ashokan Prakrit 𑀬𑁄𑀦 ( yona ) , from Old Persian 𐎹𐎢𐎴 ( y-u-n /⁠yauna⁠/ ) . Doublet of یونان ( yūnān ) and جون ( javan ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /jə.ʋən/ 

 Rhymes: -ən 

 Noun
 [ edit ] 

 یَوَن • ( yavan )  m ( Hindi spelling यवन ) ( rare ) 

 a foreigner , an outsider not part of the four-tiers of varna 
 Synonyms: پَردیشی , پَردیسی , ولایتی ( olāetī ) , فَرَنگِی ( farangī ) , بِدیسی ( bidesī ) , وِدیشی ( videśī ) 
 a Greek , an Ionian 
 Synonym: یُونانی ( yūnānī ) 

 a Bactrian 
 Synonym: باختری 

 a Parthian , a Pahlavi 
 Synonyms: پہلوی , پہلو 

 a Scythian 
 Synonyms: شاک ( śāk ) , شک 

 an Arab , a Turk , a Muslim 
 Synonyms: عَرَب ( 'arab ) , تُرْک ( turk ) , تُرْکِی ( turkī ) , مُسْلِم ( muslim ) , مُسَلْمَان ( musalmān ) , مُؤْمِن ( mumin ) 

 a European , a Westerner 
 Synonyms: یُورَپی ( yūrapī ) , مَغرِبی 

 barbarian , uncultured 

 ( figurative , Hinduism ) a follower of a religion of foreign (usually of non- Dharmic origin )
