 Noun
 [ edit ] 

 نژاد • ( nižād / nežâd ) ( plural نژادها ( nižād-hā / nežâd-hâ ) , Tajik spelling нажод , or нижод ) 

 ( archaic ) lineage 

 race ( ethnic category )

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian نِژاد ( nižād , “ lineage ” ) . 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /nɪ.ʒɑːd̪/ , /nə.ʒɑːd̪/ 

 Audio ( Pakistan ) : ( file ) 

 Rhymes: -ɑːd̪ 

 Noun
 [ edit ] 

 نِژاد or نَژاد • ( niźād or naźād )  m or f ( Hindi spelling निझ़ाद or नझ़ाद ) 

 race 

 family ; genealogy , lineage ; descent 

 root , origin ; seed 

 Derived terms
 [ edit ] 

 بَد نِژاد ( bad niźād , “ low-born, lowly ” ) 
 سِکَنْدَر نِژاد ( sikandar niźād , “ brave ” , literally “ [of the] race of Alexander the Great ” ) 
 نِژاد پَرَسْت ( niźād parast , “ racist ” ) 
 نِژادَہ ( niźāda , “ noble ” ) 
 نِژادِ نَو ( niźād-i nau , “ new generation ” )
