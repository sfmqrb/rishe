 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian lcm ( razm ) . Akin to Old Armenian ռազմ ( ṙazm ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈrazm/ 

 ( Dari, formal ) IPA ( key ) : [räzm] 

 ( Dari, formal ) IPA ( key ) : [räzm] 
 ( Kabuli ) IPA ( key ) : [räzm] 

 ( Hazaragi ) IPA ( key ) : [räzm] 

 ( Iran, formal ) IPA ( key ) : [ɹæzm] 

 ( Tajik, formal ) IPA ( key ) : [ɾäzm] 

 Rhymes: -azm

 Noun
 [ edit ] 

 رزم • ( razm ) ( plural رزم‌ها ( razm-hā / razm-hâ ) , Tajik spelling разм ) 

 war , battle , combat 
 Synonyms: نبرد ( nabard ) , پیکار ( peykâr ) , آورد ( âvard ) , کارزار ( kârzâr ) , جنگ ( jang )
