 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Turkic *kagan 
 Old Anatolian Turkish خان ( ḫān ) 
 Ottoman Turkish خان ( han ) 

 Ottoman Turkish ـم ( -m ) 

 Ottoman Turkish خانم 

 Inherited from Old Anatolian Turkish خانم ( xānım ) . Compare Chagatai خانم ( xānım ) . By surface analysis , خان ( han , “ king, ruler ” ) +‎ ـم ( ım , “ first person singular possessive suffix ” ) . [ 1 ] 

 Noun
 [ edit ] 

 خانم • ( hanım ) 

 lady , woman 

 Miss , Mrs , Lady 

 wife

 Persian

 Alternative forms

 خانوم ( xânum ) 

 Etymology
 [ edit ] 

 Borrowed from Turkic languages. Compare Old Anatolian Turkish خانم ( ḫānum ) , Chagatai خانِم ( xānım ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /xaː.ˈnum/

 ( Iran, formal ) IPA ( key ) : [xɒː.nóm] 

 ( Tajik, formal ) IPA ( key ) : [χɔ.núm]

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian خانم ( xānum ) .

 Noun
 [ edit ] 

 خانَم • ( xānam )  f ( Hindi spelling ख़ानम ) 

 a lady, a woman of rank, a princess; title of the wife of a ḵẖān
