 Baluchi
 [ edit ] 

 Etymology 1
 [ edit ] 

 Unclear. Cognate with dialectal Persian گند ( gond ) and Southwestern Fars گند ( gond ) . See Middle Persian gwnd for further etymology.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡʊnd̪/ , [ɡʊnd̪] 

 Rhymes: -ʊnd̪ 

 Noun
 [ edit ] 

 گند • ( gund ) 

 ( anatomy ) testicle , testis ; ( vulgar slang ) ball , bollock 
 آئیءَ منی گنداں را لگت جت! áí'a maní gundán rá lagat jat! He kicked me in the bollocks ! 

 Derived terms
 [ edit ] 

 گندبری ( gundburrí ) 

 References
 [ edit ] 

 Uppsala University ( 2026 ), “ گند ”, in Southern Baluchi Dictionary (Webonary) (in Baluchi), Dallas, Texas, USA: SIL International, published 2019 . 

 Dames, Mansel Longsworth ( 1922 ), “ Gund ”, in A text book of the Balochi language : consisting of miscellaneous stories, legends, poems and Balochi-English vocabulary , Lahore: Government Printing Press, Punjab 

 Etymology 2
 [ edit ] 

 Back-formation from گندگ ( gandag , “ dirty , filthy , bad ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ɡənd̪/ , [ɡənd̪] 

 Rhymes: -ənd̪ 

 Noun
 [ edit ] 

 گند • ( gand ) 

 dirt , filth 

 References
 [ edit ] 

 Uppsala University ( 2026 ), “ گند ”, in Southern Baluchi Dictionary (Webonary) (in Baluchi), Dallas, Texas, USA: SIL International, published 2019 . 

 Dames, Mansel Longsworth ( 1922 ), “ Gand ”, in A text book of the Balochi language : consisting of miscellaneous stories, legends, poems and Balochi-English vocabulary , Lahore: Government Printing Press, Punjab

 present stem of گندگ ( gindag ) 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian gwnd ( /⁠gund⁠/ ) .

 Noun
 [ edit ] 

 گند • ( gond ) ( plural گندها ) 

 ( anatomy , archaic , dialectal , Kazerun , Khesht , Konartakhteh ) testicle 
 Synonyms: خایه ( xâye ) , تُخم ( toxm ) , بیضه ( beyze ) 

 Derived terms
 [ edit ] 

 گُنداوری ( gondâvari ) , گُنداور ( gondâvar ) 

 References
 [ edit ] 

 Dehkhoda, Ali-Akbar ( 1931– ), “ گند ”, in Dehkhoda Dictionary Institute , editors, Dehkhoda Dictionary (in Persian), Tehran: University of Tehran Press . 

 Southwestern Fars
 [ edit ] 

 Noun
 [ edit ] 

 گند ( gond ) 

 ( anatomy , Masarm , Deh Sarv , Kuzarg ) testicle 

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Sanskrit गन्ध ( gandha , “ smell, stink ” ) . Cognate with Persian گنده ( gande , “ stenchy ” ) .

 Noun
 [ edit ] 

 گند • ( gãnd )  m ( Hindi spelling गंद ) 

 stink 

 stench 

 filth
