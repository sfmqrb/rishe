 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *h₁neḱ- [ 1 ] [ 2 ] [ 3 ] [ 4 ] 

 to receive , take away 

 Reconstruction notes
 [ edit ] 

 Conflated with *h₂neḱ- ( “ to reach, attain ” ) by Pokorny. [ 5 ] 

 Derived terms
 [ edit ] 

 Terms derived from the Proto-Indo-European root *h₁neḱ- (24 c, 0 e)

 Ancient Greek: ἐνεγκεῖν ( enenkeîn , infinitive ) , ἤνεγκα ( ḗnenka ) ( aorist of φέρω ( phérō ) ) 

 *h₁e-h₁nóḱ-e ~ *h₁e-h₁n̥ḱ-ḗr ( stative ) 
 Proto-Hellenic: 
 ⇒ Ancient Greek: κατ-ήνοκα ( kat-ḗnoka ) 

 Ancient Greek: ἐνήνοχα ( enḗnokha ) ( with secondary reduplication and aspiration ) 

 *h₁néḱ-e-ti ( thematic present ) 
 Proto-Balto-Slavic: *neśtei ( see there for further descendants )

 *h₁noḱ-éye-ti ( o-grade iterative ) 
 Balto-Slavic:
 Proto-Slavic: *nosìti ( see there for further descendants )
