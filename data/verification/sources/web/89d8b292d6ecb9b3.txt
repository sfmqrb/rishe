 Etymology 1
 [ edit ] 

 From Middle Persian 𐭥𐭧𐭱𐭲𐭩 ( wahišt ) ; see there for more. From Old Persian *vahištah , from Proto-Iranian *Hwáhišt-Háhuš ( “ بهست-هستی ” , literally “ best existence ” ) . Cognate with Northern Talysh وییشت ( vaiišt ) and Baluchi گْوَهِشت ( gwahišt , “ heaven ” ) . Compare Gujarati વહિશ્ત ( vahiśt ) .

 Noun
 [ edit ] 

 بهشت • ( bihišt / behešt ) ( Tajik spelling биҳишт ) 

 paradise , heaven 
 Synonym: جَنَّت ( jannat ) 
 Antonyms: دوزَخ ( dōzax  / duzax ) , جَهَنَّم ( jahannam )
