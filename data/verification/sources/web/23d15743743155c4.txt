 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 A result noun from the same root as ῥέζω ( rhézō , “ to dye, color ” ) , meaning something like "that which has been dyed." [ 1 ] However, this is morphologically not entirely straightforward, as the vowel ῆ ( ê ) and the exact stem alternation ῥεζ- ( rhez- ) vs ῥηγ- ( rhēg- ) do not line up neatly.

 Noun
 [ edit ] 

 ῥῆγος • ( rhêgos )  n ( genitive ῥήγεος ) ; third declension 

 blanket , coverlet 

 cover , cushion ( for bed or chairs )
