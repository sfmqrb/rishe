 Persian

 Alternative forms
 [ edit ] 

 آختن ( âxtan ) ( literary , poetic ) 

 آهختن ( âhextan ) , آهنجیدن ( âhanjidan ) , آهنگیدن ( âhangidan ) , هنجیدن ( hanjidan ) , هیختن ( hixtan ) , هختن ( hoxtan ) 

 Etymology
 [ edit ] 

 From Middle Persian ʾhhtn', 'hnj- ( āhixtan, āhanj- , “ to draw out , pull up , extract ” ) , from Proto-Iranian *ā- ( “ ad ” ) + *θanǰáyati ( “ to pull, draw ” ) . [ 1 ] The prefix is from Proto-Indo-European *h₂éd ( “ near, at ” ) .
