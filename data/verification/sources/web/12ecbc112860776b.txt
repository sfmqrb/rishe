 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From earlier Σκλαβηνός ( Sklabēnós ) , Σθλαβηνός ( Sthlabēnós ) , ultimately from Proto-Slavic *slověninъ .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈskla.vos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈskla.vos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈskla.vos/ 

 Noun
 [ edit ] 

 Σκλᾰ́βος • ( Sklắbos )  m ( genitive Σκλᾰ́βου ) ; second declension 

 ( Byzantine ) Slav 

 Inflection
 [ edit ] 

 Second declension of ὁ Σκλᾰ́βος ; τοῦ Σκλᾰ́βου ( Attic )
