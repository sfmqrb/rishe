 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /paj.ˈkaːn/ 

 ( Dari, formal ) IPA ( key ) : [pʰäj.kʰɑːn] 

 ( Dari, formal ) IPA ( key ) : [pʰäj.kʰɑːn] 
 ( Kabuli ) IPA ( key ) : [pʰäj.kʰɑːn] 

 ( Hazaragi ) IPA ( key ) : [pʰäj.kʰɔːn] 

 ( Iran, formal ) IPA ( key ) : [pʰej.kʰɒːn] 

 ( Tajik, formal ) IPA ( key ) : [pʰäj.kʰɔn] 

 Rhymes: -aːn

 Noun
 [ edit ] 

 پیکان • ( paykān / peykân ) ( Tajik spelling пайкон ) 

 arrowhead , spearhead 

 Noun
 [ edit ] 

 پیکان • ( paykān  / peykân ) ( Tajik spelling пайкон ) 

 broken plural of پیک ( payk  / peyk )
