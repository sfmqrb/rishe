 Ottoman Turkish
 [ edit ] 

 آری 
 Etymology 1
 [ edit ] 

 Inherited from Proto-Turkic *ārï ( “ wasp, bee ” ) ; cognate with Azerbaijani arı , Chuvash тӗкӗлтура ( tĕk̬ĕlt̬ura ) , Kazakh ара ( ara ) , Kyrgyz аары ( aarı ) , Turkmen ary , Tuvan ары ( arı ) , Uyghur ھەرە ( here ) , Uzbek ari and Yakut ыҥырыа ( ïŋïrïa ) .

 Noun
 [ edit ] 

 آری • ( arı ) ( definite accusative آریی ( arıyı ) , plural آریلر ( arılar ) ) 

 bee , any flying insect of the family Apidae known for collecting pollen and producing wax and honey 
 Near-synonym: زنبور ( zenbur )

 Etymology 2
 [ edit ] 

 Inherited from Proto-Turkic *arïɣ ( “ clean, pure ” ) , from *arï- ( “ clean, pure, to be clean; to clean, purify ” ) + *-ïg . Cognate with Azerbaijani arı , Kazakh ару ( aruw ) , Kyrgyz аруу ( aruu ) , Southern Altai ару ( aru ) , Tuvan арыг ( arıg ) , Uzbek ori' and Yakut ыраас ( ïraas ) .

 Adjective
 [ edit ] 

 آری • ( arı ) 

 clean , pure , pristine , immaculate , spotless , unsullied , free of flaws , blemishes , or imperfections 
 Synonyms: پاك ( pak ) , تمیز ( temiz ) , خالص ( halis ) , صفی ( safi ) 

 Related terms
 [ edit ] 

 آریمق ( arımak , “ to become clean or pure ” )
