 From re- + vēlō ( “ to cover; to conceal ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [rɛˈweː.ɫoː] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [reˈvɛː.lo] 

 Verb
 [ edit ] 

 revēlō ( present infinitive revēlāre , perfect active revēlāvī , supine revēlātum ) ; first conjugation 

 to uncover ; to unveil ; to reveal 

 to show 

 to reveal or disclose
