 Etymology
 [ edit ] 

 From mer Méditerranée , from méditerranée , originally an epicene adjective, now considered the feminine of méditerrané .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /me.di.tɛ.ʁa.ne/ ~ /me.di.te.ʁa.ne/ 

 Audio ( France ( Brétigny-sur-Orge ) ) : ( file ) 

 Proper noun
 [ edit ] 

 Méditerranée   f 

 short for mer Méditerranée ( “ Mediterranean ” )
