 Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Singulative noun composed of بَيْض ( bayḍ , “ eggs ” ) +‎ ـَة ( -a ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /baj.dˤa/ 

 Audio : ( file ) 

 ( Hijazi ) IPA ( key ) : /beːdˤa/ , [be̞ːdˤa] 

 Noun
 [ edit ] 

 بَيْضَة • ( bayḍa )  f ( singulative , collective بَيْض   m ( bayḍ ) , plural بَيْضَات ( bayḍāt ) ) 

 egg 

 testicle 
 Synonyms: خَصْيَة ( ḵaṣya ) , خِصْيَة ( ḵiṣya ) 

 helmet 
 Synonym: خُوذَة ( ḵūḏa ) 

 main part, substance , essence 

 counterweight of a steelyard
