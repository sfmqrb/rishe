 Persian
 [ edit ] 

 Persian Wikipedia has an article on: گزارش 

 Wikipedia fa 

 Etymology
 [ edit ] 

 From گزار ( gozâr- , present stem of گزاردن ( gozârdan , “ to announce ” ) ) +‎ ـش ( eš ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡu.zaː.ˈriʃ/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.zɑː.ɾɪʃ] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.zɑː.ɾɪʃ] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.zɑː.ɾɪʃ] 

 ( Hazaragi ) IPA ( key ) : [ɡu.zɔː.ɾiʃ] 

 ( Iran, formal ) IPA ( key ) : [ɡ̥o.zɒː.ɹeʃ] 

 ( Tajik, formal ) IPA ( key ) : [ɡu.zɔ.ɾiʃ] 

 Rhymes: -iʃ

 Homophone : گذارش ( gozâreš ) 

 Noun
 [ edit ] 

 Dari

 گزارش 

 Iranian Persian

 Tajik

 гузориш 

 گزارش • ( gozâreš ) ( plural گزارش‌ها , or گزارشات ) 

 report 
 Synonym: راپورت ( râport ) 

 account , description 
 Synonyms: شرح ( šarh ) , توصیف ( towsif ) , وصف ( vasf ) 

 interpretation of a dream 
 Synonym: تعبیر ( ta'bir ) 
 c. 1111 , Ḥakim Iranshān ibn Abū l-Khayr , کوش‌نامه [ Kūsh-Nāma ]: چنین است خواب و گزارش چنین
در این کار شاها سگالش گزین čunīn ast xwāb u guzāriš čunīn
dar īn kār šāh-ā sigāliš guzīn Such is the dream, and the interpretation is such:
Make up your mind in this business, o king.

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian گزارش ( guzāriš ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /ɡʊ.zɑː.ɾɪʃ/ 

 Rhymes: -ɪʃ 

 Noun
 [ edit ] 

 گُزارِش • ( guzāriś )  f ( Hindi spelling गुज़ारिश ) 

 request 
 Synonyms: عرض ( arz ) , درخواست ( darxvāst ) 
 میری آپ سے ایک گزارش ہے۔ merī āp se aik guzāriś hai. I have a request for you.
