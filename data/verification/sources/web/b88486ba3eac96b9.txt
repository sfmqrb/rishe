 Etymology
 [ edit ] 

 Etymology tree

 Proto-Dravidian *waẓVtV der. 
 Sanskrit वातिङ्गण ( vātiṅgaṇa ) bor. 
 Persian بادنجان 

 From earlier بَادِنْگَان ( bādingān ) , an Indo-Aryan borrowing, from Sanskrit वातिङ्गण ( vātiṅgaṇa ) , from Dravidian , ultimately from Proto-Dravidian *waẓVtV .

 Noun
 [ edit ] 

 بادنجان • ( bādinjān / bâdenjân ) ( plural بادنجان‌ها ( bādinjān-hā / bâdenjân-hâ ) , Tajik spelling бодинҷон ) 

 aubergine , eggplant 
 Synonym: کهپرک ( kahparak )

 Etymology
 [ edit ] 

 Borrowed from Classical Persian بادنجان from Sanskrit वातिङ्गण ( vātiṅgaṇa , “ the plant that cures the wind ” ) from Dravidian , ultimately from Proto-Dravidian *waẓVtV . Doublet of بینگن ( baiṅgan ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /bɑː.d̪ən.d͡ʒɑːn/ 

 Hyphenation: با‧دَنْ‧جان 

 Noun
 [ edit ] 

 بادَنْجان • ( bādanjān )  m ( Hindi spelling बादंजान ) 

 aubergine , eggplant
