 From Wiktionary, the free dictionary

 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Italic *klounis , from Proto-Indo-European *ḱlównis . Cognate with Lithuanian šlaunis , Sanskrit श्रोणि ( śróṇi ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [ˈkɫuː.nɪs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [ˈkluː.nis] 

 Noun
 [ edit ] 

 clūnis   m or f ( genitive clūnis ) ; third declension 

 ( anatomy ) rump , buttocks 
 Synonyms: cūlus , natis , pōdex , puga 
 c. 35 BCE , Horatius , Sermones 1.2.86–89 : Rēgibus hic mōs est, ubi equōs mercantur: opertōs
īnspiciunt, nē sī faciēs, ut saepe, decora
mollī fulta pede est, ēmptōrem indūcat hiantem,
quod pulcrae clūnēs , breve quod caput, ardua cervīx. (please add an English translation of this quotation) 

 Usage notes
 [ edit ] 

 More common in the plural form.
