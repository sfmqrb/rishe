 Latin
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Italic *juwenkos , from Proto-Indo-European *h₂yuHn̥ḱós , equivalent to iuvenis +‎ -cus . De Vaan suggests that Latin -enc- instead of -inc- is explainable either as a Sabellicism or as the result of analogical remodeling after iuvenis or iuventus . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Latin ) IPA ( key ) : [jʊˈwɛŋ.kʊs] 

 ( modern Italianate Ecclesiastical ) IPA ( key ) : [juˈvɛŋ.kus] 

 Adjective
 [ edit ] 

 iuvencus ( feminine iuvenca , neuter iuvencum ) ; first / second-declension adjective 

 ( very rare , of domesticated animals ) young
