 Italian
 [ edit ] 

 Etymology
 [ edit ] 

 Feminine form of arancio ( “ orange (tree) ” ) , from Arabic نَارَنْج ( nāranj ) , [ 1 ] from Persian نارنگ ( nârang ) , from Sanskrit नारङ्ग ( nāraṅga ) . [ 2 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /aˈran.t͡ʃa/ 

 Audio (un'arancia) : ( file ) 

 Rhymes: -antʃa 

 Hyphenation: a‧ràn‧cia 

 Noun
 [ edit ] 

 arancia   f ( plural arance , diminutive arancìna ) 

 orange (fruit)
