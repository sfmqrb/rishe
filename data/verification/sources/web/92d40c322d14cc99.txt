 Etymology
 [ edit ] 

 From Proto-Iranian *Hárǰati , from Proto-Indo-Iranian *Hárǰʰati , from Proto-Indo-European *h₂elgʷʰ- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔar.ziː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [ʔäɾ.ziː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [ʔäɾ.ziː.d̪án] 
 ( Kabuli ) IPA ( key ) : [ʔäɾ.ziː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [ʔäɾ.zi.d̪án] 

 ( Iran, formal ) IPA ( key ) : [ʔæɹ.ziː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [ʔäɾ.zi.d̪án]
