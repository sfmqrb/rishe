 Etymology
 [ edit ] 

 From Middle Persian [Term?] ( /⁠spandadāt⁠/ ) , in turn derived from Avestan 𐬯𐬞𐬆𐬥𐬙𐬋𐬜𐬁𐬙𐬀 ( spəntōδāta , literally “ given by Amesha Spenta ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ʔis.fan.di.ˈjaːr/ 

 ( Dari, formal ) IPA ( key ) : [ʔɪs.fän̪.d̪i.jɑ́ːɾ] 

 ( Dari, formal ) IPA ( key ) : [ʔɪs.fän̪.d̪i.jɑ́ːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔɪs.fän̪.d̪i.jɑ́ːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔis.fän̪.d̪i.jɔ́ːɾ] 

 ( Iran, formal ) IPA ( key ) : [ʔes.fæn̪.d̪i.jɒ́ːɹ] 

 ( Tajik, formal ) IPA ( key ) : [ʔis.fän̪.d̪i.jɔ́ɾ] 

 Rhymes: -aːr

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian اسفندیار ( isfandiyār ) .

 Proper noun
 [ edit ] 

 اسفندیار • ( isfandiyār )  m ( Hindi spelling इस्फ़ंदियार ) 

 name of the son of Gishtāsb, of the first dynasty of Persian kings.

 a male given name
