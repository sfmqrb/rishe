 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 سیاووش ( siyāwūš  / siyâvuš ) , سیاوخش ( siyāwaxš  / siyâvaxš ) ( archaic ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( syyʾwhš /⁠siyāwaxš⁠/ ) , from Late Old Persian *Šyāvaršā , from Old Persian *Θyāvaršā ( literally “ having black stallions ” ) . Akin to Avestan 𐬯𐬌𐬌𐬁𐬎𐬎𐬀𐬭𐬱𐬀𐬥 ( siiāuuaršan ) , Parthian 𐫢𐫏𐫏𐫀𐫇𐫢 ( šyyʾwš /⁠siyāwaš⁠/ ) , Khwarezmian 𐿃𐾰𐾶𐿃 ( šʾwš ) , Old Armenian Շաւարշ ( Šawarš ) , Arabic سِيَاوَش ( siyāwaš ) .

 Proper noun
 [ edit ] 

 سیاوش • ( siyāwaš  / siyâvaš ) ( Tajik spelling Сиёвуш ) 

 ( Iranian mythology ) Siavash 

 a male given name , Siyavash , Siavash , and Syavash
