 Verb

 rest ; observe the Sabbath

 Noun
 [ edit ] 

 שַׁבָּת • ( shabát )  f ( plural indefinite שַׁבָּתוֹת ) 

 Shabbat , Sabbath ; weekly day of rest 
 a. 500 CE , Genesis Rabbah , 17:5 , with translation from Sefaria : רַבִּי חֲנִינָא בַּר יִצְחָק אָמַר : ג׳ נוֹבְלוֹת הֵן : נוֹבֶלֶת מִיתָה שֵׁינָה , נוֹבֶלֶת נְבוּאָה חֲלוֹם , נוֹבֶלֶת הָעוֹלָם הַבָּא שַׁבָּת . Rabbi Hanina bar Yitzhak said: they are three samples: a sample of death is sleep, a sample of prophecy is dream, a sample of the world-to-come is the Sabbath . 

 Saturday 

 ( archaic ) week (Mishnaic Hebrew)

 שֶׁבֶת • ( shévet ) 

 bare infinitive (infinitive construct or gerund) of יָשַׁב ( yasháv ) 

 Etymology 3
 [ edit ] 

 From Talmudic Hebrew, from Akkadian 𒅆𒂍𒌈 ( /⁠šibittu⁠/ ) ; cognate to Persian شوید ( ševid ) , Jewish Babylonian Aramaic שִׁיבְתָא ( šiḇəṯā ) , Classical Syriac ܫܒܬܐ . ( Arabic شِبِثّ ( šibiṯṯ ) comes via Aramaic.)

 Pronunciation
 [ edit ] 

 ( Mishnaic ) IPA ( key ) : /ʃe.ˈbeːθ/ , [ʃe.ˈβeːθ] 

 ( Tiberian ) IPA ( key ) : /ˈʃɛ.vɛθ/ , [ˈʃɛː.vɛː(.ɛ)θ] 

 ( Mizrahi ) IPA ( key ) : /ˈʃe.bet/ 

 ( Iraqi ) IPA ( key ) : /ˈʃe.beθ/ 

 ( Sephardi ) IPA ( key ) : /ˈʃe.vet/ 

 ( Ashkenazi ) IPA ( key ) : /ˈʃe.ves/ 

 ( Yemenite ) IPA ( key ) : /ˈʃæ.væθ/ 

 ( Modern Israeli ) IPA ( key ) : /ˈʃe.vet/ , [ˈʃe̞.ve̞tʰ] 

 Noun
 [ edit ] 

 שֶׁבֶת • ( šévet )  m 

 ( dated ) Dill 
 שבת קי״ט א:ח׳ 
 אָמַר לוֹ קֵיסָר לְ רבי יהושע בן חנניה : מִ פְּנֵי מָה תַּבְשִׁיל שֶׁל שַׁבָּת רֵיח וֹ נוֹדֵף ? אָמַר לוֹ: תַּבְלִין אֶחָד יֵשׁ לָנוּ וְשֶׁבֶת שְׁמ וֹ …. Caesar said to Rabbi Joshua ben Hananiah : "Why does the Shabbat dish's smell propagate?" He replied: "We have one spice [called] shevéth …"
