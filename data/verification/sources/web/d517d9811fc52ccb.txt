 Chagatai
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian آبَادَان ( ābādān ) .

 Adjective
 [ edit ] 

 آبادان • ( ʾʾbʾdʾn / ābādān /) ( comparative آبادان‌راق ( ābādānraq ) ) 

 prosperous , flourishing 
 Synonyms: آباد ( ʾʾbʾd /⁠ābād⁠/ ) , معمور ( mʿmwr /⁠mäʿmūr⁠/ ) 
 آبادان بولماق ― ʾʾbʾdʾn bwlmʾq / ābādān bolmaq / ― to become prosperous, to flourish, to prosper 
 آبادان قیلماق ― ʾʾbʾdʾn qylmʾq / ābādān qılmaq / ― to make flourish, prosper 

 Derived terms
 [ edit ] 

 آبادان‌لیق ( ʾʾbʾdʾn-lyq /⁠ābādānlıq⁠/ , “ prosperity ” )

 Alternative forms
 [ edit ] 

 آوادان ( āwādān  / âvâdân ) , آبدان ( ābadān  / âbadân ) , ابدان ( abadān  / abadân ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [Book Pahlavi needed] ( ʾp̄ʾtʾn /⁠ābādān⁠/ , “ thriving ” ) . [ 1 ] By surface analysis , آباد ( ābād  / âbâd , “ prosperous ” ) +‎ ـان ( -ān  / -ân ) .
