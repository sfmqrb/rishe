 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 πῠκῐνός ( pŭkĭnós ) — poetic 

 Etymology
 [ edit ] 

 Possibly from Proto-Indo-European *puḱ- ( “ press together ” ) ; compare Avestan 𐬞𐬎𐬯𐬁 ( pusā , “ headband, diadem ” ) , [ 1 ] as well as Albanian putë .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /py.knós/ → /pyˈknos/ → /piˈknos/ 

 ( 5 th BCE Attic ) IPA ( key ) : /py.knós/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /pyˈknos/ 

 ( 4 th CE Koine ) IPA ( key ) : /pyˈknos/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /pyˈknos/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /piˈknos/ 

 Adjective
 [ edit ] 

 πῠκνός • ( pŭknós )  m ( feminine πῠκνή , neuter πῠκνόν ) ; first / second declension 

 thick 
 Synonym: πᾰχῠ́ς ( păkhŭ́s ) 

 dense 

 sagacious ; crafty ; cunning

 Greek
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Ancient Greek πυκνός ( puknós ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /piˈknos/ 

 Hyphenation: πυ‧κνός 

 Adjective
 [ edit ] 

 πυκνός • ( pyknós )  m ( feminine πυκνή , neuter πυκνό ) 

 dense ( having relatively high density ) 

 dense , compact ( crowded together; closely packed ) 

 dense , thick ( difficult to penetrate ) 

 fine-toothed ( comb ) 

 fine - meshed ( sieve ) 

 heavy ( of great force, power, or intensity ) 

 compact ( of prose: brief and pithy; not verbose )
