 Etymology
 [ edit ] 

 Etymology tree

 Proto-Dravidian *wēr

 Old Tamil 𑀇𑀜𑁆𑀘𑀺𑀯𑁂𑀭𑁆 ( iñcivēr ) bor. 
 Prakrit 𑀲𑀺𑀁𑀕𑀺𑀯𑁂𑀭 ( siṃgivera ) der. 

 ▲ 

 Sanskrit शृङ्ग॑ ( śṛ́ṅga ) influ. 

 Sanskrit शृङ्गवेर 

 Sanskritization of Prakrit 𑀲𑀺𑀁𑀕𑀺𑀯𑁂𑀭 ( siṃgivera ) , with influence of शृङ्ग ( śṛṅga , “ horn ” ) , borrowed from Old Tamil 𑀇𑀜𑁆𑀘𑀺𑀯𑁂𑀭𑁆 ( iñcivēr , “ ginger root ” ) , equivalent to Tamil இஞ்சி ( iñci , “ ginger ” ) + வேர் ( vēr , “ root ” ) (whence Tamil இஞ்சிவேர் ( iñcivēr , “ ginger root ” ) ).
