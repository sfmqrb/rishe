 Alternative forms
 [ edit ] 

 خاگ ( xâg ) ( dialectal , Kazerun ) 

 Etymology
 [ edit ] 

 From Middle Persian [Term?] ( /⁠xāyak⁠/ ) , from Proto-Iranian *Hāwyám (compare Northern Kurdish hêk , Ossetian айк ( ajk ) , Avestan 𐬀𐬉𐬨 ( aēm ) ), from Proto-Indo-Iranian *Hāwyám , from Proto-Indo-European *h₂ōwyóm ( “ egg ” ) (compare Armenian ձու ( ju ) , English egg , Italian uovo , Russian яйцо́ ( jajcó ) ). Doublet of هاگ ( hāg  / hâg , “ spore ” ) .

 Noun

 Dari

 خایه 

 Iranian Persian

 Tajik

 خایه • ( xâye ) ( plural خایه‌ها ) 

 ( vulgar ) testicle , balls 
 Synonyms: تُخم ( toxm ) , بیضه ( beyze ) , تستیکول ( testikul ) 

 ( figurative , vulgar ) courage , guts , balls 

 ( archaic ) egg 
 Synonym: تُخم ( toxm )
