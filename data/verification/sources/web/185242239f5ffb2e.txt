 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From σᾰ́ρξ ( sắrx , “ meat; flesh ” ) +‎ -ᾰ́ζω ( -ắzō , verbal suffix ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sar.káz.dɔː/ → /sarˈka.zo/ → /sarˈka.zo/ 

 ( 5 th BCE Attic ) IPA ( key ) : /sar.káz.dɔː/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /sarˈka.zo/ 

 ( 4 th CE Koine ) IPA ( key ) : /sarˈka.zo/ 

 ( 10 th CE Medieval ) IPA ( key ) : /sarˈka.zo/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /sarˈka.zo/ 

 Hyphenation: σᾰρ‧κᾰ́‧ζω 

 Verb
 [ edit ] 

 σᾰρκᾰ́ζω • ( sărkắzō ) 

 to gnash 

 to tear or lacerate flesh

 to bite one's lip in anger

 ( figuratively ) to tear apart with sarcasm
