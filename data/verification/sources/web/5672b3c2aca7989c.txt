 Alternative forms
 [ edit ] 

 دولمه ( dōlma  / dulme ) 

 Etymology
 [ edit ] 

 Borrowed from Turkic , cf. Azerbaijani dolma , Turkish dolma .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /dul.ˈma/ 

 ( Dari, formal ) IPA ( key ) : [d̪ʊl.má] 

 ( Dari, formal ) IPA ( key ) : [d̪ʊl.má] 
 ( Kabuli ) IPA ( key ) : [d̪ʊl.má] 

 ( Hazaragi ) IPA ( key ) : [d̪ul.má] 

 ( Iran, formal ) IPA ( key ) : [d̪ol.mé] 

 ( Tajik, formal ) IPA ( key ) : [d̪ul.má] 

 Rhymes: -a
