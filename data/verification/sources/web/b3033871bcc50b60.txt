 Etymology
 [ edit ] 

 From Middle Persian 𐭡𐭥𐭫𐭭𐭣 ( buland ) , from Old Persian *br̥dāh , from Proto-Iranian *br̥jáns ( “ high, tall ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bu.ˈland/ 

 ( Dari, formal ) IPA ( key ) : [bʊ.lán̪d̪] 

 ( Dari, formal ) IPA ( key ) : [bʊ.lán̪d̪] 
 ( Kabuli ) IPA ( key ) : [bʊ.lán̪d̪] 

 ( Hazaragi ) IPA ( key ) : [bu.lán̪d̪̥] 

 ( Iran, formal ) IPA ( key ) : [bo.lǽn̪d̪̥] 

 ( Tajik, formal ) IPA ( key ) : [bä.lán̪d̪] 

 Rhymes: -and
