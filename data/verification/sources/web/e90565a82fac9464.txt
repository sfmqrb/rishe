 Kashmiri
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /nɑːʋ/ 

 Etymology 1
 [ edit ] 

 From Sanskrit नामन् ( nāman , “ name ” ) , from Proto-Indo-Iranian *Hnā́ma , from Proto-Indo-European *h₁nómn̥ .

 Noun
 [ edit ] 

 ناو • ( nāv )  m ( plural ناو , Devanagari नाव ) 

 name 
 مےٚ روٗد نٕہ تٔمؠ سُنٛد ناو وَنہِ me rūd nụ tạm' sund nāv vani I couldn’t remember his name 

 Etymology 2
 [ edit ] 

 From Sanskrit नावा ( nāvā ) . Also influenced by Classical Persian ناو ( nāv ) .

 Noun
 [ edit ] 

 ناو • ( nāv )  f ( plural ناوٕ , Devanagari नाव ) 

 boat 
 ناوٕ چھےٚ سَرَس پؠٹھ پَکان ― nāvụ che saras pyaṭh pakān ― Boats travel on the lake 

 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian ناو ( nâv , “ anything long and hollow ” ) .

 Noun
 [ edit ] 

 ناو • ( nav ) 

 pipe , tube , anything that is hollow and cylindrical in shape 
 Synonyms: بورو ( boru ) , لوله ( lüle ) 

 drainpipe , a pipe that carries fluid which is being drained

 gutter , drain , a channel intended for the drainage of water 
 Synonym: اولق ( oluk ) 

 boat , a watercraft , smaller than a ship , used for various purposes 
 Synonym: قایق ( kayık ) 

 Descendants
 [ edit ] 

 Turkish: nav

 Etymology
 [ edit ] 

 From Middle Persian nʾw ( nāw , “ ship ” ) , from Old Persian 𐎴𐎠𐎺 ( n-a-v /⁠nāva⁠/ ) , from Proto-Iranian *náHuš (compare Ossetian нау ( naw ) / науӕ ( nawæ ) ), from Proto-Indo-Iranian *náHuš (compare Sanskrit नाव ( nāva ) ), from Proto-Indo-European *néh₂us (compare Ancient Greek ναῦς ( naûs ) , Latin nāvis ).

 Etymology
 [ edit ] 

 Inherited from Sauraseni Prakrit 𑀡𑀸𑀯𑀸 ( ṇāvā ) , from Sanskrit नौ ( náu ) , नावा ( nāvā ) , from Proto-Indo-Aryan *náHuṣ , from Proto-Indo-Iranian *náHuš , from Proto-Indo-European *néh₂us . Cognate with Hindi नाव ( nāv ) , Pali nāvā , and Punjabi ਨਾਉ ( nāu ) . Cognate through Indo-European with Ancient Greek ναῦς ( naûs ) , Persian ناو ( nâv ) , and Spanish nave .
