 Hindi
 [ edit ] 

 मरकत 
 Etymology
 [ edit ] 

 Borrowed from Sanskrit मरकत ( marakata ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /məɾ.kət̪/ , [mɐɾ.kɐt̪] 

 Noun
 [ edit ] 

 मरकत • ( markat )  m 

 emerald 
 Synonyms: see Thesaurus: हरिन्मणि 
 उसने अपनी अँगूठी में एक चमकता हुआ मरकत लगवाया है। usne apnī aṅgūṭhī mẽ ek camaktā huā markat lagvāyā hai. He has set a shining emerald in his ring.

 Noun
