 Hijazi Arabic
 [ edit ] 

 درابزين 
 Etymology
 [ edit ] 

 From Ottoman Turkish طرابزان ( tarabizan ) , from Persian داربزین ( dârabzin ) .

 This etymology is incomplete. You can help Wiktionary by elaborating on the origins of this term. 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /da.ra(ː)b.ˈziːn/ 

 Noun
 [ edit ] 

 درابزين • ( darābzīn )  m ( plural دربزينات ( darābzīnāt ) ) 

 railing , handrail , banister 
 Alternative form: ( alternative spelling ) دربزين ( darabzīn )
