 Hebrew
 [ edit ] 

 המנורה (the menorah) 
 Etymology
 [ edit ] 

 Root 

 נ־י־ר ( n-y-r ) 

 8 terms 

 Cognate with Aramaic מְנָרְתָא ( mənārəṯā ) , Arabic مَنَارَة ( manāra ) .

 Pronunciation
 [ edit ] 

 ( Modern Israeli ) IPA ( key ) : /me.noˈʁa/ 

 Audio : ( file ) 

 Noun
 [ edit ] 

 מְנוֹרָה • ( m'norá )  f ( plural indefinite מְנוֹרוֹת , singular construct מְנוֹרַת־ , plural construct מְנוֹרוֹת־ ) 

 A light , a lamp .
 המנורה דולקת? ― ham'norá doléket? ― Is the light on? 

 A menorah or other candelabrum .
 ( Ashkenazi ) hanukkiah 
 Synonym: חֲנֻכִּיָּה ( khanukiyá ) 

 ( usually definite ) The menorah as a symbol.
 המנורה on the Hebrew Wikipedia. Wikipedia he

 Yiddish
 [ edit ] 

 אַ מנורה. 
 Etymology
 [ edit ] 

 From Hebrew מְנוֹרָה ( m'norá ) . 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /məˈnɔɪ̯ʁə/ 

 Hyphenation: מנורה 

 Noun
 [ edit ] 

 מנורה • ( menoyre )  f , plural מנורות ( menoyres ) 

 menorah , candelabrum , hanukkiah
