 Etymology
 [ edit ] 

 Borrowed from Sanskrit तुला ( tulā ) . Doublet of तुली ( tulī ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /t̪ʊ.lɑː/ , [t̪ʊ.läː] 

 Noun
 [ edit ] 

 तुला • ( tulā )  f ( Urdu spelling تلا ) 

 balance , scales 
 Synonyms: मापन ( māpan ) , तराज़ू ( tarāzū )

 Etymology
 [ edit ] 

 Etymology tree

 Proto-Indo-European *telh₂- 

 Proto-Indo-European *-éh₂ 

 Proto-Indo-European *tl̥h₂-éh₂ 
 Sanskrit तुला 

 Inherited from Proto-Indo-European *tl̥h₂-éh₂ , from *telh₂- + *-éh₂ . [ 1 ] 

 The astrological sense is a semantic loan from Ancient Greek Ζυγός ( Zugós ) . Compare Latin Libra .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /tu.lɑ́ː/ 

 ( Classical Sanskrit ) IPA ( key ) : /t̪u.l̪ɑː/ 

 Noun
 [ edit ] 

 तु॒ला • ( tulā́ ) stem ,  f [ 2 ] [ 3 ] 

 balance , scales 
 c. 1200 BCE – 800 BCE , Śukla-Yajurveda (Vājasenayi Saṃhitā) 

 weight 

 ( astronomy , astrology ) Libra
