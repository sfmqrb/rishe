 Alternative forms

 قِيتَارَة ( qītāra ) , قِيثَار ( qīṯār ) , قِيتَار ( qītār ) 

 Etymology
 [ edit ] 

 Etymology tree

 Pre-Greek der. 
 Ancient Greek κῐθᾰ́ρᾱ ( kĭthắrā ) bor. 
 Aramaic קיתרא ( qīṯārā ) bor. 
 Arabic قيثارة 

 Borrowed from Aramaic קיתרא ( qīṯārā ) , from Ancient Greek κῐθᾰ́ρᾱ ( kĭthắrā ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /qiː.θaː.ra/

 Noun
 [ edit ] 

 قِيثَارَة • ( qīṯāra )  f ( plural قِيثَارَات ( qīṯārāt ) or قَيَاثِير ( qayāṯīr ) ) 

 ( music ) guitar
