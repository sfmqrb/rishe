 Hindi

 Etymology
 [ edit ] 

 Borrowed from Classical Persian کاش ( kāš ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /kɑːʃ/ , [käːʃ] 

 Conjunction
 [ edit ] 

 काश • ( kāś ) ( Urdu spelling کاش ) 

 I wish , if only 
 काश मैं आज दुकान गया होता kāś ma͠i āj dukān gayā hotā If only I had gone to the store today.

 Etymology 2
 [ edit ] 

 Of uncertain origin. Comparisons to the "shining" sense of Etymology 1, as well as to Persian کاه ( kâh , “ chaff, straw, hay ” ) , have been made. Others have considered the term as a Dravidian borrowing. [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /kɑ́ː.ɕɐ/ 

 ( Classical Sanskrit ) IPA ( key ) : /kɑː.ɕɐ/ 

 Noun
 [ edit ] 

 काश॑ • ( kā́śa ) stem ,  m 

 a species of grass , Saccharum spontaneum , used for mats , roofs , etc.
 also personified , together with the Kusha grass, as one of Yama 's attendants
