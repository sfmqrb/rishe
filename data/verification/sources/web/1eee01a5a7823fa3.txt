 Alternative forms
 [ edit ] 

 Σᾰ́ρδῐες ( Sắrdĭes ) — Ionic 

 Etymology
 [ edit ] 

 From earlier *Σϝάρδ- ( *Swárd- ) , ultimately from pre- Lydian *Swar- , parallel with Old Persian 𐎿𐎱𐎼𐎭 ( s-p-r-d /⁠Spardaʰ⁠/ ) , and whence Lydian 𐤮𐤱𐤠𐤭 ( sfar , “ Sardis ” ) . [ 1 ] [ 2 ] [ 3 ] [ 4 ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /sár.deːs/ → /ˈsar.ðis/ → /ˈsar.ðis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /sár.deːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈsar.dis/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈsar.ðis/ 

 ( 10 th CE Medieval ) IPA ( key ) : /ˈsar.ðis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈsar.ðis/ 

 Proper noun
 [ edit ] 

 Σᾰ́ρδεις • ( Sắrdeis )  f   pl ( genitive Σᾰ́ρδεων ) ; third declension 

 Sardis , Lydia; Sart , Manisa, Turkey
