 Greek

 Alternative forms
 [ edit ] 

 λόγκος ( lógkos ) 

 Etymology
 [ edit ] 

 Inherited from Byzantine Greek λόγγος ( lóngos ) , from Proto-Slavic *lǫ̑gъ ( “ depression , meadow , valley ” ) .

 Noun
 [ edit ] 

 λόγγος • ( lóngos )  m ( plural λόγγοι ) 

 dense and bushy forest , grove 
 Hypernym: δάσος ( dásos )
