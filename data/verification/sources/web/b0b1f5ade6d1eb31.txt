 Root

 Pronunciation
 [ edit ] 

 IPA ( key ) : /riz.ma/ 

 Noun
 [ edit ] 

 رِزْمَة • ( rizma )  f ( plural رِزَم ( rizam ) or رِزْمَات ( rizmāt ) ) 

 bundle , packet , bale 
 Synonym: حُزْمَة ( ḥuzma ) 

 ream ( of paper ) 

 ( networking ) packet ( unit of data carried over a network ) 

 ( software ) package 
 Synonym: حُزْمَة ( ḥuzma ) 
 رِزْمَة بَرَامِج ― rizma(t) barāmij ― software package 
 2006 May 20, GNU ‎ [1] , archived from the original on 22 August 2026 : للحصول على رزمات من البرمجيات الحرة من نوع GNU وغيره من الأنواع، الرجاء العودة إلى دليل البرمجيات الحرة حيث أن هذا الأخير يشكل قاعدة بيانات منظمة يمكن البحث فيها. تحافظ على الدليل المذكور مؤسسة البرمجيات الحرة علماً أنه يتضمن روابط إلكترونية تصله بصفحات رئيسية متوفرة لبرامج مختلفة. To get free software packages , both GNU and non-GNU, please visit the Free Software Directory whch is a categorized, searchable database of free software. The aforementioned director is actively maintained by the Free Software Foundation and includes, when available, links to the homepages of various programs.
