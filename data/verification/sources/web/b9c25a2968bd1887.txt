 North Levantine Arabic
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Persian لگن ( lagan ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈla.ɡan/ 

 Noun
 [ edit ] 

 لَگَن • ( lagan )  m ( plural لْگُونِة ( lgūne ) ) 

 alternative form of لَكَن ( lakan , “ washbasin ” ) 
 2016 , تعلم اللهجة البيروتية ( taʕallam al-lahja l-bayrūtiyya ) [ Learn the Beiruti Dialect ] ( عكيف وعفيف ( ʕakīf wa ʕafīf , “ Akeef and Afeef ” ) )‎ [1] , archived from the original on 20 March 2023 : عكيف: رُزْقالله على إيّام اللَّبِن بال لَّگِن . ايه والله
عفيف: ايه والله... رُزقالله... لبِن بال لَّگِن ʕakīf: ruzʔ̣aḷḷa ʕala ʔiyyēm l-labin bi l- lagin . ʔē waḷḷa
ʕafīf: ʔē waḷḷa... ruzʔ̣aḷḷa... labin bi l- lagin Akeef: God bless the good old days of yogurt in the basin . By God
Afeef: Yeah, by God... those good old days... yogurt in the basin These characters are speaking in the traditional Old Beiruti dialect, which features an emphatic ق ( /⁠ʔ̣⁠/ ) , pausal raising of final ـَا ( -a ) to ـِي ( -e ) , and raising of words on patterns like فَعَل ( CaCaC ) to فَعِل ( CaCiC , with [i] )  — notice لَگِن ( lagin ) instead of لَگَن ( lagan ) .

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Semi-learned borrowing from Sanskrit लग्न ( lagna ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /lə.ɡən/ 

 Rhymes: -ən 

 Noun
 [ edit ] 

 لَگَن • ( lagan )  m ( Hindi spelling लगन ) ( rare ) 

 love , affinity 

 time 
 1989 , پْروفیسَر عَزِیز اَحْمَد [ profesar 'azīz ahmad ], بَرِّ صَغِیر میں اِسْلامی کَلْچَر [ barr-i saġīr mẽ islāmī kalcar , Islamic Culture in the Indian Subcontinent ]‎ [3] , page 243 : مُسَلْمان، ہِنْدُوون کے ساتھ دُرْگاپُوجا میں شَرِیک ہوتے تہے اَور شادی بْیاہ وَغَیرَہ کے مَوقَع پَر بَرَہْمَنوں سے شُبھ لَگَن اَور سَعدِ ساعَت دَریافْت کِیا کَرتے تھے. musalmān, hinduvon ke sāth durgāpūjā mẽ śarīk hote the aur śādī byāh vaġaira ke mauqa' par barahmanõ se śubh lagan aur sa'd-i sā'at daryāft kiyā karte the.
