 Adjective
 [ edit ] 

 کل • ( kull / koll ) ( Tajik spelling кул ) 

 whole , all ( entire , undivided ) 

 ( in some phrases from Arabic ) every , each 
 کلَّ یومٍ ― kulla yawmin / kolla yowmen ― every day 

 Noun
 [ edit ] 

 کل • ( kull / koll ) ( Tajik spelling кул ) 

 total , whole , entirety 

 ( in titles ) in chief ( highest in command ) 

 Pronoun
 [ edit ]

 Etymology 3
 [ edit ] 

 Akin to Northern Kurdish ker , Central Kurdish کەرت ( kert ) , Southern Kurdish قەڵ ( qell ) , all meaning "slice, piece" etc. Probably from the same root as کارد .

 Noun
 [ edit ] 

 کل • ( kal ) 

 ( dialectal , Bushehr , Khesht , Konartakhteh ) piece , part 
 هر کلش یه جا رفت. har kaleš ye jâ raft. (It broke and) Every piece of it went somewhere.
