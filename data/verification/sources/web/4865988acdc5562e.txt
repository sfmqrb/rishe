 Ancient Greek
 [ edit ] 

 Etymology
 [ edit ] 

 From Proto-Indo-European *(s)kewH- ( “ to cover ” ) or from κῠ́ω ( kŭ́ō ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /kýs.tis/ → /ˈcys.tis/ → /ˈcis.tis/ 

 ( 5 th BCE Attic ) IPA ( key ) : /kýs.tis/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈkys.tis/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈcys.tis/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈcys.tis/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈcis.tis/ 

 Noun
 [ edit ] 

 κῠ́στῐς • ( kŭ́stĭs )  f ( genitive κῠ́στεως ) ; third declension 

 bladder 
 Synonym: φῦσᾰ ( phûsă ) 

 Declension
 [ edit ] 

 Third declension of ἡ κῠ́στῐς ; τῆς κῠ́στεως ( Attic )
