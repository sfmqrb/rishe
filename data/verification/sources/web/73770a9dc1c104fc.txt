 Persian
 [ edit ] 

 Persian Wikipedia has an article on: پردیس 

 Wikipedia fa 

 Etymology
 [ edit ] 

 Borrowed from some reflex of Proto-Iranian *paridayjah . Akin to پالیز ( pâliz ) . Northern Luri پںریز ( pəriz ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /par.ˈdeːs/ 

 ( Dari, formal ) IPA ( key ) : [pʰäɾ.d̪éːs] 

 ( Dari, formal ) IPA ( key ) : [pʰäɾ.d̪éːs] 
 ( Kabuli ) IPA ( key ) : [pʰäɾ.d̪éːs] 

 ( Hazaragi ) IPA ( key ) : [pʰäɾ.d̪éːs] 

 ( Iran, formal ) IPA ( key ) : [pʰæɹ.d̪íːs] 

 ( Tajik, formal ) IPA ( key ) : [pʰäɾ.d̪ís]

 Noun
 [ edit ] 

 پردیس • ( pardēs / pardis ) ( plural پردیس‌ها ( pardēs-hā / pardis-hâ ) , Tajik spelling пардис ) 

 garden 
 Synonyms: بوستان ( bustân ) , باغ ( bâġ ) 

 paradise , heaven 
 Synonyms: بهشت ( behešt ) , فردوس ( ferdows ) 

 campus , grounds or property of a school, college, or university

 Descendants
 [ edit ] 

 → Arabic: فرديس ( fardīs ) 

 Proper noun
 [ edit ] 

 پردیس • ( pardēs  / pardis ) ( Tajik spelling Пардис ) 

 a female given name , Pardis 

 Punjabi
 [ edit ] 

 Etymology
 [ edit ] 

 Semi-learned borrowing from Sanskrit प्रदेश ( pradeśa ) . Equivalent to پَرـ ( par- ) +‎ دیس ( des , “ homeland ” ) .

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /pəɾᵊ.d̪eːsᵊ/ 

 Noun
 [ edit ] 

 پَرْدیس • ( pardes )  m ( Gurmukhi spelling ਪਰਦੇਸ ) 

 abroad ; foreign country
