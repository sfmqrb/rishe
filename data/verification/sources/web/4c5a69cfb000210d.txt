 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 کشودن ( košudan ) , گشادن ( gošâdan ) , کشادن ( košâdan ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( wšʾtn' /⁠wišādan⁠/ , “ to open, loose, free ” ) , ultimately from Proto-Indo-European *sh₂ey- ( “ to bind, fetter ” ) with the preverb *wi- . "To conquer": semantic loan from Arabic فَتَحَ ( fataḥa , “ to open; to conquer ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡu.ʃuː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.ʃuː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [ɡʊ.ʃuː.d̪án] 
 ( Kabuli ) IPA ( key ) : [ɡʊ.ʃuː.d̪án]

 ( Tajik, formal ) IPA ( key ) : [kʰu.ʃɔ.d̪án]

 Verb
 [ edit ] 

 گشودن • ( gošudan ) ( present stem گشای ( gošây ) ) ( formal , transitive ) 

 to open 
 Synonym: باز کردن ( bâz kardan ) 
 به گفتهٔ وزیر دادگستری ترکیه یکی از مهاجمان با کلاشنیکف به روی مردم آتش گشود . be gofte-ye vazir-e dâdgostari-e torkiye yeki az mohâjemân bâ kalâšnikof be ru-ye mardom âtaš gošud . According to the Turkish Minister of Justice one of the attackers opened fire on people with a Kalashnikov. 

 to conquer 
 Synonyms: تسخیر کردن ( tasxir kardan ) , فتح کردن ( fath kardan ) 
 عثمانی‌ها پس از آن، به گشودن قلعه‌های کوچک اطرافش پرداختند. osmâni-hâ pas az ân, be gošudan -e qel'e-hâ-ye kuček-e atrâf-aš pardâxtand. Following this, the Ottomans set themselves to conquering the small fortifications around it. 

 Usage notes
 [ edit ] 

 گشودن ( gošudan ) is highly formal in both Iran and Afghanistan, where باز کردن ( bâz kardan ) and واز کردن ( wāz kardan ) are the respective normal words for "to open." However, in Tajikistan, the variant кушодан ( kušodan ) is the normal word for "to open."
