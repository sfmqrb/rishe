 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( myzdwbl /⁠mizdwar⁠/ , “ hireling, hired laborer ” ) . [ 1 ] Equivalent to مزد ( muzd  / mozd , “ wage ” ) +‎ ـور ( -war  / -var ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /muz.ˈduːr/ 

 ( Dari, formal ) IPA ( key ) : [mʊz.d̪úːɾ] 

 ( Dari, formal ) IPA ( key ) : [mʊz.d̪úːɾ] 
 ( Kabuli ) IPA ( key ) : [mʊz.d̪úːɾ] 

 ( Hazaragi ) IPA ( key ) : [muz.d̪úɾ] 

 ( Iran, formal ) IPA ( key ) : [moz.d̪úːɹ] 

 ( Tajik, formal ) IPA ( key ) : [muz.d̪úɾ] 

 Rhymes: -uːr

 Noun
 [ edit ] 

 مزدور • ( muzdūr / mozdur ) ( Tajik spelling муздур ) 

 mercenary 

 hired laborer , hireling , mazdoor 
 c. 1011 , Abu'l-Qāsim Firdawsī , “The reign of Yazdgird”, in شاهنامه [ Book of Kings ]‎ [1] : نشسته نظاره من از دورشان
تو گفتی بدم پیش مزدورشان nišasta nazāra man az dūrašān
tu guftī budam pēš muzdūrašān I sat, looking at them from afar:
You would have said I was a hireling before them. (Classical Persian romanization)

 Etymology
 [ edit ] 

 Borrowed from Classical Persian مزدور ( muzdūr , “ mercenary ; labourer ” ) , which in turn inherited from Middle Persian [script needed] ( myzdwbl /⁠mizdwar⁠/ , “ hireling, hired laborer ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /məz.d̪uːɾ/ 

 Rhymes: -uːɾ 

 Hyphenation: مَزْ‧دُور 

 Noun
 [ edit ] 

 مَزْدُور • ( mazdūr )  m ( Hindi spelling मज़दूर ) 

 labourer , worker 

 porter , carrier , coolly
