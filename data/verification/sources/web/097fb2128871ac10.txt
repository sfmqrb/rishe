 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [Term?] ( /⁠ayād⁠/ ) , [ 1 ] [ 2 ] from Proto-Iranian *Habí- + *yáH- ( probably from Proto-Indo-European *yeh₂- ( “ to go; to go in, to enter ” ) , with Iranian semantic shift "to enter [the mind]" > "to remember" ) . [ 3 ] Compare Tocharian A [Term?] ( opyāc , “ in remembrance ” ) , probably borrowed from an Eastern Iranian language.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈjaːd/ 

 ( Dari, formal ) IPA ( key ) : [jɑːd̪] 

 ( Dari, formal ) IPA ( key ) : [jɑːd̪] 
 ( Kabuli ) IPA ( key ) : [jɑːd̪] 

 ( Hazaragi ) IPA ( key ) : [jɔːd̪̥] 

 ( Iran, formal ) IPA ( key ) : [jɒːd̪̥] 

 ( Tajik, formal ) IPA ( key ) : [jɔd̪] 

 Rhymes: -aːd

 Noun
 [ edit ] 

 یاد • ( yād / yâd ) ( Tajik spelling ёд ) 

 memory 
 Synonyms: حافظه ( hāfiza  / hâfeze ) , خاطر ( xātir  / xâter ) 
 c. 1390 , Shams-ud-Dīn Muḥammad Ḥāfiẓ , “Ghazal 11”, in دیوان حافظ [ The Dīwān of Ḥāfiẓ ]‎ [2] : گو نام ما ز یاد به عمداً چه می‌بری
خود آید آن که یاد نیاری ز نام ما gō nām-i mā zi yād ba amdan či mē-barī
xwad āyad ān ki yād nay-ārī zi nām-i mā Say, why do you purposely forget my name?
The [time] shall come by itself that you do not remember my name. (Classical Persian transliteration)
