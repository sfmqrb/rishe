 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Classical Persian مرغ ( murg , “ bird ” ) , from Middle Iranian *murγ ( “ bird ” ) , ultimately from Proto-Iranian *mr̥gáh ( “ bird ” ) .

 Noun
 [ edit ] 

 مرغ • ( mürg ) ( definite accusative مرغی ( mürgü ) , plural مرغلر ( mürgler ) ) 

 bird , any member of the class of animals Aves , characterized by having feathers and wings 
 Synonyms: طیر ( tayr ) , قوش ( kuş ) 

 fowl , any bird in the order Galliformes , including chickens , turkeys , pheasant and partridges 
 Synonyms: دجاج ( decac ) , طاوق ( tavuk )

 Etymology 2
 [ edit ] 

 Borrowed from Arabic [Term?] .

 Noun
 [ edit ] 

 مرغ • ( merg ) ( definite accusative مرغی ( mergi ) , plural مرغلر ( mergler ) ) 

 meadow , a field or pasture covered or cultivated with grass , usually intended to be mown for hay 
 Synonyms: چایر ( çayır ) , مرج ( merc ) , یشیللك ( yeşillik )

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭬𐭥𐭫𐭥𐭠 ( mwlw' /⁠murw⁠/ ) (Manichaean Middle Persian 𐫖𐫇𐫡𐫇 ( mwrw ) ), [ 1 ] from Proto-Iranian *mr̥gáh ( “ bird ” ) . Compare Middle Persian 𐭬𐭥𐭫𐭥𐭠 ( mwlw' /⁠murw⁠/ ) , Parthian 𐫖𐫇𐫡𐫃 ( mwrg /⁠murγ⁠/ ) , Avestan 𐬨𐬆𐬭𐬆𐬖𐬀 ( mər ə γa ) , Pashto مرغه ( mërğë ) , Ossetian маргъ ( marǧ ) , Baluchi مرگ ( murg ) , Old Armenian սիրամարգ ( siramarg ) and լորամարգ ( loramarg ) .

 Noun
 [ edit ] 

 مرغ • ( murġ / morġ ) ( plural مرغ‌ها ( murġ-hā / morġ-hâ ) , or مرغان ( murġān / morġân ) , Tajik spelling мурғ ) 

 hen 
 تخم‌گذاری مرغ ― tuxm-guzārī-yi  / toxm-gozâri-ye murġ  / morġ ― hen laying eggs 

 ( synecdochic ) chicken (regardless of sex)

 ( archaic , poetic , or in compounds ) bird 
 c. 1260s , Jalāl ad-Dīn Mohammad Rūmī , translated by Reynold A. Nicholson , مثنوی معنوی [ Masnavi-ye-Ma'navi ], volume I, verse 3412: کاتب آن وحی ز آن آواز مرغ 
برده ظنی کاو بود همباز مرغ‌‌ kātib-i ān wahy zi ān āwāz-i murġ 
burda zannē k-ō buwad hambāz-i murġ The writer of the Revelation, from (hearing) the Bird' s voice,
supposed that he was the Bird' s equal. ( Classical Persian transliteration ) 

 ( archaic or poetic ) nightingale
