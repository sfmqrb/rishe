 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *mey- [ 1 ] [ 2 ] 

 to attach , bind , strengthen

 Root
 [ edit ] 

 *mey- [ 7 ] [ 8 ] 

 to change 

 to exchange 

 to change places → to go past

 Alternative reconstructions
 [ edit ] 

 *h₂mey- , if *h₂meygʷ- ( “ to exchange, to wander ” ) (compare Ancient Greek ἀμείβω ( ameíbō ) and Latin migro ) belongs here.

 Root
 [ edit ] 

 *mey- [ 10 ] [ 11 ] 

 small , little 

 Alternative reconstructions
 [ edit ] 

 *meyh₁- [ 12 ] 

 *(s)mey(h₁)- , *(s)mey(h₁)-g/k- ( if related to Latin mīca , Ancient Greek σμῑκρός ( smīkrós ) / μικρός ( mikrós ) , Proto-Germanic *smikraz etc., but these appear to be formally incompatible, perhaps sound-symbolic )
