 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 جفتن 

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( ywmb-ytn' /⁠jumbīdan⁠/ ) , from Proto-Iranian *Hyámbdi ( “ to move around ” ) , from Proto-Indo-European *h₃yebʰ- ( “ to enter into ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /d͡ʒum.biː.ˈdan/ 

 ( Dari, formal ) IPA ( key ) : [d͡ʒʊm.biː.d̪án] 

 ( Dari, formal ) IPA ( key ) : [d͡ʒʊm.biː.d̪án] 
 ( Kabuli ) IPA ( key ) : [d͡ʒʊm.biː.d̪án] 

 ( Hazaragi ) IPA ( key ) : [d͡ʒum.bi.d̪án] 

 ( Iran, formal ) IPA ( key ) : [d͡ʒom.biː.d̪ǽn] 

 ( Tajik, formal ) IPA ( key ) : [d͡ʒum.bi.d̪án] 

 Rhymes: -an

 Verb
 [ edit ] 

 جنبیدن • ( jonbidan ) ( present stem جنب ( jonb ) ) 

 to shake , quiver , vibrate 

 to move around, fidget ; wiggle around

 to move it , get a move on
