 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 رویناس ( rōynās ) , روغناس ( rōġnās ) 

 رویان ( rōyān ) , رودینه ( rōdīna ) , روذینه ( rōḏīna ) ( obsolete ) 

 Etymology
 [ edit ] 

 Borrowed from Ancient Greek ῥόϊνος ( rhóïnos , “ garnet, pomegranate-coloured ” ) , influenced by روی ( rōy , “ copper ” ) , plausibly also acquired via Aramaic attested in Classical Syriac ܪܘܙܢܘܣ .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /roː.ˈnaːs/ 

 ( Dari, formal ) IPA ( key ) : [roː.nɑ́ːs] 

 ( Dari, formal ) IPA ( key ) : [roː.nɑ́ːs] 
 ( Kabuli ) IPA ( key ) : [roː.nɑ́ːs] 

 ( Hazaragi ) IPA ( key ) : [rʊː.nɔ́ːs] 

 ( Iran, formal ) IPA ( key ) : [ɹo.nɒ́ːs] 

 ( Tajik, formal ) IPA ( key ) : [ɾɵ.nɔ́s] 

 Rhymes: -aːs
