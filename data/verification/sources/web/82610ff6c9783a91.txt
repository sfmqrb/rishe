 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ἀλωή ( alōḗ ) — Epic 

 ἀλωά ( alōá ) — Doric 

 Etymology
 [ edit ] 

 Probably from Pre-Greek . Compare, however, Albanian lëmë and its proto-form.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /há.lɔːs/ → /ˈa.los/ → /ˈa.los/ 

 ( 5 th BCE Attic ) IPA ( key ) : /há.lɔːs/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈ(h)a.los/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈa.los/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈa.los/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈa.los/ 

 Noun
 [ edit ] 

 ᾰ̔́λως • ( hắlōs )  f ( genitive ᾰ̔́λω ) ; second declension 

 threshing floor 

 grain on the floor

 disk ( of the sun, the moon, or a shield ) 

 halo 

 serpent's coil

 bird's nest

 ciliary body of the eye

 circular piazza at Delphi

 Declension
 [ edit ] 

 Attic second declension of ἡ ᾰ̔́λως ; τῆς ᾰ̔́λω ( Attic )
