 Etymology 1
 [ edit ] 

 The “light” noun is inherited from Proto-Semitic *nūr- .

 Pronunciation
 [ edit ] 

 Verb: IPA ( key ) : /naw.wa.ra/ 

 Noun 1: IPA ( key ) : /nawr/ 

 Noun 2: IPA ( key ) : /nuːr/ 

 Verb
 [ edit ] 

 نَوَّرَ • ( nawwara ) II ( non-past يُنَوِّرُ ( yunawwiru ) , verbal noun تَنْوِير ( tanwīr ) ) 

 to flower , to blossom 

 to light , to radiate , to illuminate 

 to shed light 

 to enlighten

 النور 

 نُور • ( nūr )  m ( plural أَنْوَار ( ʔanwār ) )

 الْقَمَرُ يُضِيءُ اللَّيْلَ بِ نُورِ هِ السَّاحِرِ. al-qamaru yuḍīʔu l-layla bi- nūri hi s-sāḥiri. The moon illuminates the night with its enchanting light . 

 brightness , gleam , glow 

 illumination 

 lamp , light , lantern 

 headlight

 Ottoman Turkish

 Etymology
 [ edit ] 

 Borrowed from Arabic نُور ( nūr , “ light, ray of light ” ) , from Proto-Semitic *nūr- ( “ light ” ) . 

 Noun
 [ edit ] 

 نور • ( nur ) ( definite accusative نوری ( nuru ) , plural انوار ( envâr ) or نیران ( nirân ) ) 

 light , the electromagnetic radiation in the wavelength range visible to the human eye 
 Synonyms: آیدین ( aydın ) , ایشق ( ışık ) 

 light , any source of illumination , such as a candle , lightbulb , torch , lamp , streetlight , etc.
 Synonyms: آیدین ( aydın ) , ایشق ( ışık ) , چراغ ( çerağ, çirağ ) , سراج ( sirac )
