 Karakhanid
 [ edit ] 

 Etymology
 [ edit ] 

 Uncertain, according to Clauson, a borrowing. Similarity to Persian موش ( muš , “ mouse ” ) is a coincidence. [ 1 ] 
compare with Uyghur مۈشۈك ( müshük ) and Uzbek mushuk .

 Noun
 [ edit ] 

 موُشْ ( mǖš ) 

 ( Chigil ) cat 
 اُلْدَجىِ سِجْغانْ موُشْ تَشَقىِ قَشِرْ ― Öldečī sïčğān mǖš tašaqï̄ qašïr. ― The dying rat scratches the cat's testicles.

 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Persian موش ( muš , “ mouse ” ) , itself from Middle Persian [script needed] ( mwšk' /⁠mušk⁠/ , “ mouse, rat ” ) .

 Noun
 [ edit ] 

 موش • ( muş ) ( definite accusative موشی ( muşu ) , plural موشلر ( muşlar ) ) 

 mouse , rat , any small or medium-sized rodent of the genera Mus and Rattus 
 Synonyms: صیچان ( sıçan ) , فاره ( fare ) 

 rodent , any mammal of the order Rodentia , characterized by long incisors 
 Synonym: كمریجی ( kemirici )

 موش پرنده ( muş-i perende , “ bat ” )

 Persian موش 

 Inherited from Middle Persian [script needed] ( mwšk' /⁠mušk⁠/ , “ mouse, rat ” ) , from Proto-Iranian *múHs , from Proto-Indo-Iranian *múHs , from Proto-Indo-European *múHs . Doublet of ماوس ( mâvs ) .

 Noun
 [ edit ] 

 موش • ( mūš / muš ) ( plural موش‌ها ( mūš-hā / muš-hâ ) , Tajik spelling муш ) 

 mouse ; rat 
 دم موش ― dom-e muš ― mouse tail; rat tail 

 cutie ; someone cute 
 موش ی ― muš -i ― you're a cutie 

 synonym of ماوس ( māws  / mâvs , “ computer mouse ” )
