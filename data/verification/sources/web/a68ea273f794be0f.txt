 Adjective

 صَفْرَاء • ( ṣafrāʔ ) 

 feminine singular of أَصْفَر ( ʔaṣfar ) 

 Noun
 [ edit ] 

 صَفْرَاء • ( ṣafrāʔ )  f ( dual صَفْرَاوَان ( ṣafrāwān ) , plural صَفْرَاوَات ( ṣafrāwāt ) or صُفْر ( ṣufr ) ) 

 bile 
 Synonym: مِرَّة ( mirra )
