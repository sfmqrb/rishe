 Irish
 [ edit ] 

 Etymology
 [ edit ] 

 From Old Irish tóeb , [ 1 ] from Proto-Celtic *toibos .

 Pronunciation
 [ edit ] 

 ( Munster ) IPA ( key ) : /t̪ˠeːvˠ/ [ 2 ] 

 ( Connacht ) IPA ( key ) : /t̪ˠiːvˠ/ [ 3 ] [ 4 ] [ 5 ] , /t̪ˠiːw/ [ 6 ] [ 7 ] 

 ( Ulster ) IPA ( key ) : /t̪ˠiːw/ , ( older ) /t̪ˠɯːw/ [ 8 ] 

 Noun
 [ edit ] 

 taobh   m ( genitive singular toibh , nominative plural taobhanna ) or 

 taobh   f ( genitive singular toibhe , nominative plural taobha ) 

 side , flank

 Scottish Gaelic
 [ edit ] 

 Etymology
 [ edit ] 

 From Old Irish tóeb , from Proto-Celtic *toibos .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /t̪ʰɯːv/ [ 1 ] 

 ( Lewis ) IPA ( key ) : /t̪ʰɯːv/ , /t̪ʰuː/ , ( unstressed ) /t̪ʰu/ [ 2 ] 

 ( Ross-shire , Sutherland , East Perthshire , Mid Argyll ) IPA ( key ) : /t̪ʰuː/ [ 3 ] 

 ( Strathspey ) IPA ( key ) : /t̪ʰʊi/ 

 ( West Perthshire , eastern Argyll ) IPA ( key ) : /t̪ʰɤː/ 

 Noun
 [ edit ] 

 taobh   m ( genitive singular taoibh , nominative plural taobhan ) 

 side 

 way , direction
