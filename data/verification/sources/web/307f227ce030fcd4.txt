 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 ᾰ̓ρτηρῐ́η ( ărtērĭ́ē ) — Ionic 

 Etymology
 [ edit ] 

 Supposed contraction of *ᾰ̓ορτηρῐ́ᾱ ( *ăortērĭ́ā ) (cf. ᾰ̓ορτήρ ( ăortḗr ) ), from ᾰ̓είρω ( ăeírō , “ to bind, hang up ” ) . [ 1 ] 

 It was assumed that all blood vessels transported both blood and πνεῦμα ( pneûma , “ breath, spirit ” ) , in a similar way as how the latter is transported through the τραχεῖα ἀρτηρία ( trakheîa artēría , literally “ rough artery ” ) . [ 2 ] This might explain why windpipe and artery share the same name.

 Noun
 [ edit ] 

 ᾰ̓ρτηρῐ́ᾱ • ( ărtērĭ́ā )  f ( genitive ᾰ̓ρτηρῐ́ᾱς ) ; first declension 

 ( anatomy ) 
 windpipe , trachea 
 Synonyms: τραχεῖα ἀρτηρία ( trakheîa artēría ) , βρόγχος ( brónkhos ) , γαργαρεών ( gargareṓn ) 

 artery ( as distinct from a vein )

 aorta 
 Synonym: ᾰ̓ορτή ( ăortḗ ) 

 ( in the plural ) ureters 

 ( in the plural ) bronchi 
 Synonym: βρόγχια ( brónkhia )
