 Central Kurdish
 [ edit ] 

 سماق ( Rhus coriaria ) 
 Etymology
 [ edit ] 

 Borrowed from Arabic سُمَّاق ( summāq ) , from Classical Syriac ܣܘܡܩܐ ( summāqā , “ red; sumac ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /səmaːq/ 

 Noun
 [ edit ] 

 Northern Kurdish

 simaq 

 سماق ( simaq ) 

 sumac ( Rhus )
 particularly, tanner's sumac ( Rhus coriaria )

 sumac (spice)
