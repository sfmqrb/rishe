 Etymology
 [ edit ] 

 From Middle Persian pstk' ( pistag ) , if not via Aramaic ( Jewish Babylonian Aramaic פיסתקא ( pistəqā ) , פסתקא ( pistəqā ) , Classical Syriac ܦܘܣܬܩܐ ( pustəqā ) , ܦܷܣܬܩܐ ( pestəqā ) ).

 Borrowed from Arabic فُسْتُق ( fustuq , “ pistachio ” ) , borrowed from Middle Persian pstk' ( pistag ) , from Old Persian *pistaka , possibly from Proto-Iranian *pištakáh ( “ crushed ” ) , from Proto-Indo-Iranian *pištás + *-ikas .

 Noun
 [ edit ] 

 فستق • ( fıstık ) ( definite accusative فستغی ( fıstığı ) , plural فستقلر ( fıstıklar ) ) 

 pistachio , the nutlike fruit produced by any tree in the species Pistacia vera

 Etymology
 [ edit ] 

 From Arabic فُسْتُق ( fustuq ) , from Middle Persian pstk' ( pistag , “ pistachio nut ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /fus.toʔ/ , [ˈfʊs.toʔ] 

 Audio ( Ramallah ) : ( file ) 

 Noun
 [ edit ] 

 فستق • ( fustuʔ )  m ( collective , singulative فستقة   f ( fustuʔa ) , paucal فستقات ( fustuʔāt ) ) 

 peanuts 
 Synonyms: فستق عبيد ( fustuʔ ʕabīd ) , ( formal ) فول سوداني ( fūl sūdānī ) 

 pistachios 
 Synonym: فستق حلبي ( fustuʔ ḥálabi , literally “ Aleppo peanuts ” ) 
 Audio ( Ramallah ) : ( file ) 

 فستقة / حبّة فستق ― fustoʔa / ḥabbet fustoʔ ― a peanut / pistachio
