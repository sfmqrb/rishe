 Hebrew
 [ edit ] 

 Root 

 צ־ח־ק ( ts-kh-q ) 

 6 terms 

 Alternative forms
 [ edit ] 

 יִשְׂחָק ( yiskhák, yiśḥāq ) 

 Etymology
 [ edit ] 

 Grammatically, the third person singular imperfect of צָחַק ( tsakhák , “ to laugh ” ) .

 Pronunciation
 [ edit ] 

 ( reconstructed Biblical ) IPA ( key ) : /jisˤˈħaq/ [jisˤˈħakˤ] or [jit͡sˤˈħakˤ] 

 ( Tiberian ) IPA ( key ) : /jisˤˈħɔːq/ [jisˤˈħɔːq] 

 ( Yemenite ) IPA ( key ) : /jisˤˈħɔq/ [jisˤˈħɔːɡ] ( Sanaani ) , [jisˤˈħɔːq] ( Sharaabi ) 

 ( Persian ) IPA ( key ) : /jisˈhɒɢ/ [jisˈhɒʁ] 

 ( Sephardi ) IPA ( key ) : /jisˈχak/ ( Iberian ) , /jisˤˈħaq/ ( Mizrahi ) 

 ( Ashkenazi ) IPA ( key ) : /jit͡sˈχɔk/ , [ˈjɪt͡s.χɔk] 

 ( Modern Israeli ) IPA ( key ) : /(j)it͡sˈχak/ , ( Oriental ) [jit͡sˈħak] 
 Audio : ( file ) 

 Proper noun
 [ edit ] 

 יִצְחָק • ( yitskhák, yiṣḥāq )  m 

 ( biblical ) Isaac ( the son of Abraham and Sarah , father of Esau and Jacob , from whom the Hebrew people trace their descent ) 

 a male given name , equivalent to English Isaac

 Verb
 [ edit ] 

 יִצְחַק • ( yitskhák ) 

 Third-person masculine singular future (prefix conjugation) of צָחַק ( tsakhák ) , to laugh.
