 Ottoman Turkish
 [ edit ] 

 Etymology 1
 [ edit ] 

 Borrowed from Persian موبد ( mowbed, mubed , “ mobad ” ) .

 Noun
 [ edit ] 

 موبد • ( mubed ) ( plural موبدان ) 

 mobad , a Zoroastrian cleric 

 Descendants
 [ edit ] 

 Turkish: mubid

 [ edit ]

 Adjective
 [ edit ] 

 موبد • ( muʿebbed ) 

 perpetual , eternal , everlasting , permanent 
 Synonyms: ابدی ( ebedî ) , دایم ( daim ) , صوڭسز ( soñsız )

 Alternative forms

 Etymology
 [ edit ] 

 From [Book Pahlavi needed] ( mgwpt' /⁠mowbed⁠/ ) with the same meaning, from Old Persian *magupatiš⁠ ( literally “ head of the Magi ” ) . By surface analysis , مغ ( moġ , “ magus ” ) +‎ ـبد ( -bad , “ lord, master ” ) . Compare the Iranian borrowings: Old Armenian մոգպետ ( mogpet ) , մովպետան մովպետ ( movpetan movpet ) , մուբիտան մուբիտ ( mubitan mubit ) , Classical Syriac ܡܘܒܕ ( mawbed ) , ܡܘܗܦܛܐ ( mawhəp̄āṭā ) .
