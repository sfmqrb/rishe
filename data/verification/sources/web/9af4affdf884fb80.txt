 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian nxwst ( naxwist , “ first ” ) , from Proto-Iranian *naxwist- ( “ first ” ) , from Proto-Iranian *naxu- ( “ first, in front, high ” ) , of uncertain origin, with no known cognates outside Iranian. Cognate to Northern Kurdish nexrî ('first-born') and akin to Old Armenian նախ ( nax ) , an Iranian borrowing. [ 1 ] [ 2 ]

 ( Dari, formal ) IPA ( key ) : [nʊ.xʊst̪] , [nä.xʊst̪]

 ( Iran, formal ) IPA ( key ) : [no.xost̪ʰ] , [næ.xost̪ʰ]

 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian نُخُسْت ( nuxust ) . Compare روزِ نُخُسْت ( roz-i nuxust ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /nʊ.xʊst̪/ , /nə.xʊst̪/ 

 Hyphenation: نُ‧خُسْت 

 Adjective
 [ edit ] 

 نُخُسْت or نَخُسْت • ( nuxust or naxust ) ( Hindi spelling नुख़ुस्त or नख़ुस्त ) 

 first 
 Synonyms: پہلا ( pahlā ) , اول ( avval ) , یکم ( yakum ) , فَرْدُم ( fardum ) 

 foremost , primary 
 Synonyms: نُخُسْتِین ( nuxustīn ) , اولین ( avvalīn ) , اولاً ( avvalan ) , فَرْدُم ( fardum )
