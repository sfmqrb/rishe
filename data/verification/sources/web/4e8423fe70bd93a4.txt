 Noun
 [ edit ] 

 کمیسیون • ( komisiyon ) ( plural کمیسیون‌ها ) 

 commission ( fee charged by an agent or broker for carrying out a transaction ) 
 Synonym: حق‌العمل ( haqq-ol'-amal ) 

 committee , commission 
 Synonyms: هیئت ( hey'at ) , کمیته ( komite )
