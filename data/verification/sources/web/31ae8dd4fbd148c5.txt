 [ edit ]

 بچه • ( bačča, bača / bačče, bače ) ( plural بچگان , or بچه‌ها ( bačča-hā, bača-hā / bačče-hâ, bače-hâ ) , Tajik spelling бача , or бача ) 

 child , kid 
 Synonyms: فَرزَند ( farzand ) , کودک ( kôdak ) 

 ( informal ) native to
 بَچهِ اِصفَهانَم ― bačče -ye esfahân-am ― I'm native to Isfahan. 

 ( Dari ) boy , son 
 Synonym: پسر ( pesar ) 

 ( Dari , informal ) bro 

 Usage notes
 [ edit ] 

 In Dari, بچه ( bačča ) usually means "boy," not "child," with most Kabuli speakers using کودک ( kōdak ) for the sense of "child." In some Iranian dialects ببه (babe) is used which may be related to English baby .
