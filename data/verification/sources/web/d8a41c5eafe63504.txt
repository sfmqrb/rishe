 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭤𐭭𐭰𐭠𐭥 ( hanjār ) , from Parthian ʾnjʾr ( anjār , “ behaviour ” ) . Akin to Old Armenian հանճար ( hančar ) , an Iranian borrowing.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /han.ˈd͡ʒaːr/ 

 ( Dari, formal ) IPA ( key ) : [hän.d͡ʒɑːɾ] 

 ( Dari, formal ) IPA ( key ) : [hän.d͡ʒɑːɾ] 
 ( Kabuli ) IPA ( key ) : [ʔän.d͡ʒɑːɾ] 

 ( Hazaragi ) IPA ( key ) : [ʔän.d͡ʒɔːɾ]

 Noun
 [ edit ] 

 هنجار • ( hanjār / hanjâr ) ( plural هنجارها ( hanjār-hā / hanjâr-hâ ) , Tajik spelling ҳанҷор ) 

 norm , convention 
 هنجارها ی اجتماعی ― hanjār-hā -ye ejtemâ'i ― social norms 

 way , rule , law 

 habit , custom
