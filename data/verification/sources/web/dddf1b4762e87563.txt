 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 تاویدن ( tāvidan ) 

 تابیدن ( tābidan ) 

 Etymology 1
 [ edit ] 

 From Proto-Iranian *tāp- ( “ to twist, wind ” ) , perhaps from Proto-Indo-European *temp- ( “ to span, stretch, extend ” ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /taːf.ˈtan/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰɑːf.t̪ʰán] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰɑːf.t̪ʰán] 
 ( Kabuli ) IPA ( key ) : [t̪ʰɑːf.t̪ʰán] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰɔːf.t̪ʰán] 

 ( Iran, formal ) IPA ( key ) : [t̪ʰɒːf.t̪ʰǽn] 

 ( Tajik, formal ) IPA ( key ) : [t̪ʰɔf.t̪ʰán] 

 Rhymes: -an 

 Readings

 Verb
 [ edit ] 

 تافتن • ( tâftan ) ( present stem تاب ( tâb ) ) 

 to twist 

 to twine 

 Related terms
 [ edit ] 

 تابیدن ( tâbidan )

 Etymology 2
 [ edit ] 

 From Proto-Indo-European *tep- ( “ to be warm, tepid ” ) .

 Verb
 [ edit ] 

 تافتن • ( tâftan ) ( present stem تاب ( tâb ) ) 

 to heat 

 to shine
