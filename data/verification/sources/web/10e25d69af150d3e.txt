 Persian فلفل 

 Borrowed from Arabic فِلْفِل ( filfil ) , from Classical Persian پلپل ( pilpil ) , from Sanskrit पिप्पलि ( pippali , “ long pepper ” ) , ultimately from Dravidian . Compare Tamil திப்பலி ( tippali ) , Swahili pilipili , Aramaic פלפלא ( pelplā ) , Hebrew פלפל ( pilpél ) , Old Armenian պղպեղ ( płpeł ) , պղպիղ ( płpił ) , Armenian պղպեղ ( pġpeġ ) and Georgian პილპილი ( ṗilṗili ) , Iranian borrowings.

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /fil.ˈfil/ 

 ( Dari, formal ) IPA ( key ) : [fɪl.fɪ́l] 

 ( Dari, formal ) IPA ( key ) : [fɪl.fɪ́l] 
 ( Kabuli ) IPA ( key ) : [fɪl.fɪ́l] 

 ( Hazaragi ) IPA ( key ) : [fil.fíl̥] 

 ( Iran, formal ) IPA ( key ) : [fel.fél̥] 

 ( Tajik, formal ) IPA ( key ) : [fil.fíl]
