 Arabic

 Etymology 1
 [ edit ] 

 Root 

 ع ر ي ( ʕ r y ) 

 7 terms 

 Derived from the active participle of عَرِيَ ( ʕariya , “ to become naked ” ) 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕaː.rin/ 

 Adjective
 [ edit ] 

 عَارٍ • ( ʕārin ) ( informal عَارِي ( ʕārī ) , feminine عَارِيَة ( ʕāriya ) , masculine plural عَارُون ( ʕārūn ) or عُرَاة ( ʕurāh ) , feminine plural عَارِيَات ( ʕāriyāt ) or عَوَارٍ ( ʕawārin , informal عَوَارِي ( ʕawārī ) ) ) 

 active participle of عَرِيَ ( ʕariya ) .

 bare , naked , nude 

 stark , barren 

 blank 

 free of, devoid of, deprived of ( with عَن ( ʕan ) or مِن ( min ) )

 Etymology 3
 [ edit ] 

 Morphologically from the root ع ي ر ( ʕ y r ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕaːr/ 

 Noun
 [ edit ] 

 عَار • ( ʕār )  m ( plural أَعْيَار ( ʔaʕyār ) ) 

 shame , disgrace , ignominy 
 Antonym: شَرَف ( šaraf ) 
 Abu al-Aswad al-Du'ali 
 لَا تَنْهَ عَنْ خُلُقٍ وَتَأْتِيَ مِثْلَهُ 
 عَارٌ عَلَيْكَ إِذَا فَعَلْتَ عَظِيمُ lā tanha ʕan ḵuluqin wataʔtiya miṯlahu 
 ʕārun ʕalayka ʔiḏā faʕalta ʕaẓīmu Do not forbid a thing you do; 
 If you do, shame on you.
