 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( whwmn' /⁠wahman⁠/ ) , see Persian بهمن ( bahman ) below.

 Pronunciation
 [ edit ] 

 IPA ( key ) : /bah.man/ 

 Noun
 [ edit ] 

 بَهْمَن • ( bahman )  m 

 behen 
 1025 , ابن سينا (Avicenna) , القانون في الطب‎ [ Canon Medicinae ], Rome: Stamperia Orientale Medicea , published 1593 , Liber 2, page 252 : زعم قوم أن الريوند أصول بهمن في الصين ويجلب من ثم الى البلاد The people says that the rhubarb is the stems of the behen in China and it is imported from there into the bleds. 

 white behen ( Centaurea behen )

 red behen ( Limonium vulgare )

 Etymology
 [ edit ] 

 From Middle Persian [Book Pahlavi needed] ( whwmn' /⁠wahman⁠/ ) , from Old Persian *Vahumanāh , name of the first Amahraspand (divine deity) in Zoroastrianism, guardian of cattle, in Avestan 𐬬𐬊𐬵𐬎⸱𐬨𐬀𐬥𐬀𐬵 ( vohu.manah ) . Also showing botanical meanings in Middle Persian, from which Classical Syriac ܒܗܡܢ ( bahman ) and Arabic بَهْمَن ( bahman ) are borrowed.

 Proper noun
 [ edit ] 

 بهمن • ( bahman ) ( Tajik spelling баҳман ) 

 Bahman ( the eleventh solar month of the Persian calendar ) 

 Name of the second day of any month of the solar Persian calendar

 a male given name , Bahman
