 Arabic
 [ edit ] 

 Root 

 ء ب ه ( ʔ b h ) 

 2 terms 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʔa.ba.ha/ , /ʔa.bi.ha/ 

 Verb
 [ edit ] 

 أَبَهَ or أَبِهَ • ( ʔabaha or ʔabiha ) I ( non-past يَأْبَهُ ( yaʔbahu ) , verbal noun أَبَه ( ʔabah ) or أَبْه ( ʔabh ) ) 

 to pay attention 

 to heed 

 to take notice
