 Etymology
 [ edit ] 

 From گرد ( gerd , “ round ” ) + ـو ( -u ) .

 Pronunciation
 [ edit ] 

 ( Iran, formal ) IPA ( key ) : [ɡʲeɹ.d̪úː]

 گردو • ( gerdu ) ( plural گردوها ) 

 ( Iran ) walnut 
 Synonyms: گوز ( gowz ) , گردکان ( gerdekân ) , چارمغز ( čârmaġz ) , جوز ( jowz ) 
 گردو شکستن ― gerdu šekastan ― cracking a walnut
