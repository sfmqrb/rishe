 Arabic
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ba.haːʔ/ 

 Rhymes: -aːʔ 

 Etymology 1
 [ edit ] 

 From the root ب ه و ( b h w ) or ب ه ي ( b h y ) .

 Noun
 [ edit ] 

 بَهَاء • ( bahāʔ )  f 

 verbal noun of بَهَا ( bahā )   ( form I ) 

 verbal noun of بَهَى ( bahā )   ( form I ) 

 beauty , splendour 

 (of God) glory , greatness , majesty

 Noun

 بَهَاء • ( bahāʔ )  f 

 ( obsolete ) a she-camel familiar with, accustomed to, tame towards, its milker

 Persian
 [ edit ] 

 Alternative forms
 [ edit ] 

 بها ( bahâ ) ( unhamzated ) 

 Etymology
 [ edit ] 

 Borrowed from Arabic بَهَاء ( bahāʔ ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ba.ˈhaːʔ/ , /ba.ˈhaː/ 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑ́ːʔ] , [bä.ɦɑ́ː] 

 ( Dari, formal ) IPA ( key ) : [bä.ɦɑ́ːʔ] , [bä.ɦɑ́ː] 
 ( Kabuli ) IPA ( key ) : [bɑːɑ́ː] , [bɑːɑ́ː] 

 ( Hazaragi ) IPA ( key ) : [bɔːɔ́ː] , [bɔːɔ́ː] 

 ( Iran, formal ) IPA ( key ) : [bæ.ɦɒ́ːʔ] , [bæ.ɦɒ́ː] 

 ( Tajik, formal ) IPA ( key ) : [bä.ɦɔ́ʔ] , [bä.ɦɔ́]
