 Hindi
 [ edit ] 

 Etymology
 [ edit ] 

 Learned borrowing from Sanskrit यातु ( yātú ) . Doublet of जादू ( jādū ) .

 Pronunciation
 [ edit ] 

 ( Standard Hindi ) IPA ( key ) : /jɑː.t̪uː/ , [jäː.t̪uː] 

 Noun
 [ edit ] 

 यातु • ( yātu )  m ( rare , formal ) 

 one who goes or wanders 

 a demon , rakshasa 

 witchcraft , black magic

 Etymology 1
 [ edit ] 

 From Proto-Indo-Iranian *yaHtúš ( “ magic, witchcraft, sorcery ” ) , possibly from Proto-Indo-European *yeh₁- ( “ to do, make, act vigorously ” ) . Cognate with Avestan 𐬫𐬁𐬙𐬎 ( yātu ) , Old Persian 𐎹𐎠𐎬𐎢 ( yātu ) (whence Persian جادو ( jâdu , “ magic ” ) ).

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /jɑː.tú/ 

 ( Classical Sanskrit ) IPA ( key ) : /jɑː.t̪u/ 

 Noun
 [ edit ] 

 या॒तु • ( yātú ) stem ,  m 

 witchcraft , black magic 
 c. 1500 BCE – 1000 BCE , Ṛgveda 5.12.2 : नाहं यातुं सहसा न द्वयेन ऋतं सपाम्यरुषस्य वृष्णः ॥ nāhaṃ yātuṃ sahasā na dvayena ṛtaṃ sapāmyaruṣasya vṛṣṇaḥ. I use no sorcery with might or falsehood; the sacred Law of the Red Steer I follow. 

 a kind of evil spirit, demon
