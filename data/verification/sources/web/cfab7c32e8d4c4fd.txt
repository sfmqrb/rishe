 Etymology
 [ edit ] 

 From Proto-Indo-Iranian *ćRayš ( “ to adhere, attach ” ) ; cognate with Persian سِریشُم ( serišom , “ glue ” ) . Further origin is uncertain; perhaps related to Proto-Indo-European *ḱley- ( “ to lean, incline ” ) .

 Pronunciation
 [ edit ] 

 ( Vedic ) IPA ( key ) : /ɕliʂ/ 

 ( Classical Sanskrit ) IPA ( key ) : /ɕl̪iʂ/ 

 Root
 [ edit ] 

 श्लिष् • ( śliṣ ) 

 to adhere , attach , cling to

 to clasp , embrace 

 to unite , join 

 to result , be the consequence of anything 

 to be joined or connected 

 to be implied or intimated

 [ edit ]
