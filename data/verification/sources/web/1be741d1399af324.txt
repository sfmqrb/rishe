 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭣𐭯𐭩𐭥𐭥 ( dibīr ) , see there for more. Borrowed into Sanskrit as दिविर ( divira , “ scribe ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /da.ˈbiːr/ 

 ( Dari, formal ) IPA ( key ) : [d̪ä.bíːɾ] 

 ( Dari, formal ) IPA ( key ) : [d̪ä.bíːɾ] 
 ( Kabuli ) IPA ( key ) : [d̪ä.bíːɾ] 

 ( Hazaragi ) IPA ( key ) : [d̪ä.bíɾ] 

 ( Iran, formal ) IPA ( key ) : [d̪æ.bíːɹ] 

 ( Tajik, formal ) IPA ( key ) : [d̪ä.bíɾ] 

 Rhymes: -iːr

 Noun
 [ edit ] 

 دبیر • ( dabir ) 

 high school teacher 

 ( historical ) scribe , secretary 

 ( historical ) writing - master
