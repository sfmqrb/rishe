 Etymology 1
 [ edit ] 

 Compare Hebrew עָקֵב ( ʿāqēḇ , “ heel ” ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕa.qib/ , /ʕaqb/ 

 Noun
 [ edit ] 

 عَقِب or عَقْب • ( ʕaqib or ʕaqb )  f or m ( plural أَعْقَاب ( ʔaʕqāb ) ) 

 ( feminine ) heel 

 ( masculine ) end 

 ( masculine ) grandson 

 ( masculine ) offspring , progeny

 Pronunciation

 Verb
 [ edit ] 

 عَقَّبَ • ( ʕaqqaba ) II ( non-past يُعَقِّبُ ( yuʕaqqibu ) , verbal noun تَعْقِيب ( taʕqīb ) ) 

 to follow , to succeed ; to ensue , to pursue , to trail , to tail ; to return to

 to comment , to revise [ with عَلَى ( ʕalā ) ]

 Etymology 5
 [ edit ] 

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ʕuqb/ , /ʕu.qub/ 

 Noun
 [ edit ] 

 عُقْب or عُقُب • ( ʕuqb or ʕuqub )  m 

 end , latter   part , consequence , result , issue , butt , that wherewith one is left 
 Synonyms: عُقْبَة ( ʕuqba ) , عُقْبَى ( ʕuqbā ) , عَاقِبَة ( ʕāqiba ) , عِقْبَان ( ʕiqbān ) , عُقْبَان ( ʕuqbān ) 
 609–632 CE , Qur'an , 18:44 : هُنَالِكَ ٱلْوَلَايَةُ لِلّٰهِ ٱلْحَقِّ هُوَ خَيْرٌ ثَوَابًا وَخَيْرٌ عُقْبًا hunālika l-walāyatu lillāhi l-ḥaqqi huwa ḵayrun ṯawāban waḵayrun ʕuqban At this time, support comes ˹only˺ from Allah—the True ˹Lord˺. He is best in reward and best in outcome .

 Noun

 عقب • ( ʿakab ) 

 heel , the rear part of the foot , where it joins the leg 
 Synonyms: اوكچه ( ökçe ) , طوپوق ( topuk )
