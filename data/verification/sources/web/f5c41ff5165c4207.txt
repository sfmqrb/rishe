 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( glwb' /⁠graw⁠/ ) , from Proto-Indo-Iranian *grabʰ- , from Proto-Indo-European *gʰrebʰ- . Cognate with Avestan 𐬔𐬀𐬭𐬆𐬡 ( gar ə β , “ to seize ” ) , Sanskrit ग्रभ् ( grabh ) , English grab . Related to گرفتن ( gereftan , “ to take ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ɡi.ˈraw/ , /ɡa.ˈraw/ 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾáw] 

 ( Dari, formal ) IPA ( key ) : [ɡɪ.ɾáw] 
 ( Kabuli ) IPA ( key ) : [ɡɪ.ɾáw] 

 ( Hazaragi ) IPA ( key ) : [ɡi.ɾáw] 

 ( Iran, formal ) IPA ( key ) : [ɡʲe.ɹów] 

 ( Tajik, formal ) IPA ( key ) : [ɡä.ɾáw] 

 Rhymes: -aw 

 Readings

 Classical reading ? 

 giráw, garáw

 Dari reading ? 

 giraw

 Iranian reading ? 

 gerov

 Tajik reading ? 

 garav

 Noun
 [ edit ] 

 گرو • ( giraw / gerov ) ( Tajik spelling гирав ) 

 mortgage ; security ; pawn 
 Synonym: رهن ( rahn ) 

 pledge 

 wager ; bet
