 Ottoman Turkish
 [ edit ] 

 این 
 Etymology
 [ edit ] 

 Inherited from Proto-Turkic *īn ( “ lair, burrow ” ) ; [ 1 ] cognate with Old Turkic 𐰃𐰤 ( in ) , Kazakh ін ( in ) , Southern Altai ийин ( iyin ) , Turkmen hīn , Uzbek in and Yakut иин ( iin ) .

 Noun
 [ edit ] 

 این • ( in ) ( definite accusative اینی ( ini ) , plural اینلر ( inler ) ) 

 den , lair , burrow , luster , any small cave or hollow place used by an animal for shelter or concealment 
 Synonyms: جحر ( cuhr ) , عرین ( ʼarin ) , كنام ( künâm )

 [ edit ]

 Persian

 Alternative forms
 [ edit ] 

 ای ( ē  / i ) , اِی ( ī  / i ) ( dialectal , Dashtestan , Bushehr , Kabuli , Mashhad , Shiraz , Kazerun ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian 𐭦𐭭𐭤 ( ēn ) . Compare Mazanderani ام ( am ) , Central Kurdish ئەم ( em ) , Northern Kurdish ev , Alviri-Vidari ام ( am ) . Possibly related to Sanskrit एन ( ena ) .
