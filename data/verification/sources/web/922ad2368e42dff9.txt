 جَزّ 
 Etymology 1
 [ edit ] 

 Root 

 ج ز ز ( j z z ) 

 5 terms 

 Pronunciation
 [ edit ] 

 Verb: IPA ( key ) : /d͡ʒaz.za/ 

 Noun: IPA ( key ) : /d͡ʒazz/ 

 Verb
 [ edit ] 

 جَزَّ • ( jazza ) I ( non-past يَجُزُّ ( yajuzzu ) , verbal noun جَزّ ( jazz ) ) 

 to shear , to prune , to cut down , to fleece 

 to slash , to gash 

 to mow ; to churn up

 Preposition
 [ edit ] 

 جز • ( juz  / joz ) ( Tajik spelling ҷуз ) 

 except 
 جز این از هر کتابی خوشم می‌آد. 
 joz in az har ketâbi xošam mi-âd.
 I like every book except for this one.
