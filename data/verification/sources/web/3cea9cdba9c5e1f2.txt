 English Wikipedia has an article on: balalaika 

 Wikipedia 

 A balalaika 
 Alternative forms
 [ edit ] 

 balalajka , balalayka 

 Etymology
 [ edit ] 

 From Russian балала́йка ( balalájka ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /bæləˈlaɪkə/ 

 Audio ( Southern England ) : ( file ) 

 Audio ( US ) : ( file ) 

 Rhymes: -aɪkə 

 Noun
 [ edit ] 

 balalaika ( plural balalaikas or balalaiki ) 

 A plucked stringed instrument with a triangular body, short neck and three strings, of Russian origin.

 Derived terms
 [ edit ] 

 balalaikist
