 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Root
 [ edit ] 

 *h₃reǵ- [ 1 ] [ 2 ] [ 3 ] 

 to straighten 

 to righten 

 Reconstruction notes
 [ edit ] 

 Dunkel reconstructs the main root as *reǵ- and derives ὀρέγω ( orégō ) from *h₂o reǵ- . Also from this root *reǵ- would be ἀρήγω ( arḗgō ) (with prefix *sm̥- ) and *werǵ- (< *we reǵ- ). [ 4 ]
