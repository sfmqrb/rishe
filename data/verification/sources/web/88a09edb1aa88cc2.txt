 Pronunciation

 Noun
 [ edit ] 

 مَسْخَرَة • ( masḵara )  f ( plural مَسَاخِر ( masāḵir ) or مَسْخَرَات ( masḵarāt ) ) 

 object of ridicule, laughing stock
