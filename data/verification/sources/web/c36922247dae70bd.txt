 Ottoman Turkish
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian بِرْیَان ( biryān ) .

 Noun
 [ edit ] 

 بریان • ( biryân ) 

 roast , kebab 
 Synonyms: كباب ( kebâb, kebâp ) , قاورمه ( kâvurma ) 

 Descendants
 [ edit ] 

 Turkish: biryan , büryan , piryan , püryan 

 → Bulgarian: пиря́н ( pirján ) 

 → Greek: μπριάμ ( briám ) 

 → Serbo-Croatian: 
 Cyrillic script: пѝрја̄н 
 Latin script: pìrjān 

 Further reading
 [ edit ] 

 Nişanyan, Sevan ( 2002– ), “ biryan ”, in Nişanyan Sözlük 

 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From برشتن ( birištan , “ to roast, fry ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /bir.ˈjaːn/ 

 ( Dari, formal ) IPA ( key ) : [bɪɾ.jɑ́ːn] 

 ( Dari, formal ) IPA ( key ) : [bɪɾ.jɑ́ːn] 
 ( Kabuli ) IPA ( key ) : [bɪɾ.jɑ́ːn] 

 ( Hazaragi ) IPA ( key ) : [biɾ.jɔ́ːn] 

 ( Iran, formal ) IPA ( key ) : [beɹ.jɒ́ːn] 

 ( Tajik, formal ) IPA ( key ) : [biɾ.jɔ́n] 

 Rhymes: -aːn
