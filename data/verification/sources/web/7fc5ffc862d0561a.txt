 Urdu
 [ edit ] 

 Etymology
 [ edit ] 

 Borrowed from Classical Persian برکت ( barakat ) , from Arabic بَرَكَة ( baraka ) .

 Pronunciation
 [ edit ] 

 ( Standard Urdu ) IPA ( key ) : /bəɾ.kət̪/ 

 Rhymes: -ət̪ 

 Hyphenation: بَر‧کَت 

 Noun
 [ edit ] 

 بَرْکَت • ( barkat )  f ( formal plural بَرَکات ( barakāt ) , Hindi spelling बरकत ) 

 blessing ( good fortune ) 
 Synonym: نعمت ( nēmat ) 
 اَچّھے کاموں سے بَرْکَتیں مِلْتی ہَیں۔ acche kāmõ se barkatẽ miltī ha͠i. You receive blessings from doing good deeds. (literally, “ goods works from blessings get 's. ”)
