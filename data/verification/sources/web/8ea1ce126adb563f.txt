 English
 [ edit ] 

 English Wikipedia has an article on: myna 

 Wikipedia 

 A myna. 
 Alternative forms
 [ edit ] 

 mino ( archaic ) 

 mynah , mina 

 Etymology
 [ edit ] 

 Borrowed from Hindi मैना ( mainā ) / Urdu مینا ( mainā ) , from Sanskrit मदन ( madana ) .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /ˈmaɪnə/ 

 Audio ( Southern England ) : ( file ) 

 Rhymes: -aɪnə 

 Noun
 [ edit ] 

 myna ( plural mynas ) 

 One of the South and East Asian birds of the starling family Sturnidae .
