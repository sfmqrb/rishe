 Etymology
 [ edit ] 

 Either onomatopoeic and inherited from Ashokan Prakrit *𑀕𑀧𑁆𑀧- ( *gappa- ) , or inherited from Sanskrit गल्प ( galpa ) . Cognate with Classical Persian گَپ ( gap ) , Punjabi ਗੱਪ ( gappa ) / گپّ ( gappa ) , Bengali গপ ( gop ) , Gujarati ગપ ( gap ) , Nepali गफ ( gaph ) , Odia ଗପ ( gapa ) , Assamese গপ ( gop ) .

 Rhymes: -əp
