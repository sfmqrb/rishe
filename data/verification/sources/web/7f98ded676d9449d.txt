 Persian
 [ edit ] 

 Etymology
 [ edit ] 

 From Middle Persian [script needed] ( twnd /⁠tund⁠/ , “ sharp, violent ” ) , from Proto-Iranian *tund- ( “ to act violently ” ) , from Proto-Indo-Iranian *tund- , from Proto-Indo-European *tu-n-d- , ultimately from Proto-Indo-European *(s)tewd- .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /ˈtund/ 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊn̪d̪] 

 ( Dari, formal ) IPA ( key ) : [t̪ʰʊn̪d̪] 
 ( Kabuli ) IPA ( key ) : [t̪ʰʊn̪d̪] 

 ( Hazaragi ) IPA ( key ) : [t̪ʰun̪d̪̥]

 Adjective
 [ edit ] 

 Dari

 تُند 

 Iranian Persian

 Tajik

 тунд 

 تند • ( tond ) 

 fast ; quick 
 Synonym: سریع ( sari' ) 
 خیلی تند می‌دود. ― xeyli tond mi-davad. ― He runs very fast . 
 قلبم تند می‌زد. ― qalb-am tond mi-zad. ― My heart was beating quickly . 

 spicy ; hot 
 Synonym: تیز ( tiz ) 
 این فلفل تند است. ― in felfel tond ast. ― This pepper is spicy . 

 harsh ; acrid ; biting ; sharp 
 انتقاد تند ― enteqâd-e tond ― harsh criticism 

 severe ; intense 
 Synonyms: شدید ( šadid ) , سخت ( saxt ) 
 باد تند می‌وزد ― bâd tond mi-vazad ― the wind blows harshly 

 strong ; intense (of a beverage, a color)
 قرمز تند ― qermez-e tond ― deep red 
 قهوهٔ تند ― qahve-ye tond ― strong coffee 

 quick to anger ; irate 
 مرد تند ― mard-e tond ― man with a temper 

 sharp ; steep 
 Synonym: تیز ( tiz ) 
 شیب تند ― šib-e tond ― steep slope

 Punjabi
 [ edit ] 

 Etymology 1
 [ edit ] 

 Inherited from Prakrit 𑀢𑀁𑀢𑀼 ( taṃtu ) , from Sanskrit तन्तु ( tántu ) . [ 1 ] 

 Pronunciation
 [ edit ] 

 ( Standard Punjabi ) IPA ( key ) : /t̪ənd̪/ , [t̪ɐ̃nd̪ᵊ] 

 Noun
 [ edit ] 

 تَنْد • ( tand )  f ( Gurmukhi spelling ਤੰਦ ) [ 2 ] [ 3 ] 

 thread , strand , fibre 

 ( botany ) a tendril ( of a creeper ) 

 string ( of a musical instrument ) 

 ( anatomy ) a tentacle
