 Persian
 [ edit ] 

 تصویری از یک کفچه 

 Alternative forms
 [ edit ] 

 کپچه ( kapča  / kapče ) ( archaic ) 

 کمچه ( kamča  / kamče ) ( dialectal ) 

 Etymology
 [ edit ] 

 Inherited from Middle Persian [script needed] ( kpck' /⁠kafčag⁠/ , “ spoon, ladle ” ) .

 Pronunciation
 [ edit ] 

 ( Classical Persian ) IPA ( key ) : /kaf.ˈt͡ʃa/ 

 ( Dari, formal ) IPA ( key ) : [kʰäf.t͡ʃʰä] 

 ( Dari, formal ) IPA ( key ) : [kʰäf.t͡ʃʰä] 
 ( Kabuli ) IPA ( key ) : [kʰäf.t͡ʃʰä] 

 ( Hazaragi ) IPA ( key ) : [kʰäf.t͡ʃʰä] 

 ( Iran, formal ) IPA ( key ) : [kʰʲæf.t͡ʃʰe] 

 ( Tajik, formal ) IPA ( key ) : [kʰäf.t͡ʃʰä] 

 Rhymes: -a

 Noun
 [ edit ] 

 کفچه • ( kafča / kafče ) ( Tajik spelling кафча ) 

 skimmer ( sieve-like, slotted spoon ) 

 ( dialectal , Lori, or archaic ) ladle
