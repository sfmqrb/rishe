 Etymology
 [ edit ] 

 From Middle Persian *pōl , perhaps a borrowing from Ancient Greek ὀβολός ( obolós ) . [ 1 ] 

 Pronunciation
 [ edit ]

 ( Dari, formal ) IPA ( key ) : [pʰuːl]

 Noun
 [ edit ] 

 Dari

 پَیسَه 

 Iranian Persian

 پول 

 Tajik

 пул , пӯл 

 پول • ( pūl, pōl / pul ) ( plural پول‌ها ( pūl-hā, pōl-hā / pul-hâ ) , Tajik spelling пул , or пӯл ) 

 ( chiefly Iran ) money 
 فعلا پول ندارم. fe'lan pul na-dâram. At the moment, I have no money . 

 coin 

 ( archaic ) a coin of inferior value

 Etymology 2
 [ edit ] 

 Inherited from Sauraseni Prakrit 𑀧𑀤𑁄𑀮𑀻 ( padolī ) , from Sanskrit प्रतोली ( pratolī ) .
