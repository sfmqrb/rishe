 Ancient Greek
 [ edit ] 

 Alternative forms
 [ edit ] 

 οὖλος ( oûlos ) — Ionic , Homeric 

 Etymology
 [ edit ] 

 From Proto-Indo-European *solh₂wós , from *solh₂- ( “ whole ” ) . Cognates include Sanskrit सर्व ( sárva ) , Avestan 𐬵𐬀𐬎𐬭𐬬𐬀 ( haurva ) , Latin salvus , sollus . [ 1 ] Unrelated false cognate of English whole .

 Pronunciation
 [ edit ] 

 IPA ( key ) : /hó.los/ → /ˈo.los/ → /ˈo.los/ 

 ( 5 th BCE Attic ) IPA ( key ) : /hó.los/ 

 ( 1 st CE Egyptian ) IPA ( key ) : /ˈ(h)o.los/ 

 ( 4 th CE Koine ) IPA ( key ) : /ˈo.los/ 

 ( 10 th CE Byzantine ) IPA ( key ) : /ˈo.los/ 

 ( 15 th CE Constantinopolitan ) IPA ( key ) : /ˈo.los/ 

 Adjective
 [ edit ] 

 ὅλος • ( hólos )  m ( feminine ὅλη , neuter ὅλον ) ; first / second declension 

 whole , entire , perfect , complete 

 absolute , utter 

 generally , on the whole 

 ( with negative ) : at all

 actually 

 Inflection
 [ edit ] 

 First and second declension of ὅλος ; ὅλη ; ὅλον ( Attic )
