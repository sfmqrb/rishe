 Alternative forms
 [ edit ] 

 امرداد ( amordâd ) ( formal, archaic ) 

 Etymology
 [ edit ] 

 From Middle Persian 𐭠𐭬𐭥𐭥𐭣𐭠𐭣 ( ʾmwrdʾd /⁠Amurdād⁠/ ) , lit. “immortality”; name of the sixth Amahraspand (divine deity) in Zoroastrianism. Compare مردن (mordan, “to die”).

 Proper noun
 [ edit ] 

 مرداد • ( murdād  / mordâd ) ( Tajik spelling мурдод ) 

 Mordad ( the fifth solar month of the Persian calendar ) 

 Name of the seventh day of any month of the solar Persian calendar.
