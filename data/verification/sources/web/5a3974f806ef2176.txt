 This Proto-Indo-European entry contains reconstructed terms and roots . As such, the term(s) in this entry are not directly attested , but are hypothesized to have existed based on comparative evidence.

 Proto-Indo-European
 [ edit ] 

 Etymology
 [ edit ] 

 Reanalyzed reduplication from *teḱ- ( “ to sire, beget ” ) .

 Root
 [ edit ] 

 *tetḱ- ( imperfective ) [ 1 ] [ 2 ] [ 3 ] [ 4 ] [ 5 ] [ 6 ] [ 7 ] [ 8 ] [ 9 ] 

 to create , produce 

 to cut , hew 

 Reconstruction notes
 [ edit ] 

 Before the modern deciphering of thorn clusters , this root was formerly represented as *tekþ-, *teḱþ- . [ 10 ] This analysis has now been abandoned.
